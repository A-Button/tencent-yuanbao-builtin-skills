# 权威指南出处与推荐等级

> **用途**：专业版模式下引用出处；判读标准有争议时的裁决依据。
> **原则**：**中国指南优先**。国际指南仅在中国无对应指南时采用，且必须标注人群适用性局限。

---

## 一、引用优先级

```
中国指南（最新版）
   ↓ 无对应指南时
亚太／中国参与制定的国际指南
   ↓ 仍无时
欧美指南（必须标注「基于欧美人群，对中国人群适用性有限」）
```

### 1.1 时效性核对（引用前必做）

| 动作 | 要求 |
|---|---|
| 核年份 | 引用任何一部指南前先确认发布/修订年份，**已被新版替代的旧版不得作为判定依据** |
| 写全名 | 一律写《XX指南（20XX年）》。**禁止**「最新指南」「按国际标准」这类用户无法核对的表述 |
| 版本冲突 | 同一领域新旧两版阈值不一致时，按新版判读，并在 10.3 用一句话说明改动了什么 |
| 本表时效 | 本清单为编制时的现行版本。若用户报告日期晚于本表某部指南年份较多，须提示「该领域可能已有更新版本，建议以就诊医院现行标准为准」 |
| 不确定时 | 无法确认是否为现行最新版时，**降级为「参考」而非「依据」**，并在 10.3 注明 |

## 三、推荐等级表述规范（专业版使用）

沿用中国指南通行的分类方法：

### 推荐类别

| 类别 | 含义 | 措辞 |
|---|---|---|
| **Ⅰ 类** | 已证实和/或一致公认有益、有用、有效 | 「给予推荐」 |
| **Ⅱa 类** | 证据/观点倾向于有用有效 | 「应当考虑」 |
| **Ⅱb 类** | 有用性尚不能充分证明 | 「可以考虑」 |
| **Ⅲ 类** | 已证实无用或有害 | 「不推荐」 |

### 证据水平

| 水平 | 含义 |
|---|---|
| **A** | 研究人群广泛，基于多项随机试验或荟萃分析 |
| **B** | 研究人群有限，基于单项随机试验或大型非随机对照研究 |
| **C** | 研究人群十分有限，仅专家共识和/或小规模、回顾性、注册研究 |

**专业版引用格式示例**：
> LDL-C 目标值 <1.8 mmol/L 适用于极高危 ASCVD 患者（《中国血脂管理指南 2023》，Ⅰ类推荐，A 级证据）。

## 四、指南冲突处理规则

| 情形 | 处理 |
|---|---|
| 中国指南与国际指南冲突 | **以中国指南为准**，可注明国际差异 |
| 同一指南新旧版本冲突 | 以最新版为准 |
| 报告参考区间与指南区间冲突 | **以报告自带区间为准**（反映该实验室方法学），指南区间作参考 |
| 两个中国指南冲突 | 以专科对应指南为准（如血脂问题以血脂指南为准，而非高血压指南附带条目） |
| ASCVD 模型结果冲突 | China-PAR 优先，PCE 仅作对照并标注局限 |
| 影像分级体系版本不同 | 以报告采用的体系为准 |

## 五、引用规范

**通俗版**：不引用文献编号，用「按中国最新血脂管理指南」这类自然表述即可。

**专业版**：需给出指南名称 + 年份 + 推荐类别与证据水平。不需要完整参考文献格式，但指南名与年份必须准确。

**禁止**：
- 编造指南名称、年份、条目
- 引用已废止的旧版指南而不注明
- 用国际指南数据冒充中国指南结论
- 在没有把握时凭记忆写具体数值 —— 应查证或明确标注「具体阈值请以最新指南为准」

## 六、更新维护提示

指南更新频率较快，以下为高频更新项，使用时如遇疑问应查证最新版本：

- 血脂指南（目标值可能进一步下调）
- 糖尿病指南（诊断与目标值）
- 影像分级体系（BI-RADS / TI-RADS 版本迭代）
- 肥胖与体重管理指南
- eGFR 计算方程（去种族系数趋势）

> 本文件记录的是 2026 年 8 月时点的指南版本。若用户报告日期显著晚于此，或涉及关键治疗决策，应提示「建议以就诊时最新指南为准」。

## 七、第 10 段「参考指南」的生成规则

报告输出的第 10 段是**面向用户的指南溯源**，由本文件筛选生成。

### 7.1 铁律：只列本次真正用到的，禁止堆砌

**本文件收录 40 余部指南，严禁全表照搬进报告。**

理由：全列 = 用权威感掩盖不确定性，反而降低可信度，也让用户无法判断哪部才是关键依据。
用到 8 部就列 8 部。

```
正例：本次用到 8 部，列 8 部，每部注明「用于判定什么」
反例：把本文件所有指南列进报告                      ← 退化成书单
反例：只写「依据中国相关指南」不列具体名称            ← 无法追溯，等于没写
```

### 7.2 三个小节的结构

| 小节 | 表头 | 关键约束 |
|---|---|---|
| **10.1 本次判读用到的指南** | 指南名称 ｜ 发布方 ｜ **本次用于判定什么** | 第三列必填，这是全表价值所在 |
| **10.2 关键数值的出处** | 本报告中的判定 ｜ 用的数值 ｜ 来源 | 每个阈值可追溯到条目 |
| **10.3 使用这些标准时的说明** | 散文式，3~4 条 | 讲清适用边界 |

### 7.3 筛选方法

按报告实际涉及的系统，从本文件第二章对应小节取条目：

| 报告含 | 取自 | 典型条目 |
|---|---|---|
| 血脂项 | 2.1 | 中国血脂管理指南（2023年） |
| 血糖 / HbA1c | 2.2 | 中国糖尿病防治指南（2024版） |
| 腰围 / BMI | 2.2 | 肥胖症诊疗指南（2024年版） |
| 计算了 ASCVD 风险 | 2.1 | 中国心血管病风险评估和管理指南（2019） |
| 命中代谢综合征 | 2.2 | 中国代谢综合征诊断标准 |
| 任何检验项（区间兜底） | 2.3 | 全国临床检验操作规程（第4版） |
| 命中危急值 | 2.3 | 临床危急值报告制度 |
| 肝酶 / 脂肪肝 | 2.4 | 非酒精性脂肪性肝病防治指南（2018更新版） |
| 肌酐 / eGFR / UACR | 2.5 | KDIGO CKD 指南、CKD-EPI 方程 |
| 甲功 / 甲状腺结节 | 2.6 | 中国甲状腺疾病诊治指南、C-TIRADS（2020） |
| 影像分级 | 2.7 | 对应分级体系 + 中国抗癌协会口径 |
| 骨密度 T 值 | 2.8 | 原发性骨质疏松症诊疗指南（2022） |
| 贫血 / 血小板 | 2.9 | 对应专家共识 |
| 肿瘤标志物 | 2.10 | 常用血清肿瘤标志物专家共识 |

**未涉及的系统一律不列。** 报告里没有影像项，就不要出现 BI-RADS。

### 7.4 10.2 的写法

把报告里每一个「达标 / 未达标 / 已达阈值」的判断，逐条追溯：

| 本报告中的判定 | 用的数值 | 来源 |
|---|---|---|
| 坏胆固醇「未达标」 | 目标 <2.6 mmol/L | 血脂指南 2023 —— 糖尿病合并年龄 ≥40 岁归入高危 |
| 血糖「已达诊断线」 | 空腹 ≥7.0 mmol/L | 中国糖尿病防治指南（2024版） |
| 腹部肥胖 | 男性腰围 ≥90 cm | 肥胖症诊疗指南 2024（中国标准，非国际 ≥94 cm） |
| 10 年风险「中危」 | 5% ~ 10% | 心血管风险评估指南 2019 |
| 血钾接近危险线 | 危急值 6.2 mmol/L | 临床危急值报告制度 |

**要求**：报告中出现的每个分层结论都能在此表找到对应行。用户可逐条核对，医生可快速确认口径。

### 7.5 10.3 必须用具体反例

抽象表述等于没说，要举出「换标准结论就变」的实例：

```
正例：腹部肥胖的腰围线，中国是 90 cm，国际标准是 94 cm；
     按国际标准判，你这次就「不算」腹部肥胖了。本报告一律以中国指南为准。

正例：本次用中国人群模型 China-PAR 算出中危（8.72%），美国 PCE 模型算出 14.18%（高危），
     相差 63%。China-PAR 原始研究已证实 PCE 不适用于中国人群，故以 China-PAR 为准。
```
