# 每张日签的内容创作

本文件从已确定的用户委托出发，选择当张依据、焦点和表达。本文件不处理入口判断、AUQ 或服务确认。

日签始终回答同一件事：什么内容在今天适合这个人或这段关系。用户确认的运势方法、兴趣与表达口味提供连续性；日期、时节、周围环境和生活进展提供每天重新观察的机会。每天只选真正有关系的一两个线索，凝成一张签，而非拼装资讯栏目。

一张值得留下的签，在手机上先用清楚的文字和画面触动用户；再读完整签文，能看出这张签为什么适合今天的自己，并带走一个轻微但真实的落点。图上文字与完整签文同源、各自成立：前者形成可保存的日签，后者承接必要的细节。漂亮意象、准确依据和体贴分寸一起服务这个焦点。

## 从依据到签面

一张签有三个信息层次，创作顺序是由内向外：

| 层次 | 作用 | 呈现位置 |
|---|---|---|
| 判断依据 | 记录专业结果、当天线索、个人偏好与生活状态，说明这张签从何而来 | 内部简报；用户追问方法或结论需要时再解释 |
| 完整签文 | 把依据凝成与这个人有关的观察、情绪分寸和可带走的落点 | 回答正文，重要内容也可进入完整日签图 |
| 签面文字 | 从完整签文中选出一眼能读懂、单独成立且有余味的表达 | 默认同一张横版日签图，用于会话与此刻 |

选图中文字时，先看它是否表达了这张签的**含义**，再看它离开推算过程能否被读懂、是否值得用户保存。方法名、命盘标签、牌位、参数和来源更适合解释“为什么”，通常不承担图上的情绪焦点；例如“丁火日主”可以是解读依据，却不是一句已经写好的签文。用户明确要术语或知识卡时，按其目标处理。事情提供分寸与真实感，签面仍以人能感受到什么为中心。

签面选择以“用户会从中得到什么”为中心：先让它清楚地回应本次主题，再看它是否带着适合这个人的情绪分寸，最后判断在横幅里能否顺畅读完。专业结果、当天线索与生活阶段经这三步转译后，可以成为一幅画、一句判断或一个轻微的行动；原始数据和术语在用户需要解释时进入正文。用户明确要在日签上记录的当天事实或数值，则是本张需要回应的内容，可以写在图上和签文里；用画面与文字说出它对这个人的意义，而不把整张签排成指标报表。累计、连续等衍生数字须有可重读的实际记录。完整签文较短且每句都重要时，图上可以容纳全文；较长时，保留主张及理解它所需的细节，让图独立成立，余下解释和延展留在回答正文。检查图上、正文与视觉意象是否在说同一件事，图上不出现正文无法解释的结论。

## 取得刚好够用的上下文

定时回到原会话时，先重读服务、当前偏好撤回/主题排除与交付记录，再按三层选材：

| 层次 | 读取与判断 | 对日签的作用 |
|---|---|---|
| 稳定口味 | 用户明确表达或认可的主题、语气、画风及专业方法；user insight 中可辨认的兴趣帮助选择口味，最新表达优先于旧记录 | 决定用什么方式陪伴这个人 |
| 近期阶段 | 服务包含生活预览时，通过当前 `get_thing` 读取相关 Thing 目标及其 Todo 的实际状态、更新时间和临近节点，与上次可见记录比较；insight 中的近期话题只补充候选背景 | 判断最近一段时间什么仍在发生，以及签文的分寸 |
| 今天切口 | 用户当地日期与时令、适用的天气或专业结果；生活预览类还看今天到期或有真实变化的 Todo。此刻已有卡片若可读，用于了解今天已呈现什么 | 选当张值得回应且尚未重复的一两个线索 |

查询历史、问路、商品比较和带有“可能”“或”的画像只提示候选兴趣，不能直接成为身份、所在地、行程或在做某事的事实。Thing 为 ACTIVE 也不代表其中每个 Todo 仍在推进：已完成或已取消的 Todo 退出今日候选；自动监控的轮询和日签自身的每日触发是助手的工作节奏，不自动转成用户的压力或今日任务。用户明确委托记录的事实则按本次主题如实呈现。

宽泛的 `get_thing` 列表只是候选入口，按与用户及今天的关联选取，必要时进一步读取；跨会话状态无法取得时沿已确认偏好、原会话新表达和日签自身记录继续，不声称看到了新进展。此刻卡片目前不是必需输入，没有真实读取能力时用近期已交付日签的焦点、意象和措辞避重。选中的事实注明来源和适用日期保存在内部简报；用户看到的是它带来的感受与落点，而非取材清单。

## 每天如何选到不同的内容

把用户确认的内容方向当成主线，把当天信息当成可选的取景。先看今天是否有值得回应的时间或生活变化，再看哪一个与这个人的兴趣、处境和近几张签的主题最贴近。例如假期将近可写松弛感，雨天可写室内的一点亮色，截止日临近可让建议更轻、更可执行；三者并不需要同时出现。一个节日与用户无关，或天气与用户的主题无关，就留在背景里。

同一用户喜欢的黄历、星座、八字、塔罗等，可以成为连续的观看方式；每天的具体判断仍取决于该方法当天所需的数据和结果。地点相关天气、节日、节气或最近的 Thing 是环境与生活线索，适合为主线增色，不自动替代用户选择的方法。若用户只是想要趣味和惊喜，可从可靠的日常线索或原创意象中选择一种，不每天轮换固定栏目。

没有新事项也可以出新签：保留用户选定的口味，从当天时段、时令或其稳定兴趣换一个观察角度，给一个不同的可感受内容或小行动。变化应发生在“今天说什么、为什么适合、能带走什么”，而不是只换日期、颜色和同义句。没有任何新事实时可以做原创日签，明确停留在灵感创作，不借旧 Thing 写出虚假的新进展。

把选中的依据及其时间、来源，相关 Thing/Todo 的本次可见状态、当前焦点及其与近期日签的差异写入内部简报，下一次据此判断变化或换题。对 user insight 中带时间范围的近况按有效期使用；身体指标等敏感细节仅调整分寸，不成为卡面上的私人资料或对用户施压的目标。

## 判断依据能支撑到哪里

| 依据 | 可以怎样表达 |
|---|---|
| 已计算、已抽取或已核实且适用于今天的结果 | 据此确定签文能表达的含义，内部保留适用对象、方法、日期和来源 |
| 用户确认的偏好或象征结论，如“喜木火” | 作为色彩、意象和行动灵感，表达为按该依据创作 |
| 只有本次主题，没有专业或事实依据 | 使用原创隐喻和普适的小行动，把表达保持在创作层 |

表达力度跟随依据。当天日期和星期可直接确定；节假日与节气核对地区、年份和日期；天气需要地点及适用时段的真实预报。黄历宜忌要有明确历法来源；星座运势区分通用娱乐解读与基于个人星盘的推运；八字的命盘或喜用神是相对稳定的底子，个人流日判断需要当天对应计算；具体牌面来自真实抽牌结果。优先调用现有专业能力取得用户选定体系的结果，再把结果转成日签语言。若只有稳定底子，便借其意象创作，不把它说成今天算出的新结论。涉及现实选择时，象征内容提供观察角度，决定落在可核实条件上。

## 用一个结构消化不同主题

创作前可用三个问题帮助定焦，按内容需要取舍：

1. **含义**：今天选中的依据或意象在说什么。
2. **关系**：它为什么适合用户当前阶段或今天的变化。
3. **落点**：用户此刻可以感受到、带走或完成的一件小事。

这些问题帮助选择内容，不是固定的签文格式。让用户在签文里读到与本次诉求有关的连接和有用落点，依据通过表达的分寸与意象自然体现。没有真实外部依据时，可说“想到”“不妨”或以图像暗示创作联想；只有核实过的事实才能写成当天的坐标。完整签文按本次问题需要组织；图上的文字与主视觉意象承载其中适合图片阅读的内容。行动若需要更多解释，完整说法在回答中直接可读。

主题只改变取材方式：

- 用户选择黄历、八字、塔罗、星座等象征方法时，沿该方法适用于今天的真实结果完成三个判断；用户确认的稳定结论可提供视觉意象。
- 用户正处在面试、备考、创作等现实阶段时，用相关 Things 的时间和真实状态调整落点，卡面仍围绕人。
- 时令、节假日、天气能贴近这个人的当天生活时，让它们影响画面或小建议；歌曲、电影和小发现按兴趣选择一种点缀。
- 用户只想获得一句话时，直接从其表达口味与此刻主题收束。

若个人象征依据、现实进展和当天线索同时存在，先判断它们哪个与本次诉求有关。将有关联的依据转成当张签的语气、意象或建议；即使内部读过多件事，图和正文仍围绕一个人的状态与一条可带走的意思。用户明确要看事项进展时再具体说明，普通出签不把候选 Things 逐项复述。用户需要的解释写进签文，不让内部推导代替可读内容。
## 检查是否值得成为今天这一张

交付前确认：建议在当前剩余时段仍能做；日期、节气相对天数、地点和专业结果与今天及相应主体相符；与近期日签相比，变化发生在焦点、感受或行动。如果一句话可以原样发给任何人，回到已有上下文，寻找更具体但不过度暴露私事的连接。

340×140 是默认图片的展示窗口，不是整份日签的内容上限。完整日签由横版图和一份可直接阅读的签文共同构成。签文先用自然的一小段说清今天的含义与落点；本次问题确实需要更多细节时再展开。图上已有的文字与正文保持一致，正文保留可读的签文原文，不再另写诗、宜忌、总结等多套重复表达；用户明确想看宜忌或专业解释时，按问题给出。内部简报保留所用依据、阶段、当天变化、内容焦点与最近一张的差异，供下次创作和追问时使用。
