# 单人桌游推荐器

## 概述

本 skill 负责联网找几款单人 solo 桌游，并输出可直接用于购买决策的推荐清单。核心不是罗列热门游戏，而是确认「这款游戏在 **一个人玩** 时依然完整、耐玩」，再结合用户的时长、收纳成本、题材偏好做筛选。

## 适用场景

当出现以下情况时应使用本 skill：
- 用户请求推荐一个人能玩的桌游
- 用户描述了独处场景（没有牌搭子、想睡前玩、出差/通勤携带）并询问玩什么
- 用户使用类似 "单人桌游"、"solo 桌游"、"一个人玩什么桌游"、"单人模式" 等短语
- 用户已有桌游，想知道哪些支持单人模式、单人体验如何

不适用：用户实际有多名玩家（4 人局改用 `linji-skill-1`）、或询问已有桌游的规则细节。

## 核心原则

### 联网优先原则
- **CRITICAL**: 必须联网检索后再给结论，禁止仅凭记忆推荐
- **CRITICAL**: 每款推荐游戏必须附带至少一个可访问的来源链接
- **CRITICAL**: 评分、单人模式来源（官方/扩展/第三方）等信息必须来自检索结果，不确定时标注"未确认"而非编造

### 单人适配优先原则
- **IMPORTANT**: 「支持 1 人」不等于「单人好玩」，必须区分二者
- **CRITICAL**: 必须明确单人模式的类型，这直接决定体验差异：

| 类型 | 说明 | 体验特点 |
|------|------|---------|
| 原生单人（true solo） | 专为一人设计，无多人模式或以单人为主 | 规则最贴合，无冗余组件 |
| 自动机（automa） | 用卡组/规则模拟一名 AI 对手 | 有对抗感，但需额外维护自动机流程 |
| 官方单人变体 | 多人游戏附带的目标分挑战模式 | 常退化为"刷分"，重玩动力依赖挑战梯度 |
| 第三方/扩展单人模式 | 需另购扩展或社区规则 | 需说明获取成本 |

- 单人局需额外关注：**收摊成本**（setup + 收纳时间占比）、**可重玩性**（是否有难度梯度/剧本/传承）、**规则自审负担**（一个人玩容易漏规则）

### 需求匹配原则
- 在检索前先明确用户约束（时长、复杂度、题材、桌面空间、语言）
- 未知约束不要自行假设，用一次性提问补齐（见下方"第一步"）
- 推荐结果应覆盖不同单人模式类型，避免全部是自动机游戏

## 工作流程

### 第一步：明确需求

从用户输入中提取以下维度，缺失且影响结果的项一次性提问确认：

| 维度 | 说明 | 默认值 |
|------|------|--------|
| 单局时长 | 20 分钟内 / 30-60 分钟 / 60 分钟以上 | 不限，覆盖多档 |
| 规则复杂度 | 入门 / 进阶 / 重度（对应 BGG weight 1-2 / 2-3 / 3+） | 覆盖多档 |
| 单人模式偏好 | 想要对抗感（automa） / 纯解谜优化 / 剧本推进 | 不限 |
| 桌面空间 | 小桌/床上可玩 / 需大桌面 | 优先占地小 |
| 题材偏好 | 经营、解谜、爬塔、卡牌构筑等 | 不限 |
| 语言依赖 | 是否必须有中文版（剧本类语言依赖高） | 优先有中文版 |
| 已有游戏 | 避免推荐重复或同质化的游戏 | 无 |

**IMPORTANT**: 若用户只说"随便推荐几款"，直接使用默认值执行，不要反复追问。

### 第二步：联网检索

按以下顺序检索，交叉验证：

1. **BGG 单人榜单**：检索 `boardgamegeek solitaire games rank`、`best solo board games`，记录榜单排名与年份
2. **BGG 单人适配投票**：检索 `<游戏名> bgg best with 1 player`，确认社区是否认可 1 人
3. **单人模式类型核验**：检索 `<游戏名> solo mode automa`，确认单人模式是原生、自动机还是变体，以及是否需要扩展
4. **中文社区与评测**：检索中文桌游社区、B 站/小红书的单人实况与测评，确认中文版情况与实际收摊成本

**检索要点**：
- 每款候选至少 2 个独立来源支撑
- 记录原始数据：BGG 单人榜排名、评分、weight、官方单人时长
- 遇到"单人模式敷衍"这类负面评价，在输出中如实标注

### 第三步：筛选

按顺序过滤候选池：

1. **硬性过滤**：必须有明确的单人规则来源；仅靠"自己控两方"凑单人的游戏剔除
2. **需求过滤**：不满足用户时长/复杂度/空间约束的剔除
3. **质量过滤**：BGG 评分低于 7.0 或评分人数过少（<1000）的游戏需额外说明理由才保留
4. **可重玩性过滤**：只有单一固定关卡、通关即弃的游戏需明确标注"一次性体验"
5. **多样性排序**：最终保留 3-5 款，覆盖不同单人模式类型与时长档

### 第四步：输出推荐

使用下方模板输出。**IMPORTANT**: 先给结论（推荐哪几款、分别适合什么单人场景），再给逐款详情。

## 输出模板

```markdown
## 推荐结果

根据你的需求（单人、[时长]、[复杂度]），推荐以下 N 款：

### 1. [中文名]（[英文名]，[年份]）

- **人数**：X-Y 人，**单人模式类型**：[原生单人 / 自动机 / 官方变体 / 需扩展]
- **时长 / 复杂度**：单人约 XX 分钟 / BGG weight X.XX（[入门/进阶/重度]）
- **BGG 评分**：X.X（单人榜排名 #XXX）
- **玩法一句话**：[核心机制与目标]
- **单人体验**：[具体说明一个人玩时在做什么决策、对手如何模拟]
- **收摊成本 / 可重玩性**：[setup 时间、占地大小、是否有难度梯度或剧本]
- **注意**：[缺点、是否需额外购买扩展、语言依赖、中文版情况]
- **来源**：[链接1]、[链接2]

### 2. ...

## 选择建议

- 想要 [场景A，如睡前 20 分钟] → 选 [游戏名]
- 想要 [场景B，如周末长局] → 选 [游戏名]

## 补充说明

[被剔除的热门候选及原因；单人模式评价存在争议的游戏；未确认的信息]
```

## 注意事项

- **区分单人适配**：始终明确"支持 1 人"与"单人好玩"的差异，并标注单人模式类型，这是本 skill 的核心价值
- **说明额外成本**：单人模式若需另购扩展或第三方自动机卡组，必须在推荐中写明
- **不夸大**：不使用"神作""必买"等断言，用具体机制和数据说明适配理由
- **信息时效**：桌游会绝版与再版，中文版信息尤其易过时，检索时留意结果日期并在输出中标注
- **数量控制**：一次推荐 3-5 款，超过会让用户无法决策
- **术语首次出现给中英对照**，如 "自动机(automa)"、"复杂度权重(weight)"，后续直接用中文
