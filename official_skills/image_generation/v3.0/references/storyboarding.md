# storyboarding —— 连续叙事类场景生图技能

把"一个故事"变成"一套剧情连贯饱满、图文一体、像正规出版绘本 / 专业级分镜的作品"。成败关键在于：把 prompt 写成**可量化、可复用、可自检的规格**（相对位置 + 相对尺寸 + 精确色值），而不是模糊形容词——这是一致性、丰富度、文字质量所有手段的共同底座。

## 0. 两条统摄性总则（先记住，贯穿全流程）

**总则一 · 作品内绝对统一，跨作品/按主题多样。**
"统一"和"多样"分属两个层级，不冲突：
- **多样发生在"选型时"**：不同主题/体裁的作品，应从版式基型库里挑不同的基型、不同的装饰素材、不同的标题艺术处理（§2.3）。别让所有绘本都长成"上/下文字带 + 矩形边框"。
- **统一发生在"选定后"**：一旦为本作品锁定了比例、字体档、配色、页码体系、版式基型，全书每一格逐字复用、绝不中途变。作品内出现任何跳变都是缺陷。

**总则二 · 四类一致性各有各的生效机制，别混为一谈**（这是修掉"跳变"问题的关键）：

| 一致性维度 | 失控表现 | **真正生效的机制**（照此做才稳） |
|---|---|---|
| **画幅比例** | 各图宽高比乱跳 | 比例由**工具参数**恒定，**不靠 prompt 文字里写"4:3"**。每次生成（含封面）都显式传入**同一个** `aspect_ratio`/尺寸参数；图生图时同样显式传同一尺寸参数。 |
| **文字样式**（字体/字号/色） | 这页手写体那页黑体、字号忽大忽小、颜色漂 | 先把首张内页精修成**"母版"**，之后每格走**图生图锚母版**，prompt 显式写"文字的字体/字号/颜色与参考图完全一致"；文字版式锚点逐字复用。 |
| **页码顺序** | 序号重号/跳号/倒序/中英混用 | 生成前先列**页码台账**（格→数字一一对应）；图生图时页码**只借样式、数字必须覆盖**——显式写死本格数字并注明"替换参考图上继承的页码"。 |
| **角色/画风** | 长相服饰漂移、画风不一 | 母版参考图 + 角色锚点/画风锚点逐字复用。 |

**总则三 · 边框/文字带/字体/页码这四样，禁止逐图"生成"，一律走"固定模板层"叠加（最重要的一条）。**
血泪教训：扩散模型跨图一致性**最差**的部分，恰恰是**繁复边框（尤其四角纹样）、正文字体字重、页码数字体系**。这些是"概率渲染"，你在 prompt 里写得再精确，模型每张也会随机重绘四角花纹、随机决定写「3」还是「三」、随机加不加粗——**靠 prompt 描述去稳定它们有硬性天花板，再加规则也拦不住。**
唯一可靠解：**把这四样从"生成层"里剥离出去，做成一套一次性设计好的"固定模板资产"，生成后用确定性的合成/叠加步骤盖上去**（详见 §2.5）。模型**只负责画框内插画**；边框、文字带、正文排版、页码由模板层逐像素复制到每一页。这样它们从"每次都可能变"变成"物理上不可能变"。这是专业 AI 绘本/连环画流水线的标准做法，也是本次修订的核心。
> 若你的生成管线**完全没有**任何图像合成/叠加/代码能力，退回 §2.5「纯生成降级方案」——但要清楚：那是下策，仍会残留漂移，必须逐张自检 + 挑重生。

**总则四 · 每张图必须带且只带一个序号标记；序号位置必须用绝对坐标锚定，不能只写"右下角"这类相对描述。**
- **有且仅有一个**：非分镜类每张图（含封面）都要有**页码**；分镜类每格用**镜号**顶替页码、不再另设页码，两者不重复出现（详见 §2.6-C）。**绝不允许出现"这张有页码、那张没有"的空缺**——上一版有的页完全没打页码，就是漏了这条硬底线。
- **位置必须用绝对坐标描述，不能只写相对位置词**：多图之间出现序号位置漂移，根源是"右下角"这种描述在不同 prompt/不同批次里会被理解成不同的具体坐标。正确写法是**以整张画布（含边框，未裁切的完整画面）的角点为基准，给出两个百分比偏移量**，例如："以画布右下角为基准点，序号圆心落在**距右边缘 5%、距下边缘 5%**处"，而不是笼统写"右下角"。此坐标全书写死、逐格照抄，不重新措辞。
- **走 §2.5 模板层时，这条天然满足**（页码槽在模板 PNG 上是固定像素位置，不存在"描述模糊"的问题）；**只有降级方案纯生成时才需要在每条 prompt 里显式写死这个百分比坐标**。

**总则五 · 实测结论：坐标写得再精确，纯生成路线下页码/文字仍会漂移——这是模型的物理限制，不是文案精度问题，继续抠字眼没有边际收益。**
最新一轮实测：把页码位置从"右下角"改成"距右边缘 5%、距下边缘 5%"的精确坐标后，同一套图里**照样出现同一页两个页码圆标（位置还不一样）、不同页页码位置漂移**的问题。这证明了一件事：**扩散模型每次生成都是独立的概率采样，它不具备"记住并在像素级复现上一次同一个位置"的能力，无论 prompt 把坐标写多细都无法突破这个上限**。继续在 prompt 措辞上打磨坐标描述，边际收益已经归零。
**结论与行动：**
- **只要用户环境具备任何合成/图像编辑能力，页码、镜号、正文文字这三样必须走 §2.5 模板层或本节新增的「局部重绘锚定法」（见下），不得再依赖纯生成 + 精确坐标描述这条路——这条路已被验证走不通。**
- 若环境**确实**没有任何合成/编辑能力，如实告知用户"当前环境下页码/文字位置和样式无法做到多图像素级一致，只能做到大致同区域、需人工逐张核对与挑选"，不要用"再精确描述坐标"这种已知无效的方法给用户虚假的确定性承诺。
- 若模型在同一页内画出**不止一个**页码/数字徽标（如本次同页出现两个"2"），这是纯生成路线的典型伪影：说明模型把"页码"这个概念在画面里实现了不止一次。**纯生成 prompt 必须显式加一条反向约束**："全图有且仅有一个数字/徽标出现在指定位置，画面其余任何角落都不得再出现数字、圆形徽标或类似页码的图形"（见 §2.5 降级方案更新）。

## 1. 触发与不触发

### 1.1 触发条件
- 关键词：「分镜」「故事板」「连环画」「绘本」「漫画分镜」「短视频脚本配图」「storyboard」「分镜稿」「画面脚本」等。
- 给一段叙事性文本（小说片段 / 童话 / 剧情 / 个人叙事 / 产品故事 / 广告故事）并要求"画出来 / 配画面 / 出一组图"。
- 已有同一角色，要求"再画一张该角色在 XX 场景"并形成系列（绘本续集逻辑）。
- 多轮：前一轮是连续叙事类生图（本 skill），本轮在前序基础上做复杂编辑/再生成/故事续写等。

### 1.2 不触发
- 单做角色设定 / 三视图 / 衍生（无连续叙事属性）→ character_design。
- 重版式、宣传目的、叙事属性弱的社媒图文卡片 / 轮播 → media_planning。
- 判断不出叙事强度时先询问用户，进行需求澄清。

## 2. 工作流（三阶段）

### 阶段 A：意图识别与信息抽取

| 槽位 | 含义 | 缺省策略 |
|---|---|---|
| `story_text` | 完整故事 / 剧情大纲 | 用户没给完则请求补充或基于片段提议 |
| `panel_count` | 生图数量（此处指正文内页，封面另计为第 1 张） | **所有体裁默认第 1 张为封面**（除非用户明确不要）；优先遵循用户对页数的指令，若无要求则默认 9 张正文内页 + 1 张封面 |
| `genre` | 体裁 | 绘本 / 连环画·小人书 / 漫画分镜 / 短视频·广告分镜 / 影视故事板。决定可选版式基型与功能符号（§2.2、§2.3） |
| `art_style` | 画风 | 仅选一种；未指定则据内容主题与调性推荐（如儿童绘本"柔和水彩 + 细腻线条 + 淡雅高级色"） |
| `aspect_ratio` | 比例 | **全书锁死唯一一个比例，作为工具参数每格传同一值、封面也用同一值、绝不中途变**。优先用户指定，否则用各体裁通用比例：绘本 4:3 或 1:1；漫画 3:4 或 4:3；短视频 9:16 或 16:9；影视故事板 16:9 |
| `text_in_image` | 文字是否排进画面（默认 `true`） | 默认每格正文/旁白/对白直接印进画面；仅用户明确"画面中不要文字"才 `false` |
| `layout_archetype` | **版式基型**（本作品版式的骨架，从库里按主题挑 1 种） | 见 §2.3；选定后全书锁定 |
| `text_style_spec` | 全书统一字体/字号/颜色（文字版式锚点） | 开工前定死、逐字复用、每项可量化；详见阶段 B‑4 |
| `decor_spec` | 内页版式装饰/符号（内页装饰锚点） | 开工前定死、逐字复用，每元素写清位置+尺寸+颜色；详见阶段 B‑5 |
| `cover_spec` | **封面版式（独立于内页）** | 封面独立设计，只继承视觉基因、不套内页模板；详见阶段 B‑5b |
| `cross_panel_consistency` | 一致性强度 | 默认强 |

### 2.2 各体裁版式规范（选定后全书需保持统一）

> **通用规则（所有体裁）**：
> ① **默认第 1 张为封面图**（除非用户明确不要）——承载标题 + 主题基调，文字**仅含标题类内容**（主标题、副标题、引子、作者/年代等，可灵活生成），**绝不含正文剧情**；**封面独立设计版式**（§2.3b），只在字体族、色调、画风上与内页统一，**不照搬内页的文字带 + 边框模板**。
> ② **有对话 / 内心活动的场景，任何体裁都推荐加"对话框 / 心声云朵"**丰富画面（同款样式全书统一）。剧情需要时，心声云朵内可嵌"被联想场景的小图"（§2.4）。
> ③ **装饰元素可通用**：符合本作品主题与画风的装饰元素可多用，但克制不喧宾夺主。

| 体裁 | 文字分量 | 主承载 | 可叠加元素 | 红线（功能性冲突，绝不出现） |
|---|---|---|---|---|
| 绘本 | 每格 3~4 句、约 30~50 字 | 从版式基型库挑 1 型锁定 | 对话框/心声云朵、装饰边框、角落点缀、页码、页眉页脚、嵌套小图 | 镜号栏、景别/角度标注、时间码、焦点虚线框等影视**功能标注** |
| 连环画 / 小人书 | 每格旁白 + 关键对白，不能太少 | 从库挑 1 型；古典题材常用"主题融合边框型" | 对话框、装饰边框、角落点缀、页码、页眉页脚、嵌套小图、印章 | 时间码、镜号栏等影视功能标注 |
| 漫画分镜 | 对白气泡、心声云朵、拟声词、少量旁白框，不能太少 | **分格型**：分格 + 对白气泡（圆/云/尖角按情绪，每类统一） | 拟声词大字、旁白方框、集中线/效果线、装饰边框、格间联想小图 | 影视时间码、SC 镜号栏 |
| 短视频 / 广告分镜 | 字幕条 / 标语 / 产品名 | 底部同款字幕安全区（或分格型） | 对话框、统一角标、图标点缀、装饰边框 | — |
| 影视故事板 | 分镜画面 + 信息栏须完整带字段标签（镜号/景别/角度/时长/动作） | **信息栏型**：带边线画格 + 标签标注栏 + 注释框 + 时长角标 | 运动箭头、焦点虚线框、对话框、装饰边框 | 童趣花草边框、卡通手写页码等严重违和风格 |

### 2.3 版式基型库（layout archetypes）—— 修"版式雷同"的主抓手

**用法：为每部作品按主题/体裁从下表挑 1 种基型，锁定为全书骨架，逐格复用。多样性体现在"不同作品挑不同基型/不同装饰内容"，而非同一书内乱变。** 基型 1–4 可跨体裁按主题选（判据是"配不配这个故事"）；基型 5–6 按体裁锁定。

| 基型 | 骨架描述 | 适配主题举例 |
|---|---|---|
| **① 文字带型 band** | 上或下固定文字带 + 画面主体区，四周可选细边框 | 低龄儿童绘本、需大段旁白的连环画 |
| **② 图底文框型 inset‑on‑fullbleed** | **画面满版出血作背景、图像自然融入背景**，文字反过来被收进一个带描边/底色的**文本框/卷轴/牌匾/题签**里（"边框包文字"而非"边框包图"） | 意境类绘本、古典故事、名著 |
| **③ 主题融合边框型 themed‑frame** | 边框本身承载主题元素、四角镶嵌呼应主题的纹样，图文都在框内——中国古典（**海浪、锦鲤、七彩祥云、回纹**填四角）、科普（电路/星轨/分子链）、童话（藤蔓花环）等 | 历史/古典/名著连环画、主题性强的科普/童话绘本 |
| **④ 分隔线型 divider** | 图区与文字区**仅用一条艺术分隔线**（横向或**轻微斜向**）分开，**无完整边框**，留白干净 | 现代绘本、图文散文、清爽/极简风 |
| **⑤ 分格型 comic‑grid** | 一图内多格（大小/斜切按节奏），格间沟统一，对白气泡/拟声词 | 多格漫画分镜 |
| **⑥ 信息栏型 storyboard‑board** | 带边线画格 + 标签信息栏（镜号/景别/角度/时长）+ 注释条 | 影视故事板 |

**"作品内受控变化"的严格边界（防止像结局页那样整框换掉）**：关键情绪页至多让**框内插画**做满版出血/大场景处理；**但边框、文字带、字体、页码属于固定模板层（§2.5、总则三），任何页都绝不改动——同一套框、同一条带、同一字体、同一数字体系贯穿全书，包括封面之外的每一张内页。** 换句话说："变"只允许发生在插画内容里，"框和字"永远不变。若某页不想要边框，则**全书都不要边框**，不能只有一页特殊。

**装饰素材库**（从中挑符合主题的锁进锚点、全书逐字复用；**丰富但克制**）：
- **边框/描边**：手绘边框、圆角画框、纸胶带贴角、做旧纸纹边、光影晕边、卷轴/牌匾/题签框、主题纹样框（海浪/祥云/回纹/藤蔓/星轨…）。
- **角落点缀小图标**：呼应主题的小元素（古典—锦鲤/云纹/灯笼；童话—蘑菇/星星；科普—齿轮/试管）。
- **文字装饰**：标题下花纹分隔线、关键词高亮底色、段首字放大。
- **对话框/心声云朵**：有对话/心理活动时用，同款样式（圆角框/云朵/尖角按情绪）全书统一；心声云朵可内嵌联想小图（§2.4）。
- **页码/角标**：统一样式页码（圆圈数字/被小图案环绕的数字），角落小角标。
- **页眉/页脚花纹**：顶/底统一细纹样/波浪线/图案带，框住版心。
- **嵌套小图 spot illustration**：主画面一角小圆/小方框内的特写（道具/手部/表情/联想场景）。
- **构图装饰**：满版出血大场景、跨页连续构图、留白点题、竖排题字。

**同体裁也要跨作品换样——纹样按"这个具体故事的世界"选，忌套路化（修"同类型千篇一律"）。** 同一体裁的不同作品必须换用不同纹样：别所有古典故事都堆祥云+锦鲤、别所有儿童故事都套花草边框。选纹样的依据是**本故事的时代/地域/场景/关键物**，而非"这个体裁一般用什么"。参考菜单（每部只挑 2~3 类**贴合本故事**的锁进模板，下一部同体裁作品换一组）：
- **中国古典**：宫廷缠枝·团花·回纹 / 江河水波·芦苇·舟楫 / 边塞旌旗·云气·城砖·兵戈暗纹 / 山居远山·松柏·竹石 / 市井灯笼·幌子·瓦当。（祥云、锦鲤只是其中一类，勿默认全用）
- **儿童**：森林藤蔓·蘑菇·树叶 / 海洋泡泡·贝壳·浪花 / 星空星月·流星 / 家庭日常布纹·纽扣·小物剪影 / 节庆灯笼·彩旗。（花草边只是其中一类）
- **科普**：天文星轨·轨道环 / 生物叶脉·细胞·DNA / 机械齿轮·电路 / 地理等高线·波纹。
> 一句话判据："换一个同体裁的故事，边框会不会长得不一样？"答"会"才算过关。

**边框/装饰配色必须从本作品调色板派生，禁生硬撞色（修"边框颜色生硬、与主题不搭"）。** 边框色不是套一个固定深蓝/深红，而是**从插画主色或辅色里取**：用主色的加深/降饱和版，或与主色相邻、同明度区间的和谐色（如青绿赭石画面→墨青或深赭边框；暖木调画面→深棕/褐边框；冷蓝画面→藏蓝/靛青边框）。**避免暖调画面硬配纯靛蓝框**这类高对比生冷撞色。此边框色在设计模板（§2.5 第 1 步）时从调色板定死、全书复用。

**功能性符号（按体裁，不跨用）**：影视故事板专属——镜号+景别+角度标注栏、运动/入画出画箭头、焦点虚线框/画外来源箭头、时间码角标、底部注释框；漫画专属——集中线/效果线、拟声词大字。
> 功能性符号是**有意画进画面的设计符号**，与"禁把 `/` 写进正文"不冲突——前者有明确样式与位置；正文引号里仍只含干净汉字与标点。

**选型三原则**：①**合理**——基型 1–4 只要**符合本作品主题与画风**即可按主题选（不按体裁死锁）；基型 5–6 及功能符号按体裁锁定、不跨用；宁缺毋滥。②**多样（含同体裁跨作品）**——不同作品挑不同基型、不同纹样、不同配色；**即便同一体裁，也须按故事换纹样、按调色板派生边框色**，不套路化；同一作品内主承载外可按情节合理点入对话框/旁白框/竖排/嵌套小图/角落点缀。③**统一**——同一作品内，选定的基型与元素的样式/尺寸/颜色全书视觉观感一致。

**兜底版式美观度（baseline decoration floor）—— 任何体裁/任何基型都不许"素颜"（修"科普类等缺装饰、不美观"）。** 即便选了最简的基型④「分隔线型」或本身画风偏简约，**以下三项是硬底线、任何作品都不能省**：
1. **文字承载必须有设计感，不能是"图片下面贴一块纯色圆角矩形+黑字"**：文字区至少具备"底色（呼应本作品调色板，非默认纯白/纯灰）+ 圆角或细描边或轻投影"三选二的处理，让它看起来是"设计过的卡片/题签"，而非随手加的字幕条。
2. **至少一处贴题小装饰**：哪怕不用完整边框，也要在角落/文字区旁放至少 1 个**呼应主题的小图标或小纹样**（如科普绘本可用星轨角标、齿轮小图标、虚线轨道），不能整幅画面除了插画和文字外空无一物。
3. **页码/镜号必须有底纹承托**（圆圈/胶囊/小徽标等），不能是裸数字直接摆在背景上。

**判断标准**：拿掉插画后，剩下的版式（文字区+装饰+页码）单独看是否"像一件设计作品"——如果只是"一块白底文字条 + 一个孤零零的数字"，就没达到兜底线，需要回 §2.3 装饰素材库或版式基型库重新挑选、至少补足以上三项。**兜底不等于必须繁复**：极简风格完全可以達标（比如干净的题签卡+一枚线性小图标+一个胶囊页码），关键是"经过设计"而不是"什么都没加"。

### 2.3b 封面独立设计（修"封面与内页一个样"+ 标题艺术化）

**封面是全套的门面，独立设计版式，不套用内页的文字带 + 边框模板。** 它与内页的统一，仅体现在**四个视觉基因**上：`同一画幅比例`、`同一主色调/配色`、`同一画风`、`同一字体族（标题可用其艺术化变体）`。除此之外版式自主。

**标题艺术化（按体裁挑，符合主题调性）**：
- **儿童绘本**：彩色手绘艺术字标题 + 童趣手绘点缀（星星/气球/小动物/涂鸦），吸引低龄受众。
- **历史/名著连环画**：**毛笔书法**标题 + 一句点题句 + **朱红印章/闲章**；若为名著可标**作者、年代、背景信息**。
- **科普绘本**：几何/科技感标题 + 主题图标点缀（分子/星轨/齿轮）。
- **短视频/广告/影视**：片名式主标题 + 副标/slogan/产品名。

**封面布局要点**：标题区显著（约占画面上/中部），主视觉为最能概括主题的核心角色/场景/概念图；只放标题类文字（主标、副标、引子、作者/年代），**不放正文剧情**；页码记为 1（或"一"，与内页同款；若标题版式不宜放页码可省略封面页码，内页仍严格递增）。

### 2.4 剧情驱动的画内叙事元素（修"元素单调" + 增强丰富度）

**在合适的格子里，按剧情需要**加入更多叙事性小元素，让画面更会"讲故事"——但**只在与本格剧情相关时加，绝不为凑元素而加无关内容**：
- **联想/心声小图**：角色产生心理活动、回忆或想象某场景时，在**心声云朵内嵌一张被联想场景的小图**（如小女孩想到明天的郊游 → 云朵里画出草地风筝的小景）。
- **闪回/插叙插框**：主画面一角用做旧/描边小框放一段回忆特写。
- **图标/符号点缀**：情绪或概念的小图标（灯泡=想到主意、音符=歌声、问号=疑惑），风格与画风统一。
- **道具特写嵌图**：关键道具在角落用嵌套小图放大特写。

分镜表须为这些元素单列一栏（"特殊叙事元素"），并标注"因何剧情而加"，防止无脑堆砌。

### 2.5 固定模板层工作流（core fix —— 彻底消除边框/文字带/字体/页码跳变）

把每一页拆成两层，**分开处理、绝不混在一次生成里**：

| 层 | 内容 | 谁来做 | 一致性保证 |
|---|---|---|---|
| **A 生成层（插画）** | 只有框内那幅画（场景/角色/动作/氛围/联想小图） | 图像模型生成 | 靠母版图生图 + 锚点复用（画风/角色一致） |
| **B 模板层（框+字+页码）** | 边框（含四角纹样）、文字带/文本框、正文文字、页码 | **确定性合成/叠加**（代码/图层/版式工具），**不经过模型** | **逐像素复制同一套资产 → 天然零漂移** |

**标准流程（首选，只要有任何合成/叠加能力就走这条）：**
1. **定模板资产（一次性）**：设计**一张**空模板 PNG（透明中心 + 固定边框 + 固定文字带底 + 固定页码底纹槽位），确定唯一比例。**边框纹样按本故事的世界从菜单挑 2~3 类**（§2.3，忌套路化）、**边框颜色从本作品调色板派生**（取主色加深/降饱和或和谐邻近色，别硬配撞色）。边框可以繁复，因为它只画一次、之后每页复用**同一个文件**，再华丽也不会变。
2. **定字体资产**：选**一个具体字体文件**（写清字体名 + 版本/字重档，如"思源黑体 CN Bold"而非笼统的"黑体"或"圆润手写体"这类模糊描述——**模糊字体描述本身就是纯生成路线下字体漂移的另一个根源**，字体名必须精确到可安装文件级别），锁定字号（按画面高百分比换算成像素）、字距/字宽（是否加宽/紧缩）、颜色（精确色值）、字重（**统一，不许某页加粗**）、行距对齐。**首字放大若采用，则由排版层统一处理——只放大/换色首字，其余字全一致**（首字色按调性选、不必红，全书同款）。
3. **只生成插画层**：每页用图生图/文生图**只画框内插画**，传同一 `aspect_ratio`，插画区**不画边框、不画文字带、不写正文、不写页码**（prompt 里明确"画面为纯插画，无边框无文字无页码，四周留出安全边"）。
4. **合成**：把插画贴进模板中心 → 用固定字体把本页正文排进文字带 → 用固定字体把本页页码打进页码槽（数字从台账 B‑7b 取，**由代码控制，永不选错体系**）。
5. 全书循环 3–4，模板/字体/页码样式**永远是同一套文件**。

> 这样一来：**边框永远同一张、文字带永远同一条、字体字重永远一致、页码永远同一数字体系且严格递增**——因为它们根本不再由模型"画"，而是被"盖"上去的。你上传那批图里 3/四/五/6 混用、四角纹样每页不同、结局页整框换掉、"春去秋来"莫名加粗，全部属于"把 B 层丢给模型生成"导致的，用本流程可一次性根除。

**局部重绘锚定法（inpaint‑on‑frozen‑template，无完整合成软件时的次优解，比"纯生成+精确坐标"可靠得多）：** 若环境没有图层合成能力、但**有图像局部重绘/inpainting 能力**（对一张已有图片指定一块区域、只重绘该区域、其余像素保持原样不变），可用这条替代标准流程达到接近的一致性：
1. 生成**一张**带边框/装饰但**页码位与文字带留空白/占位色块**的"冻结模板图"（只做一次）。
2. 之后每一页，都对**这同一张冻结模板文件**（不是重新生成的新图）做两次局部重绘：①在插画区域重绘出本格插画（其余区域含边框/页码位不受影响）；②在页码占位块区域重绘出本格数字。因为边框和页码位置**本来就是同一批像素、根本没有被重新生成**，位置和样式不可能漂移。
3. 此法的关键是"复用同一份文件反复局部编辑"，而不是"每页从头生成一张新图再去对齐"——后者正是漂移的根源。

**纯生成降级方案（真的连局部重绘能力都没有时才用，最下策，务必如实告知用户会残留漂移）：** 若只能靠模型出全图，则把伤害降到最低——
- **边框极简化**：改用**均匀细线单色描边**或**四角完全相同的单一小纹样**，放弃"每角不同的繁复纹样"（每角不同 = 必漂移）。
- **页码不指望模型**：模型写数字不可靠；**要么全书统一留白页码槽、之后哪怕手动补打**，要么明确只用阿拉伯数字（模型对阿拉伯数字比中文数字稳）并**逐张核对、错就重生**。
- **禁止重复徽标**：prompt 必须显式加一条反向约束——"全图有且仅有一个数字/圆形徽标出现在指定位置，画面其余任何角落都不得再出现数字、圆形徽标或类似页码的图形"，防止模型在别处又画出第二个页码（本轮实测中同页出现两个"2"的伪影）。
- **字体描述精确到可安装字体级别**：不写"圆润手写体"这类风格化形容，改写具体字体名（如"站酷快乐体""思源宋体 Regular"），并明确字宽/字重档，降低"这页宽那页窄"的漂移概率——但要清楚，**这只能降低漂移概率，不能消除**（总则五）。
- **正文字重锁死**：prompt 显式"正文全部同一字重、不得加粗任何字词"。
- **严格图生图锚母版** + 低重绘幅度保住边框区；仍需逐张过 §D 自检清单，不合格挑出重生，**且要向用户说明此路线的一致性上限**，不承诺"完全不漂移"。

### 2.6 专业分镜信息规范（影视故事板 / 短视频·广告分镜等"分镜类"必读）

分镜类不是"配插画"，而是**给拍摄看的工程图纸**：每一格都必须带完整、可读、行业通用的信息栏，**缺字段即不合格**。这些信息由模板层（§2.5）用固定字体排版，保证每格齐全、样式一致。

**A. 每格必带的标准字段（信息栏，逐格填写、不留空）：**

| 字段 | 含义 | 例 |
|---|---|---|
| **镜号** | 顺序号（=本格序号，严格递增、唯一） | 镜01 / SC12-04 |
| **场景** | 地点 + 时间（内外景、日夜） | 内景·书房·夜 |
| **景别** | 远 / 全 / 中 / 中近 / 近 / 特 / 大特 | 全景 |
| **角度/机位** | 平视 / 俯 / 仰 / 过肩 / 主观 等 | 低角度仰拍 |
| **运镜** | 固定 / 推 / 拉 / 摇 / 移 / 跟 / 升降 | 缓推 |
| **时长** | 本镜秒数 | 3s |
| **画面/动作** | 一句话说清本镜发生什么 | 男主推门冲入雨中 |
| **音效/对白/旁白** | 声音信息（放注释条） | 台词"站住！"＋雨声 |

（短视频/广告分镜可把"景别/角度/运镜"简化，但**镜号、场景、时长、画面动作、字幕/口播**不可缺。）

**B. 排版（清晰易读、行业通用、逐格绝对一致）：** 画格居中，**信息与画面分区、绝不叠字**——镜号/场景/景别/角度/运镜/时长走**画格上方或下方的标签栏**（每字段带标签，字段间用**竖线或分格**隔开，**绝不用 `/` 把多字段塞成一行**）；音效/对白/旁白走**画格下方注释条**。全部由模板层用固定无衬线字体排版，字号足够读清。**信息栏的位置、高度、字号、字重、颜色、字段顺序，必须逐格完全相同**（只换字段里的内容文字）——判据同总则二"文字样式"：先定死一版母版信息栏、全片逐格复制，绝不出现"这格信息栏矮一点、那格字大一点"。

**C. 序号规则（呼应"所有图都要有序号"＋"镜号与页码不重复"）：** 分镜类**以「镜号」作唯一序号标记，不再另设页码**（镜号本身就是顺序号）；镜号从第一镜起严格递增、每张唯一、样式统一；**封面/扉页在镜号位写「扉页」或「00」**。镜号在信息栏中的位置同样要用**绝对坐标**锁定（如"信息栏最左侧、距画布左边缘 2%"），不能只写"左上角"。非分镜类（绘本/连环画/漫画/短视频字幕类）仍用页码，规则见 B‑5。

### 阶段 B：plan 输出（项目计划书）

<!-- for: 保证剧情有推进、转折、情绪起伏 -->
1. **故事节拍与情绪曲线**：一句主题（logline）+ 起承转合 + **节拍表**（拆成与 `panel_count` 等量的节拍，每格写"这格在故事里干什么"：引入/铺陈/触发/上升/受挫/转折/高潮/回落/升华/结局，相邻格有明确因果或情绪推进）+ **情绪曲线**。自检："看节拍表能否讲出内容丰富、有转折、有起伏的完整故事？"成长/情感类推荐含一段**低谷**再拉回。

<!-- for: 跨格角色一致性的命脉，逐字复用防漂移 -->
2. **角色锚点**：每个出现 ≥2 格的角色写 30–60 字固定描述（物种/性别/年龄/体型、五官、发型发饰、标志服装配色 + 材质、标志道具、习惯姿态/微表情），写到"能画出来"，之后逐字复用到每条 prompt。示例："五六岁小女孩，圆脸、黑色齐耳短发、笑起来眯眯眼，穿黄色条纹长袖 T 恤 + 蓝色背带裙、红色小球鞋"。

<!-- for: 全组共用画风 -->
3. **画风锚点**：20–40 字画风短句，全组共用（媒介词 + 色调词 + 笔触词 + 质感/细节密度词；用风格特征而非"某艺术家"）。

<!-- for: 多图成套命脉，文字版式必须可量化 -->
4. **文字版式锚点（text‑style anchor）**：写 30–50 字固定描述，逐字复用到每 prompt 文字段。一次性锁定且每项可量化（模糊词会让多图飘移）：
   - **承载形式**：与所选版式基型（§2.3）匹配——`底部/顶部文字带`（基型①）/ `文本框·卷轴·牌匾内`（基型②）/ `分隔线一侧的文字区`（基型④）/ `对白气泡内`（基型⑤）。位置可按每格构图在同一基型内微调以避主体，但**不许风格跳变**（这页手写体那页黑体、这页浅米底那页透明字）。
   - **字体（全书唯一，精确到可安装字体级别，不写风格化形容）**：不写"圆润手写体""古典楷体"这类模糊风格描述——这类词在不同批次生成中会被理解成不同的具体字形，是字体漂移的根源之一。**改为写出具体字体名 + 字重档 + 字宽/字距**，如"站酷快乐体 Regular，字距正常"或"思源宋体 CN Bold，字距略宽"，全书唯一、逐字复用不改写。**此规则只在走§2.5模板层或局部重绘锚定法时能真正生效**（固定字体文件渲染）；纯生成路线下精确字体名能降低漂移概率，但不能消除（总则五）。
   - **字号档（全书唯一，锁死相对字高）**：正文字高约画面 4~5%、封面标题约 7~9%、气泡内约 3%。**同一角色的正文全书同一字高**，不许忽大忽小。
   - **颜色（精确色值）**：封面标题、内页正文各给定精确色值（如深棕 #4A3620、浅米 #F5EFE0），全书通用。**正文一律同一颜色**，除下面的"首字"外不得再有任何字词变色。
   - **首字放大（drop cap，唯一允许的字内变化）**：绘本/连环画可统一用"每页/每段正文**首字放大**"作装饰，但**严格限定——只有首字可放大和/或换色；其余每一个字的字体、字号、颜色必须完全一致，不得再有任何加粗、变色、变大、变字体**。首字的放大倍数（如 1.6×）与颜色**全书锁死同一套**，逐页同款。**首字颜色不必是红色**，按主题调性从本作品配色里选一个和谐强调色（暖调绘本→赭红/南瓜橙；青绿古典→石青/靛蓝；冷调科普→钴蓝；森林童话→墨绿）。此处理由排版层统一施加（§2.5），保证每页一致；若不用首字放大，则正文连首字也完全一致。
   - **对齐与行距**：如"横排居中，两段间空一行"（竖排作品则注明竖排规则）。
   - **统一手段**：优先由排版层用固定字体施加（§2.5）；降级方案下精修首张内页为"版式母版"，后续图生图并显式写"文字的字体/字号/颜色与参考图完全一致，除首字外无任何变化"。
   - 示例："全书文字统一排在画面底部约四分之一浅米色（#F5EFE0）文字带内，横排居中、两段间空一行，站酷快乐体 Regular、深棕（#4A3620），正文字高约 4%、每段**首字**放大 1.6× 用赭红（#B24A2E），除首字外全文字体/字号/颜色完全一致，简体中文、字迹清晰"。

<!-- for: 内页装饰规格可量化；页码须锁死数字体系与递增顺序 -->
5. **内页版式装饰锚点（decor anchor）**：写 30–50 字固定描述，逐字复用。按所选基型 + 主题从素材库挑元素，每元素写清"位置 + 尺寸 + 颜色"：
   - 绘本类（示例·基型①）："每页四周离画边约 3% 一圈 2px 浅棕（#8A6A4A）手绘花草细边框，段首字放大约 1.6 倍用朱红（#C8402F），**页码圆形（浅米底 #F5EFE0、深棕字）直径约画面 6%，圆心以画布右下角为基准、距右边缘 6%、距下边缘 6%**，被小树叶环绕，装饰克制不糊主体"。
   - 古典连环画（示例·基型③，纹样按故事选、边框色从调色板派生）："四周**深赭墨青**（从画面青绿赭石派生的加深和谐色）主题边框，四角镶**贴合本故事的纹样**（如边塞题材用旌旗/云气/城砖、江河题材用水波/芦苇——**非默认祥云锦鲤**），右下角环回纹圆形页码用**中文数字**（浅金底 #E8D9A0、深赭字），每段首字放大约 1.6 倍用石青"。
   - 影视故事板（示例·基型⑥）："带 3px 深灰（#3C3C3C）边线画格、内缩约 8% 留信息区；上方高约 10% 浅灰（#E6E6E6）标注栏分「镜号/景别/角度/时长」等带标签字段；动势用 3px 红描边箭头，下方高约 10% 窄注释条"。
   - **对话框锚点（有对话/心理活动时用）**：选一种样式写清规格。示例："人物对话用白底、2px 深灰描边圆角矩形气泡，尖角指向说话者；心声用同色系云朵气泡（需要时内嵌联想小图）；泡内简体楷体、字高约 3%、每泡 ≤20 字"。位置随说话者浮动，形状/描边/字体/字号全书统一。
   - **页码/角标锚点（对抗序号乱与漂移，六项全锁死）**：
     - **必须每张都有**：非分镜类，含封面在内，每一张都要有页码，不许有的页漏打。
     - **数字体系锁死唯一一种**——全书统一用**阿拉伯数字**（当代题材推荐）**或全用中文数字**（古典题材推荐），**绝不混用**。
     - **顺序 = 严格递增**：页码是画面在成套中的**顺序号，从封面/首格起严格递增、每张唯一、不重复、不跳号、不倒序**（封面记 1 或 一，内页顺延）。
     - **样式与位置双锁死**：圈样/环绕图案、字体、颜色、出现位置全书完全一致，逐格**只改其中的数字**；**位置用绝对坐标写死**（如"以画布右下角为基准，页码圆心距右边缘 5%、距下边缘 5%"），不写"右下角"这类相对描述，全书逐字复用同一坐标。
     - **有且仅有一个**：任何一页都不许出现第二个页码/数字徽标；纯生成路线必须显式反向约束禁止画面其他位置再出现类似图形（总则五）。
     - **实现路径按优先级选**：模板层合成（§2.5 标准流程）＞ 局部重绘锚定法（§2.5）＞ 纯生成+精确坐标（已验证不可靠，仅无其他选择时用，且要如实告知用户会残留漂移）。
     - **生成阶段配套**：见 B‑7b「页码台账」与阶段 D 的覆盖机制。

5b. **封面版式锚点（cover anchor，独立于 B‑5）**：写 30–40 字，描述封面**独立布局**（区别于内页）：标题艺术处理（§2.3b）+ 主视觉 + 只放标题类文字 + 继承的四个视觉基因（比例/配色/画风/字体族）。示例（儿童绘本）："封面独立版式，无内页文字带与边框；上部彩色手绘艺术字标题《我喜欢我自己》约 9% 字高，点缀手绘星星气球；中下部主角环抱自己站春日花海；配色/画风/比例与内页同套；右下角同款圆形页码写 1"。

<!-- for: 对抗画面简朴 -->
6. **场景/世界观锚点**：主要场景各写 20–40 字固定描述（环境要素与标志物、氛围季节、可复用陈设/道具），出现该场景的格子复用，让每格"有生活痕迹"而非角色悬浮空白背景。

<!-- for: 对抗雷同，保证画面丰富 -->
7. **道具/场景变化表**：每格分配不同的、贴合剧情的生活道具或活动，列"镜号→道具/活动/场景要素"对照，确保画面丰富不单调。

7b. **页码台账（page‑number ledger，修跳号）**：生成前先列一张显式清单，把"格 → 页码数字"一一写死，全用同一数字体系，人工核一遍是否严格连续。示例：`封面=1，内页 2、3、4、5、6、7、8、9、10`（或中文 `一、二、…、十`）。生成时逐格照此台账取数，不临场心算。

<!-- for: 逐格规划；封面固定第1格；规格层不进表 -->
8. **分镜表**：**（封面规则·所有体裁默认，除非用户明确不要）第 1 格固定为封面图**，不参与情节节拍、不填「承接上格」（用「—」），是全套主题门面，**独立版式**（§2.3b）、与内页同比例同画风同配色同字体族、预留显著标题区（页码记为 1）。逐格列出：镜号（=页码顺序号，照 B‑7b 台账，递增不重复）/ **承接上格（因果或情绪推进）** / 景别 / 镜头视角 / 场景背景 / **角色与动作（含落脚点与承载面）** / **本格道具** / **特殊叙事元素（联想小图/闪回/图标，注明因何剧情而加；无则填「—」）** / **画面丰富度（逐区域：前景/中景/背景/天空地面各一具体元素 + 配色「主·辅·点缀」+ 光影 + 本格独有装饰）** / 情绪光线 / **画面内文字** / 比例（全书同一，照搬阶段 A 锁定值）。
   - **空间落点**：填"角色与动作"必须交代人物站/坐在何承载面、与建筑道具的前后上下关系（如"孔明**坐在城楼平台矮桌前**抚琴"），写清才不嵌墙/不悬浮。
   - **规格层不进表**：文字版式（B‑4）、内页装饰（B‑5）全书每格照搬，不逐格设计；分镜表只变"内容层"（剧情/动作/道具/联想元素/文字）。
   - 景别要有节奏（远景·全景·中景·中近景·近景·特写·大特写）；关键情绪点用非平视角度；不写"运镜"。相关列不允许留空（无则填「—」）。

9. **prompt 列表**：把分镜表每行翻成一条 prompt（九段式见阶段 C）；全组共用同一画风/场景/文字版式/装饰锚点，角色逐字复用同一角色锚点，封面用封面版式锚点。每条 prompt = 逐格变化内容 + 全书不变锚点（原样复制）。多图并行与参数由基础 image_generation 约束。

### 阶段 C：prompt 改写（核心专精点）

**内页每条 prompt 至少含以下九段：**
```
[画风锚点] + [比例(工具参数恒定)/构图 + 按版式基型预留文字位置] + [景别/镜头] + [场景锚点·复用 + 时间光线] + [角色锚点·复用] + [当前动作与情绪 + 空间落点 + 本格专属道具] + [丰富度：前景/中景/背景三层次 + 氛围 +（若有）本格特殊叙事元素] + [画面内文字 = 本格成品文字(引号写死、无排版符号) ⊕ 文字版式锚点] + [版式装饰 = 内页装饰锚点 ⊕ 本格独有符号(本格页码数字/镜号/箭头方向)]
```

**封面 prompt 用封面版式锚点替换第 2 段与第 8/9 段的内页版式部分**，其余（画风/比例/配色/字体族）保持同套。

**⚠ 每条 prompt 出厂前的强制字段清单（missing‑spec guard）——本节最重要，专治"规则写在文档里、但翻译成 prompt 时被丢掉"。**
反复出现的失败是：skill 明明规定了字体要精确、页码要绝对坐标，可实际生成的 prompt 里**文字只带了颜色色号、字体和字号没写，页码又退回成"右下角"**。根因是"锚点没被逐字复制进 prompt"。因此，**每写完一条 prompt，落笔前必须逐项核对下面 6 个字段是否都显式出现在 prompt 文本里，缺任何一项即为不合格、必须补齐再出**（不是"默认继承"，而是"每条都要肉眼可见地写出来"）：

| # | 字段 | 合格标准（prompt 里必须出现） | 反例（本次真实问题） |
|---|---|---|---|
| 1 | **文字字体** | 具体字体名+字重档，如"站酷快乐体 Regular" | ❌ 只字"文字深棕色"，没写字体 |
| 2 | **文字字号** | 相对字高，如"字高约画面 4%" | ❌ 完全没提字号 |
| 3 | **文字颜色** | 精确色值 | ✅ 有写 #4A3620 |
| 4 | **文字位置/承载** | 与基型一致的承载+对齐 | ✅ 有写"文字区横排居中" |
| 5 | **页码绝对坐标** | "距 X 边缘 N%、距 Y 边缘 N%"，**禁止只写"右下角"** | ❌ 只写了"右下角小圆形页码" |
| 6 | **页码字体/字号/色** | 与全书页码锚点一致的具体规格 | ❌ 只说"浅杏底深棕字"，没写字体字号 |

**同一条 prompt 的正反对照（用你这次的毕业插画为例）：**

> ❌ **不合格（当前生成的样子）**：……文字区内横排居中写："…"文字深棕色（#4A3620），字迹清晰。右下角一个浅杏底深棕字小圆形页码写"6"。
> —— 字体、字号缺失（1、2、6 项没写）；页码只写"右下角"（第 5 项不合格）。

> ✅ **合格（应该生成的样子）**：……文字区内横排居中写："…"，**字体站酷快乐体 Regular、字高约画面 4%、深棕色（#4A3620）**、字距正常、字迹清晰。**页码为浅杏底（#FDF6EC）深棕字圆形徽标、直径约画面 6%、字体思源黑体 CN Regular，圆心以画布右下角为基准、距右边缘 5%、距下边缘 5%**，写"6"；**全图仅此一个页码徽标，其余位置不得再出现任何数字或圆形徽标**。

**做法**：这 6 个字段的具体值，在 §B‑4 文字版式锚点、§B‑5 页码锚点里已经一次性定死；写每条 prompt 时**把锚点原文复制进去、只改本格数字/文字内容**，而不是凭记忆重写一句简化版——简化的那一刻，字体和坐标就丢了。

> **受挫内页（基型①）**：柔和水彩绘本风，细腻线条，淡雅温暖高级色调，纸面颗粒质感；**4:3（工具参数，与封面同）**；底部同位置同款浅米文字带；中近景平视；配色暖木棕奶白为主、台灯暖黄辅、朱红点缀，与封面同套；温馨书房暖黄台灯；同款小女孩抱膝坐书房木地板低头懊恼、旁地歪头小狗；前景散落作业本铅笔橡皮、中景坐地女孩与小狗、背景木桌歪字帖与台灯、窗外渐暗暮色；**特殊叙事元素：无**；底部文字带横排居中分两小段深棕"有时候，我会写错字，会不小心摔倒，把事情做得不够好。""可是妈妈说，犯错并不代表我不好，它只是说明我在努力长大。"站酷快乐体约 4%、清晰无符号；内页装饰：同款花草边框、段首字放大朱红、右下角同款圆形页码写 5（**若走图生图：覆盖参考图继承的页码，本格写 5**）。

#### 示范 2 · 古典历史连环画（基型③主题融合边框 + 书法封面 + 中文页码）

#### 执行硬约束（落笔前对照）
- **【第 0 硬约束·每条 prompt 出厂核对】每写完一条 prompt，先逐项确认 6 个字段都显式写进了 prompt 文本：①文字字体名+字重 ②文字字号(相对字高) ③文字颜色 ④文字位置/承载 ⑤页码绝对坐标(距边缘 N%，禁止"右下角") ⑥页码字体/字号/色。** 缺任一项即不合格、补齐再出。做法是把 §B‑4/§B‑5 锚点**原文复制**进 prompt、只改本格数字与文字内容，不凭记忆写简化版（简化就会丢字体和坐标——这是本轮真实翻车点，见阶段 C 强制字段清单）。
- **【第一硬约束】边框、文字带、正文字体/字重、页码——四样一律走固定模板层叠加或局部重绘锚定法（§2.5、总则三、总则五），不逐图交给模型生成。** 违反此条，前面所有细则都救不回跳变。**实现路径按优先级：模板层合成 ＞ 局部重绘锚定法 ＞ 纯生成+精确坐标（已验证不可靠，仅无其他选择时用）**。
- **每张图必须有且只有一个序号标记，不许缺失、也不许出现第二个**：非分镜类每张（含封面）都要打页码；分镜类每格用镜号顶替、不再另设页码；两者绝不同格并存（§2.6-C）；纯生成路线须显式反向约束禁止画面其他位置再画出数字/徽标（总则五）。
- **序号位置一律用绝对坐标锚定**：以画布角点为基准给出"距 X 边缘 N%、距 Y 边缘 N%"的百分比偏移，不写"右下角"这类相对措辞；全书逐字复用同一坐标（总则四）；**但要清楚，纯生成路线下即便坐标精确，位置仍可能漂移（总则五），坐标精确只是必要非充分条件**。
- **字体名精确到可安装字体级别**：不写"圆润手写体"等风格化形容，写具体字体名+字重档+字宽/字距，全书逐字复用。
- **所有图片（封面 + 内页）传同一 `aspect_ratio` 工具参数**，封面也不例外；比例靠参数恒定，不靠文字描述。
- **封面独立版式**：标题艺术化、只放标题类文字、不套内页文字带 + 边框模板；只共享比例/配色/画风/字体族。
- **文字样式全书统一**：字体族、字号档（相对字高）、颜色（精确色值）逐字复用；图生图 prompt 显式写"文字字体/字号/颜色与参考图完全一致"。
- **首字放大是唯一允许的字内变化**：如用，则只放大/换色**首字**，其余每字字体/字号/颜色完全一致，**不得再有任何加粗、变色、变大、变字体**；首字色按调性选（**不必红**）、全书同款。
- **同体裁也要跨作品换样**：纹样按本故事的时代/地域/场景/关键物选（**别所有古典都祥云锦鲤、别所有儿童都花草边**），每部只挑 2~3 类贴合的；判据"换个同体裁故事边框会不会不一样"。
- **边框/装饰配色从本作品调色板派生**，用主色加深/降饱和或和谐邻近色，**禁高对比生冷撞色**（如暖调画面硬配纯靛蓝框）。
- **页码首选由模板层用固定字体打**（数字从 B‑7b 台账取、代码控制，**永不选错体系、永不跳号**）；仅降级方案才让模型渲染，且必须锁死单一体系（推荐阿拉伯）+ 逐张核对 + 错就重生。全书一种数字体系、从封面起严格递增、每张唯一、不重复不跳号不倒序。
- **版式基型全书锁定**：从库按主题选 1 型，作品内不乱换；**边框/文字带/字体/页码任何页都不动（受控变化只允许发生在框内插画，见 §2.3 边界）**。
- **特殊叙事元素按剧情加**：联想小图/闪回/图标仅在与本格剧情相关时加，不为凑而加。
- 画面内文字必写且有信息量（成句成段，除非用户明确"只要画"）。
- 多字段信息区每字段带标签、绝不用 `/`；文字引号内只含干净正文，禁 `/ | \ \n` 符号。
- 第 7 段必逐区域 + 配色（主辅点缀 + 色调词 + 光影）；第 6 段交代空间落点（防嵌墙/悬浮）。
- 通用装饰按主题共用、仅功能符号按体裁、装饰克制；角色/画风/场景锚点逐字复用；每格道具不重样；相邻格按"承接上格"衔接；一条 prompt 只描述一格。
- **分镜类信息栏逐格绝对一致**：位置/高度/字号/字重/颜色/字段顺序全片同款，只换字段内容（§2.6-B）。
- **兜底美观三项不可省**：任何体裁/基型，文字承载须有设计感（底色+圆角/描边/投影）、至少一处贴题小装饰、序号须有底纹承托，杜绝"插画+纯白字幕条+裸数字"的素颜效果（详见 §2.3 兜底版式美观度）。

### 阶段 D：工具调用与交付呈现

**第 0 步（最关键）：确定走哪条路线。**
- **有任何合成/叠加/代码能力 → 走 §2.5 标准流程**：先做好固定模板资产（边框+文字带+页码槽）与字体资产，之后模型**只生成框内插画**、再合成。边框/文字带/字体/页码天然零漂移，下面第 1–3 步只用于**保证插画层**的画风/角色/比例一致。
- **有局部重绘/inpaint 能力但无完整合成 → 走 §2.5 局部重绘锚定法**：复用同一份冻结模板文件，逐页做局部编辑，边框/页码天然不动。
- **完全无合成/重绘能力 → 走 §2.5 纯生成降级方案**：如实告知用户存在一致性上限，边框极简、字重锁死、页码优先留白或锁阿拉伯，并严格执行下面的图生图锚母版 + 逐张自检。

**插画层生成顺序（先立基准，再统一锚定）：**

1. **先出母版（第 2 格 / 首张内页）**：反复精修到满意——**画幅比例、画风、（降级方案下还含字体/文字带/边框）全部一次定型**。它是全套的**视觉基准与比例基准**。记下所用 `aspect_ratio` 参数值。标准流程下母版只需定死"插画风格 + 比例"。
2. **再出封面（第 1 格）**：走 `Image2Image` 锚母版以继承**同一比例/配色/画风/字体族**，但 prompt 显式写"**封面采用独立版式（艺术标题 + 主题装饰），不套用内页文字带/边框；保持与参考图相同的画幅比例、色调、画风、字体族**；标题写'…'，右下角页码写 1"。**传入与母版完全相同的 `aspect_ratio` 参数。**
3. **再出第 3 格起（其余内页）**：每格 `Image2Image`、母版作参考，**传入与母版完全相同的 `aspect_ratio` 参数**，prompt 写"参考输入图画风、角色相貌服饰、**文字的字体/字号/颜色与位置**、边框/装饰样式，**保持同一画幅比例**；生成【本格新场景动作】；文字处写'本格文字'；**右下角页码写本格序号数字（按 B‑7b 台账，如第 4 格写 4），替换/覆盖参考图上继承的页码**"。图生图比各自文生图稳得多。

**三个"必须显式覆盖"的点**（图生图会继承母版内容，须逐格改写，否则跳变或重号）：
- **文字内容**：只借样式、内容换成本格文字（"文字样式同参考图，内容改为'…'"）。
- **页码数字**：只借样式、数字换成本格序号（"页码样式同参考图，数字改为 X"）。
- **场景/动作/道具/联想元素**：换成本格分镜表内容。
- **保持不变的**：比例（同参数）、画风、角色相貌服饰、字体/字号/颜色、装饰样式、配色。

**纯文生图备选**：全组同 seed + **同一比例参数** + 文字版式锚点逐字复用 + 页码显式写死；一致性通常不如图生图锚母版（比例与文字更易漂），仅在无法图生图时用。

**一次最多 10 张**：若用户有明确页数按需生成；若无则默认 10 张（1 封面 + 9 内页）。

**交付前自检清单（逐条核；下列每一项都对应真实翻车过的点）**：
- [ ] **【出图前先查 prompt 文本】每条 prompt 是否都写全了 6 字段**：文字字体名+字重、文字字号、文字色、文字位置、页码绝对坐标（非"右下角"）、页码字体字号色？（任一缺失 = 规则没落地进 prompt，先补 prompt 再出图）
- [ ] **边框/四角纹样**：每一页是否完全同一套？（四角纹样逐页不同 = 没走模板层，打回）
- [ ] **文字带**：每页文字带的有无、形状、底色是否完全一致？（有的页有带、有的页没带 = 打回）
- [ ] **字体字重**：是否全书同一字体、**无任何一页某词加粗**？
- [ ] **首字放大**：若用，是否**只有首字**变（放大/换色）、其余每字完全一致、全书同款首字色？
- [ ] **序号必现**：每一张（含封面）是否都有页码或镜号，无一张缺失？
- [ ] **序号无重复类型**：分镜类是否只用镜号、没有再多打一个页码（两者未并存）？
- [ ] **单页无重复徽标**：同一页内是否只出现一次页码/数字徽标，没有像本轮实测那样同页出现两个数字？
- [ ] **序号位置零漂移**：是否每张的序号坐标（距边缘百分比）完全相同，而非"看起来差不多"？
- [ ] **页码**：是否全用同一数字体系（**不出现 3/四/五/6 混用**）、从 1 起严格递增、每张唯一无跳号？
- [ ] **字体名是否精确**：文字版式锚点写的是具体字体名+字重档，而非"圆润手写体"这类风格形容？
- [ ] **分镜信息栏**：镜号/场景/景别/角度/运镜/时长字段是否齐全、位置字号色彩逐格一致？
- [ ] 所有图（含封面）宽高比是否完全一致？
- [ ] 封面是否独立版式且与内页共享视觉基因、未套内页模板？
- [ ] **纹样是否贴合本故事、非体裁套路**？（换个同体裁故事应换一组纹样，古典未默认祥云锦鲤、儿童未默认花草边）
- [ ] **边框色是否从调色板派生、与主题和谐**、无生冷撞色？
- [ ] **兜底美观**：拿掉插画后，版式（文字区+装饰+序号）单独看是否"经过设计"，而非"一块白底字幕条+裸数字"？
- [ ] 联想小图/特殊元素是否都与本格剧情相关、无硬凑？

> 前几项若走了 §2.5 标准模板层或局部重绘锚定法，天然全过；若有任一项跳变（尤其页码位置/重复徽标/字体），说明还在用纯生成+坐标描述这条已验证不可靠的路，回到 §2.5 换实现路径，而不是继续打磨 prompt 措辞。
