# 信息收集模板

用于价格直查、参数规格、在售状态、商品基础信息和品类知识。只陈述可核验事实，不做“推荐/更值得买”的判断；可以说明用户需要核对的版本、条件或含义。

## 一句话事实结论

先直接回答用户的问题，并用一句话说明该事实对其当前判断的影响；不把参数或报价本身当作完整答案：

- 价格：`{商品} 当前可查参考价约为 {价格/区间}。`
- 参数：`{商品} 的 {参数} 为 {数值}。`
- 在售：`{商品} 当前在 {渠道} 可查到在售结果。`

不要附加“来源：”“查询于”或固定时间戳。如果价格、库存或活动可能快速变化，只自然补充一句“实际以结算页/商品页显示为准”或对应的活动条件。用户明确询问数据来源或时点时，再用一句简短自然语言回答。若有确认的商品详情页 URL，首次商品名使用 Markdown 文本超链接。

## 版本或渠道明细（仅必要时）

只有多版本、多容量或多渠道会改变答案时才保留表格；否则删掉本节。

| 版本 / 渠道 | 可核验信息 | 参考价 | 说明 |
|---|---|---|---|
| {配置或渠道} | {规格/在售状态} | {价格} | {券、补贴或配置差异} |

## 注意事项（可选）

只写会影响事实理解的 1–2 项，例如价格是否含券/补贴、配置是否一致、参数是否对应特定版本。品类知识问题不出链接或商品表，直接用简洁的定义、差异和适用场景回答。
