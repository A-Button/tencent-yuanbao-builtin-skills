# 情绪曲线模板

## 短视频推文情绪曲线公式

```
情绪强度
  ▲
  │╭─╮  ← 钩子引入（小高峰，制造好奇）
  │╭╯╰╮    ← 背景铺垫（情绪平缓下降）
  │╭╯  ╰╮  ← 事件推进（上升）
  │╭╯    ╰╮← 爽点爆发（最高峰）
  │╭╯      ╰╮← 情绪收尾（略降）
  │╭╯        ╰╮← 悬念钩子（微升）
  └──────────────► 时间/字数
```

---

## 5种经典情绪曲线模型

### 模型1：穿越开场型（最适合穿越文）

适合：穿越/穿书/重生 开场集

```
【开头-信息炸弹】(0-10句)
情绪：高亢、震撼
手法：连抛3个重磅信息，建立"我"的人设
示例：
我穿越了
穿到了三国，成了赵云的大哥
不仅如此，我还意外的收获了一个媳妇

【中段-代入感建立】(10-25句)
情绪：平缓但持续紧张
手法：用第一视角描述日常，建立观众对主角处境的共情
示例：
她问我愿不愿意带她走
我沉默了

【爽点-高潮】(25-40句)
情绪：激动、兴奋、爆裂
手法：核心收获/打脸时刻，情绪拉到最满
示例：
旨意念完，我傻了
周围的人也傻了
三千黄巾俘虏，全归我了？！

【悬念-结尾钩子】(40-50句)
情绪：悬念、好奇
手法：留一个"下一集预告"式的结尾
示例：
可我没想到的是
更大的麻烦，也随之而来……
```

### 模型2：打脸爽文型（适合逆袭文）

适合：都市逆袭、古风装逼打脸文

```
【开场-制造期待】(0-5句)
情绪：好奇、同情（假装弱者）
手法：先让观众以为主角处于劣势/被欺负
示例：
沙摩柯被气得一拍桌子
「你凭什么！」
我低头看了看自己
然后把圣旨亮了出来

【冲突-情绪递进】(6-20句)
情绪：紧张、对抗
手法：双方对峙，每一句都往主角赢的方向推
示例：
「废什么话俺老沙认栽了！」
「好，那就打吧」

【打脸-爆发时刻】(21-35句)
情绪：极度亢奋
手法：这一刻主角完全碾压对方，观众极度舒适
示例：
张飞搓着手走上来
「大哥你就放心吧！」
「俺老张的手可痒得不行了！」
一棍下去，沙摩柯的脸都绿了

【收尾-余韵】(36-45句)
情绪：满足、得意
手法：主角或配角的一句得意台词
示例：
「子虎，你可真够坏的！」
我哈哈一笑：打脸就要啪啪响！
```

### 模型3：悬念恐怖型（适合悬疑/虐文）

适合：真相揭露、悲剧时刻

```
【开场-压抑】(0-8句)
情绪：低沉、压抑
手法：环境描写+心理独白，铺垫悲剧氛围
示例：
当棺材打开的那一刻
我整个人都愣住了
黄巾军首领张角，死了

【真相-情绪爆发】(9-25句)
情绪：震惊、悲痛、愤怒交替
手法：先用震惊打蒙观众，再给情绪出口
示例：
爹爹！张宁惨叫一声
整个人向后倒去
我一把扶住她
她已经泣不成声

【高潮-最强冲击】(26-35句)
情绪：极度悲痛
手法：不给情绪缓和机会，直接拉到最顶点
示例：
我看着她的眼睛
那双眼睛里，已经没有了光

【悬念-情绪余韵】(36-45句)
情绪：沉重、悲伤
手法：留白，让观众自己消化
示例：
襄平的冬天，真冷啊……
```

### 模型4：收获满足型（适合系统流/系统文）

适合：获得系统、获得技能、获得美人

```
【开场-期待】(0-5句)
情绪：好奇、兴奋
手法：铺垫收获即将到来
示例：
系统提示音响了
「叮！恭喜主人获得……」

【揭晓-惊喜高潮】(6-25句)
情绪：极度亢奋
手法：收获越大，情绪越高
示例：
「恭喜主人获得：武力+50！」
「恭喜主人获得：绝世美人×1！」
我看着系统面板
整个人都笑出了声

【确认-满足感】(26-35句)
情绪：满足、自信
手法：用具体细节证明收获是真实的
示例：
她站在我面前
抬头看我：你是谁？
我微微一笑：我是你未来的夫君

【余韵-新的目标】(36-45句)
情绪：期待
手法：收获只是开始，新的挑战即将出现
示例：
可系统提示音又响了
「叮！检测到新任务——」
```

### 模型5：多爽点串联型（适合快节奏推文）

适合：多个爽点并列，不同时期发糖

```
结构：爽点A → 爽点B → 爽点C → 爽点D → 悬念
节奏：每8-12句一个爽点，不停地给观众新鲜刺激

示例节奏：
[0-10句] 爽点A：收获张宁
[10-20句] 爽点B：打败敌军
[20-30句] 爽点C：圣旨赏赐
[30-40句] 爽点D：曹操羡慕
[40-45句] 悬念：更大的敌人来了
```

## 爽点分类清单

| 爽点类型 | 关键词/信号 | 适合文案开头句 |
|---------|------------|--------------|
| 打脸爽 | "把脸打得啪啪响" | 「我随口一句话……」 |
| 逆袭爽 | "从弱者变强者" | 「你们不知道的是……」 |
| 收获爽 | "获得/拥有/得到" | 「系统响了——」 |
| 暧昧爽 | "牵手/脸红/低头" | 「她问我……」 |
| 揭秘爽 | "真相是……」 | 「直到今天我才知道……」 |
| 反转爽 | "但谁也没想到……」 | 「所有人以为我会输……」 |
| 碾压爽 | "根本不是对手" | 「俺老张还没怕过谁！」 |
| 复仇爽 | "终于等到这一天" | 「这一刻我等了十年」 |

## 快速选择情绪曲线

根据原文内容，选对情绪曲线类型：

- **穿越/穿书文** → 模型1（穿越开场型）
- **装逼打脸文** → 模型2（打脸爽文型）
- **悬疑/揭秘文** → 模型3（悬念恐怖型）
- **系统/收获文** → 模型4（收获满足型）
- **多剧情推进文** → 模型5（多爽点串联型）
- **混合型** → 以一种模型为主，根据剧情段落灵活切换
