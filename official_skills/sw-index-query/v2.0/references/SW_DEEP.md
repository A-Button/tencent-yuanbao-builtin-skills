# SW_DEEP — 单指数深度报告（综合）

## 1. 概述

单指数全维度综合报告：实时行情（无实时接口的指数用最新 K 线合成）+ K 线 + 估值（PE/PB/股息率/换手率/流通市值）+ 年化收益风险 + 成分股 Top10 + 行业分布 + 8 项技术信号 + 综合评分 + 支撑压力位。回答"XX 深度分析 / 全面分析 / 分析报告"。

## 2. 输入

```
sw_deep.py --code CODE [--name NAME] [--days N]
```

| 参数 | 必填 | 默认 | 说明 |
|------|------|------|------|
| `--code` | 是 | — | 6 位申万指数代码 |
| `--name` | 否 | 空 | 展示名（便于用户理解） |
| `--days` | 否 | `120` | K 线回溯根数，最小 60 |

## 3. 输出

```json
{
  "status": "ok",
  "mode": "deep",
  "code": "801780", "name": "银行",
  "latest": 4019.66, "change_pct": -0.4,
  "score": 67, "signal_summary": "4多/4中/1空",
  "y1_return": 1.22, "y1_vol": 15.14,
  "pe": 6.14, "pb": 0.52, "dp": 5.16, "turnover": 0.79, "circ_mcap": 25071.17,
  "summary_text": "指数: 银行(801780)\n最新价: 4019.66, 涨跌幅: -0.4%\n估值: PE 6.14, PB 0.52, 股息率 5.16%, 换手率 0.79%, 流通市值 25071亿元\n技术信号综合评分: 67/100 (4多/4中/1空)\n..."
}
```

| 字段 | 含义 | Agent 使用要点 |
|------|------|---------------|
| `score` | 综合技术评分 0-100 | 必列 |
| `signal_summary` | "多/中/空" 信号数 | 必列 |
| `pe/pb/dp/turnover/circ_mcap` | 基本面估值字段 | 必列（深度报告的核心差异化） |
| `y1_return/y1_vol` | 年化收益 + 波动率 | 必列 |
| `summary_text` | 含成分股 Top3 + 行业分布 Top3 + 支撑压力位 | agent 引用 |

## 4. 路由示例

| 用户说 | Agent 执行命令 |
|-------|--------------|
| "银行深度分析" | `sw_deep.py --code 801780 --name 银行` |

| "基础化工近半年深度分析" | `sw_deep.py --code 801030 --name 基础化工 --days 125` |
| "电子指数分析报告" | `sw_deep.py --code 801080 --name 电子` |

## 5. 已知坑 / 边界

- 用户没给具体指数 → 先触发澄清（`clarification-patterns.md` 模板 1）
- 对**大类风格/金创指数**（`801271-801276` / `802608-802612`）：无实时分时 API，脚本会用最近 K 线合成 realtime 不报错
- **严禁预测**和**严禁投资建议**（AGENTS.md 硬性规则 #5）— 只陈述数据
- 与 `sw_tech.py` 区别：sw_tech 只出技术面（8 指标 + 评分 + 压力位）；本脚本多了估值 + 成分股 + 行业分布 + 年化收益风险
- 与 `sw_stats.py` 区别：sw_stats 只出统计表（年化/波动/Sharpe/Calmar/MDD/胜率），无技术面无成分股
- 若用户要**历史分位数**（"银行 PE 现在在 5 年什么分位"）→ 单独走 `sw_quantile.py`
