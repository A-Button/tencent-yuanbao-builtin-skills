# 误读陷阱与干扰因素

> **核心用法**：对每个异常项**强制反问**——「这个异常有没有非疾病解释？」
> 把溶血导致的假性高钾当真性高钾、把健身后的 CK 升高当心肌损伤，会制造无谓恐慌，也可能掩盖真问题。
> **输出要求**：必须在报告中体现「已排除项」与「待排除项」，不能跳过此环节。

---

## 一、采样与标本因素

| 干扰 | 受影响指标 | 表现 | 识别线索 |
|---|---|---|---|
| **标本溶血** | K⁺↑、LDH↑、AST↑、血清铁↑、NSE↑、磷↑ | 假性升高 | **高钾必查此项**。看报告是否标注溶血；LDH 与 K 同步升高高度可疑 |
| 止血带过久 | 乳酸↑、K⁺↑、蛋白类↑ | 假性升高 | 采血过程描述 |
| 输液侧采血 | 血糖↑/↓、电解质稀释、Hb↓ | 严重偏差 | 数值与临床严重不符时考虑 |
| 标本放置过久 | 血糖↓（糖酵解）、K⁺↑ | 血糖假性偏低 | 采样至检测间隔长 |
| 抗凝剂错误 | 钙↓（EDTA 管）、凝血异常 | 假性异常 | 单项极端异常且无临床对应 |
| EDTA 依赖性血小板聚集 | PLT↓↓ | 假性血小板减少 | **无出血倾向但 PLT 极低**，需换枸橼酸管复查或看血涂片 |
| 冷凝集 | RBC↓、MCV↑↑ | 假性异常 | 冬季、低温标本 |
| 脂血标本 | 多项比色法指标偏差 | 数值不可靠 | TG 极高时 |

> **溶血是最高频陷阱**。高钾在报告中出现时，第一反应应是"排除溶血"，而非"高钾危急值"。但若报告明确标注"无溶血"或伴 ECG 改变、肾功能异常，则按真性高钾处理。

## 二、生理时相与状态

### 2.1 进食状态

| 状态 | 受影响指标 | 影响方向 |
|---|---|---|
| **非空腹** | TG↑↑（可虚高 30~50%）、血糖↑、胰岛素↑ | 显著假性升高 |
| 空腹时间过长（>16h） | 游离脂肪酸↑、酮体↑、血糖↓、胆红素↑ | 偏差 |
| 高脂餐后 | TG↑↑、ALT 轻↑ | 假性升高 |
| 大量饮水后 | 尿比重↓、尿液指标稀释 | 假性偏低 |

> **TG 判读铁律**：非空腹的 TG 不能用于诊断高甘油三酯血症。必须确认空腹 8~12 小时。

### 2.2 运动与体力活动

| 状态 | 受影响指标 | 影响 |
|---|---|---|
| **前 1~3 天力量训练/剧烈运动** | **CK↑↑↑、AST↑、ALT↑、LDH↑、肌酐↑、尿酸↑、肌红蛋白↑** | 可升高数倍至数十倍 |
| 马拉松等极限运动 | 上述 + 尿蛋白↑、镜下血尿 | 显著异常 |
| 长期久坐 | HDL-C↓、TG↑ | 真实影响 |

> **CK 升高的第一反问**：最近有没有做力量训练？健身人群 CK 升至 500~2000 U/L 极常见，与心肌损伤无关。鉴别看 CK-MB 占比与 cTn（心肌特异）。

### 2.3 女性生理周期与妊娠

| 状态 | 受影响指标 |
|---|---|
| 月经期 | Hb↓、铁蛋白↓、CA125↑、尿液红细胞污染 |
| 排卵期 | 雌激素/LH 波动，激素判读需明确周期日 |
| 妊娠期 | ALP↑↑（胎盘源）、D-二聚体↑、Hb↓（血液稀释）、TSH 区间下移、AFP↑、CA125↑、eGFR↑ |
| 哺乳期 | 泌乳素↑↑ |
| 绝经后 | ALP↑、血脂↑、骨密度↓ |

> **妊娠期报告必须用孕期专用区间**。用普通成人区间判读孕妇报告是严重错误。

### 2.4 昼夜节律与季节

| 指标 | 节律特征 |
|---|---|
| 皮质醇 | 晨 8 时最高，午夜最低。**必须记录采血时间**，否则无法判读 |
| 睾酮 | 上午偏高，需晨起采血 |
| TSH | 夜间偏高，晨起较低 |
| 血压 | 晨峰、夜间低谷 |
| 铁 | 晨高夜低，波动可达 30% |
| 维生素 D | 冬季普遍偏低（日照少） |

### 2.5 其他生理状态

| 状态 | 影响 |
|---|---|
| 应激/急性病/术后 | CRP↑、WBC↑、血糖↑、白蛋白↓、低 T3 综合征、TG↓ |
| 睡眠剥夺 | 血糖↑、胰岛素抵抗↑、CRP↑ |
| 脱水 | Hb↑、Cr↑、尿酸↑、Hct↑（浓缩效应） |
| 高原居住 | Hb↑、RBC↑（生理性适应） |
| 吸烟 | WBC↑、Hb↑、CEA↑、HDL-C↓ |
| 饮酒（近期） | GGT↑、AST↑、TG↑、尿酸↑、MCV↑ |

## 三、药物与补充剂干扰

### 3.1 常见药物

| 药物 | 受影响指标 | 影响 |
|---|---|---|
| **他汀类** | CK↑、ALT↑ | 需监测，多数为轻度且可耐受 |
| **二甲双胍** | 维生素 B12↓、乳酸↑ | 长期服用需监测 B12 |
| **糖皮质激素** | 血糖↑、WBC↑（中性↑淋巴↓）、K⁺↓、骨密度↓ | 显著影响 |
| **利尿剂**（噻嗪类） | K⁺↓、Na⁺↓、尿酸↑、血糖↑、钙↑ | 常见 |
| **ACEI/ARB** | K⁺↑、Cr 轻↑（初期正常反应） | 起始 2 周内 Cr 升高 <30% 属可接受 |
| **口服避孕药/雌激素** | TG↑、凝血因子↑、D-二聚体↑、TBG↑、铁↓ | 显著 |
| **甲状腺素** | TSH↓、FT4↑（需按服药时间判读） | 服药后 4h 内采血 FT4 偏高 |
| **华法林** | INR↑、PT↑ | 治疗目标 INR 2~3 |
| **质子泵抑制剂** | 胃泌素↑、B12↓、镁↓ | 长期服用 |
| **别嘌醇/非布司他** | 尿酸↓（治疗效应，非病情好转） | 需结合服药史 |
| **抗癫痫药** | GGT↑、ALP↑、叶酸↓ | 酶诱导作用 |
| **非甾体抗炎药** | Cr↑、K⁺↑、尿酸↑ | 肾灌注影响 |
| **SGLT-2 抑制剂** | 尿糖阳性（药理作用非病情）、Cr 初期轻↑ | **尿糖阳性不代表血糖失控** |

### 3.2 保健品与补充剂（易被忽略）

| 补充剂 | 干扰 |
|---|---|
| **生物素（维生素 B7、美容片）** | **严重干扰甲功、cTn、激素等免疫检测**，可致 TSH 假性降低、FT4 假性升高，误诊为甲亢。需停用 1 周复查 |
| 大剂量维生素 C | 尿糖假阴性、便隐血假阴性、尿酸偏差 |
| 铁剂 | 便隐血假阳性、血清铁↑ |
| 红曲/纳豆制品 | 类他汀效应，可致 CK↑、ALT↑ |
| 蛋白粉/肌酸 | 肌酐↑、尿素氮↑、CK↑ |
| 中药（部分） | ALT/AST↑（药物性肝损） |
| 大剂量维生素 B 族 | 尿色深，影响尿液比色 |

> **生物素干扰是当代高频陷阱**。美容类保健品普遍含高剂量生物素，遇"甲亢样"甲功结果（TSH↓ + FT4↑）但无症状者，必须问是否服用相关保健品。

## 四、个体差异因素

| 因素 | 影响 |
|---|---|
| **肌肉量大**（健身人群） | 肌酐基线高 → eGFR 被低估。看胱抑素 C 更准 |
| **肌肉量少**（老年、消瘦、截肢） | 肌酐偏低 → eGFR 被高估，可掩盖肾功能下降 |
| 老年人 | eGFR 生理性下降、ALP↑、白蛋白↓、免疫指标偏低 |
| 儿童/青少年 | ALP↑↑（生长期骨源）、区间与成人完全不同 |
| 素食者 | B12↓、铁↓、同型半胱氨酸↑ |
| 高蛋白饮食 | 尿素氮↑、尿酸↑、尿钙↑ |
| 遗传性良性异常 | Gilbert 综合征（间接胆红素轻度↑，终生良性）、良性家族性血小板减少 |
| 种族差异 | 非洲裔肌酐基线高、白细胞基线低（良性种族性中性粒细胞减少） |
| BMI 极端 | 肥胖者 CRP↑、维生素 D↓、eGFR 计算偏差 |

## 五、方法学与实验室因素

| 因素 | 影响 |
|---|---|
| 不同检测平台 | **甲功、肿瘤标志物、激素跨机构不可直接互比** |
| 试剂盒批次变更 | 同一医院不同时期结果可能有系统性偏移 |
| 参考区间来源不同 | 报告区间不同不代表数值有问题 |
| 单位制不同 | 见 unit_reference.md。最高频误读源 |
| 稀释检测 | 极高值需稀释后测，可能有偏差 |
| 干扰抗体（HAMA、异嗜性抗体） | 免疫检测假性升高，罕见但存在 |
| 巨 TSH / 巨泌乳素 | 生物无活性但检测升高，需特殊处理确认 |

## 六、强制排查清单（按异常项类型）

发现以下异常时，**必须**先问对应问题：

| 异常项 | 必问 |
|---|---|
| **K⁺↑** | 标本有无溶血？LDH 是否同步升高？有无服 ACEI/ARB、保钾利尿剂？ |
| **CK↑** | 近 3 天有无剧烈运动/力量训练？在服他汀或红曲？有无肌痛？ |
| **肌酐↑** | 肌肉量如何？近期蛋白粉/肌酸？脱水？服 NSAID？ |
| **TG↑** | 是否空腹 8~12h？近期饮酒？服避孕药/雌激素？ |
| **ALT/AST↑** | 饮酒？在服药/中药/保健品？体重与超声脂肪肝？近期运动？ |
| **甲功异常** | **有无服生物素类保健品？** 服甲状腺素？采血时间？近期重病？ |
| **PLT↓** | 有无出血倾向？血涂片是否见血小板聚集？（EDTA 假性减少） |
| **Hb↓** | 女性是否月经期？有无黑便/血便？素食？ |
| **尿酸↑** | 近期高嘌呤饮食/饮酒？服利尿剂？脱水？ |
| **尿糖阳性** | 是否服 SGLT-2 抑制剂？血糖是否正常？ |
| **CA125↑** | 女性是否月经期？有无子宫内膜异位/腹腔炎症？ |
| **PSA↑** | 近期骑车/射精/直肠检查？有无前列腺炎症状？ |
| **D-二聚体↑** | 妊娠？近期手术/外伤？高龄（生理性升高）？ |
| **WBC↑** | 应激/急性感染？服激素？吸烟？ |

## 七、输出模板（陷阱排查段）

```
【干扰因素排查】

已排除：
  ✓ 标本溶血 —— 报告标注「无溶血」，且 LDH 正常，高钾为真性
  ✓ 近期剧烈运动 —— 用户确认近两周无力量训练，CK 升高非运动所致

待排除（需用户确认或补充检查）：
  ? 生物素干扰 —— 请确认近 1 周是否服用含维生素 B7 的美容/复合维生素类保健品。
    若有，建议停用 1 周后复查甲功，当前「甲亢样」结果可能为检测干扰
  ? 空腹状态 —— TG 3.8 mmol/L 的判读依赖空腹。若本次为非空腹采血，
    实际水平可能低 30~50%，建议规范空腹复查后再定论

未获取信息（影响判读精度）：
  - 采血具体时间（皮质醇判读必需）
  - 完整用药与保健品清单
```

---

## 边界

- 陷阱排查的目的是**提高判读精度**，不是否认异常。排除干扰后仍异常的项，按正常流程走随访分级。
- 不能因"可能是干扰"而降低危急值的处置等级。危急值命中优先，排查在后。
- 无法确认干扰因素时，如实标注「待排除」并列出需要用户提供的信息，不臆断。
