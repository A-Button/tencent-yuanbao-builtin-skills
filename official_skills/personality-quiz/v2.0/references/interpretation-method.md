# 跨体系解释

用于导入盘面与明确的体系比较；普通内置八字／西占直接用各自方法，不必另读本文件。

把可读盘面事实、传统解释规则和对用户情境的推断分清。事实来自引擎或用户明确提供的材料，规则是解释框架，不能把两者写成已经发生的个人经历。用户反馈可以帮助调整解释，不能倒过来改盘或挑选未知候选。

围绕用户问题说明：哪些配置相关，它们如何形成当前判断，有哪些条件或反向信号。用具体含义代替关键词堆叠；没有支持的主题留空，不强制每条都有建议、校准问题和优缺点配对。共同边界复用 [safety.md](safety.md)。

## 口径与精度

- 日期级、范围盘只解释稳定字段，不从候选中挑“最像”的一个。
- 复用用户材料的流派与时间口径；有冲突时区分条件，不能拼接成更强断言。资料不足以支持的问题只说明限制。
- 八字关注历法、时制、换日与起运口径；西占关注黄道、宫制、实际相位及引擎范围；紫微关注流派／四化、安星配置与时间层；印度占星关注 ayanamsha、宫制、分盘与大运口径。只核对会影响当前问题的项目，不把这份列表变成逐项问卷。
- 排盘软件和书目并不自动保证解释正确。精确引文、冷门规则或版本争议才读 [source-registry.md](source-registry.md)。
