# 塔罗体系调研与牌义/案例库设计

## 用途

本文供塔罗牌库、即时基础牌义、智能助手解读和后续案例检索升级时使用。它不是要证明塔罗具有预测效力，而是让内容口径可识别、可追溯、不会把不同传统混成一套。

## 结论先行

1. 塔罗没有跨牌组、跨流派统一的“官方定义”。产品界面应使用“韦特—史密斯基础牌义”“本牌组传统释义”或“来源牌义”，不要写“官方牌义”。
2. 当前默认继续采用 Rider–Waite–Smith（RWS）传统。RWS 的 78 张结构、全图像小阿尔卡那和大量衍生牌组，使它最适合中文大众产品的第一套完整内容。
3. Marseille、Thoth 和 Etteilla 不是 RWS 的补充词典。它们的编号、图像、宫廷牌、对应关系或读法不同；未来支持时必须使用独立 `tradition_id` 和独立语料库。
4. 牌面先展示可追溯的标准层，再进入情境解释。案例只能帮助“把牌义放回问题”，不能反过来改写牌的基础资料。
5. 经典著作适合作为来源和方法参照，不宜直接抓取成大段案例库。现代著作多受版权保护，应保存书目、页章指针和团队短摘要；真实用户案例须取得同意并彻底去标识化。

## 历史边界

塔罗最初是牌戏。V&A 的馆藏综述把常见 78 张结构概括为 22 张王牌和 56 张花色牌，并指出占卜用途到 18 世纪后期才明确出现；“源自古埃及”的说法缺乏历史证据。产品不应把后来的神秘学对应描述成 15 世纪牌面自带的古老事实。

历史、牌组和解释方法是三个不同层次：

- 历史牌型说明一副牌长什么样、如何编号；
- 神秘学体系添加占星、赫尔墨斯卡巴拉、元素等对应；
- 现代读法再加入心理、自我反思、叙事或教练式问题。

把三者分层标注，会比堆叠术语更显专业。

## 主流体系比较

| 体系 | 关键特征 | 与当前产品的关系 | 建议 |
|---|---|---|---|
| Rider–Waite–Smith（RWS，1909/1910） | 78 张；小阿尔卡那数字牌使用完整叙事场景；力量 VIII、正义 XI；宫廷牌为 Page、Knight、Queen、King | 当代英语世界及大量现代衍生牌的共同基础，用户识别度最高 | 作为默认且唯一启用的 `rws` 传统；先做完整来源审校 |
| Tarot de Marseille（马赛体系） | 78 张历史牌型家族；小阿尔卡那通常是非叙事点数牌；正义 VIII、力量 XI；钱币而非 RWS 式 Pentacles 命名 | 视觉、数字、排列和开放式读图比固定情节更重要；并不存在一套所有马赛读者都承认的逐牌“官方牌义” | 未来作为 `marseille` 独立模式；不可套用 RWS 小牌故事或逆位词典 |
| Golden Dawn（黄金黎明） | 更像一套对应关系与解释架构：希伯来字母、占星、元素、生命之树、元素尊贵等；深刻影响 RWS 与 Thoth | 可提高结构深度，但也最容易产生“术语很多、来源混乱”的假专业 | 默认不展示；只在 `rws-gd` 等明确资料层启用，并逐项记录来源 |
| Thoth（托特） | Crowley 设计、Frieda Harris 绘制；Adjustment VIII、Lust XI、Art、Aeon、Universe 等改名；宫廷牌为 Knight、Queen、Prince、Princess；数字牌带标题及占星/卡巴拉结构 | 与 RWS 同源于黄金黎明背景，但不是 RWS 换皮；常用相邻牌的尊贵/失势而非一套机械逆位词典 | 未来作为 `thoth` 独立模式；先解决版权、版本和术语翻译 |
| Etteilla / Grand Etteilla | 18 世纪末第一批为占卜专门设计的塔罗体系；重排牌序，并为正逆位配置明确占卜词汇和占星/元素对应 | 历史上非常重要，今天的大众辨识度低，结构也不兼容 RWS | 作为历史与逆位方法来源登记；非默认产品牌组 |
| 现代心理/自我反思式塔罗 | 强调象征、投射、叙事、校准问题和自主决策 | 这是应用方法，不是一副牌，也不是古典共识 | 继续作为智能助手的解释政策；必须和“传统牌义”分栏 |

Visconti–Sforza 等早期意大利牌具有重要历史和艺术价值，但不是现成的现代占卜词典。Lenormand、Oracle cards、playing-card cartomancy 也不属于塔罗 78 张体系，不能混入同一牌库。

## 为什么不能直接展示“Waite 官方定义”

Waite 的 *The Pictorial Key to the Tarot*（1911）是 RWS 最重要的一手文本，但书内至少有三种不同性质的材料：

1. Pamela Colman Smith 画面的可观察描述；
2. Waite 对大阿尔卡那的神秘/宗教象征解释；
3. 面向占卜的正位、逆位词表和牌阵方法。

这三层不能合并成一行关键词。Waite 自己承认部分占卜分配高度人为；同一张牌的象征章节和占卜词表有时也不一致。例如星星牌在现代常见的“希望”主轴与 Waite 占卜列表中的负面候选并列。原书还包含按年龄、性别、发色和肤色选择宫廷牌等过时规则，不能无筛选地包装成当代标准。

因此，建议把 Waite/Smith 作为“一手来源”，再由团队形成标明版本的中文标准摘要，而不是声称逐字照搬“官方释义”。

## 用户先看到什么

当前聚焦抽牌界面在翻牌后只显示牌面、三个专属关键词和一条与朝向对应的完整展示句，并保留复制牌面信息与重新抽牌两个动作。展示句属于团队标准层，不读取用户问题，因此可以和牌面同时出现；问题相关的判断仍由智能助手完成。

完整资料继续保留在数据和交接消息中，包括：

1. 中文牌名；
2. 体系：`韦特—史密斯体系`；
3. 大/小阿尔卡那、编号，或花色与点数/宫廷级别；
4. 本局朝向：正位或逆位；
5. 3—5 个**该牌专属**关键词；
6. 一句标准母题；
7. 2—4 个能从本牌图像中直接看到的视觉锚点；
8. 本局朝向的核心短义与完整展示句；深度解读时再选择逆位机制；
9. 来源徽标，例如 `《塔罗图解钥匙》（1911）｜团队中文编辑版 1.0`。

随后再分开显示：

- `位次作用`：这张牌在“情况/障碍/建议”等位置回答什么；
- `结合问题的解释`：从标准层和案例层生成的现实映射；
- `替代表现/校准问题`：避免把一种解释写成唯一事实；
- `可逆行动`：仍由用户做决定。

推荐界面文案：

```text
力量 VIII · 正位
韦特—史密斯体系｜大阿尔卡那

传统牌义：勇气、耐心、温和而坚定的自我掌握
标准母题：用持续的内在稳定承接本能、压力或冲动，而非靠压制取胜。
图像锚点：人物与狮子、花环、无限符号
来源：《塔罗图解钥匙》（1911）｜团队中文编辑版 1.0

本局位次：障碍
情境解释：……
```

“传统牌义”不等于对现实的结论；这条边界应在视觉层级上明确。

## 四层内容模型

### A. 原始来源层 `source_claim`

只保存来源确实主张或画面确实可见的内容：

- 来源、版本、章节/牌页；
- 原文短摘或团队释义；
- `claim_type`：`image_observation`、`symbolic_commentary`、`divinatory_meaning`、`correspondence`、`method`；
- 适用体系；
- 版权/许可和复核状态。

不要把模型记忆写成原文，不要把现代网络关键词反向署名给 Waite、Smith 或 Crowley。

### B. 团队标准层 `editorial_standard`

这是产品真正展示的“基础牌义”：

- 综合一手来源、画面和已选现代经典资料；
- 使用团队自己的短句；
- 保留冲突和少数派含义，但不把互相矛盾的词全部堆出；
- 每条都要有 `editorial_version`、`source_refs`、`review_status`；
- 不含用户情境、不预测外部事实。

### C. 案例层 `interpretation_case`

记录“标准牌义在什么条件下可以映射成哪种现实解释”。案例不是新牌义，也不是事实预测。

### D. 生成层 `reading_output`

只引用已翻牌面、位次、用户问题、标准层和入选案例。输出中能够解释每个核心判断来自哪张牌、哪个位次和哪种关系；案例原文不得直接拼接给用户。

## 逆位模型

逆位没有一套跨流派统一规则。当前的“受阻、内化、过量、延迟、正在松动”方向比“正位的负面反义词”更接近现代专业读法，但数据结构应调整为：

- 每张牌保留一个稳定的正位主题；
- 为五种逆位机制分别写短句；
- 解读时根据位次、问题和相邻牌选择一至两个机制；
- UI 标明“本局按：受阻”之类的解释选择；
- 不把逆位固定等同于坏事，也不把正位固定等同于好事。

是否使用逆位本身也是读牌政策。当前 42% 的逆位概率是产品内部参数，不是 RWS 标准，应记录为 `draw_policy`，不能作为传统知识展示。

## 案例库的正确单位

不要把一整篇占卜回答只存成向量。建议同时维护四种粒度：

1. `single-card-context`：某牌、朝向和主题下的典型现实表现；
2. `position-example`：某牌落在情况、障碍、建议等位置时如何改变句法；
3. `relation-example`：两张或多张牌的加强、冲突、转向、补偿；
4. `full-reading-case`：完整问题、牌阵、候选、反证、校准和行动。

每个案例至少包含：

## 案例来源分级

优先顺序：

1. **公版一手资料**：保存短摘、页章和团队摘要；适合标准层，不一定有现代真实案例；
2. **经典现代著作**：Rachel Pollack、Mary K. Greer、Yoav Ben-Dov 等只登记书目、适用方法和团队短摘要；未获授权不复制大段正文或案例；
3. **团队编写标准案例**：根据已复核标准层构造，最适合可控覆盖；必须有反向信号和校准问题；
4. **获同意的匿名真实案例**：只用于补充语言与情境分布；单独保存同意、去标识化和撤回状态；
5. **模型自动合成案例**：只能是待审候选，不能未经人工复核直接进入生产检索。

不要把互联网上来源不明的“78 张牌义大全”批量抓取为权威库。

## 检索与排序

基础牌义不走向量检索：按 `tradition_id + card_id + editorial_version` 确定性读取。只有情境案例进入检索。

先硬过滤：

- 体系一致；
- 牌面均已翻开；
- 许可允许生产使用；
- 已通过内容与安全复核；
- 高影响问题不进入预测式案例；
- 语言和产品版本兼容。

再进行混合排序，建议初始权重：

| 信号 | 权重 |
|---|---:|
| 用户问题的语义与问题模式 | 24% |
| 牌面重合度（加权 Jaccard） | 22% |
| 位次一致性 | 14% |
| 主题/子主题一致性 | 10% |
| 朝向与逆位机制 | 10% |
| 牌间关系模式 | 8% |
| 牌阵类型 | 5% |
| 人工质量与低 Barnum 风险 | 7% |

精确三牌组合通常很稀疏，按以下顺序回退：完整组合 → 两牌关系 → 同牌同位次同主题 → 同牌同主题 → 同花色/数字/阶段模式。回退必须在结果中可追踪，不能把“相似花色案例”说成这组三牌的经典定论。

检索前八名后，用最大边际相关或等效方法去重，选 3—5 条：限制同一来源最多两条，至少保留一个替代表现或反例。智能助手先形成 2—4 个候选解释，再按用户情境相关性排序；不得把最高相似案例整段改写成唯一结论。

## 质量门

逐牌内容进入生产前至少检查：

- 78 张 id、编号、花色、宫廷级别完整且不重复；
- 体系字段一致，没有 RWS/Marseille/Thoth 静默串库；
- 视觉锚点能在实际牌图中定位；
- 每条展示内容有来源和编辑版本；
- 正逆位不是机械好/坏二分；
- 解释候选包含适用条件与反向信号；
- 案例没有个人身份信息、未经许可的长摘和高影响预测；
- 用盲测检查通用套话：只看回答、不看用户问题时，评审应能区分至少一部分问题主题；
- 同一输入可复现同一标准层与案例检索结果，模型只负责情境组织。
