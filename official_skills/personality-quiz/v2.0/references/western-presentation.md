# 西洋星盘结果页与交付

修改西洋星盘 HTML 或排盘后的默认展示时读取。`chart` 层级把计算确定的盘面事实、太阳简述和四项简短标签渲染为单文件 HTML；对配置关系与用户问题的分析由模型读取去身份化分析盘，在同一回复正文中完成。HTML 不展示五项详细解读卡。

## 页面内容

固定显示太阳主项及上升、月亮、金星、水星四项速览。首屏沿用 MBTI 报告的浅绿背景、白色圆角主卡、衬线星座名和透明元宝；速览是浅底分组卡。太阳主项显示已确定的星座名、元宝和一段简短完整的 `summary`，其中经过校验的重点短语保留绿色下划线；不显示此前用户标红要求删除的“你的星座”、功能标签或短注。四项速览显示天体名、已确定的星座名及原有短标签；未确定或跨界时显示候选范围与简短原因，不分配趣味标签。没有性格底色、初见印象等预置详细解读卡，也没有跳转到这些卡片的链接。小标题不加装饰下划线；主视觉与速览之间保持紧凑间距。

页面不展示出生资料行、十天体全表、度数、坐标、相位、宫位、重复导读、底部说明或“本次省略”。原始盘面仍保留计算字段；显示范围不限制普通技术分析的数据范围。地点来源和许可保留在数据与 HTML 元信息中。组合盘保留八字区域原有的标题、资料和说明。

样式集中在 `assets/zodiac-result.css` 并内联到单文件 HTML。桌面端速览为两列；手机端主视觉和速览单列，文字保持可读，不横向滚动。元宝静止，无运行时网络请求。星座名称用本机 CJK 衬线字体，其余信息用本机黑体。

独立星座页提供“复制给元宝”和“保存或分享图片”。沿用同工作空间 MBTI 报告的右对齐操作区、浅灰次按钮与深色主按钮、12px 圆角、底部 toast 和圆角弹窗。复制内容只含已核验的位置与待定原因，标记为 `WESTERN_CHART_RESULT_V1`，不复制出生资料、短标签或预置简述；成功时 toast 提示可粘贴给元宝，自动复制失败时提供手动全选弹窗。分享与保存由用户点击后才用随包内联的 `html2canvas` 在本地把星盘卡导出为 PNG，不发送出生资料或盘面到网络；图片在统一弹窗中展示，手机底部提示长按图片保存或分享，PC 底部提供下载图片及右键保存提示；不通过网页按钮调用原生分享。详细行为见 [image-save-share.md](image-save-share.md)。图片只含页面展示的太阳简述与四项事实／短标签，不加底部说明，也不声称包含聊天中的模型分析；图像生成失败不得显示成功状态。组合盘不显示星座独立操作，保留原组合交付。

## 十二星座元宝

十二张 RGBA PNG 位于 `assets/yuanbao-zodiac/`，`manifest.json` 固定文件、尺寸与 SHA-256。仅当五项投影中 `key=sun` 且 `status=available`，`scripts/western_mascots.py` 才选择该星座的一张；准确盘与日期级稳定太阳均可显示。太阳跨界或未知时不挑代表图。渲染前验证映射、格式、哈希与尺寸，仅内联选中的一张；不联网加载，也不将十二张全部打包。图片使用空替代文本，因为相邻标题已写出太阳星座。

角色沿用 MBTI 元宝的绿色本体、白色脸窗、黑色简眼和圆润漂浮手脚；小道具分别是白羊卷角、金牛牛角、双子对话气泡、巨蟹螃蟹抱枕、狮子鬃毛、处女麦穗、天秤天秤、天蝎蝎尾、射手玩具弓、水瓶水壶、双鱼双鱼饰、摩羯山峰。道具只用于识别图像，不作为人格判断。

## 事实边界

准确时间盘从已计算的 `chart.planets` 与 `chart.ascendant` 读取；日期级只读取 `chart.stable.planet_signs`；范围盘只读取 `chart.stable.planet_signs` 与实际存在的 `chart.stable.ascendant.sign`。不能从太阳、候选、用户自述或时辰名称推上升。跨星座项可列候选范围及不确定原因，不能挑一个确定值。缺地点或超出上升计算范围时保留状态和具体原因。所有动态文字转义。

`scripts/western_profile.py` 仍负责五项事实投影。结果页只读取 `western_profiles.json` 的太阳 `summary` 与四项 `tagline`；各项 `detail` 不进入 HTML。太阳重点短语由 `western_emphasis.py` 安全加粗并画细下划线。深报事实投影调用 `include_copy=False`，不加载预置文案。标签和页面简述都不作为模型分析证据。

## 同回复分析与后续报告

普通排盘的 `chart_quick.py` 在 `before_delivery` 提供已核验的 `analysis_charts.western` 和用户原问题。模型按 [western-report.md](western-report.md) 在回复正文给出有依据的概要与简要分析，再原样附 `media_info`，整份草稿运行 `verify_command`，通过后一次发出。用户明确要求只看盘面时 `include_summary=false`，仅附 HTML。用户直接要求结论或分析时，按所需深度写正文，仍与 HTML 同次交付；无需另启一个模型阶段。交付后的主题选择和深报沿用 [chart-flow.md](chart-flow.md)；深报只投影五项中已确定星座，章节依问题自由组织。
