# 影像与专科分级体系

> **核心原则**：影像报告是**描述型**，不能套用检验单的「数值比区间」逻辑。
> 重点读**「结论」与「建议」段**，套用分级体系给出恶性概率区间与处置指引。
> **绝对禁止**：判定结节良恶性。分级只给概率区间，性质判定必须依据病理。

---

## 一、乳腺 BI-RADS

> 数据源：中国抗癌协会《中国居民肿瘤防筛核心科普知识（2026）》+ ACR BI-RADS 第5版

| 分级 | 含义 | 恶性风险 | 处置 |
|---|---|---|---|
| **0** | 评估不完整 | 无法评价 | 需补充检查（钼靶/MR/超声互补） |
| **1** | 阴性 | 0% | 常规年度筛查 |
| **2** | 明确良性 | 0% | 定期随访 6~12 个月 |
| **3** | 可能良性 | **≤ 2%** | 6 个月复查；连续 2~3 年稳定可降为 2 类 |
| **4A** | 低度可疑 | **2% ~ 10%** | 建议活检；不愿活检可 3 个月短期随访 |
| **4B** | 中度可疑 | **10% ~ 50%** | 强烈建议穿刺病理 |
| **4C** | 高度可疑 | **50% ~ 95%** | 必须穿刺，完善术前评估 |
| **5** | 高度提示恶性 | **≥ 95%** | 立即组织病理学检查 |
| **6** | 已病理确诊 | 100% | 规范化治疗 |

### 判读要点

- **4 类跨度极大**（2%~95%），必须细分到 4A/4B/4C。笼统说"4 类可疑恶性"是重大误导。
- **4A 类中超过 90% 最终证实为良性** —— 输出时应主动说明此点以缓解焦虑，但不可因此劝阻活检。
- 3 类以下无需穿刺，避免过度治疗；4 类及以上不可拖延，避免延误。
- 随访分档：BI-RADS ≥4 → **L2（两周内专科）**；BI-RADS 3 → **L3（6 个月复查）**；1~2 类 → **L4**。

## 二、甲状腺 TI-RADS

> 注：TI-RADS 存在多个版本（C-TIRADS 中国版、ACR TI-RADS、Kwak TI-RADS），各版本 4c 恶性率上限口径有差异（50~80% / 50~85% / 50~90%）。本表取临床通用区间，输出时以报告采用的具体体系为准。

| 分级 | 含义 | 恶性风险 | 处置 |
|---|---|---|---|
| **1** | 正常，无结节 | 0% | 常规体检 |
| **2** | 良性（纯囊性、海绵状、粗大钙化） | 0% ~ <2% | 年度复查 |
| **3** | 可能良性 | **2% ~ 5%** | 6~12 个月复查超声 |
| **4A** | 低度可疑（1 项可疑征象） | **5% ~ 10%** | 建议穿刺或 3~6 个月短期复查 |
| **4B** | 中度可疑（1~2 项恶性特征） | **10% ~ 50%** | 建议细针穿刺（FNAB） |
| **4C** | 高度可疑（3 项及以上恶性征象） | **50% ~ 90%** | 必须穿刺，准备手术评估 |
| **5** | 高度可疑恶性（≥4 项特征 + 可疑淋巴结） | **> 90%** | 尽快穿刺或手术 |
| **6** | 病理已证实恶性 | 100% | 规范手术治疗 |

### 恶性征象清单（用于核对分级合理性）

微钙化、边界不清/模糊、形态不规则、**纵横比 > 1**（"立着长"）、显著低回声、实性成分为主、血流紊乱、侵犯包膜、颈部可疑淋巴结。

### 关键提示

- **3 类小结节盲目手术是典型过度治疗**，术后易致终身甲减需长期激素替代。输出时应明确提示此风险。
- 结节大小不等于危险程度。1 cm 的 4C 比 3 cm 的 2 类危险得多。
- 穿刺决策还需结合结节大小（通常 ≥1 cm 才建议穿刺，除外高危征象）。
- 随访分档：TI-RADS ≥4 → **L2**；3 类 → **L3（6~12 月）**；1~2 类 → **L4**。

## 三、肺结节 Lung-RADS 与随访

| 分级 | 描述 | 恶性风险 | 处置 |
|---|---|---|---|
| **1** | 阴性 | < 1% | 12 个月后 LDCT |
| **2** | 良性表现 | < 1% | 12 个月后 LDCT |
| **3** | 可能良性 | 1% ~ 2% | 6 个月复查 LDCT |
| **4A** | 可疑 | 5% ~ 15% | 3 个月复查或 PET-CT |
| **4B** | 高度可疑 | > 15% | 胸部增强 CT / PET-CT / 活检 |
| **4X** | 4B 伴附加可疑征象 | > 15% | 同 4B，优先处理 |

### 按结节类型与大小的随访建议

| 类型 | 大小 | 随访 |
|---|---|---|
| 实性结节 | < 6 mm | 无需常规随访（低危）；高危者 12 个月 |
| 实性结节 | 6~8 mm | 6~12 个月复查 |
| 实性结节 | > 8 mm | 3 个月复查 / PET-CT / 活检 |
| 部分实性 | 实性成分 < 6 mm | 6~12 个月 |
| 部分实性 | 实性成分 ≥ 6 mm | 3 个月复查，考虑活检 |
| 纯磨玻璃 GGN | < 6 mm | 无需常规随访 |
| 纯磨玻璃 GGN | ≥ 6 mm | 6~12 个月，后每 2 年 |

### 恶性征象

毛刺/棘状突起、胸膜牵拉、支气管截断、偏心空泡、血管集束、倍增时间 30~400 天、实性成分增加。

> **重要**：磨玻璃结节生长缓慢，**短期不变化不能排除**，需长期随访。多发小结节多为炎性/陈旧灶。

## 四、肝脏

### 4.1 脂肪肝超声分级

| 分级 | 表现 | 处置 |
|---|---|---|
| 轻度 | 肝回声增强，血管纹理清晰 | 生活方式干预，6~12 月复查 |
| 中度 | 回声增强，血管纹理模糊 | 干预 + 查 ALT/血脂/血糖 + FIB-4 |
| 重度 | 回声显著增强，深部衰减，血管难辨 | 需肝病科评估，排除纤维化 |

### 4.2 肝纤维化无创评估

| 方法 | 指标 | 阈值 |
|---|---|---|
| **FIB-4**（`calc.py fib4`） | 年龄/AST/ALT/PLT | <1.30 低风险；1.30~2.67 中间区；>2.67 高风险 |
| APRI | AST/PLT | >1.5 提示显著纤维化 |
| 弹性成像 LSM（FibroScan） | kPa | <7 无/轻度；7~10 中度；10~14 重度；>14 疑肝硬化 |
| CAP（脂肪定量） | dB/m | >248 提示脂肪肝 |

### 4.3 肝脏 LI-RADS（用于肝癌高危人群）

| 分级 | 含义 |
|---|---|
| LR-1 | 明确良性 |
| LR-2 | 可能良性 |
| LR-3 | 中度可能性 |
| LR-4 | 可能肝癌 |
| LR-5 | 明确肝癌 |
| LR-M | 恶性但非肝癌特异 |

> LR-4 及以上 → **L2**，需肝胆专科。

## 五、骨密度（DXA · T 值）

| T 值 | 判定 | 处置 |
|---|---|---|
| ≥ −1.0 | 正常 | 常规钙 + 维生素 D + 负重运动 |
| −1.0 ~ −2.5 | **骨量减少（骨质疏松前期）** | 干预 + 1~2 年复查，评估骨折风险（FRAX） |
| ≤ −2.5 | **骨质疏松** | 内分泌/骨科，需药物干预评估 |
| ≤ −2.5 + 脆性骨折 | 严重骨质疏松 | 必须治疗 |

### 判读要点

- **T 值用于绝经后女性与 50 岁以上男性**；儿童、青年、绝经前女性用 **Z 值**（≤ −2.0 为"低于同龄预期"）。
- 部位取腰椎、股骨颈、全髋中**最低值**。
- 骨量减少不是"还没病"，是**干预窗口期**，此时干预效果最好。

## 六、颈动脉超声

| 表现 | 意义 | 处置 |
|---|---|---|
| 内膜增厚（IMT ≥1.0 mm） | 早期动脉粥样硬化 | 血脂血糖血压干预，LDL-C 目标下调 |
| 斑块形成（IMT ≥1.5 mm 或局部凸起） | **明确动脉粥样硬化，属 ASCVD 亚临床证据** | **危险分层升级至高危，LDL-C 目标 <2.6 或更严** |
| 狭窄 < 50% | 轻度 | 强化内科干预 |
| 狭窄 50%~70% | 中度 | 血管外科/神经内科评估 |
| 狭窄 > 70% | 重度 | **L2**，需专科评估干预指征 |
| 易损斑块（低回声、溃疡、不规则） | 卒中风险高 | 专科评估 |

> **重要联动**：颈动脉斑块 = 亚临床 ASCVD 证据 → LDL-C 危险分层必须升级，目标值下调。这是极高频的漏判点。

---

## 七、心脏超声关键参数

| 参数 | 正常 | 异常意义 |
|---|---|---|
| LVEF（左室射血分数） | ≥ 50% | 40~49% 轻度降低；< 40% 心衰（HFrEF） |
| E/A 比值 | > 1 | < 1 提示舒张功能减低（早期心功能改变） |
| 左房内径 | 男 <40 / 女 <38 mm | 增大提示长期压力负荷 |
| 室壁厚度 | < 11 mm | 增厚提示高血压心脏病/心肌病 |
| 肺动脉压 | < 30 mmHg | 升高提示肺高压 |

> 舒张功能减低在高血压、糖尿病人群极常见，是**早期心脏受累信号**，不应被忽略。

## 八、眼科超声（眼 B 超）

眼 B 超**没有 RADS 类分级体系**，判读靠「回声形态 + 位置 + 后运动 + 与视盘的连接关系」四要素。
**不得自创分级，也不得套用数值比区间逻辑。**

### 8.1 玻璃体内异常回声的鉴别（核心表）

| 回声形态 | 后运动 | 与视盘连接 | 最常见对应 | 处置倾向 |
|---|---|---|---|---|
| 散在**点状**回声，少-中量 | 明显 | 无 | 玻璃体退变 / 玻璃体混浊（老年性最常见） | 年度随访 |
| 点状回声密集、呈团絮状 | 明显 | 无 | 玻璃体积血可能（需查病因） | 两周内专科 |
| **连续细弱带状**回声 | **明显** | **不固定连于视盘** | **玻璃体后脱离（PVD）** | 散瞳眼底 + OCT 评估 |
| 带状回声**较强、增厚** | **受限 / 僵硬** | **固定连于视盘（V 形 / 漏斗形）** | **视网膜脱离（RD）** | **需立即就医** |
| 带状回声强、连于视盘，伴钙化 | 受限 | 固定 | 增殖膜 / 陈旧牵拉 | 两周内专科 |
| 实性隆起，基底宽、内回声不均 | 无 | — | 眼内占位需排除 | **需立即就医** |

> **鉴别三要素记法**：**弱而飘 = 后脱离；强而僵 = 视网膜脱离。** 第三要素「是否固定连于视盘」
> 是区分二者最关键的一条 —— PVD 的带状回声两端游离，RD 的必定固定于视盘。

### 8.2 玻璃体混浊的可能性分层

| 层次 | 解释 | 支持依据 / 需排除手段 |
|---|---|---|
| 最可能 | 年龄相关玻璃体退变（50 岁以上高发） | 点状回声、量少-中、无实性隆起 |
| 需排除 | 玻璃体积血（糖尿病视网膜病变、视网膜血管病、外伤） | 散瞳眼底、眼底照相、必要时荧光造影；同步查血糖与血压 |
| 需排除 | 葡萄膜炎 / 玻璃体炎（炎性细胞） | 裂隙灯查前房细胞、眼压、必要时查炎症指标 |
| 不太可能 | 眼内淋巴瘤等（回声均匀密集、常伴视力显著下降） | 本次未见实性隆起，且量为少-中 |

### 8.3 玻璃体后脱离（PVD）的随访窗口

依据 AAO《Posterior Vitreous Detachment, Retinal Breaks, and Lattice Degeneration》PPP 2024
（基于欧美人群，对中国人群的适用性有限，仅作参考）：

| 情形 | 后续视网膜裂孔风险 | 复查窗口 |
|---|---|---|
| 急性 PVD，眼底未见视网膜裂孔 | 随后数周内约 **2%** 新发裂孔 | **6 周内**复查散瞳眼底 |
| PVD 伴玻璃体色素颗粒 / 出血 / 可见玻璃体视网膜牵拉 | 显著升高 | **1~2 周内**复查 |
| 初诊即发现视网膜裂孔 | 长期随访中 **5%~14%** 再发新裂孔 | 按专科医师安排 |

> **B 超看不到周边视网膜裂孔** —— 这是眼 B 超最重要的方法学局限。
> 提示 PVD 后**必须补散瞳眼底检查（间接检眼镜 / 三面镜 / 广角眼底照相）+ OCT**，
> 否则裂孔与早期视网膜脱离会被漏掉。

### 8.4 症状红旗（出现任一即需当日就诊）

闪光感（眼前闪电样亮光）｜ 飞蚊症骤然增多 ｜ 视野某个方位出现固定黑影或幕帘状遮挡 ｜
视力突然下降 ｜ 眼痛伴视力下降。

> 红旗症状提示可能已发生视网膜裂孔或视网膜脱离。视网膜脱离累及中心视力（黄斑）前修复，
> 视力预后明显更好，因此时间窗是关键。

### 8.5 常见眼科影像描述的正确解读

| 报告描述 | 实际含义 | 处置倾向 |
|---|---|---|
| 玻璃体混浊 | 玻璃体内出现不透明物质的统称，多为年龄相关退变 | 结合量与形态，多为年度随访 |
| 玻璃体后脱离 | 玻璃体后界膜与视网膜分离，50 岁以上常见 | 补散瞳眼底 + OCT |
| 后运动明显 | 眼球转动时回声随之飘动，提示病变**不与视网膜固定相连** | 支持 PVD 而非视网膜脱离 |
| 眶内未见明显异常回声 | 眼球后方眶内结构未见占位、炎性肿块等 | 无需处理 |
| 球壁回声光滑连续 | 未见视网膜/脉络膜脱离的间接证据 | 无需处理 |
| 晶状体回声增强 | 白内障的超声间接表现 | 视力受影响时眼科评估 |

## 九、其他常见影像描述的正确解读

| 报告描述 | 实际含义 | 是否需处理 |
|---|---|---|
| 肝内钙化灶 | 陈旧性病变愈合痕迹 | 无需处理 |
| 肝内低回声/高回声区 | 需结合形态判断，多为血管瘤/局灶脂肪 | 视描述定，多为 L4 |
| 肾结石 < 4 mm | 多可自行排出 | 多饮水，L3~L4 |
| 肾结石 > 6 mm 或伴积水 | 排出困难 | 泌尿外科，L2~L3 |
| 胆囊息肉 < 10 mm | 多为胆固醇性息肉 | 6~12 月复查 |
| 胆囊息肉 ≥ 10 mm 或快速增大 | 恶性风险升高 | 外科评估，L2 |
| 前列腺钙化 | 陈旧炎症痕迹 | 无需处理 |
| 子宫肌瘤 | 常见良性 | 按大小与症状决定，多为 L3~L4 |
| 卵巢囊肿 < 5 cm 单纯性 | 多为生理性 | 下次月经后复查 |
| 甲状腺弥漫性回声改变 | 提示甲状腺炎，需查甲功与抗体 | L3 |
| 淋巴结显示/可见 | 正常结构 | 无需处理 |
| 淋巴结增大 + 形态异常 + 皮髓质分界不清 | 需警惕 | L2 |
| 肺纹理增粗 | 非特异描述，多为陈旧或炎性 | 结合症状，多为 L4 |
| 陈旧性病灶/纤维条索 | 既往炎症愈合 | 无需处理 |

## 十、输出模板（影像段）

```
【影像报告解读】

超声结论：左侧乳腺 10 点钟方向低回声结节，大小 8×6 mm，边界尚清，
        形态欠规则，可见少量血流信号。BI-RADS 4A 类。

分级含义：
  BI-RADS 4A = 低度可疑恶性
  恶性概率区间：2% ~ 10%
  换言之，此类结节最终证实为良性的比例超过 90%

处置建议：
  档位：L2（两周内专科）
  科室：乳腺外科 或 甲乳外科
  项目：建议超声引导下细针/空芯针穿刺活检以明确性质；
       若暂不接受穿刺，需 3 个月短期复查超声对比

重要说明：
  分级只给出恶性概率区间，不等于诊断。结节性质的最终判定必须依据病理。
  4A 类不建议直接手术切除，也不建议拖延观察超过 3 个月。
```

## 边界

- 本文件用于**解读影像报告文字结论**，不用于解读影像图像本身。用户上传影像图片时，明确说明需影像科医师阅片。
- 分级体系版本众多，报告采用的体系（C-TIRADS / ACR / Kwak 等）优先，本表为兜底。
- 分级不是诊断。任何情况下不得表述为"这个结节是良性/恶性的"。
- 报告未给分级时，不要自行推断分级，应建议向出具报告的医师确认。
