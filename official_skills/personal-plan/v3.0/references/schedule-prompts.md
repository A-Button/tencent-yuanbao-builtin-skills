## 1. 推荐门槛

默认不推荐定时任务。只有满足下列至少一项时，才向未主动提出的用户展示可选入口：

| 增量价值 | 判断问题 | 示例 |
|---|---|---|
| 避免明显损失 | 错过时间是否会影响考试、面试、报名或重要阶段？ | 报名截止、面试前检查 |
| 到点需要准备 | 该节点是否需要一份与当时情境匹配的内容？ | 模考说明、复测问题 |
| 产生新信息 | 同一条固定指令到点重新执行，是否能获得新内容？ | 每周查询新增官方岗位 |

以下情况不推荐：

- 只是重复“记得执行计划”；
- 日常任务已在主产物中清楚列出；
- 任务需要读取原计划、历史对话或用户进度才能决定内容；
- 没有明确日期、时间或固定重复条件；
- 用户已表示不需要。

## 2. 数量与频率预算

| 项目 | 默认限制 |
|---|---|
| 首次建议 | 1—3条，优先展示最关键的1条 |
| 一次创建 | 不超过3条 |
| 重复任务 | 同一主目标最多1条 |
| 主动推荐频率 | 默认不高于每周 |
| 每天重复 | 仅在用户明确提出且固定内容每天都有独立价值时使用 |

用户明确要求超过3条时，先展示完整清单和数量，说明任务会占用通知空间；得到明确确认后才创建。不要把数周计划的每个学习日、训练日或投递日转成定时任务。

## 3. 任务类型

| 类型 | 适用情况 | 例子 |
|---|---|---|
| 一次性节点 | 一个高价值时间点 | 报名检查、模考、面试前检查、阶段复测 |
| 少量批量节点 | 2—3个彼此不同的关键节点 | T-2演练、T-1检查；月中测试、月底复测 |
| 固定重复任务 | 每次执行同一条指令仍能产生独立价值 | 每周查询新增官方岗位 |

选择顺序：

1. 能用一条一次性任务解决，不创建重复任务。
2. 有限计划只选择2—3个关键节点，不覆盖全部日程。
3. 只有同一指令长期重复仍有新价值时才使用重复任务。
4. 重复任务不能自动按计划截止日停止时，创建前提醒用户届时手动停止。

## 4. 用户确认

创建前展示：

| 字段 | 要求 |
|---|---|
| 任务名称 | 能看懂为什么需要它 |
| 日期和时间 | 一次性任务给完整日期；重复任务给首次触发时间 |
| 重复方式 | 不重复、每天、每周、每双周、每月或每年 |
| 固定指令摘要 | 说明到点会生成什么，不把整份敏感材料写进去 |
| 推送位置 | 使用当前产品支持的位置 |

- 用户初始请求已给全上述信息：可视为已确认。
- 本轮未调用`ask_user_question`：计划交付后可用一次结构化问题确认。
- 本轮已经调用：只提供弱入口，下一轮再确认。
- 用户没有确认具体时间、频率或任务清单：不调用`task_schedule`。

## 5. 固定指令

每条任务必须自包含：

```text
目标背景：只写完成本任务必要的最小信息。
本次任务：到点需要生成或提醒的唯一内容。
输出要求：字段、数量、耗时或完成标准。
事实与安全：需要联网时写明来源要求；不得声称知道用户进度。
```

不要写“根据我的原计划告诉我今天做什么”。任务无法读取原计划。不要写入完整简历、成绩单、病历或健康报告。

## 6. 领域候选节点

候选节点不是默认全选。每个计划从中选0—3条：

| 场景 | 优先候选 | 通常不创建 |
|---|---|---|
| 学习备考 | 报名截止检查；阶段模考；考前材料检查 | 每日学习提醒、每道错题提醒 |
| 健身减脂 | 首阶段结束复测；用户明确要求的单次训练卡 | 每个训练日、每日称重 |
| 职业与求职 | 材料完成节点；首次投递节点；每周官方岗位查询三选一 | 每日投递提醒、自动猜测投递进度 |
| 面试备战 | T-2演练；T-1检查，通常最多2条 | 每天重复面试提醒 |
| Offer与入职 | Offer答复截止；入职材料检查 | 每项手续分别建任务 |

示例：

```text
任务名称：面试前一天检查
时间：2026-08-12 20:00
重复：不重复
固定指令：为【公司】【岗位】【轮次】生成面试前检查卡，包括60秒自我介绍结构、3项真实经历证据、3个反问问题，以及材料和设备检查。不要增加大量新知识，不要编造经历。
```

```text
任务名称：每周目标岗位更新
时间：每周一09:00
重复：每周
固定指令：搜索【岗位/城市/届别】最近一周新增的官方招聘信息，输出岗位、地点、发布日期、截止日期和官方链接。没有新增时明确说明，不推断用户投递状态。
```

## 7. 验收

- 推荐理由能对应“避免损失、节点准备、产生新信息”之一。
- 默认创建不超过3条，重复任务不超过1条。
- 没有把完整日程转成通知列表。
- 每条任务的日期、时间、重复方式和固定指令均已确认。
- 每次触发能独立执行，不读取计划文件或历史进度。
- 不虚构完成率，不声称修改了原计划。
