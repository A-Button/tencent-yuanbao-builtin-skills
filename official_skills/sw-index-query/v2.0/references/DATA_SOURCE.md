# 数据获取与结果交付

## 选择与补充

行情优先 **westock CLI**。品种、字段或日期需要补充时，Agent 可使用网页搜索和页面读取工具，优先发布机构、交易所或明确标注来源及时间的金融数据页面。

网页数字必须打开原页面核实；记录 `source_name`、`source_url`、`as_of`、`unit` 和指数代码/名称。分清盘中价、收盘价与发布日期。同一表格中口径不同的数字分列，不把不同来源的零散点位合成 K 线。

完整且经核实的 OHLC 序列可交给本地脚本计算；只有几个点位时，仅交付文字或行情表格，不推算 MACD、回测和完整收益风险。

## 最终回复与页面

最终回复和 HTML/Markdown 产物只展示结论、实际日期、覆盖范围、数据和来源名称/链接，不展示内部运行诊断。不要使用“接口”“API”“数据取不到”“取数失败”“服务不可用”等表述，也不转发错误码、授权排查或额度信息。用户明确要求技术排查时才提供相关诊断。

重要限制需要保留，但用分析范围表达：

- 成分没有经核实的权重：“本次展示成分名单，未计算权重集中度。”
- 日期范围短于用户指定窗口：“这组样本覆盖2026年6月至9月，不能据此判断5年分位。”
- 没有原文依据：“目前可核实的资料尚不能支持这一结论。”

不隐瞒范围，不编造数值，不把新闻称为官方公告。网页补充数字附对应来源链接。

## 代码、字段和模块

- 六位申万代码 `801010` → `pt01` + `801010` = `pt01801010`；转换只在 `datasource.py` 完成。
- `datasource.py` 通过 subprocess 参数数组调用 CLI，不使用 shell，不输出 token。复用 `sw_common` 与 `indicators` 计算及渲染。
- 可调用 `get_kline`、`get_klines`、`get_quote`、`get_quotes`、`get_valuation`、`get_component`、`get_risk_return`。这些名称属于内部实现，不出现在普通用户回复中。
- 单代码 `--raw` 可返回对象列表；批量按 `Data[].Symbol` / `Data[].Data.nodes` 分配，检查 `Metadata.ErrorCount`，不按行号配代码。
- K线升序、去重，`last` 对应收盘价；OHLC 和日期通过校验后才能计算。
- 板块成交额为元，转亿元；板块成交量为手（100股），转亿股时除以1,000,000。分钟量另作适配，外部指数保留其实际供应商单位。
- 行业估值采用 `PeTTM/PbLF`，不能与实时行情 `pe_ratio/pb_ratio` 混写；估值日期与行情日期分别标注。
- `PeTTMPct/PbLFPct` 的历史窗口未指定年数。指定5年等窗口时按真实日期覆盖核验，不直接替换成供应商窗口百分位。

## 计算完整性

YTD 以前一年末最后交易日为基准。至少请求250根日K，并检查跨年基准；不能用年内首条或0代替。1/3/5年收益分别需足够的完整窗口；历史字段没有依据时保留 null。

风险计算采用250交易日年化、样本标准差和峰谷最大回撤；年无风险收益默认2%。周/月排行以已完成周期末对上一期末收盘计算；不冒称未完成周期为月末。

多指数先按共同交易日期对齐，再计算收益、相关性、回归和组合。样本数、实际日期和单位必须可追溯。

## 内部异常处理

临时网络异常最多重试一次；空条目仅重试缺失代码一次。`LOCAL_RATE_LIMITED` 停止重复调用，再按网页补充流程处理。错误保留在内部日志，不作为用户答复。

不要回显原始 stderr 或包含认证参数的 URL。执行失败后不得用上一次残留文件冒充本次结果；已有样本可用于验证或明确日期的分析，不能声称是当前实时行情。
