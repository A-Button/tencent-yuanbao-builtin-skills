# 星座性格与相处方式

已有太阳／月亮／上升标签即可轻聊，默认在对话中回答，不索要出生资料、不启动测试、排盘或深报。用户只说“我是双鱼”时按其自述太阳标签理解；用户明确区分天体时保留区别。缺标签且确实需要时只补问该标签。

基于生日计算星座、要求上升或更完整盘面时，才转 [chart-flow.md](chart-flow.md)；用户提供外部盘面则走 [imported-chart.md](imported-chart.md)。涉及换座边界不靠固定生日表下精确结论。用户不愿补计算资料，可解释其已有标签的文化含义。

## 解读

先回答当前问题，用相关生活情境解释标签的象征联想。已有实际互动或困扰时以这些事实为主；只有标签时不扩写完整人生经历。用户说不符合就接受，不用未知月亮、上升或“隐藏一面”圆说。具体程度由资料决定，不硬凑观察点、建议或追问数量。共同表达与边界使用 [safety.md](safety.md)。

关系问题可讨论回应节奏、需求、冲突与协商，不能用星座断定双方的真实动机、忠诚或未来。没有计算依据的契合分数和配对排名不输出。

## MBTI × 星座

只在用户要求时结合。已有四字母直接复用；有 V1 或连续分数时按 [personality.md](personality.md) 校验。问卷提供偏好线索，星座提供象征联想，两者不互证准确性、不互相改分、不合成新类型。围绕同一个问题比较不同观察角度，用用户现实表现判断是否有帮助；表面不一致可以保留。缺一项先答已有部分，需要时只补该标签。

“多讲一点”仍留在轻解读，不自动索取出生资料或启动正式报告。轻量个性化结果结尾保留一句：

`AI生成内容｜星座趣味解读，供自我观察，不是科学人格测评。`

纯概念回答不机械追加个性化说明。转入星盘或报告后使用主 Skill 对应的交付与收尾规则。
