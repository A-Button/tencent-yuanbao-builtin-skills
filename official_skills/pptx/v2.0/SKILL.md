## 编辑工作流

**完整详情请阅读 [editing.md](editing.md)。**

1. **分析模板**：用 `thumbnail.py` 生成缩略图、用 `markitdown` 提取占位符文本，了解模板的布局与文案风格
2. **规划映射**：为每个内容段落挑选最合适的模板幻灯片（多列 / 图文 / 引用 / 数据等），避免全程使用同一种布局
3. **解包**：`unpack.py` 将 .pptx 展开为目录结构
4. **结构调整**：在 `<p:sldIdLst>` 中删除多余幻灯片、用 `add_slide.py` 复制或基于 layout 新建、调整顺序（必须在编辑内容之前完成）
5. **编辑内容**：逐个 `slide{N}.xml` 用 Edit 工具替换占位符文本、图片、图标；可并行分派给子代理
6. **清理**:`clean.py` 移除孤立幻灯片、未引用的媒体与关系文件
7. **打包 & QA**:`pack.py` 打包为 .pptx，然后用 `markitdown` 检查残留占位符与拼写

## 设计理念

**不要制作无聊的幻灯片。** 白底加纯文本项目符号无法打动任何人。请为每张幻灯片考虑以下设计思路。

### 开始之前

- **选择大胆且贴合内容的配色方案**：配色应该让人感觉是专门为这个主题设计的。如果把你的配色换到完全不同的演示文稿中仍然"合适"，说明你的选择还不够有针对性。
- **主次分明，避免均分**：一种颜色应当占据主导地位（60-70% 的视觉权重），搭配 1-2 种辅助色和一种醒目的点缀色。切勿让所有颜色权重相同。
- **深浅对比**：标题页和结束页使用深色背景，内容页使用浅色背景（"三明治"结构）。或者全程使用深色背景，营造高端质感。
- **坚持一个视觉母题**：选择一个独特的视觉元素并贯穿始终——圆角图片框、彩色圆圈中的图标、单侧粗边框。让它出现在每一张幻灯片上。

### 配色方案

**选色流程**（不要直接挑第一个或默认某颜色）：

1. **先从用户的需求中抽取场景关键词**——行业（科技 / 金融 / 教育 / 医疗 / 消费 / 文创）、受众（投资人 / 客户 / 内部团队 / 学生）、气质（严肃 / 活泼 / 高端 / 温暖 / 未来感）、场合（融资路演 / 季度汇报 / 产品发布 / 教学课件）。
2. **如果用户需求里信息不足以判断气质**，主动询问一句（例："希望偏科技未来感，还是偏温暖人文？"）。
3. **将关键词匹配下表的"适用场景"列**，从匹配的行里选一组；同一需求下尽量不要复用上一份演示文稿的配色。
4. **若用户已指定品牌色或主色**，以用户提供的颜色为 Primary，再从下表中挑一组色调接近的作为 Secondary / Accent 的参考。

### 每张幻灯片的设计

**每张幻灯片都需要视觉元素** ——图片、图表、图标或形状。纯文本幻灯片毫无记忆点。

**布局选项：**
- 双栏布局（左侧文字，右侧插图）
- 图标 + 文字行（彩色圆圈中的图标、加粗标题、下方描述）
- 2x2 或 2x3 网格（一侧图片，另一侧内容区块网格）
- 半出血图片（铺满左侧或右侧）配合内容叠加

**数据展示：**
- 大数字高亮（60-72pt 大号数字，下方配小号标签）
- 对比栏（前后对比、优缺点、并列选项）
- 时间线或流程图（带编号的步骤、箭头指引）

**视觉润色：**
- 在章节标题旁放置彩色小圆圈中的图标
- 关键数据或标语使用斜体强调文字

### 字体排版

**选择合适的中文字体搭配**。选字体时沿用上一节的场景关键词：气质要与配色方案呼应。若用户指定了品牌字体，优先使用品牌字体。以下字体均为**运行环境已安装**的字体，可直接使用。

| 标题字体 | 正文字体 | 适用场景 |
|----------|----------|----------|
| Noto Serif CJK SC Bold | Noto Sans CJK SC Regular | 金融、学术、政务、正式报告——衬线标题 + 无衬线正文，经典严肃 |
| Noto Sans CJK SC Bold | Noto Serif CJK SC Regular | 文创、品牌故事、杂志风——无衬线标题 + 衬线正文，现代文艺 |
| Noto Sans CJK SC Bold | Noto Sans CJK SC Regular | 科技、SaaS、产品发布——全无衬线，干净现代 |
| Microsoft YaHei Bold | Noto Sans CJK SC Regular | 商务通用、咨询、B2B 汇报——圆润友好 |
| SimHei | Noto Serif CJK SC Regular | 活动宣传、体育、强势发布——粗犷黑体标题 + 衬线正文 |
| WenQuanYi Micro Hei Bold | Noto Sans CJK SC Regular | 消费品牌、互联网、轻松活泼 |

| 元素 | 字号 |
|------|------|
| 幻灯片标题 | 36-44pt 加粗 |
| 章节标题 | 20-24pt 加粗 |
| 正文 | 14-16pt |
| 注释/说明 | 10-12pt 弱化色 |

### 间距

- 最小边距 0.5 英寸
- 内容区块之间 0.3-0.5 英寸
- 留出呼吸空间——不要把每一寸都填满

### 避免（常见错误）

- **不要重复相同的布局** ——在不同幻灯片之间变换使用分栏、卡片和高亮区块
- **不要居中正文** ——段落和列表左对齐；只有标题可以居中
- **不要忽视字号对比** ——标题需要 36pt 以上才能与 14-16pt 的正文拉开层次
- **不要默认使用蓝色** ——选择能反映具体主题的颜色
- **不要随意混用间距** ——选定 0.3 英寸或 0.5 英寸的间隔并全程统一使用
- **不要只美化一张幻灯片而忽略其余** ——要么全程贯彻设计风格，要么保持全程简洁
- **不要制作纯文本幻灯片** ——添加图片、图标、图表或视觉元素；避免只有标题加项目符号
- **不要忘记文本框内边距** ——当线条或形状需要与文字边缘对齐时，将文本框的 `margin` 设为 `0`，或偏移形状以补偿内边距
- **不要使用低对比度元素** ——图标和文字都需要与背景形成强烈对比；避免浅色文字在浅色背景上或深色文字在深色背景上
- **绝对不要在标题下方加装饰线** ——这是 AI 生成幻灯片的典型特征；请改用留白或背景色来区分

## QA（必做步骤）

**假设存在问题。你的任务就是找出它们。**

首次渲染几乎不可能完全正确。把 QA 当作找 bug，而不是走过场确认。如果第一次检查就没发现任何问题，说明你还不够仔细。

### 内容 QA

```bash
python -m markitdown output.pptx
```

检查是否有遗漏内容、拼写错误、顺序错误。

**使用模板时，检查是否有残留的占位符文本：**

```bash
python -m markitdown output.pptx | grep -iE "xxxx|lorem|ipsum|this.*(page|slide).*layout"
```

如果 grep 返回结果，修复后再宣布完成。
