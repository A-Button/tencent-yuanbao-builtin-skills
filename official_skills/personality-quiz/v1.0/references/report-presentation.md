# 报告呈现契约

模型只填写 [report-content.md](report-content.md) 的结构化正文，不设计标题、章节、Markdown 或 HTML。`report_pipeline.py finalize` 负责校验正文、装配唯一 Markdown 内容源并渲染 `report.html`；确定性生成的 Markdown 不再接受一次重复的生产校验。

用户可见报告是一篇重点清楚的连续文章，不是仪表盘或结论卡集合。正文保持：

- 语气由 [chart-language.md](chart-language.md) 与当前体系 reference 的输出表达控制，在已有正文生成中完成，不增加单独的润色阶段；
- 一个主标题和脚本确定的章节顺序；
- 关注主题按用户选择顺序出现；
- 八字的固定大运章节位于原局分析之后、用户关注主题之前；西占不显示该章节；
- 每段一个观点，每段至多一个真正有信息量的重点；
- 盘面路径、未入选候选、验证标签和身份信息只留在后台；
- 免责声明只在末尾出现一次。

结构、盘面路径、主题一致性、身份字段 allowlist 或已知词法门控错误会阻止发布；字数、段长、重点数量和位置只作为 warning，不触发模型返工。更广泛的语义安全由 `safety.md` 约束模型生成；生产链不再增加 validator 模型调用，也不声称脚本能完整判断所有语义安全。

八字大运章节按确定性 `luck_cycle_context.status` 呈现：`available` 显示唯一当前大运分析；`conditional` 并列两条等量条件路径，用户可见文案不显示性别、顺逆方向或其依据，也不暗示某一条更可能；`unavailable` 显示固定边界文案且不影响其余章节；`excluded` 和 `not_applicable` 不渲染该章节。大运模块与其他正文共用两阶段生成，不触发第三次模型调用；只看当前大运，不默认展开流年。

校验成功后直接展示 `report.html`，聊天里只给简短完成说明，不重复粘贴整篇报告。宿主无法打开 HTML 时才回退到同源 Markdown。

两个体系复用 `report-shell.html` 的单容器文章结构，不共用配色：八字保持原红棕主题；西占由流水线显式传入 `--system western`，加载 `report-western-theme.css` 的鼠尾草绿、奶油白、宋体标题和黑体正文。重点保持加粗加浅绿色底线，不使用八字红色、大运章节或额外元宝插图。主题由已验证配置决定，不从用户文案、标题或模型输出猜测。
