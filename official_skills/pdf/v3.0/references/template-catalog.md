# PDF Template Catalog

本文件是 PDF skill 的模板索引。需要根据用户需求，选择最合适的模板场景，并通过 yuanbao-cli 获取对应的模板文件。

运行时模板文件都在云端资源中。需要使用模板时，先在本文件中选择最匹配的模板，直接使用表格里的相对路径下载：

```bash
yuanbao-cli download --skill pdf "<template_path>" --output-dir "<task_template_dir>"
```

下载主 HTML 和对应 layout 文件后，只读取下载目录中的文件作为参考。

## 兜底选择

当用户需求无法精确匹配时：

1. 优先选择同一大类下的相近模板。
2. 商务、营销、公司介绍、项目成果类默认使用 `商务报告类/项目汇报`。
3. 通用报告、复盘、数据总结默认使用 `商务报告类/工作报告`。
4. 可填写、打卡、计划、档案类默认使用 `日程计划类/日程计划`。
5. 题目、练习、公式、字帖、古诗打印类默认使用 `教育教学类/试卷类`。
