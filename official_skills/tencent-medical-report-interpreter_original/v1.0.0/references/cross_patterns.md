# 交叉推理模式库

> **核心原则**：指标的诊断价值来自**组合**，不来自单项。
> 单看 Hb 降低说明不了任何问题；MCV↓ + RDW↑ + 铁蛋白↓ 才构成缺铁性贫血证据链。
> **用法**：发现异常项后，先在本库中匹配模式，再输出可能性分层。禁止逐项独立罗列。

---

## 一、贫血四型鉴别

**入口**：Hb 低于参考下限（男 <130，女 <115 g/L）

### 第一步：按 MCV 分道

| MCV | 分类 | 主要方向 |
|---|---|---|
| < 82 fL | 微小细胞性 | 缺铁、地中海贫血、慢病性 |
| 82 ~ 100 fL | 正常细胞性 | 急性失血、慢病性、肾性、溶血、骨髓病 |
| > 100 fL | 巨大细胞性 | B12/叶酸缺乏、酒精、甲减、MDS |

### 第二步：组合鉴别表

| 类型 | MCV | RDW | 铁蛋白 | 血清铁 | 转铁蛋白饱和度 | TIBC | 其他关键 |
|---|---|---|---|---|---|---|---|
| **缺铁性** | ↓ | **↑** | **↓↓** | ↓ | ↓ (<15%) | ↑ | 网织红↓；治疗后网织红先升 |
| **地中海贫血** | ↓↓ | **正常/轻↑** | 正常/↑ | 正常 | 正常 | 正常 | MCV 显著低但 RDW 不高；需血红蛋白电泳 |
| **慢病性** | ↓/正常 | 正常 | **正常/↑** | ↓ | ↓ | **↓** | CRP/ESR↑；铁储备够但利用障碍 |
| **巨幼细胞性** | ↑↑ | ↑ | 正常 | 正常 | 正常 | 正常 | B12↓ 或 叶酸↓；LDH↑；可伴中性粒细胞核分叶过多 |
| **溶血性** | 正常/↑ | ↑ | 正常/↑ | ↑ | ↑ | ↓ | **网织红↑↑ + LDH↑ + 间接胆红素↑ + 结合珠蛋白↓** |
| **肾性** | 正常 | 正常 | 正常 | 正常 | 正常 | 正常 | eGFR↓；EPO 不足所致 |

### 关键鉴别点

- **缺铁 vs 地中海贫血**：都是 MCV↓，但缺铁 RDW↑（红细胞大小不均），地贫 RDW 正常（一致地小）。Mentzer 指数 = MCV/RBC，<13 倾向地贫，>13 倾向缺铁。
- **缺铁 vs 慢病性**：铁蛋白是分水岭。缺铁铁蛋白↓↓，慢病性铁蛋白正常或↑（急性期反应蛋白）。但**炎症会假性抬高铁蛋白**，缺铁合并炎症时铁蛋白可假正常，此时看转铁蛋白饱和度。
- **溶血的四联征**：网织红↑ + LDH↑ + 间接胆红素↑ + 结合珠蛋白↓。缺一项则证据不足。

## 二、肝损伤三型（按 R 值划分）

**R 值 = (ALT / ALT上限) ÷ (ALP / ALP上限)**

| R 值 | 类型 | 主要方向 |
|---|---|---|
| **≥ 5** | 肝细胞损伤型 | 病毒性肝炎、药物性肝损、脂肪肝、自身免疫性肝炎、酒精 |
| **2 ~ 5** | 混合型 | 药物性肝损常见 |
| **≤ 2** | 胆汁淤积型 | 胆道梗阻、结石、PBC/PSC、药物、肿瘤压迫 |

### 组合线索

| 模式 | 提示方向 |
|---|---|
| AST/ALT > 2 + GGT↑ | 酒精性肝病（AST 升高更明显） |
| AST/ALT < 1 + ALT 轻中度↑ + 超声脂肪肝 | 非酒精性脂肪肝（NAFLD） |
| ALT/AST 显著↑（>10倍） + 病毒标志物阳性 | 病毒性肝炎活动期 |
| ALP↑ + GGT↑ + 胆红素↑ + 直胆比例高 | 胆汁淤积/梗阻，需影像查胆道 |
| ALP↑ 但 GGT 正常 | 骨源性 ALP（骨病/生长期），非肝源 |
| 白蛋白↓ + PT延长 + PLT↓ | **肝合成功能受损，提示肝硬化，比转氨酶更重要** |
| 转氨酶正常但 PLT↓ + 脾大 | 隐性肝硬化/门脉高压，转氨酶正常≠肝好 |

> **重要**：**转氨酶正常不代表肝脏没问题**。肝硬化晚期转氨酶可正常甚至偏低。看白蛋白、PT、PLT 三项合成/储备指标更关键。同类技能常犯此错。

### 定量分级

调用 `calc.py fib4` 计算肝纤维化风险：
- FIB-4 < 1.30：低风险，可排除进展性纤维化
- 1.30 ~ 2.67：中间区，需弹性成像进一步评估
- > 2.67：高风险，需肝病专科

## 三、甲状腺功能四象限

| TSH | FT4 | 判定 | 处置方向 |
|---|---|---|---|
| ↑ | ↓ | **原发性甲减** | 内分泌科，通常需替代治疗 |
| ↑ | 正常 | **亚临床甲减** | TSH >10 或有症状/妊娠需治疗；否则 2~3 月复查 |
| ↓ | ↑ | **甲亢** | 内分泌科，需查 TRAb、甲状腺超声、必要时摄碘率 |
| ↓ | 正常 | **亚临床甲亢** | 排除药物、评估心血管与骨风险 |
| ↓ | ↓ | **中枢性甲减** | 垂体/下丘脑问题，需查垂体 MRI 与其他垂体激素 |
| 正常 | ↓ | 检测误差 / 甲状腺激素抵抗 / 非甲状腺疾病 | 复查确认 |
| ↑ | ↑ | TSH 抵抗 / 干扰物 / 服药不规律 | 排除生物素干扰、复查 |

### 附加线索

| 模式 | 提示 |
|---|---|
| TPOAb / TgAb 阳性 + TSH↑ | 桥本甲状腺炎，最常见甲减病因 |
| TRAb 阳性 + 甲亢 | Graves 病 |
| 甲功异常 + 严重全身疾病 | 可能为「低 T3 综合征」（非甲状腺疾病性），不宜急于治疗 |
| 服生物素（维生素 B7）保健品 | **可严重干扰甲功检测**，需停药 1 周复查。见 pitfalls.md |

## 四、代谢综合征判定（中国标准）

**满足以下 ≥3 项即诊断**：

| 组分 | 阈值 |
|---|---|
| 腹型肥胖 | 腰围 男 ≥90 cm / 女 ≥85 cm |
| 高血糖 | 空腹 ≥6.1 或 OGTT2h ≥7.8 或已确诊糖尿病 |
| 高血压 | ≥130/85 或已确诊 |
| 高 TG | ≥1.7 mmol/L |
| 低 HDL-C | < 1.04 mmol/L |

### 联动分析

命中代谢综合征后，必须追加：
1. 计算 ASCVD 10 年风险（`calc.py ascvd`）
2. 计算腰高比（`calc.py bmi`）
3. 评估脂肪肝（结合 ALT、超声、FIB-4）
4. 评估尿酸（代谢综合征常伴高尿酸）
5. LDL-C 危险分层升级 → 目标值下调

> 代谢综合征本质是"多个轻度异常的集合体"，每项单看都可能"只是轻度偏高"，组合起来风险显著放大。这正是交叉推理的价值。

## 五、肾功能三联

**单看肌酐会漏诊。必须三项合看**：

| 维度 | 指标 | 意义 |
|---|---|---|
| 滤过功能 | eGFR（由肌酐/胱抑素 C 计算） | 功能水平分期 |
| 肾损伤标志 | UACR（尿微量白蛋白/肌酐） | 早期损伤，可先于 eGFR 下降 |
| 尿沉渣 | 尿蛋白、红细胞、管型 | 病变性质线索 |

### CKD 分期（eGFR）

| 分期 | eGFR | 处置 |
|---|---|---|
| G1 | ≥90 | 有损伤标志才算 CKD |
| G2 | 60~89 | 同上 |
| G3a | 45~59 | 肾内科随访 |
| G3b | 30~44 | 肾内科规律随访 |
| G4 | 15~29 | 准备替代治疗评估 |
| G5 | <15 | 需替代治疗 |

### 关键陷阱

- **肌酐正常 ≠ 肾功能正常**：肌酐受肌肉量影响大。老年人、肌肉量少者肌酐可正常但 eGFR 已降。**必须算 eGFR，不能只看肌酐**。
- **UACR 可早于 eGFR 异常**：糖尿病肾病早期 eGFR 正常但 UACR 已升高。糖尿病患者必须查 UACR。
- 单次 UACR 升高需重复 2~3 次确认（运动、发热、感染可致假性升高）。

## 六、血脂异常表型

| TC | LDL-C | TG | HDL-C | 表型 | 主要处置方向 |
|---|---|---|---|---|---|
| ↑ | ↑ | 正常 | 正常 | 高胆固醇型 | 他汀为主，重点降 LDL-C |
| 正常 | 正常 | ↑ | ↓ | 高 TG 低 HDL 型 | 生活方式为主，TG>5.6 需防胰腺炎 |
| ↑ | ↑ | ↑ | ↓ | 混合型 | 综合干预 |
| 正常 | 正常 | 正常 | ↓ | 单纯低 HDL | 运动、戒烟为主 |
| LDL-C ≥4.9（未治） | | | | 疑家族性高胆固醇（FH） | 需家系筛查，直接归超高危 |

### 附加计算

- **非 HDL-C = TC − HDL-C**：比 LDL-C 更能反映全部致病性脂蛋白，TG 高时更可靠
- **AIP = log(TG/HDL-C)**（`calc.py aip`）：>0.24 提示高致动脉粥样硬化风险
- **TG > 5.6 mmol/L**：急性胰腺炎风险显著升高，需即刻干预

## 七、炎症与感染模式

| 模式 | 提示方向 |
|---|---|
| WBC↑ + 中性↑ + CRP↑ + PCT↑ | 细菌感染 |
| WBC 正常/↓ + 淋巴↑ + CRP 轻↑ + PCT 正常 | 病毒感染 |
| WBC↑ + 嗜酸↑ | 过敏、寄生虫、药物反应 |
| CRP↑ + ESR↑ + 补体异常 + 自身抗体 | 自身免疫性疾病 |
| PCT > 10 | 脓毒症可能，**危急值** |
| CRP↑ 但 WBC 正常 | 慢性低度炎症（肥胖、代谢综合征常见），也需警惕结核、肿瘤 |
| ESR 显著↑（>100）+ 贫血 | 需排除多发性骨髓瘤、恶性肿瘤、结核 |

## 八、肿瘤标志物解读原则（重要边界）

> **肿瘤标志物不能用于诊断癌症，只用于高危人群筛查提示与治疗后监测。**

| 标志物 | 相关器官 | 常见非肿瘤性升高原因 |
|---|---|---|
| AFP | 肝 | 肝炎活动期、妊娠、生殖系统良性病变 |
| CEA | 消化道/肺 | 吸烟、炎症性肠病、肝病、良性肺病 |
| CA19-9 | 胰/胆/消化道 | 胆道炎症、胰腺炎、糖尿病、良性梗阻 |
| CA125 | 卵巢 | 月经期、妊娠、子宫内膜异位、腹膜炎、肝病 |
| CA153 | 乳腺 | 良性乳腺病、肝病 |
| PSA | 前列腺 | 前列腺炎、良性增生、骑车、射精、直肠检查后 |
| SCC/CYFRA | 肺/鳞癌 | 皮肤病、肾功能不全 |
| NSE | 肺小细胞/神经 | 溶血标本（假性升高） |

### 判读规则

1. **单次轻度升高价值极低**，必须动态复查看趋势
2. **持续升高 + 进行性上升** 才有意义，需影像学确认
3. 标志物正常**不能排除**肿瘤
4. 输出时必须明确："肿瘤标志物不用于诊断，需结合影像与病理"
5. 显著升高（数倍以上）+ 有症状 → L2 档，两周内专科

```
【04 关联性分析】

模式匹配：微小细胞性贫血 + 铁代谢异常

组合信号：
  Hb 105 g/L ↓
  MCV 76 fL ↓
  RDW-CV 16.2% ↑
  铁蛋白 8 μg/L ↓↓
  转铁蛋白饱和度 9% ↓

可能性分层：
  最可能：缺铁性贫血
    依据：MCV↓ + RDW↑ + 铁蛋白↓↓ + 饱和度<15%，四项吻合缺铁典型模式

  需排除：慢性失血来源（消化道、月经量多）

  不太可能：地中海贫血

  不太可能：慢病性贫血
    理由：铁蛋白 8 μg/L 显著降低，慢病性铁蛋白多正常或升高
```

## 十、指标 → 问题名映射表

**异常总结的单位是「问题」，不是「指标」。** 用户记不住 8 条指标，但记得住 3 个问题。

### 10.1 命名三条铁律

| 情形 | 写法 | 示例 |
|---|---|---|
| 达到诊断阈值 | 现象 +（XX **可能**） | 血糖升高（糖尿病可能） |
| 未达诊断阈值 | 只写现象，**不得**提疾病名 | 血压偏高（临界） |
| 需排除干扰因素 | 现象 +（需先排除 X） | 血钾偏高（需先排除抽血因素） |

- **「可能」二字不可省** —— 省掉就变成确诊，越界
- 未达阈值**禁止**出现疾病名 —— 「血压偏高」不能写成「高血压」

### 10.2 映射对照

| 指标组合 | 问题名 | 归档 |
|---|---|---|
| 空腹血糖 ≥7.0 | 血糖升高（糖尿病可能） | L2 |
| 空腹血糖 6.1~6.9 | 血糖偏高（糖尿病前期） | L3 |
| HbA1c ≥6.5% | 血糖控制不佳（糖尿病可能） | L2 |
| 腰围超标 + BMI ≥24 | 中心型肥胖 | L3 |
| LDL-C 未达个体目标 + TG↑ + HDL-C↓ | 血脂异常（坏胆固醇未达标 + 好胆固醇偏低） | L3 |
| 仅 TG 显著升高（≥5.6） | 甘油三酯显著升高（胰腺炎风险） | L2 |
| 130/85 ≤ 血压 < 140/90 | 血压偏高（临界） | L3 |
| 血压 ≥140/90 | 血压升高（高血压可能） | L2 |
| ALT↑ + 超声脂肪肝 + AST/ALT<1 | 肝酶升高（脂肪肝可能） | L3 |
| ALT/AST 升高 >3 倍正常上限 | 肝功能明显异常（需查明原因） | L2 |
| 血钾轻度↑ + LDH↑ | 血钾偏高（需先排除抽血因素） | L2 |
| eGFR 60~89，尿检正常 | 肾功能轻度下降（需结合尿检复核） | L3 |
| eGFR <60 | 肾功能下降（慢性肾病可能） | L2 |
| 尿酸↑ 无症状 | 尿酸升高（无症状高尿酸血症） | L3 |
| Hb↓ + MCV↓ + 铁蛋白↓ | 贫血（缺铁性可能） | L2 |
| TSH↑ + FT4 正常 | 甲状腺功能减退（亚临床，需复查确认） | L3 |
| TSH 区间内但持续上升 | 甲状腺功能可能正在减退（趋势发现） | L3 |
| 命中代谢综合征 ≥3 项 | 代谢综合征（整体性问题） | L2 |
| 肿瘤标志物轻度↑ 单次 | 肿瘤标志物轻度升高（需复查排除干扰） | L3 |

### 10.3 组合诊断标准单列为整体性问题

命中以下组合标准时，**除各单项问题外，还要单列一条整体性问题**：

| 组合标准 | 问题名 | 判定 |
|---|---|---|
| 代谢综合征 | 代谢综合征（命中 N 项） | 五组分满足 ≥3 项 |
| 糖尿病肾病风险 | 糖尿病合并早期肾损伤可能 | 糖尿病 + UACR↑ |
| 极高危 ASCVD | ASCVD 极高危 | 已有心血管事件 或 糖尿病 + 靶器官损害 |

整体性问题的价值：**它解释了为什么各单项加起来比单看一项更严重**。

## 十一、因果链模板

命中组合模式后，**尽量输出一条因果链**，说明哪个是上游、哪个是下游。

### 11.1 代谢综合征型（最常见）

```
内脏脂肪堆积（腰围 92）
  → 胰岛素抵抗
  → 血糖升高 + 甘油三酯升高 + 好胆固醇下降
  → 脂肪堆积在肝脏 → 肝酶升高
```

**共同上游 = 内脏脂肪**。腰围降下来，血糖、血脂、肝酶往往同步改善。
这条链决定了第 09 段生活指导里为什么把减少腹部脂肪排第一。

### 11.2 缺铁性贫血型

```
慢性失血（消化道 / 月经量多）
  → 铁储备耗竭（铁蛋白↓）
  → 血红蛋白合成不足
  → 红细胞变小（MCV↓）+ 大小不均（RDW↑）
  → 携氧能力下降 → 乏力、面色苍白
```

**关键**：链条起点是失血，补铁只解决下游。**缺铁不是终点诊断，必须找失血原因**。

### 11.3 高尿酸型

```
嘌呤摄入过多 / 排泄减少（肾功能下降）
  → 血尿酸升高
  → 尿酸盐结晶沉积
  → 关节（痛风）+ 肾脏（尿酸性肾病）双重损害
```

### 11.4 甲减型

```
自身免疫攻击甲状腺（TPOAb↑）
  → 甲状腺激素合成减少
  → 垂体加大指令（TSH↑，此时 FT4 仍可正常 = 亚临床）
  → 代偿失败 → FT4↓（临床甲减）
  → 代谢率下降 → 血脂升高、体重增加、乏力畏寒
```

**这条链解释了为什么 TSH 是最早的信号** —— 它是代偿指标，比 FT4 更敏感。

### 11.5 因果链的写法要求

| 要求 | 说明 |
|---|---|
| 用代码块呈现 | 保留缩进箭头，层级清晰 |
| 标出实测值 | 「内脏脂肪堆积（腰围 92）」而非「内脏脂肪堆积」 |
| 末尾点明共同上游 | 这是因果链的价值所在 |
| 与生活指导段联动 | 说明「所以第 09 段把 X 排第一」 |
| 不确定时不强行画 | 模式不匹配就如实说「当前组合未构成典型链条」 |

**因果链的作用**：让用户明白共同上游是什么，从而理解各段建议之间的关系。
没有因果链，各段建议是散的，用户不知道该先做哪件。

## 边界

- 本库为**推理线索库**，不是诊断标准。所有输出必须表述为"提示/倾向/需排除"，不做确诊。
- 模式不匹配时如实说明"当前指标组合未构成典型模式，建议专科评估"，不强行套模式。
- 罕见病、儿童特有疾病不在本库覆盖范围，遇疑似需明确提示转专科。
