# 排播功能参考

当用户询问某部作品的播出进度、更新日程、下一集播出时间等排播相关问题时，使用 `schedule` 脚本查询。

> 架构说明：CLI 的 `schedule` 命令只负责调用 API 并输出原始 JSON；`scripts/schedule.ts` 负责解析 JSON 并格式化为人类可读的输出。

## 触发场景

用户说的话 | 使用的命令
---|---
"《庆余年3》播到第几集了" | `bun scripts/schedule.ts <cid>`
"《庆余年3》每周几更新" | `bun scripts/schedule.ts <cid>`
"下一集什么时候能看" | `bun scripts/schedule.ts <cid>`
"这部剧一共多少集，还剩几集没播" | `bun scripts/schedule.ts <cid>`
"这周有什么新剧开播" / "最近有什么剧在更新" | 排播日历浏览（见下方「排播日历」）
"更新了提醒我" / "开播前通知我" | 先查询排播获取下一集时间，再设置定时任务（见下方「追剧提醒」）

## 查询流程

1. **获取 CID**：先通过 `search` 命令搜索作品，从返回结果中提取 CID（URL 中 `/cover/` 后面的部分即为 CID）
2. **查询排播**：执行 `bun scripts/schedule.ts <cid>`（脚本内部调用 CLI 的 `schedule` 子命令获取 JSON，再格式化输出）
3. **格式化输出**：将脚本输出直接展示给用户

## 命令格式

```sh
# 排播查询（推荐使用脚本，自动格式化）
bun scripts/schedule.ts <cid>

# CLI 直接调用（返回原始 JSON，供脚本或程序消费）
<cliPath> schedule <cid>
<cliPath> sch <cid>
```

## CID 获取方法

search 命令返回的 URL 中包含 CID：

```
URL: https://v.qq.com/x/cover/mzc00200mp74m8e.html
                           ^^^^^^^^^^^^^^^^
                           这部分就是 CID
```

提取规则：URL 格式为 `https://v.qq.com/x/cover/{cid}.html`，其中 `{cid}` 即为所需参数。

注意：部分搜索结果 URL 为 `/x/search/?q=xxx` 格式，这些没有 CID，无法查排播。

## 输出格式

脚本的输出已经是格式化后的可读文本，直接展示即可：

```markdown
🎬 作品名称

📊 播出状态：正在热播 / 已完结 / 即将上线 / 敬请期待

📺 已更新 N/M 集，还剩 X 集未播出

🔓 免费可看：N 集

👑 VIP 可多看 N 集

📅 更新日程：周二 20:00、周三 20:00

⏰ 下一集（第 N 集）播出时间：4月7日（周二）20:00（VIP）

📋 最近集数信息：
  第 N 集：标题 ✅ 免费可看
  第 N+1 集：标题 👑 VIP可看
  第 N+2 集：标题 📅 待播出（4月7日（周二）20:00）
```

### 格式规则

1. **来源标注**：输出末尾添加 `**来源：腾讯视频**`
2. **字段缺失**：脚本已处理字段缺失情况，缺失字段不会显示
3. **直接展示**：脚本输出已是格式化文本，直接展示给用户即可，不需要二次加工

## 排播日历

当用户想浏览近期有哪些作品更新/开播/完结时，通过 **search + schedule 组合**实现：

1. **搜索**：用 `search` 命令搜索时间维度的关键词（如"本周新剧"、"正在热播"、"今天更新的剧"、"本周大结局"等，将用户原话直接传给 search）
2. **提取 CID**：从搜索结果的 URL 中提取 CID（格式 `/x/cover/{cid}.html`）。**注意：部分结果 URL 为 `/x/search/?q=xxx` 格式，这些没有 CID，无法查排播**
3. **批量查排播**：对所有有 CID 的结果，逐一执行 `bun scripts/schedule.ts <cid>` 查询排播详情
4. **按日期聚合输出**：将所有作品的排播信息按日期归类，输出排播日历

输出格式示例：

```markdown
📅 **排播日历**

**4月15日（今天）**
🎬 白日提灯 — 第37集更新 18:00（VIP）
🎬 秦岭青铜诡事录 — 首播

**4月17日（周四）**
🎬 方圆八百米 — 首播 18:00

**4月20日（周日）**
🎬 白日提灯 — 第38集更新 18:00（VIP）

**已完结作品**
🎬 雁回时 — 共31集，已完结
🎬 棋士 — 共22集，已完结

**来源：腾讯视频**
```

注意事项：
- search 返回的结果中，URL 为 `/x/search/?q=xxx` 的条目没有 CID，无法查询排播详情，仅在搜索结果中展示基本信息
- 如果所有结果都没有 CID，则只展示搜索结果，不展示排播日历
- 已完结作品归入"已完结"分组，不按日期排列
- 每部作品的排播信息来自 `schedule.ts` 输出，重点关注：播出状态、下一集播出时间、首播时间、更新日程
- search + schedule 组合是同一次用户请求内的操作，不违反"只搜索一次"规则（只执行一次 search，后续的 schedule 是排播查询）

## 追剧提醒

当用户要求在更新时获得通知（如"更新了提醒我"、"开播前10分钟通知我"），由 Agent 侧的定时任务能力实现：

1. **查询排播**：先执行 `bun scripts/schedule.ts <cid>` 获取下一集播出时间
2. **计算提醒时间**：根据用户要求（如"提前10分钟"），从播出时间减去对应时长作为提醒时间
3. **设置定时任务**：使用 Agent 的定时任务/自动化能力，在提醒时间触发通知
4. **提醒内容**：在定时任务触发时，告知用户"《{作品名}》第 {N} 集即将在 {时间} 开播"

注意事项：
- 如果排播查询显示"未定"或无具体播出时间，告知用户暂无法设置提醒，建议后续再问
- 已完结作品无需设置提醒
- 提醒是一次性的，每集需单独设置（用户要求"每集都提醒"时，可基于更新日程规律设置多个定时任务）
