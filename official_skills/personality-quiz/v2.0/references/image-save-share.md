# 结果图片弹窗与保存分享

塔罗、人格测试（20／50 题）、独立西洋星盘共用 `assets/result-image.js`。修改图片交互时读取本文件。

## 交互

- 塔罗「分享结果图片」、人格／星盘「保存或分享图片」生成本地 PNG 后打开同一个图片弹窗，不再在结果页追加长图。
- 图片按弹窗宽度等比显示；图片区域独立滚动，顶部关闭与底部操作／提示固定可见。弹窗与业务布局分离，使用 Shadow DOM 隔离样式，并按实际可视区域约束宽高。
- 手机／平板底部仅提示“长按图片保存或分享”。最终图片是 img，保留默认长按菜单；不放无法使用的原生保存／分享按钮，不调用 navigator.share、猜测的 JSBridge 或合成长按事件。
- PC 底部提供“下载图片”，提示“下载图片后即可分享，也可右键保存图片”。下载 PNG 不替换当前页面。没有伪造发送给第三方应用的按钮。
- 打开后背景不参与操作；关闭或按 Escape 后恢复滚动位置及焦点。键盘 Tab 限制在弹窗内。实际长按／右键菜单由浏览器或宿主提供。
- 图片加载中有明确状态，失败时可关闭重试；不把生成图片误报成已保存或已分享。同一结果重新打开复用缓存；重抽、重测、修改答案或接收新结果快照时清除旧图。
- 图片留在本地，不上传个人资料，不生成公网分享链接。

## 链接分享与本地恢复

本机重开恢复依赖 localStorage。宿主分享原始 HTML 地址不会自动带走本机存储或当前 DOM，接收端可能回到初始状态。

塔罗已有结果快照协议，宿主须采集快照并在接收页面回填，见 [tarot-state-share.md](tarot-state-share.md)。没有宿主接入时不能宣称容器自带链接分享会恢复结果。此版本只调整图片交互，不改变存储 key 或快照格式。

## 验证

`test_result_image_browser.cjs` 验证手机／PC 弹窗、窄屏与横屏尺寸、固定底栏、长图、位置恢复、无原生 API 调用及 PC 下载，并检查真实塔罗、MBTI 20／50 题、星盘入口。桌面 WebKit 不能确认元宝 iOS 实际长按菜单项；需在真机长按新产物图片验证保存与分享。
