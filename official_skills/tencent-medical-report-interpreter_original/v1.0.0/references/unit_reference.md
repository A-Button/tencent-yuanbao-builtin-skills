# 单位换算 · 参考区间 · 个体目标值

> **数据源**：《全国临床检验操作规程》（第4版）+ 各专科指南（详见 guidelines.md）
> **核心用法**：任何数值判读前**先归一单位**，再做**双基准比对**（参考区间 + 个体目标值）。
> **重要**：报告未提供参考区间时才用本表兜底，且必须标注「区间来源为内置标准，非本次报告提供」。

---

## 一、单位换算系数（最高优先级，误读之源）

### 1.1 血脂

| 项目 | mmol/L → mg/dL | mg/dL → mmol/L |
|---|---|---|
| 总胆固醇 TC | × 38.6 | ÷ 38.6 |
| LDL-C | × 38.6 | ÷ 38.6 |
| HDL-C | × 38.6 | ÷ 38.6 |
| 非 HDL-C | × 38.6 | ÷ 38.6 |
| 甘油三酯 TG | **× 88.5** | ÷ 88.5 |
| Lp(a) | mg/L ÷ 10 = mg/dL | — |

> **陷阱**：TG 的系数与胆固醇类**不同**（88.5 vs 38.6）。混用会导致 TG 判读偏差 2.3 倍。

### 1.2 肾功能

| 项目 | 换算 |
|---|---|
| 肌酐 Cr | μmol/L ÷ 88.4 = mg/dL |
| 尿素氮 BUN | mmol/L × 2.8 = mg/dL |
| 尿酸 UA | μmol/L ÷ 59.5 = mg/dL |
| 胱抑素 C | 通常直接用 mg/L，无需换算 |

### 1.3 血糖与糖代谢

| 项目 | 换算 |
|---|---|
| 血糖 | mmol/L × 18.0 = mg/dL |
| HbA1c | NGSP(%) 与 IFCC(mmol/mol)：IFCC = (NGSP − 2.15) × 10.929 |
| 胰岛素 | μIU/mL × 6.945 = pmol/L |

### 1.4 其他高频

| 项目 | 换算 |
|---|---|
| 总胆红素 | μmol/L ÷ 17.1 = mg/dL |
| 血钙 | mmol/L × 4.0 = mg/dL |
| 血清铁 | μmol/L × 5.58 = μg/dL |
| 维生素 D (25-OH-D) | nmol/L ÷ 2.5 = ng/mL |
| 维生素 B12 | pmol/L ÷ 0.738 = pg/mL |
| 叶酸 | nmol/L ÷ 2.266 = ng/mL |
| 睾酮 | nmol/L × 28.8 = ng/dL |
| 皮质醇 | nmol/L ÷ 27.6 = μg/dL |
| 血氨 | μmol/L ÷ 0.587 = μg/dL |

## 三、个体目标值（防漏诊核心）★★★

> **这是本技能与同类技能的关键差异点。** 报告参考区间是"人群统计区间"，个体目标值是"临床干预目标"。
> LDL-C 3.2 mmol/L 在报告上**不带箭头**，但 ASCVD 高危者目标 <1.8 —— 差了 78%，这是漏诊重灾区。
> **每次判读血脂、血压、血糖，必须做此层比对。**

### 3.1 LDL-C 分层目标值（《中国血脂管理指南 2023》）

| 危险分层 | 判定条件 | LDL-C 目标 | 非 HDL-C 目标 |
|---|---|---|---|
| **超高危** | ASCVD + 再发事件 / 多血管床病变 / LDL-C≥4.9 未治 / 糖尿病+ASCVD | **< 1.4** 且降幅 >50% | < 2.2 |
| **极高危** | 已确诊 ASCVD（心梗、卒中、外周动脉疾病等） | **< 1.8** 且降幅 >50% | < 2.6 |
| **高危** | 糖尿病+年龄≥40 / CKD 3-4期 / 高血压+2项危险因素 / 10年风险≥10% | **< 2.6** | < 3.4 |
| **中危** | 10 年风险 5~10% | **< 3.4** | < 4.2 |
| **低危** | 10 年风险 <5% | **< 3.4** | < 4.2 |

**危险因素清单**（用于高危判定）：吸烟、低 HDL-C（<1.0）、年龄（男≥45/女≥55）、肥胖（BMI≥28）、早发心血管病家族史。

### 3.2 血压目标值
### 血压：三种测量方式的诊断阈值（2024 年修订版新增）★

**《中国高血压防治指南（2024年修订版）》起，家庭自测与 24 小时动态血压也可直接用于诊断**，
不再只认诊室血压。用户报家庭血压计读数时，必须按对应口径判读，**不能套用诊室 140/90**。

| 测量方式 | 高血压诊断阈值（未服降压药） |
|---|---|
| **诊室血压** | ≥ 140/90 mmHg |
| **家庭自测血压** | ≥ 135/85 mmHg |
| **24 小时动态血压** · 全天平均 | ≥ 130/80 mmHg |
| **24 小时动态血压** · 白天平均 | ≥ 135/85 mmHg |
| **24 小时动态血压** · 夜间平均 | ≥ 120/70 mmHg |

> **为什么必须区分**：一个家庭自测 136/86 的人，按诊室标准（140/90）会被判成「血压偏高（临界）」，
> 按家庭标准（135/85）则已达诊断阈值。同一组数字，判读结论完全不同。
> **判读前必须先确认这个读数是怎么测出来的**；报告未说明测量方式时，写入信息缺口并提示向医师核对。


| 人群 | 目标 |
|---|---|
| 一般成人 | < 140/90，能耐受可 < 130/80 |
| 糖尿病 | < 130/80 |
| CKD 伴蛋白尿 | < 130/80 |
| 65~79 岁 | < 140/90，能耐受可 < 130/80 |
| ≥80 岁 | < 150/90 |
| 妊娠期 | < 140/90 |

| 人群 | 目标 |

### 3.5 体重与体成分目标

| 指标 | 正常 | 超重 | 肥胖 |
|---|---|---|---|
| BMI（中国标准） | 18.5 ~ 23.9 | 24 ~ 27.9 | ≥ 28 |
| 腰围 | 男 <85 / 女 <80 cm | 男 85~90 / 女 80~85 | 男 ≥90 / 女 ≥85 |

## 四、判读输出模板（双基准）

```
LDL-C 3.2 mmol/L
├─ 参考区间：< 3.4 mmol/L → 区间内，报告未标箭头
├─ 个体目标：< 1.8 mmol/L（极高危：已确诊冠心病）
└─ 结论：⚠️ 虽在参考区间内，但距个体目标超出 78%，属未达标，需干预
```

**这类"报告不带箭头但未达标"的项，必须单独列出并明确提示**，否则用户会误以为无问题。

---

## 五、边界

- 儿童、孕妇、老年人的参考区间与成人差异显著，本表主要适用于 18~65 岁成人。遇儿童/孕期报告，必须提示"需按年龄/孕周专用区间判读"。
- 本表为兜底数据，**报告自带区间优先**。
- 方法学差异显著的项目（甲功、肿瘤标志物、激素）跨机构不可直接互比。
