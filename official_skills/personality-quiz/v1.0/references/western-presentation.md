# 五项星座结果页

修改西洋星盘 HTML、预置解读或排盘后的默认展示时读取。本页是 `chart` 层级的确定性产物：引擎计算结果，脚本按天体与星座索引文案，无需模型生成。完整 JSON 仍供用户明确请求的盘外分析和深度报告使用。

## 展示内容

固定五项与顺序：太阳、上升、月亮、金星、水星。

| 项目 | 文案关注（内部写作方向，不作为页面副标题） |
|---|---|
| 太阳 | 自我表达、投入感与做事偏好 |
| 上升 | 进入陌生环境时的表现方式 |
| 月亮 | 情绪表达、安定感与被照顾的方式 |
| 金星 | 喜好、审美与关系中的表达 |
| 水星 | 理解信息、说话与交换观点 |

页面从太阳主项与四行结构化排盘信息开始，没有顶部栏、面板序号、标题口号或出生资料行。太阳展示静止透明元宝、星座及短注；其余四项按“天体—星座—短注”统一对齐，用浅色行线分隔，不再做散落的四张卡片。使用语义化定义列表；只有有下方解读的太阳、上升、月亮提供锚点，金星、水星不伪装成可点击控件。手机窄屏时太阳图文左右排布置顶，下面保留四行，不横向滚动或整体缩小文字。

下方简要报告只解释太阳、上升、月亮，固定三段；每段一行“天体 星座”标题和完整解读，把 `summary` 与 `detail` 连为一段。太阳主项和解读标题用留白分隔天体与星座，不加中点。金星、水星只在上方保留星座和短注，不在简报重复展开。未知项保留简短原因；不设展开、收起、折叠或每日运势入口。

星座独立页底部只显示：`星座测试是一种文化解读` 不展示地点数据栏；已有地点来源与许可保留在原始数据及 HTML 的 `data-attribution` 元信息中，不展示出生资料。组合盘仍保留八字区域自身的标题、资料和共用说明。

## 配色与十二星座元宝

星座页沿用 MBTI 的鼠尾草绿与奶油白色系，采用更自然、低对比的背景与边线：背景 `#f3f4ef`、卡片 `#fffdf8`、标题 `#29392f`、正文 `#405045`、辅助文字 `#647267`、边线 `#dde4d9`、鼠尾草绿 `#5d7964`。Tag 以无底色、无描边的自然短注呈现，不加前置短横线；不用胶囊、按钮框或大块色底。四行信息之间保留浅色分隔线，不为每项铺独立渐变或绘制密集表格线。

星座名称与解读标题使用本机宋体 / CJK 衬线字体，正文使用 PingFang / CJK 黑体，正文 17px、短注 15px（极窄屏 14px），减少小字号层级，不联网拉取字体。移动端调整布局而不是整体缩小文字。

动效只用 CSS：正文短暂淡入，悬停仅改变短注文字颜色。元宝始终静止，首次打开和鼠标悬停时均不浮动，也不通过父卡片位移间接移动。`prefers-reduced-motion: reduce` 下关闭动效与位移。主题与动效限定在星座页面或星座面板，不改变八字主题。

十二个角色沿用既有 MBTI 元宝的绿色本体、白色脸窗、两只黑色简眼和圆润漂浮手脚。通过姿态和小道具区分星座，不加人类发型、衣服、性别、额外五官，不将形象当作人格诊断。固定资产位于 `assets/yuanbao-zodiac/`，由 `manifest.json` 记录文件、尺寸和 SHA-256：

`scripts/western_mascots.py` 只接受五项投影中 `key=sun` 且 `status=available` 的已确定星座；不得用上升、月亮、候选星座或用户的自述替代。太阳有跨星座范围或无法确定时显示 0 张，不挑选代表图。准确时间和日期级的稳定太阳结果都显示对应的 1 张。

十二张素材使用真正带透明通道的 RGBA PNG，去掉原图纸色和地面投影，保留绿色本体、白色脸窗与道具。不用混合模式、近似底色或棋盘格图片伪装透明。

渲染前校验固定映射、RGBA 格式、资源哈希与尺寸；素材测试检查透明边缘与不透明白色脸窗。只把选中的一张 PNG 内联进最终 HTML，不联网加载、不在运行时生成，不把整套十二图嵌入每个结果页。角色图使用统一正方形可视槽，保持完整构图、不裁脸；相邻文字已表达太阳星座，图片使用空替代文本避免重复播报。其他四项及下方解读不重复展示元宝。

页面不显示十天体全表、精确度数、黄道坐标、相位列表、容许度、宫位、技术覆盖清单、重复盘面导读或“本次省略”。计算仍保留已有字段，展示范围不改变后续分析的数据范围。

## 预置文案

`scripts/western_profiles.json` 收录五项各十二星座，共 60 组原创文案。每组有 `tagline`、`summary`、`detail`；同一个星座在不同项目下使用不同的生活主题，不能复制同一段再替换天体名。

`scripts/western_highlights.json` 单独记录这 60 段中的重点短语，不改变正文。参照八字深度报告，每段只突出一个有信息量的短语，用加粗与浅绿色细底线表达，不整句刷底色或增加重点卡片。`western_emphasis.py` 只在项目已确定、重点在完整正文中恰好出现一次且不超过段落 45% 时包裹安全的 `<strong>`；未知项不高亮，文案修订导致重点失效时原样显示全文，不猜测替代词、不阻塞出盘。维护文案时同步核对重点清单，确保文本未被改写、插入或重复。

正文按 [chart-language.md](chart-language.md) 的公共语气执行：`summary` 直接说明该项侧重；`detail` 可以用具体情境、感受或简短对话展开，连读为自然的一段。不强制每项给建议或补一个缺点。运行时仍直接索引，不加载语言规范或调用模型改写。

盘面 `tagline` 按用户指定的轻趣味风格，用 4—6 个汉字写有画面、好记的小称号或生活短句，允许轻比喻，不沿用正文的平实概括限制。保留「好奇不打烊」「默契合伙人」等贴合主题的原有表达，搭配「人稳话不多」「淡淡的很靠谱」「已读全都回」「活人感拉满」这类日常也能读懂的网络表达，不要求每条都玩梗，也不按固定比例替换。选择长效表达：脱离某次热搜、某位人物、影视台词或音视频语调仍能理解，不依赖时事反转、短期谐音或圈内暗号。

同一星座的五个 Tag 分别对应上表的五个主题，不能换个天体名就复用；同一项目的十二个 Tag 也应有区分。先看是否贴合该项正文，再选原有短注或改写网梗，不为凑梗改变正文含义。借鉴趣味测验的亲近感，文案保持原创，不抄第三方测试、不连续套同一后缀模板。不用贬损、病理化称呼或人格优劣判断，也不把小称号当作事实诊断。未知与跨星座项继续显示原来的资料缺失原因，不配趣味 Tag。

文案借用常见文化象征，围绕日常偏好与互动场景，允许用户认为不符合。避免“决定你的性格”、命运断言、优劣排名、诊断、依恋类型、智商或第三方秘密。结尾只保留一条适用说明，不每段重复免责声明。

页面只做已验证字段到预置内容的索引；用户问题、出生资料或外部文本均不参与 HTML 代码拼接。所有动态文字必须转义。无网络请求、无持久化存储，也不需要额外模型调用。

## 不完整资料

日期级只信任 `chart.stable.planet_signs`。跨星座项显示候选范围与简短原因，不分配标签或正文，不挑一个“更像”的星座。不向用户呈现采样时刻、内部状态码或技术字段。

明确出生时段的 `precision=time-range` 读取 `chart.stable.planet_signs` 和 `chart.stable.ascendant.sign`，范围内不变的五项均正常显示 Tag、元宝及对应简报，不因时间不精确一律降级。只有实际跨界的项目显示 `possible` 候选和短原因，不分配趣味 Tag 或人格正文；不能从候选中挑一个更像的。

上升须有可靠地点坐标，配合准确出生时刻或经引擎核验全范围不变的星座结果。真正缺少条件时保留“暂未确定”和具体原因；不能从太阳、时辰名称或用户自述性格推导。其他已确定项目照常显示。

## 与报告的关系

五项盘面与三项预置解释都属于快速 `chart` 产物，无需模型生成。展示成功后执行 `chart_followup.py` 返回的主题提问；只有用户选择／明确请求后才生成深报，不把预置段落当成行为证据。深报使用同一五项的已确定星座，而非仅简报中的三项；沿用八字的连续文章结构，使用星座自己的绿白主题，不出现八字大运章节。
