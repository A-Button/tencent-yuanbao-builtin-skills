# 牌库内容模型与能力边界

需要修改逐牌资料、逆位结构或解释案例库时，先完整读取 [tarot-systems-and-corpus-design.md](tarot-systems-and-corpus-design.md)。该文档定义韦特—史密斯默认口径、跨体系隔离、用户可见基础资料、来源分层、案例结构和检索排序；只核验书目或在线指针时读取 [sources-tarot.md](sources-tarot.md)。

## 已覆盖

- 78 张韦特—史密斯体系牌：22 张大阿尔卡那、四花色各 14 张；
- 每张牌的中文名、牌组/花色、序号、逐牌关键词、正逆位核心义，以及正逆位各一条可即时展示的完整短句；
- 每张牌的图像锚点、来源、内容版本、初审状态和五种逆位机制；
- 大阿尔卡那原型，四花色元素与生活领域，数字/宫廷阶段；
- 可供 UI 与模型使用的反思问题；
- 单牌生产交互；时间线三牌与困境三牌已有数据定义和运行时保留能力，但当前生产页面未提供入口，不得对用户宣称可在页面选择；
- 单牌的确定性抽取、渐进揭示、即时基础牌义与智能助手消息交接；用户提供的既有多牌牌阵仍可按可见位次直接解读；
- 18 条团队编写的中文情境种子案例，含适用条件、反向信号、校准问题和可逆行动；
- 按问题、牌面、朝向、位次、主题、牌阵与质量进行确定性案例排序，并标记高影响问题。

## 不应声称“穷尽”

塔罗没有像天文位置或历法排盘那样唯一、可计算的完整事实层。不同牌系、作者、流派和提问语境会产生不同解释。当前模型提供可追溯、可组合的韦特—史密斯中文基础层，不声称覆盖所有神秘学对应关系或所有流派。当前逐牌资料标记为“团队逐牌初审”，只称“基础牌义”，不得称“官方牌义”。

当前案例库为团队初审的可运行种子集，不代表经典著作中的真实个案，也不声称已经覆盖 78 张牌的全部问题类型。当前不把以下内容当作默认真值：

- 固定的占星、卡巴拉或炼金术对应；
- 相邻牌必然改变吉凶的硬规则；
- 牌面组合的穷举表；
- 精确时间、概率、金额、人物身份或外部事件预测；
- 第三方秘密与心理诊断。

如果未来加入特定流派，必须记录来源、版本与适用范围，不能把互相冲突的体系无说明地混合成更确定的结论。
