# 术语双写规范

> **核心原则**：专业名词**不删除、不替换**，但**必须配一句人话解释**。
>
> 删掉术语，用户没法拿报告去跟医生沟通；只写术语不解释，用户看不懂。两者都不可接受。
> 本文件在**通俗版与专业版模式下都生效**（专业版可省略解释，但首次出现仍需给出）。

---

## 零、准用名规范（先定名，再解释）★

**术语的选词以全国科学技术名词审定委员会公布的《医学名词》为准。** 双写解释的是「准用名」，不是民间叫法。

三条要求：

1. **主称必须是规范名或规范英文缩写**，民间叫法只能放在人话解释里
2. **旧称、院内简称不得做主称**
3. **模糊表述必须落到具体指标 + 数值**，否则构成歧义

| 规范写法 | 不规范写法 | 问题 |
|---|---|---|
| 糖化血红蛋白（HbA1c，反映近 2~3 个月平均血糖） | 「糖化」 | 院内简称，非规范名 |
| 丙氨酸氨基转移酶（ALT，旧称谷丙转氨酶，反映肝细胞损伤） | 「谷丙」 | 旧称做主称 |
| 估算肾小球滤过率（eGFR，肾脏过滤能力） | 「肾功能指数」 | 自造名词 |
| 促甲状腺激素（TSH，指挥甲状腺干活的信号） | 「甲功一项」 | 项目名当指标名 |
| 尿素（Urea）7.2 mmol/L | 尿素氮 7.2 | **尿素 ≠ 尿素氮，差 2.14 倍**，混用直接导致误判 |
| 低密度脂蛋白胆固醇（LDL-C，俗称「坏胆固醇」）3.2 mmol/L | 「坏胆固醇 3.2」 | 只留俗称，无法与医生沟通 |
| 甘油三酯（TG，旧称三酰甘油）2.1 mmol/L | 「血脂高」 | 未落到具体指标 |
| 丙氨酸氨基转移酶 62 U/L（超上限 24%） | 「肝功能不好」 | 未落到指标与幅度，且倾向夸大 |

> **歧义词黑名单**：血脂高 ｜ 肝功能不好 ｜ 三高 ｜ 肾不好 ｜ 血象异常 ｜ 内分泌失调。
> 这些词不得单独出现，必须写明是哪一项、数值多少、超/低于阈值多少。

## 一、双写格式（强制）

### 标准格式

```
专业名词（人话解释）
```

**正例**：
- eGFR（肾脏过滤能力，反映肾功能好坏的核心指标）
- LDL-C（俗称「坏胆固醇」，是堵血管的主要元凶）
- HbA1c（糖化血红蛋白，反映近 2~3 个月的平均血糖水平）
- MCV（红细胞的平均体积，判断贫血类型靠它）
- BI-RADS 4A（乳腺影像分级，4A 表示低度可疑，恶性概率 2~10%）

**反例**：
- 反例 `eGFR 95.1 正常` —— 用户不知道这是什么
- 反例 `肾脏过滤能力 95.1 正常` —— 删了术语，无法与医生对话
- 反例 `eGFR（估算肾小球滤过率）` —— 用另一个术语解释术语，等于没解释

### 关键要求

| 要求 | 说明 |
|---|---|
| **解释必须是人话** | 不能用另一个术语解释术语。「肾小球滤过率」不是「eGFR」的人话解释 |
| **解释说清「有什么用」** | 不只说是什么，要说它反映什么、为什么要看它 |
| **每份报告首次出现时必写** | 同一份报告内重复出现可只用术语，不必每次都解释 |
| **章节标题用人话，正文保留术语** | 标题不塞术语；正文术语 + 解释并存 |

## 二、常用术语解释库

### 2.1 肾功能

| 术语 | 人话解释 |
|---|---|
| eGFR | 肾脏过滤能力，反映肾功能好坏的核心指标。数值越高越好，90 以上算正常 |
| 肌酐 Cr | 肌肉代谢产生的废物，靠肾脏排出。它偏高常提示肾脏排废能力下降 |
| 尿素氮 BUN | 蛋白质代谢的废物，也靠肾排。与肌酐一起看肾功能 |
| 胱抑素 C | 另一种反映肾功能的指标，比肌酐更少受肌肉量影响 |
| UACR | 尿里的微量白蛋白，肾脏受损的早期信号，常比 eGFR 更早发现问题 |
| CKD | 慢性肾脏病，指肾功能异常持续超过 3 个月 |

### 2.2 血脂

| 术语 | 人话解释 |
|---|---|
| LDL-C | 俗称「坏胆固醇」，是堵血管的主要元凶，越低越好 |
| HDL-C | 俗称「好胆固醇」，负责把血管里的脂质运走，越高越好 |
| TG 甘油三酯 | 血里的中性脂肪，和吃得油不油、喝不喝酒关系最大 |
| TC 总胆固醇 | 所有胆固醇的总和，包含好的和坏的 |
| 非 HDL-C | 除「好胆固醇」外的全部致病脂质，血脂高时比单看坏胆固醇更准 |
| Lp(a) | 脂蛋白 a，主要由遗传决定，偏高会独立增加心血管风险，吃药难降 |
| ASCVD | 动脉粥样硬化性心血管病，就是血管被脂质堵塞导致的心梗、脑梗这类病 |
| AIP | 由甘油三酯和好胆固醇算出的指数，反映血里「小而密」的坏颗粒多不多 |

### 2.3 血糖

| 术语 | 人话解释 |
|---|---|
| FPG 空腹血糖 | 空腹 8 小时以上测的血糖，糖尿病最基础的筛查指标 |
| HbA1c 糖化血红蛋白 | 反映近 2~3 个月的平均血糖，不受当天吃喝影响，比单次血糖更可靠 |
| OGTT | 糖耐量试验，喝一杯糖水后测血糖，看身体处理糖的能力 |
| HOMA-IR | 胰岛素抵抗指数，反映身体对胰岛素是否「变迟钝」了 |
| 胰岛素抵抗 | 身体对胰岛素反应变差，需要分泌更多胰岛素才能压住血糖，是糖尿病前奏 |

### 2.4 肝功能

| 术语 | 人话解释 |
|---|---|
| ALT（谷丙转氨酶） | 主要存在肝细胞里，肝细胞受损时会漏到血里，是最敏感的肝损伤指标 |
| AST（谷草转氨酶） | 和 ALT 类似，但心脏和肌肉里也有，所以剧烈运动后也会升高 |
| GGT | 与胆道和酒精关系密切，喝酒的人常见升高 |
| ALP 碱性磷酸酶 | 肝胆和骨头里都有，需结合其他指标判断来源 |
| 总胆红素 | 红细胞代谢产物，肝处理不了或胆道堵了会升高，高了会发黄 |
| 白蛋白 | 肝合成的蛋白质，降低说明肝的「生产能力」下降，比转氨酶更能反映肝的储备 |
| FIB-4 | 由年龄和几项血指标算出的评分，用来估算肝脏有没有变硬（纤维化） |
| NAFLD | 非酒精性脂肪肝，不喝酒的人得的脂肪肝，多与超重、血糖血脂异常有关 |

### 2.5 血常规

| 术语 | 人话解释 |
|---|---|
| Hb 血红蛋白 | 红细胞里负责运氧的成分，低了就是贫血 |
| MCV | 红细胞的平均体积。判断贫血是哪一类，主要靠它 |
| MCH / MCHC | 红细胞里血红蛋白的平均含量与浓度，配合 MCV 判断贫血类型 |
| RDW | 红细胞大小是否均匀。缺铁时大小不一，这个值会升高 |
| WBC 白细胞 | 身体的防御部队，感染、炎症时会变化 |
| 中性粒细胞 | 白细胞的主力，细菌感染时升高最明显 |
| PLT 血小板 | 负责止血凝血，太低容易出血，太高容易血栓 |
| 网织红细胞 | 刚生出来的「新兵」红细胞，反映骨髓造血是否活跃 |
| 铁蛋白 | 身体的铁库存量。它低说明真缺铁，但发炎时会假性升高 |
| 转铁蛋白饱和度 | 运铁的「车」装了多少铁，低于 15% 提示缺铁 |

### 2.6 甲状腺

| 术语 | 人话解释 |
|---|---|
| TSH | 脑垂体发给甲状腺的「指令信号」。甲状腺偷懒时，指令会加大，所以 TSH 升高常提示甲减 |
| FT4 游离甲状腺素 | 甲状腺实际产出的激素量，是判断甲功的直接指标 |
| FT3 | 活性更强的甲状腺激素 |
| TPOAb / TgAb | 攻击自己甲状腺的抗体，阳性提示自身免疫性甲状腺炎（桥本病） |
| 亚临床甲减 | 指令信号（TSH）已升高但激素产量（FT4）还正常，属于甲减的早期阶段 |
| TI-RADS | 甲状腺结节的超声分级，用数字表示恶性可能性有多大 |

### 2.7 心脏

| 术语 | 人话解释 |
|---|---|
| cTnI / cTnT 肌钙蛋白 | 心肌专有的蛋白，升高说明心肌确实受损，是判断心梗的关键 |
| CK-MB | 偏心肌的肌酸激酶，也用于心肌损伤判断 |
| CK 肌酸激酶 | 肌肉里的酶，剧烈运动后也会大幅升高，不一定是心脏问题 |
| BNP / NT-proBNP | 心脏压力大时分泌的激素，升高提示可能有心衰 |
| LVEF 射血分数 | 心脏每次收缩能把多少血泵出去，正常应在 50% 以上 |
| D-二聚体 | 血栓分解的产物，升高需排除血栓，但很多情况都会升高，不能单独诊断 |
| 颈动脉斑块 | 颈部血管壁上的脂质沉积，说明动脉硬化已经开始，是血管的「预警灯」 |

### 2.8 影像与其他

| 术语 | 人话解释 |
|---|---|
| BI-RADS | 乳腺影像分级，用数字表示恶性可能性。数字越大风险越高 |
| Lung-RADS | 肺结节分级，同理 |
| LI-RADS | 肝脏病灶分级 |
| 磨玻璃结节 GGN | CT 上看起来像磨砂玻璃的淡淡阴影，生长很慢，需长期观察 |
| 骨密度 T 值 | 骨头结实程度的评分，与健康年轻人比较。低于 −2.5 算骨质疏松 |
| 钙化灶 | 陈旧病变愈合留下的疤痕，绝大多数无需处理 |
| 肿瘤标志物 | 某些肿瘤可能升高的血液指标，但很多良性情况也会升高，不能用来诊断癌症 |
| 危急值 | 医院规定的「危险线」，超过它意味着需要立刻处置，不能等 |
| 参考区间 | 大多数健康人的数值范围，不等于「你个人的目标值」 |
| 个体目标值 | 根据你的具体情况（年龄、疾病、风险）定的目标，可能比参考区间严格得多 |

## 三、术语首现示例（正文写法）

```
eGFR（肾脏过滤能力，反映肾功能好坏的核心指标）95.1 mL/min/1.73m²
├─ 参考标准：≥90 为正常
├─ 本次结论：正常
└─ 需注意：这个值是根据肌酐算出来的，而肌酐受肌肉量影响。
          如果你健身、肌肉量大，实际肾功能可能比算出来的更好；
          如果偏瘦或年纪大，可能被高估。必要时可加做胱抑素 C 复核。
```

```
LDL-C（俗称「坏胆固醇」，是堵血管的主要元凶）3.2 mmol/L
├─ 报告参考区间：<3.4 → 在范围内，所以报告上没标箭头
├─ 你的个体目标：<2.6（因为你有糖尿病且年龄超过 40，属高危人群）
└─ 实际结论：虽然报告没标异常，但按你的情况已经超标 23%，需要干预

  为什么会有两个标准？参考区间是「大多数健康人的范围」，
  而个体目标是「针对你的风险水平定的目标」。风险越高，目标越严格。
```

## 四、章节标题命名规范

标题**专业简洁**，既不堆术语，也不口语化。格式：`序号 + 空格 + 标题文字`（**无 emoji**）。

### 4.1 十一段标准标题

| # | 标题 | 这一段回答什么 |
|---|---|---|
| 01 | 报告总结 | 有哪些问题、哪个最急 |
| 02 | 处理优先级 | 什么时候去、去哪个科 |
| 03 | 异常指标详细解读 | 每一项具体什么情况 |
| 04 | 关联性分析 | 这几项凑在一起说明什么 |
| 05 | 干扰因素排查 | 有没有可能是假异常 |
| 06 | 风险预测 | 未来风险有多大 |
| 07 | 趋势变化 | 和以前比是好了还是坏了 |
| 08 | 下一步 | 具体要做什么 |
| 09 | 生活指导 | 吃、动、睡怎么调 |
| 10 | 参考指南 | 这些判断依据是什么 |
| 11 | 重要提醒 | 边界与免责 |

**通俗版与专业版共用这一套标题**，差异只在正文的术语密度与鉴别诊断深度。

### 4.2 调性规范：四条要求

**4~8 字 ｜ 名词短语 ｜ 不用疑问句 ｜ 不用第二人称**

| 反例 | 问题 | 正例 |
|---|---|---|
| 先看这里 | 过于口语 | 报告总结 |
| 哪些要紧，哪些不用急 | 口语 + 逗号断句 | 处理优先级 |
| 每项指标什么意思 | 疑问句 | 异常指标详细解读 |
| 几项异常放在一起说明什么 | 疑问句 + 超长（11 字） | 关联性分析 |
| 这些异常会不会是虚惊一场 | 疑问句 + 超长 | 干扰因素排查 |
| 风险算给你看 | 口语 + 第二人称 | 风险预测 |
| 和以前比，是好了还是坏了 | 疑问句 + 超长 | 趋势变化 |
| 接下来该做什么 | 疑问句 | 下一步 |
| 吃动睡怎么调 | 口语 + 疑问句 | 生活指导 |
| 交叉模式发现 | 内部推理方法名 | 关联性分析 |
| 定量风险评估 | 过于技术 | 风险预测 |

> **关键认知**：通俗性不该由标题承担。
> 标题只负责导航与专业感，让人看懂的活交给正文 —— 标题写「06 风险预测」，
> 正文里照样写「eGFR（肾脏过滤能力）」。这两件事不冲突。

**03 与 04 必须拉开区分**。「异常指标详细解读」与「异常指标综合分析」前四字相同，
目录并排时扫读易混，所以 04 改为「关联性分析」，与 03 零字重复。

### 4.3 三级序号体系

```
01 异常指标详细解读            ← 一级：两位数补零
  3.1 血糖升高（糖尿病可能）     ← 二级：章节序号.序
    3.1.1 可能是什么            ← 三级：章节.序.序
  3.2 血钾偏高（需先排除抽血因素）
```

| 层级 | 格式 | 补零 | 示例 |
|---|---|---|---|
| 一级（章节） | 两位数 | 补零 | `01`、`07`、`11` |
| 二级 | 章节.序 | 不补零 | `3.1`、`8.5` |
| 三级 | 章节.序.序 | 不补零 | `3.1.1`、`8.5.1` |

三条好处：
1. **正文可精确引用** —— 写「见 6.2」「4.2 分析出…」，读者能直接定位
2. **改名不破坏引用** —— 引用只写序号不带章节名，章节改名后引用仍然准确
3. **便于评审沟通** —— 可以直接说「3.4 那段改一下」

**HTML 实现**：序号用 `font-variant-numeric: tabular-nums` 保证等宽对齐；一级用深色徽章，二三级用弱化色。

### 4.4 禁用 emoji

医疗报告**全文不使用 emoji**，三条理由：

1. **导出会坏** —— 转 Word/PDF 或黑白打印时 emoji 表现不稳定，某些环境显示成方框。这份报告要打印带去门诊。
2. **跨平台不一致** —— 同一个符号在 macOS、Windows、Android 上样式不同，视觉规范失控。
3. **医疗场景严肃性** —— 且少一个可出错的地方。

视觉层次由**序号徽章、左侧色条、字重、留白**承担，不靠 emoji。

> **唯一例外**：Markdown 交付形态允许用 `⚠` 一个符号做关键提示的视觉打断（全篇 ≤5 处）。
> 纯文本环境里它是唯一可用的打断手段。除此之外不用任何符号装饰。

### 4.5 四档随访的呈现措辞

内部推理用 L1~L4，**给用户的文字一律用右列写法**：

| 内部代号 | 给用户看的写法 | 时间窗 |
|---|---|---|
| L1 | **需立即就医** | 数小时内 |
| L2 | **两周内专科就诊** | 14 天 |
| L3 | **一至三个月复查** | 30~90 天 |
| L4 | **年度随访** | 12 个月 |

早期版本用过「马上去医院（别等）」「明年体检时再看就行」，同样太随意，已收敛为上表措辞。

## 五、问题命名规范

**异常总结的单位是「问题」，不是「指标」。**

用户记不住 8 条指标，但记得住 3 个问题。指标应降级为问题的**证据**。

### 5.1 归纳示例

```
错：LDL-C 3.2 偏高 ｜ 甘油三酯 2.1 偏高 ｜ HDL-C 1.1 偏低      ← 三条并列，看完记不住
对：血脂异常（坏胆固醇未达标 + 好胆固醇偏低）
    依据：LDL-C 3.2 · 甘油三酯 2.1 · HDL-C 1.1
```

### 5.2 命名三条铁律

| 情形 | 写法 | 示例 |
|---|---|---|
| 达到诊断阈值 | 现象 +（XX **可能**） | 血糖升高（糖尿病可能） |
| 未达诊断阈值 | 只写现象，**不得**提疾病名 | 血压偏高（临界） |
| 需排除干扰因素 | 现象 +（需先排除 X） | 血钾偏高（需先排除抽血因素） |

- **「可能」二字不可省** —— 省掉就变成确诊，越界
- 未达阈值**禁止**出现疾病名 —— 「血压偏高」不能写成「高血压」
- 命中组合诊断标准时（如代谢综合征）单列为一个整体性问题

### 5.3 常见问题命名对照

| 指标异常 | 问题名 |
|---|---|
| 空腹血糖 ≥7.0 | 血糖升高（糖尿病可能） |
| 空腹血糖 6.1~6.9 | 血糖偏高（糖尿病前期） |
| 腰围超标 + BMI 超重 | 中心型肥胖 |
| LDL-C 未达个体目标 + TG↑ + HDL-C↓ | 血脂异常（坏胆固醇未达标 + 好胆固醇偏低） |
| 130/85 ≤ 血压 < 140/90 | 血压偏高（临界） |
| 血压 ≥140/90 | 血压升高（高血压可能） |
| ALT↑ + 超声脂肪肝 | 肝酶升高（脂肪肝可能） |
| 血钾轻度↑ + LDH↑ | 血钾偏高（需先排除抽血因素） |
| eGFR 60~89 且无其他异常 | 肾功能轻度下降（需结合尿检判断） |
| TSH 区间内但持续上升 | 甲状腺功能可能正在减退（趋势发现） |

**问题名要能被用户复述给医生**。「血脂异常」比「LDL-C 3.2」更容易记住和转述。

## 六、禁止事项

| 禁止 | 原因 |
|---|---|
| 删掉术语只留人话 | 用户无法拿报告与医生沟通，也无法自行检索 |
| 只写术语不解释 | 看不懂，等于没解读 |
| 用术语解释术语 | 「eGFR 即估算肾小球滤过率」是无效解释 |
| 章节标题塞术语 | 标题是导航，必须一眼可懂 |
| 解释里塞新术语 | 解释中如必须引入另一个术语，该术语也要配解释 |
| 每次出现都重复长解释 | 同份报告内首次解释即可，后续直接用术语，避免啰嗦 |
| 解释写成教科书定义 | 要说「有什么用」，不是背定义 |
| 标题写成口语（「先看这里」「吃动睡怎么调」） | 医疗报告需要专业调性；通俗性由正文承担 |
| 标题带 emoji | 导出与打印表现不稳定、跨平台不一致 |
| 二三级标题不带序号 | 正文无法精确引用 |
| 异常总结罗列指标而非归纳问题 | 用户记不住指标名，记得住问题名 |
| 未达诊断阈值却写疾病名 | 越界，会让用户误以为已确诊 |
| 问题名省掉「可能」二字 | 「血糖升高（糖尿病）」= 确诊，越界 |
| 向用户输出 L1~L4 代号 | 用户不知道 L1 是什么，须用措辞替换 |
