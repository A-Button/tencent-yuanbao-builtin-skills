# 爆款文案范例库

## 古风穿越类 · 经典结构

### 范例1：三国穿越文

**原文事件**：赵云大哥身份、收张宁、攻黄巾、张角病死

**爆款文案结构（直接可套用）**：

```
我穿到三国成了赵云的大哥
不仅成为了辽东侯率兵征战黄巾军
还意外掠走了张角之女张宁

眼看攻城之时我却从战场回来了

大哥？你怎么回来了？
外面还是擂鼓之声阵阵
显然是战斗还未结束
我却在此时进帐
张宁惊讶地问

宁儿跟我来
不由分说我拉着张宁的手
走出军帐

嘤……张宁的手被我攥在手上
顿时满脸通红
低着头跟在我的身后
```

**写作技巧解析**：
- 开头三句直接交代"穿越+身份+收获"，信息密度极高
- 悬念句"大哥？你怎么回来了？"勾起好奇心
- 暧昧细节（握手）让观众有代入感
- 短句节奏快，口播友好

### 范例2：打脸爽文结构

**核心爽点**：用圣旨公开羞辱沙摩柯

```
子虎刚才有统计
此次攻城折损士兵总计两千六百余人！
是我皇甫义真这些年来
见过的攻城最小伤亡数了！
皇甫嵩有些赞叹地说道

两千六……我道
恩就算是两千六吧
也就是要打你一百三十军棍喽？

呦这一百三十军棍可不轻啊？
你能受得了么？
不如咱不打了吧？

废什么话俺老沙认栽了！
不就是一百三十军棍吗
打了便是！沙摩柯一张黑脸涨的通红

嘿嘿大哥打人这种体力活就不麻烦您了
交给俺老张就好了
俺老张的手可是痒得不行了！张飞插嘴道

好那就由你来执行！
每一棍的力道都要足
不然就是看不起我们的沙三爷！
还有一百三十棍一棍都不能少
不然还是看不起我们的沙三爷！我笑道
```

**写作技巧解析**：
- 数字对比："两千六"vs"一百三十军棍"，冲突感极强
- 欲擒故纵："不如咱不打了吧？"→引爆笑
- 群戏配合：沙摩柯认栽 + 张飞补刀 + 我补刀 = 三重爽感
- 每一句都是独立的"打脸画面"

## 都市逆袭类 · 常用结构

### 范例3：都市装逼打脸

```
电话响了
我瞥了一眼来电显示
是我丈母娘

「小李啊，你什么时候把彩礼钱打过来？」
「你弟弟等着这笔钱结婚呢！」

我把电话挂断
转头对秘书说
「把城西那块地的合同拿过来」

我老婆还不知道
她嫁给我那天
我就已经是这座城市最有钱的人了
```

**写作技巧解析**：
- 开场冲突：丈母娘来电催彩礼
- 反转铺垫：挂断电话 + 淡定吩咐秘书
- 身份揭露：最有钱的人
- 留悬念：老婆不知道

## 情绪爆发类 · 核心模板

### 范例4：情感冲击

```
她问我愿不愿意带她走
我沉默了

不是不想
是不能

她是仇人的女儿
而我……是亲手杀死她父亲的人
```

**写作技巧解析**：
- 三句式情绪递进：问→沉默→内心独白
- 身份冲突制造强烈戏剧张力
- 留白给观众情绪消化时间

## 爆款标题公式

| 类型 | 公式 | 例子 |
|------|------|------|
| 震惊体 | "我随口一句话，他竟然……" | 我随口一句话，130军棍没了 |
| 逆袭体 | "曾经看不起我的人，现在……" | 曾经嘲笑我是穷小子的，现在给我打工 |
| 收获体 | "攻城胜利，我获得了……" | 攻下黄巾城，我获得了3000俘虏 |
| 暧昧体 | "她问我愿不愿意……" | 她问我愿不愿意带她走 |
| 冲突体 | "他问我是要……还是……" | 他问我是要江山还是要她 |

## 改写对照表（原文→推文句式）

| 原文写法 | 推文写法 | 原因 |
|---------|---------|------|
| 赵风开口道 | 我道 | 第一人称代入感 |
| 张飞性格暴躁 | 俺老张老沙动不动就急 | 口语化、口播友好 |
| 两人纷纷陷入沉思 | 俺俩都傻眼了 | 情绪外化 |
| 戏忠娓娓道来 | 志才一拍大腿说道 | 动作+口语 |
| 程昱恍然大悟 | 仲德一拍脑门：俺咋把这事给忘了！ | 北方口语+动作 |
| 禀告将军 | 报告！/ 报！ | 简洁有力 |
| 不多时 | 没过一会儿 | 口语化 |
| 面色微红 | 脸刷地一下红了 / 满脸通红 | 情绪外化，更生动 |
