# 同程旅行搜索

用户搜索航班、酒店或国内火车票，继续查看已选航班详情或航班验价时使用。产品数据来源为同程旅行。机票支持搜索、详情和验价，酒店和火车票仅支持列表搜索。

## 使用范围

本技能只处理航班、酒店和国内火车票产品需求，并调度以下工具：

| 工具 | 使用范围 |
|---|---|
| `flight_search` | 国内、国际单程航班列表搜索；往返必须拆成去程和返程两次搜索 |
| `flight_detail` | 查看从航班搜索结果中选定的国内或国际航班详情 |
| `flight_estimate` | 对已选国际航班产品进行预订前验价 |
| `hotel_search` | 酒店列表搜索 |
| `train_search` | 国内火车票列表搜索 |
| `ai_search` | 处理单一垂类内的长尾、模糊表达、主观体验等非标准搜索需求 |

机票支持"搜索 -> 详情 -> 验价"链路：国内、国际航班可搜索和查看详情；验价仅支持国际航班，使用 `flight_detail` 返回的产品四段标识（`tripId`、`productId`、`detailKey`、`resourceId`）和 `flowId`。验价能力是返回预估单和后续创单所需数据，不代表代用户直接完成下单、支付或出票。酒店和火车票仅支持列表搜索，没有详情和验价工具。

## 适用场景

以下情况启用本技能：

- 搜索国内或国际航班，并按日期、航线、舱等、航司、时段、机场或直飞等条件筛选；
- 从航班搜索结果中继续查看已选航班详情，或对已选航班产品进行预订前验价；
- 按目的地、日期、位置、品牌、星级、预算或设施等条件搜索酒店列表；
- 按出发地、目的地、日期、车次类型、席别、时段或直达等条件搜索国内火车票列表；
- 在航班、酒店或国内火车票单一垂类内处理长尾、模糊表达、主观体验等非标准搜索需求。

## 不适用场景

- 酒店预订、锁房、支付、取消或订单售后；
- 火车票预订、占座、支付、出票、订单查询或退改签办理；
- 国际火车票，以及汽车票、船票、景点门票、租车等其他产品；
- 与三类产品搜索无关的签证、目的地攻略、天气、机场接送或纯行程内容；

遇到不适用场景时明确说明能力边界；不要用 `ai_search` 冒充不存在的交易、订单或其他产品工具。

## 工具路由与配合

垂类查询接口包括 `flight_search`、`hotel_search` 和 `train_search`，直接面向具体产品，适合日期、地点、价格、星级、舱等、车次等客观且可表达的标准条件，主要返回当前产品列表和结构化信息。这类接口不负责理解“服务好”“更舒服”“适合带宝宝”等主观或个性化判断。

`ai_search` 是航班、酒店、国内火车票垂类内的非标准需求搜索接口，适合处理长尾、非标准、主观体验等需求。它不负责跨产品综合查询、方案比较、行程规划或泛旅行问答，也不会扩展产品能力边界或替代航班详情与航班验价。`ai_search` 不是垂类查询接口的固定前置或后置步骤。

### `ai_search` 与垂类查询接口使用场景

| 场景 | 调用方式 |
|---|---|
| 标准条件明确 | 只调用对应垂直接口，不重复调用 `ai_search` |
| 长尾、非标准、主观体验等非标准需求是核心 | 直接调用 `ai_search`，保留用户原始表述 |
| 同一垂类内同时包含标准条件和非标准需求 | 使用 `ai_search` 做非标准搜索，不丢失日期、地点、预算等硬条件 |
| 跨产品比较、组合或行程规划 | 不使用本 Skill 的 `ai_search`，明确其能力边界 |
| 垂直接口失败 | 先如实说明失败、空结果或未满足条件；若用户需求本身属于 `ai_search` 适用范围（长尾、非标准、主观体验等），可再调用 `ai_search` 兜底，不强制、不默认 |
| AI 搜成功 | 使用其回答及产品参考信息，不默认重复调用垂直搜索接口 |
| AI 搜后选定航班并继续操作 | `ai_search` 的航班 structured 复用 `flight_search` 链路，含 `flightNo`、`tripId`、`flowId` 等真实标识；字段足以满足 `flight_detail` 入参时直接调用，字段缺失时先用 `flight_search` 补齐。国际航班继续验价时按 `flight_detail` -> `flight_estimate` 调用；国内航班不支持验价 |
| AI 搜后继续酒店或火车票操作 | 只能停留在列表搜索；后续标准条件查询可调用 `hotel_search` 或 `train_search`，不能调用不存在的详情或验价工具 |

根据上表选定入口后，按产品类型读取对应 Reference，确认准确的参数、后续调用顺序和能力边界：

- 航班：[references/flight-search.md](references/flight-search.md)
- 酒店：[references/hotel-search.md](references/hotel-search.md)
- 火车票：[references/train-search.md](references/train-search.md)

`ai_search` 的产品参考信息只能按实际返回内容使用。它不负责综合查询和规划；酒店和火车票经过 `ai_search` 后仍然只有列表搜索能力，不会增加详情或验价能力。

## 调用约束

- 不知道准确城市码、机场码或产品标识时不要猜，优先传名称。
- 缺少工具必需且无法从上下文确定的地点、日期或产品标识时，先向用户确认；工具明确支持未指定日期时，按对应 Reference 传递未指定状态。
- 用户未明确日期时，严格遵守各工具的未指定日期规则，不得自行编造日期。
- 机票验价仅支持国际航班，必须原样沿用 `flight_detail` 返回的 `flowId` 和 `tripId`、`productId`、`detailKey`、`resourceId` 四段标识；禁止生成、修改或跨产品混用。
- 只根据工具实际返回内容回答；价格、库存、设施、行李、退改规则和可订状态缺失时应说明无法确认。
- 搜索无结果只表示当前条件和当前数据源未返回匹配结果，不表示现实中不存在。
