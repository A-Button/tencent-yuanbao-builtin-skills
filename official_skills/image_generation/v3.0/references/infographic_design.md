# infographic_design —— 信息图 / 知识可视化生图技能

信息图（Infographic）的目标不是绘制一张漂亮的图片，而是将复杂知识组织成**易浏览、易理解、易记忆**的信息系统。相比普通插画，本技能更加关注信息架构、阅读体验和知识表达，负责将零散知识整理为一张结构完整、信息丰富、图文结合、具有教材和百科质量的信息图。

重点优化以下能力：

- 信息架构（Information Architecture）
- 阅读路径（Reading Flow）
- 信息层级（Visual Hierarchy）
- 图文比例（Text–Illustration Balance）
- 图标系统（Icon System）
- 教育插画（Educational Illustration）
- 信息密度（Information Density）
- 可读性（Readability）

# 1. 触发与不触发

## 1.1 触发条件

满足以下任一情况即可触发：

- 用户明确要求制作信息图、知识卡片、图解、示意图、教材插图、手抄报、流程图、对比图、时间轴、结构图、思维导图、科普海报、一图读懂等知识可视化内容。
- 用户提供一段说明性、知识性、结构性、流程性、数据性内容，希望整理成图片。
- 用户没有明确提到"信息图"，但语义明显属于知识可视化，例如：
  - 把光合作用画成一张科普图。
  - 给 PPT 配一张 Transformer 示意图。
  - 用一张图解释 TCP 三次握手。
  - 做一张讲解人体循环系统的插图。

## 1.2 不触发

以下场景不使用本技能：

- 纯艺术插画、海报、写真等普通生图（image_generation）。
- 多格漫画、连续故事（storyboarding）。
- 如没有风格插画等要求，仅需要一个严格的数据图表（柱状图、折线图、饼图等）优先使用代码生成；若用户希望进一步制作艺术化信息图，可结合图片处理能力进行美化。
- 社交媒体内容若本质属于知识整理、流程讲解或数据可视化，应优先使用本技能，而不是 media_planning。

# 2. 工作流

## 阶段 A：意图识别与信息抽取

| 槽位 | 含义 | 缺省策略 |
|------|------|---------|
| knowledge_source | 要可视化的知识内容 | 用户提供内容必须保留；涉及小众知识、非常见的真实实体、时效信息时，应先 web_search 查证文字内容及参考图片后再生成。 |
| audience | 受众 | 若用户指定受众，则调整知识深度、文字密度和插画复杂度；若未指定，默认面向普通公众，以百科/教材级信息密度设计，而不是儿童绘本风格。 |
| infographic_type | 信息图类型 | 根据知识结构自动判断教育插画、流程图、概念图、时间轴、对比图、长图、知识卡片等。 |
| style | 视觉风格 | 默认根据主题补充合适的艺术风格、画面质感和氛围（常见的风格如：儿童手绘、教材科学插画、扁平矢量、学科编辑报纸、MBE、等距、线稿等），避免混搭。 |
| aspect_ratio | 输出比例 | 优先遵循指令，当用户没有制定具体比例分辨率时，PPT 默认 16:9；公众号文章插图默认 2:3；小红书配图默认9:16/3:4；知识长图默认 9:16；手抄报默认4:3。 |
| text_density | 文字密度 | 默认采用中高信息密度；若预计正文超过约 1000 字，建议拆分多张。 |
| palette | 配色 | 根据主题自动规划，以表达语义为主，而非单纯装饰。 |

### 默认信息密度策略

除非用户明确要求儿童、低龄、绘本、启蒙等风格，否则默认采用**百科级、教材级、科普展板级**的信息组织方式，而不是社交媒体海报或儿童绘本。

默认应做到：

- 知识完整，而不是仅展示核心概念。
- 图文结合，而不是大面积留白。
- 有插画/图标和文字共同解释信息/知识。
- 包含必要的背景知识、组成结构、过程说明、应用价值等内容。需要有足够的信息量。
- 保持专业但易理解，而不是过度简化。

推荐结构：

- 标题
- 一句话概述
- 1～10 个一级知识模块
- 每个模块包含小标题、1～5 条知识点、对应插画、图标、标签、解释说明。大多需要成句段的文字做说明。

默认高密度信息量，除非面向小学生用户。多参考教材插图、百科图解、科学展板、博物馆展览板、科技报纸。

## 阶段 B：Plan 输出

### 1. 核心信息提炼

总结一句 Key Takeaway，明确整张图希望读者记住的核心观点。

### 2. 信息层级规划

规划整张信息图的信息结构：

- L0：输出张数。
- L1：主标题、副标题等信息层级规划（如分栏、区块、卡片布局和数量）。
- L2：一级知识模块（建议 1～10 个）。
- L3：每个模块包含 1～5 条知识点。
- L4：数据、案例、补充知识或扩展阅读。

当内容过多时，应拆分多张，而不是无限堆叠。

### 3. 插画规划

插画应承担知识解释作用，而不是装饰。每一处插画都要把画面里的具体元素铺开写清，让读者/模型能直接想象出画面。

建议根据主题规划，例如：

- 主插画（主体对象）
- 局部放大图
- 剖面图
- 流程示意图
- 场景辅助插画
- 标签说明

例如：
植物可展示整株植物、根、茎、叶、叶绿体放大；人体可展示器官、局部结构及功能箭头；机械可展示整体结构、剖面及零件放大。


### 4. 图标系统

图标数量由内容决定，不设下限。所使用的图标必须做到：
逐个描述：每个图标写清是什么、由哪些几何形状组成。
风格统一：全图图标描边规格、尺寸档位、颜色规则一致。
朝向明确：有方向的图标写清朝向。
禁止细节堆叠：图标简单即可，复杂对象放主插画区。
不写模糊词：禁止「一些精美小图标」「若干配套图标」等模糊表达。

每个一级模块至少对应一个具有明确语义的图标，例如：

- DNA → 双螺旋
- 水 → 水滴
- 能量 → 闪电
- 时间 → 时钟
- 循环 → 环形箭头
- 运输 → 箭头

避免大量使用灯泡等泛化图标。

### 5. 阅读路径

根据内容自动规划阅读方式：

- 上→下
- 左→右
- Z 型
- F 型
- 时间轴
- 环形流程
- 中心放射

箭头、编号和连接线必须帮助阅读，而不是装饰。

### 6. 版式规划

规划整体布局，例如：

顶部：标题、副标题。

中部：主体插画 + 多个知识模块。

底部：总结、公式、数据、来源或应用。

确保阅读路径自然，层级清晰。

### 7. 配色规划

颜色首先表达语义。用颜色和质感语言描述即可，围绕主题气质和内容表达选色：

生态自然：绿色 + 粉色 + 黄色 + 浅色背景、手绘质感。
海洋：蓝色 + 白色 + 珊瑚色、清新、自然。
中式文化：浅色背景、低饱和度中式配色。
工业机械：深蓝、柔和渐变蓝、白色、银色、苹果风格。
儿童科普：柔和明亮多色、儿童插画。

推荐：

- 主色 ×1
- 辅色 ×2
- 强调色 ×1
- 背景色 ×1

默认基调偏清新、明亮、通透，避免画面陈旧、土气，绝对不做“深色底 + 高饱和金/红大字/翠绿装饰/荧光色装饰”的厚重风格。 除非主题真的属于奢华、颁奖、金融庄严、复古油画这类明确需要暗底金字的场景，否则一律走清新路线：
背景：默认使用浅色底——纯白色、象牙白、宣纸、暖奶油、浅豆沙粉、雾青灰、天空浅蓝、淡绿等。如非科技感、简约类画面，避免大面积纯黑、墨色、深咖、暗紫、酒红作为主背景。
主色：柔和明亮色，或者柔和低饱和色——鼠尾草绿、雾霾蓝等。避免"贼亮橙+死黑""荧光金""厚重酒红"。
辅色：与主色同色系或邻近色的柔和变化，做出色系层次，而不是靠对比色打架。
强调色：只在关键处小面积使用，不要刺眼荧光色，面积保持很小（数字、编号胶囊、关键词高亮、少量花蕊/果实点缀）。
文字：和背景色搭配，要清新柔和、明亮大气。绝对避免“深色背景 + 金色立体字”，绝对避免“宣纸黑字大红印章”的老土的组合。即使使用金色，也尽量采用扁平、细字体、暗金色铂金质感。绝对避免“立体金属字”。
装饰：手绘感细描边 + 极浅底纹（纸纹、点阵、微斜条、水彩晕染）提升清新度，不要靠金属光、厚重投影堆质感。

### 8. 字体规划

明确各层级信息的字体，和主题匹配。主标题的文字很重要，需要高级、有设计感，颜色和整体氛围适配。除非信息内容偏官方、正式，不要默认黑体。

大致字体类型或常见明确字体，例如但不限于：无衬线 / 衬线 / 可爱手写体 / 等宽 / 现代中文黑体 / 现代中文宋体 / 毛笔字 / 草书 / 思源黑体 / 宋体 / 蜡笔手写体。
字号档位：主标题（特大）/ 副标题（大）/ 板块小标题（中）/ 正文（小）/ 标签（最小）。
轻重（字重）：粗 / 中等 / 常规 / 细。

例如："主标题“光合作用”，使用柔和明亮的绿色装饰艺术字，气泡质感，大字号"

### 9. Prompt 与输出规划

综合以上规划生成 Prompt。

超长图建议拆分上下两张生成，多图分别输出 Prompt。

## 阶段 C：Prompt 改写

Prompt 应完整描述信息图，而不是简单堆砌风格词。

推荐包含：

- 信息图类型
- 整体风格
- 输出比例
- 版式结构
- 阅读路径
- 主体插画
- 各知识模块
- 图标系统
- 标签文字
- 箭头关系
- 配色方案
- 背景及视觉约束

重点描述：

- 主插画画什么。
- 每个模块画什么。
- 每个模块有哪些图标。
- 每个图标具体画什么。
- 哪些地方需要局部放大。
- 哪些地方需要箭头。
- 哪些地方需要标签。
- 图中所有文字具体写什么。
- 图中所有箭头指向、符号、序号、数据图表、标注具体怎么画。

不要写：

> 加一些说明文字。

> 配一些插画。

而应写成：

> 左侧绘制完整植物结构，包括根、茎、叶；叶片剖开展示叶绿体；顶部绘制太阳；蓝色箭头表示水分运输；灰色箭头表示 CO₂；绿色箭头表示有机物运输；浅蓝色箭头表示氧气释放；所有关键结构均添加名称标签。

## 示例1
```text
一张横向的科学手抄报，画面像学生精心绘制的自然主题版面，整体以柔和明亮的绿色、粉色、黄色为主，搭配清新的浅色背景和轻盈的藤蔓波浪边框，氛围活泼、科普、温暖。顶部中央是最醒目的艺术字标题“蝴蝶的一生与保护”，字形圆润有装饰感，周围点缀叶子、花朵和飞舞的蝴蝶；标题下方居中写着较小的副标题“了解蝴蝶，保护生物多样性”，字体清晰端正，与主标题形成明显层级。画面中央偏下是一幅连贯的主插图：几只蝴蝶在花丛、草地和树枝间飞舞，花瓣、叶片、阳光和云朵自然融入背景，把四个知识板块连接起来，使整张手抄报内容丰富但不拥挤。


左上板块标题为“蝴蝶的一生”，放在浅色卡片区域内，标题比正文更醒目，旁边有四个连续小插图，依次表现叶片上的卵、毛毛虫、蛹和羽化的成虫蝴蝶，并用柔和箭头串联成生命周期。该板块正文分成四段短句，分别写着“卵：雌蝶把卵产在叶片上，经过一段时间孵化出幼虫。”、“幼虫（毛毛虫）：以植物为食，不断长大，会蜕皮几次。”、“蛹：幼虫找到合适的地方变成蛹，在蛹中进行变态发育。”和“成虫（蝴蝶）：蛹羽化成美丽的蝴蝶，交配后雌蝶再次产卵，开始新的生命周期。”文字排列整齐，插图与文字一一对应，科学准确又适合儿童阅读。


右上板块标题为“蝴蝶的生存需求”，配有花蜜、叶片、树木和自然环境的小图标，正文以清晰分行的短句呈现：“食物：幼虫需要特定的寄主植物叶片；成虫需要花蜜。”、“栖息地：需要有植物、树木、草地等自然环境。”、“适宜的环境：温暖、湿润、安静的环境，避免污染和破坏。”以及“安全的繁殖场所：寄主植物叶片是产卵的地方，提供庇护所。”这一栏的视觉重点在植物与蝴蝶的关系，叶片和花朵围绕文字形成自然生态感。


左下板块标题为“我们怎样保护蝴蝶”，标题旁有禁止捕捉蝴蝶、种植花草、减少农药和宣传保护的简洁图标，正文写着“保护自然栖息地：不破坏草地、树林，不随意摘花。”、“种植蝴蝶喜欢的植物：如马鞭草、醉鱼草、紫花地丁等。”、“减少农药使用：农药会杀死蝴蝶和它们的幼虫。”、“不捕捉野生的蝴蝶：让它们在自然中自由生活。”和“宣传保护知识：让更多人了解蝴蝶的重要性，一起保护它们。”这一栏排版紧凑但留有舒适间距，强调行动建议。


右下板块标题为“小知识”，周围有小放大镜、翅膀纹理、地图和传粉花朵的趣味插图，正文写着“蝴蝶用口器吸食花蜜。”、“蝴蝶的翅膀上有鳞片，帮助它们飞行和调节体温。”、“世界上有很多种蝴蝶，不同地区的蝴蝶种类不同。”和“蝴蝶是传粉者之一，帮助植物繁殖。”整张手抄报的边框由藤蔓、叶片和花朵组成，角落有蝴蝶停驻，底部花丛与中央蝴蝶插图连成一体，画面平衡饱满，文字清晰可读，呈现出一张兼具科学知识、自然美感和儿童手绘感的蝴蝶保护主题手抄报。

```

## 示例2


## Prompt 硬约束

- **文字必须完整写入 Prompt。** 图中所有标题、正文、标签均应明确写出，不允许使用「添加一些说明文字」等模糊表达。
- **默认采用高信息密度。** 除非明确要求儿童风格，否则应保证知识完整、模块丰富、图标丰富、插画丰富，而不是仅保留核心概念。
- **插画承担解释作用。** 建议同时包含主体插画、局部放大、流程箭头、标签、小场景插画等内容。主插画与板块小插画都要有具体内容与结构描述，不能只说"配一些插画"。
- **图标统一。** 全图统一一种图标风格，不混搭。
- **信息真实性。** 涉及最新新闻、知识，或者年份、机构、人物、科学数据等内容时，应先 web_search 查证。
- **配色用自然语言描述气质。** 用"柔和明亮的绿粉黄""宣纸暖米配朱砂靛青""深蓝配橙色"这样的语言。
- **插画与图标必须逐项精确描述（防畸形）。** 每一处插画、每一个图标、每一个编号、每一根箭头都要写明视角、姿态、几何构成、朝向；主体对象要写出正确的解剖或结构特征；图标简单为佳。
- **系列图直接重复描述保持一致。** 系列图每张 Prompt 中用一致语言重复描述**画面比例**、整体氛围、版面骨架、贯穿主体、字体感觉、边框装饰。
