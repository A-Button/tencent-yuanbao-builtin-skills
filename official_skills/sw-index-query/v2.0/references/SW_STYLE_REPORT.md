# SW_STYLE_REPORT —— 今日市场风格分析研报（HTML）

> **何时读取**：用户问"今日市场风格分析 / 今天风格怎么样 / 大盘小盘成长价值 / 市场风格偏向 / 风格切换"等，要求**当日市场风格 + 行业轮动 + 广度情绪**综合研报时读取本文件，按指导执行 `sw_style_report.py`。本场景是**固定版式的 HTML 研报**（宽基指数 + 风格维度 + 行业轮动 + 市场广度与情绪 + 风格判断与仓位含义），专为快速产出统一格式研报设计，是市场风格类问题的**唯一入口**（原 `sw_style.py` 风格风向标已移除）。

## 脚本

`scripts/sw_style_report.py`

```bash
python <skill根目录>/scripts/sw_style_report.py --breadth-json b.json            # 标准用法
python <skill根目录>/scripts/sw_style_report.py --breadth-json b.json --output <目录>
```

## 参数

| 参数 | 必填 | 说明 |
|------|------|------|
| `--breadth-json` | **是** | 市场广度数据 JSON 文件（见下"广度数据获取"），缺少时报错并提示获取方式 |
| `--output` | 否 | 输出目录（默认 `<工作目录>`） |

## 广度数据获取（重要：WorkBuddy 环境下用 neodata）

**市场广度与情绪区块（涨跌家数 / 涨停跌停 / 成交额 / 两融余额）不由脚本自取，也不做行业级兜底**——必须先在 WorkBuddy 中通过数据检索获取以下两项 neodata 数据，写入 JSON 后经 `--breadth-json` 传入：

1. **neodata · 大盘市场宽度统计**：沪深两市当日上涨/下跌/平盘家数、涨停/跌停家数、两市成交额（元）。
2. **neodata · 两融统计**：全市场融资融券余额、两融占流通市值比、两融交易额占成交额比（通常为前一交易日数据，如截至 8/14）。

获取后按以下结构写入 JSON 文件（字段均可省略，省略项在 HTML 中显示"—"）：

```json
{
  "up": 1435, "down": 3971,
  "limit_up": 53, "limit_down": 4,
  "up_down_note": "沪深两市个股（全市场口径）",
  "limit_note": "涨停53 / 跌停4",
  "amount": "1.39 万亿", "amount_note": "较昨日放量约1261亿",
  "margin": "2.67 万亿", "margin_note": "两融余额（截至8/14），占流通市值2.57%",
  "sentiment": "偏低", "sentiment_note": "涨幅≥7%仅45家，跌幅≥5%达1439家"
}
```

> 字段说明：`up`/`down` 为整数（上涨/下跌家数）；`amount`/`margin` 为展示字符串（可带"万亿/亿元"）；`sentiment` 为情绪定性（偏低/中性/偏暖）。这些统计可由当前可用的金融工具或网页检索提供；核实日期与全市场范围，不以行业上涨数量替代全市场个股广度。

## 数据口径（其他区块）

- **风格指数**：优先通过 westock 获取并核实的申万风格指数行情，判定市值风格（大盘/中盘/小盘）与估值风格（成长/价值）。
- **行业轮动**：申万 31 个一级行业实时行情，计算行业涨跌家数与领涨领跌（仅用于轮动图与行业结构判定，**不用于市场广度**）。
- **宽基指数**：优先 westock 获取上证指数/上证50/沪深300/中证500/中证1000/深证成指/创业板指（当日涨跌、近20日、YTD）；必要时通过网页核实对应宽基指数，保持指数名称与口径一致。
- **市场广度与情绪**：**全市场个股口径**，数据来自 neodata 大盘市场宽度统计 / 两融统计（经 `--breadth-json` 传入）。

| 用户表达 | 命令 |

```json

  "dominance": {"size": "小盘活跃", "valuation": "价值风格占优"},

              "amount": "1.39 万亿", "margin": "2.67 万亿", "sentiment": "偏低"},
```

**交付规范（必须）**：用 present_files 推送 `render_files["style-report"]["html"]`，回复中给出结论先行摘要（市场档位 + 市值/估值风格 + 行业领涨领跌 + 个股广度判断）。

## 已知坑

- 生成的 HTML 使用 ECharts CDN（需联网渲染图表）；交付前如环境允许，可对 HTML 内联 JS 做一次语法自检（`node --check`）。
- 行情为当日快照；**盘中调用得到盘中数据，收盘后调用得到收盘数据**，回复时注明"盘中/收盘"。
- 风格判定阈值：低PE vs 高PE 相差 >0.3% 才判占优，否则均衡；不要自行改动口径。
- **`--breadth-json` 必填**：缺失时脚本直接报错退出，提示通过 neodata 获取；禁止把申万一级行业 up/down 当作市场广度冒充个股口径。
- 两融统计通常滞后一个交易日（交易所 T+1 披露），回复中须注明数据截至日期。
