# 平面海报与商品视觉设计

## 触发与不触发

### 触发

- **商品销售与展示**：电商主图、车图、白底图、货架图、首图、场景图、模特图、卖点图、规格图、试色图、对比图、详情页和 A+ 页面；用户提供商品图片或描述，需要完成商品保真重绘、卖点合成、场景展示、系列主图或购买信息设计时触发。
- **品牌、活动与信息传播**：品牌或活动 KV、主视觉、海报、Banner、弹窗、促销图、大促视觉、倒计时、店招、直播间背景、短视频封面、营销长图、优惠券、朋友圈海报、菜单、电梯海报、易拉宝、展陈平面、礼盒包装及其他承担宣传、推广、销售或活动参与目标的物料。
- **成套设计与版位延展**：用户要求整套物料、多平台尺寸适配、主 KV 延展、系列海报、产品系列图、多风格提案、标题字体设计或多素材商业合成时触发；同一方向的不同资源位按同一设计系统执行，明确要求多风格提案时，各方向分别建立自己的设计系统。
- **商业语义明确**：即使没有说明设计品类，只要任务指向商品销售、品牌传播、活动推广或营销转化，例如“双十一做套大促物料”“做张周年庆海报”“新品发布做一组系列图”，均触发本技能。
- **媒体平台中的营销设计**：小红书、抖音、视频号、直播、信息流等只是传播渠道；交付物是产品发布图、商品系列图、营销封面、直播活动背景或其他宣传画面时，必须使用本技能。宣传册、画册、折页和长图即使信息较长，只要核心目标是营销传播仍使用本技能；淘宝店铺首页、活动会场、详情页及其他淘宝 UI 图也使用本技能。

### 不触发

- 核心交付是室内、户型、建筑外观或商业空间的空间设计方案时，使用 spatial_design；空间只作为商品或活动画面的背景时仍使用本技能。
- 核心交付是角色或 IP 的设定、三视图、表情动作及跨图角色一致性时，使用 character_design；已有角色或 IP 用于海报、活动与营销延展时仍使用本技能。
- 与营销、传播和销售信息无关的纯艺术创作、写真或单张配图，使用普通生图；纯演示文稿编辑、教学课件和一般媒体内容使用对应技能。
- 社媒图文、短视频和直播相关任务按最终交付判断：内容剪辑、媒体编排或一般发布不触发；需要设计营销封面、宣传主视觉、商品推广图或活动画面时触发本技能。

## A. 创意简报与设计策略

目的：先理解设计任务，整理传播内容与素材条件，明确这张图为什么做、给谁看、先传达什么，以及依靠什么形成记忆和行动。
### A1. 需求、物料与素材判断

开始设计前，先确认以下内容：

- **物料**：海报、KV、封面、主图、详情页、会场、长图、票券、信息图、包装、展板或其他实际载体，并确认数量、横竖方向、比例、实际容器和安全区；
- **用途**：品牌认知、产品发布、内容种草、销售转化、活动参与、信息说明、招商招募、文化传播或公共告知；
- **受众**：谁会看到，熟悉什么，需要相信什么，会在什么情境下作出判断；
- **观看环境**：手机信息流、商品货架、详情页、门店、展会、户外、印刷品或屏幕；
- **准确内容**：主标题、产品名、价格、折扣、日期、地点、机制、参数、品牌名、Logo 和行动信息；
- **素材条件**：商品、包装、人物、IP、场景、Logo、参考图及其清晰度和可编辑范围；
- **制作边界**：必须保持什么，允许改变什么，哪些内容可以合理补充，哪些信息必须核实。

尺寸与比例按以下顺序判断：用户明确尺寸或比例；实际广告位、印刷品和物理容器的硬规格；物料自身的阅读方式；平台常用比例；最后才使用默认值。未提供尺寸时，横版 Banner 通常采用 16:9 或实际容器比例；活动弹窗按真实容器规格，无法确认时可用 3:4 竖向内容区作为适配起点，但不把它定义为竖版海报；朋友圈营销、倒计时和品宣海报通常采用 3:4，短视频与开屏通常采用 9:16；商品主图按 C3 的平台与品类规则确定 1:1 或 3:4，同一套商品主图保持统一比例；完整详情页默认为一张连续竖向长图，按信息量采用约 1:6—1:10 或平台实际长画布，只有用户明确要求首屏或单一模块时才做单屏。直接投放前仍需核对当前平台和广告位规范。比例只决定阅读方向、信息密度、裁切和安全区，不自动决定竖版采用上文中图下文、横版采用左右分栏、方图采用居中商品。

一套物料先确定主 KV，再判断各资源位比例。用户明确指定主 KV 时服从指定；未指定时，按传播覆盖、信息完整度和后续延展能力选择首页主 Banner、完整活动海报或活动主视觉，不按用户列举顺序决定。没有明确平台和投放场景时，通常先建立横版主 KV，再延展竖版与方形物料，但这只是默认优先级，主题、素材或主要载体明显更适合竖版时可以调整。活动弹窗属于从主 KV 提炼利益与行动的适配物料，不作为整套设计的主 KV，除非用户明确指定或任务只有弹窗一种载体。

根据输入状态采用不同处理方式：

- 用户已给出完整设计提示词时，保留其核心创意、文字、图文关系和美术方向，只修复冲突、缺口、不可实现表达和载体问题；
- 用户只给出抽象诉求时，主动完成必要的内容梳理和视觉设计，不用长篇追问代替设计；
- 用户提供素材或参考图时，先判断它是主体素材、身份依据、风格参考还是不可修改区域；
- 缺失内容会改变价格、机制、人物身份、产品功效、活动事实或传播立场时，先询问或核实，不自行编造；
- 缺失内容只影响气氛、辅助短句、场景道具或普通行动词时，直接完成设计补充。

素材按以下方式使用：

- **商品、包装、Logo、人物和 IP**：作为身份依据，保持外形、比例、颜色、五官、包装文字和标志物；
- **照片和场景**：可重新裁切、组合、调光和安排层次，但不改变核心事实；
- **风格参考**：只提取当前任务真正需要的字形、版式、图文关系、配色、材质、媒介或光线；
- **品牌规范**：优先于一般审美偏好，除非用户明确要求突破或重塑；
- **多张参考图**：分别说明借鉴内容，不把几张图的所有特征同时堆入一张画面。

先判断参考资料的身份：

- **待延展的主 KV、海报或确认稿**：它是后续物料的设计源。完整记录准确文字、标题字形与字组轮廓、核心视觉概念、具体对象及位置、图文关系、图形母题、信息容器、色彩职责、媒介、材质和主光，不再重新选风格、配色和配图；
- **商品、人物、Logo 或 IP 素材**：它们提供身份和结构依据，可为构图调整裁切、角度、位置和光线，不改变识别特征；
- **风格或方法参考**：只提炼 1—3 个最能解决当前任务的依据，如标题字轮廓、标题与主体的穿插、构图骨架、媒介、材质或光线，不复制品牌、人物、文案和独有图形；
- **多张参考**：指定一张主参考，其余只补一个明确缺口，不让不同物料分别跟随不同参考。

不要把参考图改写成几十个风格形容词。待延展的确认稿应保留已经成立的强对比、真实摄影、3D、插画或平面图形关系；色彩强度也应继承，但纯正高饱和红与亮黄并用时需转为明亮朱红、橙红或珊瑚红，并以琥珀黄、橙黄色或奶油黄小面积强调，避免刺目的原色对撞。
涉及新闻、人物履历、赛事赛程、会议嘉宾、历史文化、政策公益、城市路线、商品参数、平台尺寸或时效营销时，先查阅可靠资料。优先使用官方页面、品牌资料、平台规范、机构发布和用户提供的文件；无法确认的内容不写成确定事实。
### A2. 传播目标与观看顺序

用一句话明确设计任务：
> 在什么载体上，让什么人先理解什么，再产生什么感受、记忆或行动。
依次回答：

1. 第一眼要认出什么：活动、品牌、商品、人物、服务、地点还是信息结论；
2. 为什么值得继续看：价格权益、产品卖点、功能证据、场景体验、文化意义或品牌态度；
3. 下一步是什么：购买、预约、进入会场、到店、参与、收藏、继续阅读、理解规则或记住品牌；
4. 什么内容必须远看就懂，什么内容允许近看再读；
5. 如果只能保留一个记忆点，应保留标题字、商品、人物、主视觉装置还是信息结论。

传播目标只决定信息优先级，不直接决定字体种类和风格模板。
品牌宣传中出现价格、首发或轻优惠，但删除这些信息后品牌与产品主题仍然成立时，将优惠放在辅助层。只有第一目标是购买、抢购、领取权益或参与活动时，才提高行动强度。
### A3. 文案整理、主动补充与事实核实

把文案分为三类：
#### 准确信息

只能来自用户、素材或可靠资料：品牌、产品、型号、人物、机构和活动名称；价格、折扣、满减门槛、赠品、权益和库存；日期、地点、时段、流程、规格、容量和参数；功效、认证、排名、奖项、销量、专利和官方背书；官方口号、联名方、代言人和联系方式。

准确信息必须逐字保留。不要擅自改写品牌名、产品名、折扣机制和日期，不要生成看似真实的虚构数据。
#### 必须补充的传播文案与信息元素

先检查用户提供的文字能否支撑当前物料。只有主题、活动名、产品名、人物名、地点名、一句口号或任务说明，或者仍缺少对象解释、特点、状态、场景、必要时间、信息索引与行动中的关键层级时，视为文案不足，必须在事实边界内补充文案和承载这些文案的版式元素。不能因为用户没有逐项提供，就只做“标题 + 主体 + 背景”；也不能把“文字少”直接等同于极简设计。

补充前判断物料出现在哪里、观看者停留多久，以及当下处于认知、比较、决策、参与还是使用阶段：

- 远距离海报、主 KV、户外画面和首页首屏先回答“这是什么、为什么现在值得注意”，保留完整主标题，并补一条核心解释及必要状态、时间或行动；
- 中距离社媒封面、商品卡、倒计时图、系列宣传页和展陈画面在主题之外，再补一项具体特点、阶段信息、场景结论或栏目索引；
- 近距离桌卡、柜台卡、菜单插页、功能图、参数图和详情模块继续回答“有什么特点、依据是什么、适合什么场景、如何选择或使用”，形成可停留阅读的信息层；
- 同一套物料共享主题、对象名称和核心判断，但根据距离与任务分配不同信息，不机械复制同一份文案容量。

可从以下信息中选择当前物料真正需要的内容，不要求全部出现：对象身份与类别；上新、限定、预热、倒计时、发布、进行中或收官状态；核心功能、产品特点、使用体验或主题价值；已知的材料、结构、工艺、参数、产地、配方与规格；适用人群、地点、季节、时段、动作、训练、工作或生活场景；版本、型号、组合、选择方式及购买、到店、报名、咨询等行动。补充内容必须与商品、人物、地点、场景或活动语义有关，不使用“品质生活”“焕新体验”“开启美好”等万能句冒充信息。

不同对象采用不同的信息重点：

- 手机、耳机、智能手表及其他科技产品，优先组织功能定位、交互体验、结构材质、兼容场景和已知性能；
- 篮球、足球、运动装备及赛事内容，优先组织运动类别、动作表现、训练或比赛场景、材料结构和适用条件；
- 机器人、机械工具及工业产品，优先组织任务用途、关键功能、结构特点、作业环境和已知的效率、精度或安全依据；
- 食品、饮品、美妆、服饰和日用消费品，优先组织感官体验、原料或材质、使用场景、搭配与选择；
- 人物、地点和活动，优先组织身份关系、主题内容、场地、流程、节点、参与方式和行动。

倒计时、预热、发布、开售、活动进行中和收官物料必须出现阶段信息。用户已提供日期、天数或序号时准确使用，并可组织为日期、`D-03`、`DAY 03`、期号、章节号或阶段标签；未提供具体数字时，只使用“即将开启”“今日发布”“活动进行中”“收官倒计时”等不涉及虚构事实的状态词。阶段信息之外仍需补一个与对象相关的特点、利益或主题说明，不能只放倒计时数字。

系列物料应形成信息分工。主海报或主 KV 负责总主题、对象身份和整体记忆；各卡片、页面或延展海报分别展开功能、特点、依据、场景、流程、阶段或选择中的一项，每张给出一个明确结论和一至三条支持信息。产品宣传系列先把用户明确给出的产品定位、原料、工艺、材质、功能、季节、人群、场景和情绪定为语义锚点，再完成统一的标题字组、产品与标题关系、构图骨架、图像媒介、色彩明度与冷暖、背景材质、主光和辅助图形；主海报建立整体概念，各延展图只在这套视觉关系内展开一项内容，文案、图注和标签进入既定动线，不以新增信息模块替代主视觉。品类常识只能用于补充说明和画面承载，不得替换、稀释或另造与用户提示词无关的方向；没有足够事实时减少参数、性能和品质依据，不以空泛赞美或虚构证明填补版面。用户明确要求多风格提案时，各方向按 C2 独立定稿，本段的一致性只作用于每个方向内部。

优先使用用户、包装、图片和可靠资料中的具体事实。资料不足时，可以使用品类常识范围内、不涉及量化、功效和事实承诺的体验或场景描述，但不得虚构价格、折扣、日期、性能数值、材料等级、工艺、认证、适用年龄、赛事成绩或其他可核验信息。

#### 辅助文字、索引与档案信息

文案不足时，除核心解释外，还应根据设计方向选择能够丰富层级并组织阅读的辅助元素：系列号、型号、章节号、期号、已知日期与时段、阶段标签、分类词、功能短句、参数栏、步骤编号、图注、图例、地点、票务字段、版本号、页码和简短英文栏目字。最终提示词直接写出需要上屏的内容和它与标题、主体或阅读路径的关系，不写“增加一些标签”“加入适量小字”。

辅助文字必须来自主题或信息结构，并与主体轮廓、图片边缘、网格、路径、标签容器或前后层次建立关系，不能散落填空。极简、高端与品牌发布可以使用少量高质量图注、型号、材质说明和系列标识；编辑、运动、科技、数字实验、促销和信息设计可以使用中高密度编号、状态、图注和参数索引。密度服从观看距离和信息任务，不生成无意义乱码，不把虚构字段伪装成真实品牌或官方证明。
不同物料的文案容量：

| 物料 | 建议内容层级 |
|---|---|
| 海报、KV、户外、首页首屏 | 完整主标题 + 一条核心解释 + 必要状态、时间、对象识别或行动 |
| 品牌、产品、人物宣传 | 对象或主题标题 + 一个核心价值/特点 + 身份、上新、限定、场景或轻行动信息 |
| 促销、发布、倒计时、阶段营销 | 活动或发布标题 + 对象/品类 + 核心利益或特点 + 阶段/时间 + 行动 |
| 商品主图、商品卡、销售视觉 | 商品主体为第一视觉 + 一个主卖点 + 必要型号、规格、选择或行动信息 |
| 功能、参数、结构、对比物料 | 对象名称 + 结论标题 + 已知功能/参数/结构依据 + 图注、编号或图例 |
| 桌卡、柜台卡、菜单插页 | 对象名称 + 类别/状态 + 一个体验或卖点结论 + 已知依据/场景/选择提示 + 行动 |
| 社媒封面、内容卡、系列帖子 | 内容标题 + 一个具体特点、利益或观点 + 场景、栏目、阶段或序号标签 |
| 详情页、A+、长图、说明页 | 首屏标题 + 模块标题 + 卖点说明 + 已知证据/参数/步骤 + 选择与行动 |
| 票券、邀请函、议程、路线图、信息图 | 总主题 + 日期/地点/编号 + 节点/模块标题 + 简短说明 + 必要图例或参与信息 |
| 系列传播与多物料延展 | 系列总主题 + 每张分主题 + 各张专属特点/阶段/场景/说明 + 统一索引与行动 |

用户只提供一句标题、一个主题、一个活动名、一个对象名或一个口号时，必须触发文案与信息元素补充，不得只生成“文字 + 主体 + 背景”。先形成可直接排版的完整主标题、核心解释和必要的索引或行动信息，再按对象、载体和观看任务补充特点短句、状态词、分类标签、型号/系列索引、图注、参数栏、步骤编号、阶段标记、行动信息或落款。普通海报、产品宣传和系列风格图通常形成三至六个承担不同作用的可见文字层级；促销、科技、编辑、商品卡和近距离物料可按阅读任务增加，极简、远距离和以图像为主的方向可以减少，但不得只剩孤立标题与主体。每一层都要回答新的问题，不能用同义口号凑数量，也不为增加层级堆叠标签和容器。
先区分任务说明与上屏文案。“帮我做、设计一张、来一套、海报、主图、Banner、用于投放”等描述物料和动作的词不进入画面；只有用户明确给出的标题、活动名、产品名、口号、利益、日期、标签和行动信息才按准确文案处理。用户没有给主标题时，可根据已经明确的主题补一个不涉及商业事实的传播标题，并在最终提示词中直接定稿，不能把“某某海报设计”当标题。
主标题默认保留用户给出的完整短句或完整传播关系，不从“活动/产品 + 利益/动作/对象”中抽出一个更短词另立标题。可以拆行、放大数字、嵌入标签或强调关键词，但提示词中仍要写出完整主标题和分行关系。
补充文案以“观众在当前物料前需要识别什么、理解什么、凭什么、接下来如何阅读或行动”为准，不用同义口号反复扩写。已经设置的信息区、票券、标签和页脚应放入已确认文字或不涉及事实承诺的短句；静态海报的行动词优先作为字组、票券、搜索入口或场景信息的一部分，不为补文案另造按钮。只有用户明确要求后期填写或预留时才保持空白。所有补充内容在最终提示词中直接写成具体短句、标签、图注或索引文字，不写“增加一些标签”或“配适量文案”。
不可补充：具体价格、折扣、门槛、日期、库存、赠品、功效、认证、销量、排名、奖项、机构背书、联名方、代言人和未经确认的地点。
文案补充的目的不是增加字数，而是让传播信息完整，并为字体层级、标签、图注、编号、索引和阅读路径提供真实内容。主标题仍是第一文字重点，辅助文案必须进入与主体和动线有关的版式结构，不散落填空，也不默认集中成独立底部条带。
### A4. 信息层级与断句

根据内容建立清楚的阅读层级：

- **主标题**：第一眼说明发生什么、这是什么或需要记住什么；
- **核心利益或主卖点**：解释为什么购买、相信、参与或继续阅读；
- **商品、人物或场景信息**：说明传播对象和利益来源；
- **辅助信息**：机制、时间、参数、步骤、标签、图注和行动信息；
- **品牌签名**：Logo、品牌名、系列名和必要识别，默认不抢主标题。

不要机械套固定三级文案，也不要把所有信息平均放大。画面只能有一个第一文字重点和一个主视觉核心。
设计字组前先按语义断句：

- 活动名称、品牌名称、产品名称和固定短语不得拆错；
- 主标题保留一个完整的购买、参与、发布或传播判断，不把活动名、品类名和利益点拆成彼此无关的主标题；
- “全场五折”“每满 300 减 50”“新生儿好物免费送”等利益关系必须保持完整；
- 动作与对象、时间与状态、数字与单位留在同一阅读组，不为对齐或做大字而拆散；
- 不为了对齐字数把定语与中心词拆开；
- 不把否定词、数量单位、时间范围和适用对象拆到不同阅读组；
- 同一句准确文案只出现一次，不因版式需要重复生成；
- 使用中文引号和书名号时保持统一，避免重复引号、错引号和嵌套错误。

促销第一视觉通常由以下三者共同组成：
> 活动或购买标题 + 核心利益 + 商品或品类主体
“五折”可以有高对比和大尺度，但不能脱离“双十一”与商品成为没有上下文的唯一主视觉。只有价目、清仓价格表或用户明确要求价格作为购买标题时，才让价格承担主标题职责。
### A5. 美术指导与核心创意

本节用于未触发 C1 活动机制母版的普通设计任务。简略促销简报一旦符合母版条件，只在本阶段确认传播目标、准确文案与素材边界，不另行选择视觉方向；其字体、构图、配色、媒介与表现以 C1 选定母版为准。

美术指导不是风格名，而是一套已经能够成图的设计决定。先确定传播语气与品牌人格，再同时确定主视觉结构、图像媒介、标题字来源、标题与主体关系、构图骨架、信息密度、配色职责、背景材质与主光。最终提示词必须继承这些决定，不得重新选风格。

可用一句话概括核心创意：
> 用什么具体的字体、图像和构图动作，把什么传播内容转化成什么视觉感受，并让标题与主体形成什么关系。
例如：
> 用带飞白和速度感的毛笔字穿过透明饮品与上扬风线，商品、标题和春季气流共同形成一条斜向动线。

风格判断顺序为：用户明确表达的主题、情绪和方向；品牌与商品气质；传播目的；素材条件；物料阅读方式；平台习惯；行业常见做法。用户说“慵懒旅行”的耳机种草，应采用生活方式摄影、松弛裁切和编辑字组，不能因为是数码产品改成黑底科技海报。电商是销售场景，不等于波普、3D 或大促；科技是产品属性，不等于深色背景、蓝紫霓虹和白色大字。

先从六个方面形成完整组合：设计传统与时代气质；摄影、插画、3D、拼贴、版画、像素或图形等图像媒介；书写、构造、材料成字、图像成字、编辑混排或空间文字等字体方法；网格、聚合、斜向推进、强透视、留白、拼贴、路径或模块等版式方法；产品取色、同色阶、邻近色、冷暖差或受控高能色等色彩方法；纸张、织物、玻璃、金属、自然光、棚拍光、舞台光或屏幕光等表面与光线。六项必须互相支持，不能只换风格名称。

普通单方向任务从下列方向中选择一个主方向，必要时只加入一种辅助媒介；用户明确要求多风格提案时，按 C2 为每个方向分别完成选择与定稿。商业视觉中的主标题默认必须完成字形或字组设计，不只选一款基础字体居中排放；界面功能文字、信息图正文、严格品牌规范和非产品传播的极简设计可减少字形变形，仍要通过字级、字距、分行、对齐、裁切和图文关系完成排版：

| 信息设计与品牌系统 | 结论标题有明确识别，正文、数据和功能文字使用稳定字体，由字级和编号建立层级 | 先给结论，再用模块、编号、图例、路径、对比、时间轴或参数区组织 | 功能色数量受控，以明度、位置和线型区分类别 | 固定 Logo、标题字、正文字、色板、辅助图形、边距和材料 |

行业与物料只用于筛选和修正，不能替代风格判断。美妆可以是编辑、极简、感官摄影或高能促销；科技可以是生活方式、现代主义、精密发布或数字实验；食品可以是感官摄影、复古印刷、当代东方或商品主图。普通单方向任务最终只保留一套组合；用户明确要求多风格提案时，各方向分别保留一套内部自洽的组合，不在同一方向中并列互相冲突的语言。

产品传播与产品展示先判断传播任务：品牌或新品发布强调产品身份、品牌气质和标题记忆；功能传播让结构、使用动作、局部特写、参数或结果状态证明卖点；感官传播让原料、液体、光泽、触感与商品共同成图；生活方式传播让人物、环境和使用痕迹建立情境；销售视觉让商品、主卖点、利益和行动形成一个阅读组。产品海报、新品发布、品牌宣传、产品系列宣传和系列风格图属于传播设计，以美术方向、品牌气质、产品概念、情绪与标题记忆为先，再安排产品识别和卖点说明；商品主图、商品卡、货架图和售卖系列才执行 C1 的商品识别、购买理解、规格卖点和信息模块规则。用户只说“产品宣传图、产品展示图、系列风格图”时，不默认采用中性背景、产品居中和基础无衬线，而要根据产品外形、包装、材质、功能、受众和情绪完成其中一条清楚路线。

产品传播的主标题不得直接使用黑体、宋体、圆体、纤细体或其他基础印刷字体，也不得仅靠加粗、倾斜、压缩、拉伸、描边、投影和立体效果冒充字体设计。应从书写、结构构造、材料成字、图像成字、编辑混排或空间文字中确定一种主要方法，使标题具备可识别的笔画处理、整组轮廓、节奏和与产品、摄影或场景的关系。品牌规范指定字体时保留其字形身份，但仍须通过定制字组、尺度层级、裁切、负形、网格或图文穿插完成标题系统，不能原样居中排放。

当代感优先来自更有表情和材料感的标题字、摄影与文字的前后穿插、编辑网格与局部破版、高密度但有秩序的信息、清楚而有职责的颜色，以及品牌图形在系列中的系统变化。复古、未来、手作、东方和实验语言都要重新设计，不能依赖滤镜、故障、镀铬、深紫、果冻或随机粒子代替具体构图。

完成选择后，先把方向收口成一张已经可以直接成图的主视觉：明确实际出现的主体、商品、人物、装置或场景及数量，镜头和构图方向，前景、中景、远景和地面的关系，标题字形与主体如何结合，利益、卖点和行动信息由什么具体结构承载，背景与地面出现什么，颜色各自承担什么职责，采用什么材质、主光和两至四类辅助元素。每个名词都应能在画面中找到位置，每个形容词都应有字形、色彩、光线或材质证据。后续版式和提示词只继承这份定稿，不重新起稿。

## B. 视觉设计执行

目的：把传播策略落实为完整画面，优先完成主视觉关系、标题字、版式、商品与配图、色彩和材质光影，让所有设计手段服务同一个创意方向。
### B1. 主视觉构想与图文关系

主视觉核心是观众第一眼共同识别的一组关系，不是面积最大的单个对象。
一般由主标题；核心利益、主卖点或信息结论；商品、人物、主题符号、活动装置、场景或关键信息组成。

先确定“一秒内要读懂的完整意思”，再决定哪个局部最大。Logo 默认是品牌签名；只有 Logo 发布、品牌升级或用户明确围绕 Logo 设计时，才让 Logo 成为主视觉。
只有一句文案或抽象诉求时，先判断传播承诺是省钱、效率、舒适、清爽、陪伴、专业、礼遇、探索、更新还是其他价值，再设计一个可见主体和一个有语义的画面动作。不要退化为漂亮渐变背景加文字。
主标题与主体选择一个主要关系：

可采用并列对峙、上压下托、穿插遮挡、环绕包围、沿轮廓避让、嵌入负形、共同形成路径、共享照片/材质/空间边界、由主体托起标题，或让标题成为商品、人物与信息的容器。

每张图只选择一个主要构图动作，可用一个辅助动作解决局部问题：

| 构图动作 | 主要作用 | 常见物料 |
|---|---|---|
| 中心聚合 | 让标题、利益和商品或人物形成合力 | 活动 KV、发布、促销、组合权益 |
| 斜向推进 | 建立速度、行动和时间压力 | 大促、运动、上新、短视频封面 |
| 强透视空间 | 建立沉浸、纵深和压迫感 | 游戏、演出、活动、人物 KV |
| 编辑式留白 | 建立节奏、停顿和品牌气质 | 品宣、种草、时尚、文化海报 |
| 拼贴层叠 | 建立内容现场和多层叙事 | 社媒、人物、潮牌、娱乐传播 |
| 产品舞台 | 集中展示商品身份和材质 | 电商、产品发布、详情首屏 |
| 场景切片 | 表现使用体验和真实生活 | 种草、餐饮、文旅、服务推广 |
| 框景入口 | 用门窗、票券、屏幕或图形形成入口 | 活动、内容封面、品牌传播 |
| 展开拆解 | 说明结构、步骤、权益或包装 | 信息图、详情页、功能说明 |
| 路径叙事 | 用路线、台阶、光带或文字引导阅读 | 路线图、流程、旅程、香气主题 |
| 多格叙事 | 建立前后情节和局部特写 | 漫画、长图、人物故事、产品过程 |

冲击力来自明确的视觉中心、尺度级差、方向一致、前后层次和可信主体，不来自金币、礼盒、爆炸贴、光束和粒子的数量。
需要破版时只设置一个主要事件，例如标题越出承载区、商品穿过字内负形、人物压住部分标题、照片裁切进入字组、路线跨越模块或一个前景主体突破网格。其余内容保持稳定对齐，不遮挡商品 Logo、人物五官、价格、规则和参数。
普通设计路线的构图动作必须来自 A5 已确定的设计方向；C1 活动机制母版直接继承选定母版的构图骨架、标题关系、主装置、动势和空间层级，不再从 A5 选择构图。促销、编辑、极简、科技与东方等普通设计分别按既定方向组织。同一方向内的系列共享同一种构图语言，不能每张选择互不相关的构图方案；用户明确要求多风格提案时，各方向按 C2 分别建立构图语言。
### B2. 标题字与字组设计

本节的字体设计要求用于普通设计路线；C1 活动机制母版中的标题按母版正文完整执行，不用本节重新选字或追加结构动作。

标题字是商业平面设计的优先项。先设计整组字和图文关系，再处理局部笔画、颜色和材质。
标题方案一经确定，后续物料继承同一字形来源、字重、宽窄、圆角或棱角、描边或阴影方法、关键词强调方式和颜色职责。画幅变化只调整分行、尺度、位置、局部压缩和裁切，不重新换字体或重新设计另一套字组。
每个主标题必须形成一个完整方案，同时说明：

1. **文字语气**：克制、亲近、锋利、松弛、仪式、速度、力量、理性、诗意或幽默；
2. **字形来源**：书写、毛笔、书法、衬线、无衬线、构造字、装饰字、材料成字、图像成字或受控混合；
3. **笔画特征**：粗细、提按、重心、宽窄、中宫、弧度、飞白、断口、圆角、切角、机械精度或自然不规则；
4. **整组轮廓**：横向宽块、窄高竖势、错落阶梯、斜向推进、中心聚合、环抱、跨边裁切、自由书写或模块阵列；
5. **字组节奏**：分行、疏密、大小、字距、基线、连写、共笔、嵌合和局部强调；
6. **空间关系**：压住、托起、穿过、包围、避让、跨越、贴边、成为路径或容器；
7. **颜色与材质**：来自品牌、商品、场景和核心创意，不为炫技而添加；
8. **辅助文字关系**：使用更稳定、清楚的字形和对齐方式形成层级。

基础黑体、宋体、无衬线、衬线、圆体和现成手写体在一般商业视觉中只能作为结构起点，不能直接排放后结束；产品传播按 A5 的专门条款执行，不适用这一结构起点权限。移除颜色、描边、材质和阴影后，主标题仍应看得出经过设计。
仅换字体、分行、加粗、倾斜、换色、描边、投影或拉长个别笔画，不算完整标题字设计。至少同时完成以下两类动作：

- **整组轮廓**：让整句标题形成独特大形；
- **结构关系**：连接、错位、共笔、嵌合、宽窄重组、大小嵌套或字内开窗；
- **空间关系**：压住、穿过、包围、避让、成为路径、成为容器或与主体共边；
- **媒介关系**：让标题由墨迹、纸张、织物、食材、玻璃、金属、像素、照片或场景材料构成；
- **编辑关系**：让标题与图注、标注线、照片裁切、纸片、色块、票券或网格组成同一个版面事件。

先确定整组标题的外轮廓和图文关系，再完成字与字之间的连接与负形；单字结构、重心和笔画变化；局部飞白、切角、断点、内白、压印、套色或轻包边；颜色、材料、光影和表面细节。

#### 书写、毛笔与书法

写清笔势方向、提按、墨量、飞白、连笔范围、起收笔、拖尾、行气和可读边界。整组笔势保持连续，不让每个字都重复相同甩笔。
手写、毛笔和书法可用于促销、品牌、文化、食品、运动和年轻内容。促销、编辑感、平台适配和系列统一都不得把它们改成宋体、黑体或无衬线。需要清楚数字和规则时，使用稳定辅助字体与主标题形成对比。
#### 结构构造与图形化字组

使用宽窄重组、切分、共笔、嵌合、负形、模块缺口、大小嵌套和数字关系，让整组字成为图形。不要用默认粗黑字加描边冒充构造字。
适用于科技、运动、活动、潮流、工业、功能发布和需要强识别的品牌传播，但不自动使用锐角、蓝紫霓虹和镀铬。
科技与数码标题应从产品功能和传播语气选择方法：精密与效率可使用窄体无衬线、几何切角、模块缺口、等宽节奏和技术编号；数字文化可使用可变字宽、位图、点阵、扫描线和图像切片；消费数码与生活方式内容仍可采用编辑混排、精细衬线或松弛手写。字体方法必须与摄影、构图和平台语气一致，不能仅凭品类套用黑底、荧光描边或界面装饰。
清洁科技、未来主义、数字主义和数字实验不能只写“科技字体”或“未来感排版”。精密发布让标题字组、技术编号、结构线、产品边缘、剖面或参数模块共用同一网格；未来与数字实验让主标题、大号字母数字、微型状态字、透明字层和产品或人物切片组成版面骨架。主标题至少采用两项彼此相关的处理，如可变宽度与模块切分、错位切片与透明叠印、位图点阵与局部消散、字符重构与数据路径；这些处理应进入笔画和整组轮廓，不能退化为基础字外加扫描线、HUD 或随机粒子。
#### 材料成字与物体化标题

让文字由商品或场景中真实存在的材料形成：

- 食品与饮品：糖霜、饼干、吐司、奶盖、芝麻粉、冰晶、液体、气泡和果肉；
- 母婴与家居：棉布贴片、柔软织物、低厚度软包、纸贴和轻充气材质；
- 时尚与潮牌：布艺泡泡字、水珠拼字、喷漆、贴纸、别针、金属吊牌和丝网印刷；
- 香氛与美妆：玻璃边缘、压印纸张、雾面金属油墨、水波、薄膜和细框题签；
- 文化与手作：墨迹、宣纸、木刻、织锦、拓印、印章、蜡笔、粉笔和版画；
- 活动与促销：票券切口、价格窗、入口拱门、轻透亚克力和活动标牌。

材料必须构成具体笔画、字内负形或整组轮廓，不能只散落在文字周围。每张图只选择一种主要标题材质。
#### 图像成字与正负形

可让标题从同一张照片或场景中裁出，使文字内部与背景保持连续图像；也可让照片进入字内负形、让人物或商品压住部分笔画、让上下两组文字形成正负形反转。
写清图像从哪里进入文字；文字与原图是否连续；哪些笔画被主体遮挡；如何保证标题仍然清楚；是否使用照片蒙版、镂空、裁切或反相色块；标题不能像独立贴在照片上的普通文字层。

#### 编辑混排与标题系统

编辑设计只说明网格、图像裁切、图注、标注、纸片、色块和阅读节奏，不决定主标题字形。必须另行说明主标题是手写、衬线、构造字、材料字还是其他方向。
让主标题、英文、日期、编号、图注和标签形成一个统一标题组：统一对齐基准；统一辅助字重和字距；统一标签形态与边距；统一图注和标注线的方向；主标题保持最强个性，辅助信息保持可读。

#### 空间文字与真实场景字体

需要立体、灯管、霓虹、招牌、投影或空间装置时，文字必须真实存在于场景中：

- 遵循墙面、地面、舞台或建筑透视；
- 有固定方式、厚度、接触关系和合理遮挡；
- 与环境共享主光，产生光晕、反射、溢光和环境染色；
- 灯管字有玻璃管径、弯折半径、连接点、支架和局部亮度差；
- 人物、商品、烟雾、墙面和地面真实接收文字光；
- 不能像平面标题后期贴在真实照片上。

真实场景配灯管字体时，场景氛围必须足够：保留人群、餐饮、摊位、舞台、入口、招牌、湿地反射、空气颗粒或夜间环境光中的必要内容，让字体成为活动现场的一部分。
#### 语义与字形

根据文案含义选择结构，不把品类固定成一种字体：

- 冲刺、限时、爆发、开启：斜向重心、压缩块面、锐利收笔、近大远小或边缘推进；
- 清爽、轻盈、透亮、呼吸：松中宫、舒展字距、上扬曲线、局部内白或透明承载；
- 浓郁、醇厚、温度、质感：稳定重心、粗细对比、低速笔势、压印或密实块面；
- 自然、松弛、陪伴、旅程：舒展书写、轻连笔、长线引导和宽松留白；
- 科技、精密、效率、结构：几何构造、窄体、切角、模块缺口和等宽节奏；
- 仪式、限定、礼遇、文化：高对比衬线、题签、书写笔意、压印和克制装帧；
- 年轻、趣味、社交：跳跃字组、轻手写、圆角、错位和图形嵌入；
- 专业、可靠、说明：稳定字形、清晰模块、编号和统一标题条。

同一语义可有多种设计方法。结合品牌人格、活动阶段、画幅、阅读距离和图文关系选择。动作导致错字、粘连和难读时，降低变形强度，不更换已经确定的字形来源。
商品主图、淘宝主图、促销海报和活动会场中的主标题必须完成字形与版式设计：说明基础字形、宽窄与字重、整组轮廓、关键词强调、描边或阴影方式，以及标题与主体如何压叠、托起、穿插、避让或成为价格与卖点的容器。商品主图与淘宝主图以商品识别为先，标题只能进入商品外围负形、沿轮廓避让、与商品共轴或位于商品后景；需要压叠时，只允许商品位于前景遮住少量非关键标题笔画，标题不得覆盖商品轮廓、包装正面、功能部件、材质细节和操作接触区。促销海报与活动会场仍按其主视觉关系决定压叠和破版。黑体、宋体、圆体和现成展示字体可以作为结构起点，不能原样居中排放后结束。
#### 辅助文字、数字和标签

- 只设置一个第一文字重点；
- 核心利益与主标题都重要时，将它们做成同一阅读组；
- 价格、日期、门槛、参数和 CTA 使用清楚稳定的字形；
- 标签、图注、标注和小卡片使用同一套视觉语法，可设置主标签与批注标签两级变化，统一字重、色彩、线条和边距，不要求所有内容复制同一种外框；商品主图系列先确定一种主要标注语法，如部件引线、边缘索引、统一编号、参数纵列或场景票签，后续各张不随意换用另一套方式；
- 标签应嵌入标题字间、上下行或负形，贴合商品、人物和图片边缘，沿视线、轮廓或步骤路径排列，或以手写批注、编号索引、票根、便签、杯套、包装贴纸和状态标记进入真实场景；
- 标签必须说明卖点、状态、场景、步骤或结论，并对应明确的商品部位、画面对象或阅读节点，写清锚点、对齐轴与阅读顺序，不在空白处随机悬浮或填充胶囊框；
- 一张静态画面最多设置一个具有按钮或入口外观的行动容器。优惠标签、搜索入口、状态条和 CTA 不得同时做成相近的圆角方块；已有搜索框、票券入口或场景化行动信息时，行动词直接并入其中，不再增加第二个按钮。真正需要交互的 H5、页面或弹窗也只保留一个主操作，其余信息使用文字、图标或轻量标签降级；
- 辅助无衬线、衬线或等宽字只负责解释和秩序，不得替换手写或毛笔主标题。

最终生图提示词中的标题段必须写成可见画面，例如：
> 主标题“[准确文字]”位于[画面区域]，采用[字形来源]的[笔画特征]，整组形成[外轮廓与方向]，通过[结构动作]与[商品、人物、数字、照片或背景]产生[压住、穿插、包围、避让、共边或成为路径]的关系；辅助文字使用[稳定字形]沿[网格、弧线、标签或留白]形成降级阅读。商品主图使用压叠时，明确写成商品在前、标题在后，不使用方向不明的“标题与商品压叠”。
只写“醒目中文大标题、现代无衬线、粗体、居中排版”不合格，必须继续说明标题的整组形状和图文关系。
### B3. 版式构图与阅读动线

版式设计先回答第一眼落点、第二眼如何读到利益或卖点、标题与商品/人物/场景如何相遇、辅助信息与品牌签名放在哪里、哪里需要呼吸和裁切余量，以及改变画幅后必须保持什么关系。

优先使用明确的图文关系：上压下托、同轴聚合、对角推进、穿插环绕、避让嵌合、前中后景、边缘裁切、局部破格、留白对峙、网格分组、标签连接、路径阅读、左大右小、上疏下密、中心强边缘弱，或一张主图与若干局部切片形成叙事。

普通商业海报优先写清阅读路径、主体尺度、负空间和图文关系。只有复刻、固定坑位、包装刀版、信息图、展板或用户明确要求高度还原时，才使用精确坐标。
除非用户明确要求相框、拍立得、相册、卡片展示、画中画、边框海报、留白装裱或作品集排版，成品视觉应直接填满整个画布。背景、主体、标题、装饰和信息模块属于同一画面空间；不要把完整海报缩小后放进另一个背景里，不做“图中图”或内嵌海报。留白应是版式留白，边框应服务风格、票券、档案或信息层级，不能让主体像随手贴在外层画布上。
主体尺度、负空间和信息区根据构图动作决定，不使用固定的顶部标题区、中部图片区和底部说明区。标题可以占据画幅边缘、进入主体前后、沿照片负形展开或与利益数字共同成为容器；商品、人物和场景可从边缘裁切进入。字号级差应清楚，移动端避开界面遮挡，户外减少小字并扩大标题和主体轮廓，但这些要求不能把画面重新分成三段。
完成主视觉后检查整个画布的重量分布。除明确采用大留白构图外，画幅下部和底边必须由主体裁切、地面或场景延伸、前景遮挡、图形路径、商品投影或必要信息形成连续承接，不能只剩大面积无内容的纯色或渐变背景。上部信息密集而下部、底部或横版远端持续空置时，应放大或裁切主体、移动商品组、延伸场景与前景，或让标题、图形和必要信息进入同一动线；不能用脱离主视觉的深色底栏、按钮加小字、渐变蒙层和无关装饰填空。全宽底栏只用于真实平台组件、固定品牌页脚或参考图已有结构，并须与主体、地面或图形路径连续。主动留白必须具有明确边界和视觉作用，服务标题呼吸、视线停顿、材质展示或不对称张力；内容集中在上部或一侧后自然遗留的空处均视为无效空白，必须重新排版。
不同物料的版式重点不同：海报/KV 保留一个主视觉核心、一条清楚动线与受控负空间；社媒封面保证缩略图仍能识别标题和主体；商品主图优先商品全貌、包装、数量与识别，商品通常承担画面最大的视觉重量，标题与卖点不得凭超大字号或过重字重抢占商品展示空间；详情页/长图按首屏、卖点、表现、参数、场景、信任和行动形成连续模块；信息图先给结论，再用模块、编号、箭头、图例与标注组织；票券/邀请函明确主题区、图像窗、票务字段、票根和编号；包装展板以档案式陈列串联主标志、包装、颜色、字体和应用；户外与展架实现远看标题主体、近看日期地址和行动信息。

避免所有内容机械居中，避免“左上标题—中央商品—底部 Logo”和“顶部标题—中部孤立配图—底部一两行说明”的默认模板，尤其不能把促销竖图机械分成互不关联的三段。优先让标题与主体压叠、共轴、穿插、沿边裁切、进入前后景或共享同一承载结构；只有品牌规范、信息性质或真实容器明确需要时，才采用稳定分区。避免模块等大、标签填空和复杂背景上依赖描边阴影放字；不要为了满版牺牲文字与商品，不用大量精确坐标制造僵硬排版，也不要为了编辑感错误拆分标题语义。

### B4. 商品、人物与配图设计

配图至少承担一项商业作用：

- **证明**：展示商品外形、材质、功能、结构、规格或使用结果；
- **感官**：表现清爽、浓郁、柔软、温度、香气、声音、速度或光泽；
- **情境**：建立生活方式、使用现场、活动语境或品牌世界；
- **组织**：承托文字、形成分区、路径和节奏；
- **记忆**：把抽象主题转成独特符号、装置或空间。

不要只写“商品环绕、产品组合、母婴用品、护肤品、零食”等泛词。商品陈列至少说明：

1. 几件商品，哪一件最大，哪些是辅助；
2. 位于前景、中景、背景、左右、底部还是边缘；
3. 玻璃、纸盒、织物、毛绒、食物、液体、金属或塑料的具体细节；
4. 如何托起标题、围绕票券、形成半环、与价格窗同轴或制造遮挡；
5. 如何避开标题、利益数字、Logo 和包装正面。

移动端促销图通常安排 3—5 件商品：一件主商品最大，2—3 件辅助商品形成半环或前后层次，少量前景元素轻微裁切或虚化。不要十几件小商品平均围一圈。
场景和道具从商品与文案推导：

- 功能性能：真实使用动作、结构拆解、结果状态、环境反馈或对比；
- 味觉香气：相关食材、植物、液体、蒸汽、气流和微距质感；
- 肤感触感：液体、泡沫、织物、纸张、颗粒、皮肤光泽和材料切片；
- 生活方式：可信人物动作、自然光、使用痕迹和环境细节；
- 文化节点：材料、工艺、地域结构、仪式动作和当代活动装置；
- 活动机制：入口、通道、票券、舞台、聚合、品类区和商品阵列；
- 信息说明：编号、模块、标注、对比、步骤、剖面和展开结构。

不要机械抽取名词。“轻松通勤”不等于只放包，“夏日清爽”不等于堆冰块，“沉浸旅程”不等于只放耳机。
#### 商品与包装准确性

- 保持商品外形、比例、颜色、包装、标签、Logo、型号、数量和功能部件；
- 商品正面与主要识别信息清楚；
- 不擅自增加按钮、接口、配件、新包装、虚构功能和不存在的组合；
- 不让花朵、水珠、液体、贴纸、标题和阴影遮挡品牌与包装文字；
- 多商品共享地面、透视、主光和环境反射；
- 复杂商品图宁可减少无语义陪衬，也不要牺牲准确性；减少陪衬不等于商品孤立居中，仍应保留能说明卖点的镜头、场景、光影、前后层次和构图动势；
- 产品主图、规格图和详情页中的商品信息保持一致。

用户上传商品图时，可为构图轻微旋转、转向、调整俯仰、重排组合、统一透视光线或进行局部裁切，使包装正面、标题承载区、接触关系和视觉重心更稳定；不得改变商品结构、比例、Logo、真实颜色、组件数量、型号和包装信息。原始角度已经适合画面时不强行转动，多商品调整后仍应共享地面、消失方向、主光和尺度逻辑。

商品主图系列以商品认知和购买判断为内容骨架，不以同一商品外观的机械重复冒充完整系列。标准货架首图可以克制，内容型主图及系列后续图不能只剩商品与孤立标题；每张围绕一个购买结论组织，除商品或系列识别外，通常配置一条结论标题和二至四条直接支持该结论的信息。支持信息从材质、结构、功能、尺寸、规格、工艺、细节、使用方式、适用场景和组合关系中选择，并通过局部特写、结构标注、尺寸参照、步骤、操作动作、场景关系、型号索引或选择提示进入画面，不把全部说明压成一行小字。

补充内容优先使用用户文案、包装、商品图片和可靠资料中的事实。资料较少时，仍需根据清楚可见的结构与材质、已经确定的品类用途和不涉及效果承诺的使用常识补足信息层级，可补使用步骤、适用场景、搭配或选择提示、维护与收纳提醒；未确认的尺寸数值、材料等级、工艺名称、功能参数、认证和功效不得编造。整套张数约 60% 承担商品主体、核心卖点、材质细节、结构功能与尺寸规格，约 40% 呈现真人试穿、试戴、手持、操作过程或真实使用场景；比例用于整套内容配置，不要求单张同时容纳两类内容，也不强制每张改变商品角度，不适合真人出镜的品类以操作过程和真实环境完成场景表达。摄影商品或写实商业渲染默认搭配真实摄影人物、写实手部或同等写实度的三维人物，并统一透视、肤色、光源、接触影和受力；插画手、卡通手只用于整套已明确采用插画、扁平图形或风格化三维的商品视觉，不直接拼贴到写实商品上。手部不适合表现时，改用局部袖口、简单单手动作、操作痕迹或无人物的真实使用场景，不为满足内容比例强行加手。

#### 人物与 IP

- 保持人物脸型、五官比例、发型、关键服装、姿态气质和身份辨识；
- 保持 IP 轮廓、颜色、标志物和角色性格；
- 多人物建立主次、比例、视线、光源和空间层级；
- 标题可沿人物动作、视线和轮廓排布，但不遮挡五官；
- 不伪造代言、联名、奖项、官方活动和人物身份；
- 肢体复杂时优先选择无手、局部手部或简单单手动作，避免交叉和不合理受力。

#### 素材重构与合成

多产品、多人和多图合成时，先统一观看角度与消失方向；主体比例和前后尺度；主光方向、色温和阴影软硬；清晰度、颗粒、景深和色域；接触影、环境反射和遮挡；画面边缘与裁切方式。

每份素材先处理身份与结构，再进入整体画面。不要用统一滤镜掩盖透视、光影和清晰度不一致。
#### 媒介选择

根据传播内容选择摄影、插画、3D、平面图形、拼贴、版画、手绘、漫画、像素或有目的的混合媒介。
产品传播的配图方法必须与传播结论对应：产品身份可用完整英雄视角、局部裁切和识别性轮廓；功能可用结构拆解、工作状态、使用动作和环境反馈；感官可用材质微距、原料、液体、光泽和触感；生活方式可用真实人物、场景和使用痕迹；实验与未来方向可用产品切片、透明叠层、受控粒子、扫描轨迹和大号字符结构。系列风格图可以改变镜头、裁切和图像处理，但同一方向内必须保持产品身份、标题系统、图形语法、色彩职责和主光，不能每张回到产品居中加小标题。
混合媒介看视觉语气是否统一，不看形式是否完全相同。扁平标题可以搭配 3D 商品、立体小元素、空间背景或摄影商品，尤其适合当代电商、食品、儿童、潮流、节日和促销视觉；关键是让字形情绪、圆角语言、描边厚度、投影软硬、色彩纯度、材质光泽和画面动势相互呼应。
摄影、3D、插画和贴纸需要通过一致透视、共同光源、统一颗粒、同一色域、共享边界、遮挡、尺度、网格或承载色块相互连接。极简冷淡标题不要直接搭配厚重金属 3D，柔软可爱标题不要放进冷硬赛博空间，高级留白排版不要堆廉价卡通 3D；媒介可以混合，气质不能割裂。
### B5. 色彩系统

先安排颜色职责，再选择色相。主色负责品牌、场景或活动识别；背景色负责主体分离和整体明度；辅助色建立空间与模块；强调色只用于最重要的标题局部、利益、CTA 或状态；标题色、正文色和标签色各自固定，不能在系列中随意互换。

配色顺序：

1. 从品牌规范、包装、商品材质、人物服装、原料、场景、季节或文化材料中确定来源；
2. 先确定背景、主体、标题和辅助信息的明度关系；
3. 明确主色、辅助色、强调色和文字色各用在哪里；
4. 再用同色阶、邻近色、透明层、材质色或冷暖差补充层次；
5. 删除没有来源、没有职责或只为“丰富”而增加的颜色。

产品宣传的“从产品取色”不只继承色相，还要先锁定产品和用户提示词体现的整体明度、冷暖、纯度、通透度与情绪方向，再确定背景深浅和对比。同色相加深如果改变了产品原有的轻盈、清透、温暖、柔和、自然或活力气质，不视为忠于产品取色。深色背景需要品牌规范、夜间场景、材质表现、功能概念或用户明确方向作为依据，不只为了分离商品或增强对比而把整体转为深色。同一个形容词可以对应多种风格时，先依据产品类别、真实使用体验和消费情境判断，不因表面词汇相似而误入科技、极简或其他不相符的方向。

品牌规范、已确认的 campaign 色板和用户明确的活动色板具有最高优先级。品牌参与大促时，先以暖白、浅灰等中高明度中性色和大促活动色建立背景、环境光、标题与利益强调，再将品牌标准色用于 Logo、商品本体、关键界面和少量识别图形；大促色调主导活动气氛，品牌色辅助确认身份，不把品牌色及其同色阶扩展为整张背景、环境光和全部立体材质。品牌色低明度或高纯度时，标准色只在识别位置准确保留；用于局部背景呼应的衍生色必须提高明度、降低纯度，并以暖白、浅暖灰、柔和暖光或明亮活动色调和，不能形成从深品牌色到浅品牌色的整幅同色渐变。画面整体保持明亮、积极和促销行动感，不因品牌原色偏深、偏冷而转为沉重暗场。品牌规范禁止偏色或规定标准色面积时服从规范，商品本色与 Logo 标准色不得被活动色覆盖。只有用户明确指定整套活动色板或品牌 campaign 规范要求品牌色大面积应用时，才按其准确色彩职责执行；品牌名称或单一识别色本身不等于整套活动色板。

常见面积关系可为背景与主色 60%—80%、辅助色 15%—30%、清晰强调色 3%—10%，但应根据商品、照片和活动强度调整。高纯度色只能局部使用，并通过面积、明度、中性色或材质色稳定画面；纯正高饱和红与亮黄不得同时承担背景和行动强调，也不得形成黄底黑字按钮。即使用户要求“高饱和红黄”，仍保留热烈、强对比和促销力度，但将背景组织为明亮正红、朱红、橙红与珊瑚红之间的暖向渐变，黄色调整为琥珀黄、橙黄色或奶油黄，并降低至少一方的纯度。综合大促暖色不以莓红、紫红、酒红、绯红和暗红为主调，也不在暖色背景中混入大面积偏冷色或低明度色。

提示词明确要求冷暖对比、温度变化或两种色彩氛围时，不把背景均分为冷色块与暖色块。保持主体和空间连续，通过环境光的冷暖偏移、明度与色温的柔和过渡、远近层次、材质反射、局部状态和少量呼应色建立差异，让冷暖关系沿光线、景深、主体轮廓或场景结构自然发生；避免笔直分界、等面积拼色、左右镜像和机械对称。只有用户明确要求左右或上下分屏、前后状态同框、Before/After 等具体对照形式时才采用分割构图，并保持对应对象与信息关系清楚；仅出现“对比图”“冷暖对比”“场景对照”或“两种状态”不构成切割背景的依据。

不同方向采用不同配色方法：

| 设计方向 | 配色方法 |
|---|---|
| 现代主义、信息设计 | 黑白、品牌单色与一块功能色建立明确分区，靠面积和明度组织信息 |
| 编辑、时装、生活方式 | 由照片整体色调、肤色、服装和环境光决定主调，纸色与一处轻强调色辅助 |
| 极简精品、产品发布 | 从包装、玻璃、金属、膏体和材质高光取色，以暖白、冷白、灰、黑或品牌深色承托 |
| 感官产品、食品饮品 | 从原料、液体、果肉、茶汤、咖啡、香料和包装提取同色阶，强化食欲或触感 |
| 美妆护肤 | 根据妆效、肤感、膏体和包装选择裸粉、红、棕、冷灰、银、蓝、绿或紫，不统一做甜粉 |
| 大促、波普、高能活动 | 使用明亮正红、朱红、橙红、珊瑚红、粉橙、琥珀黄、橙黄色或奶油黄建立暖色主关系；一个暖红主色统领，利益色小面积集中，冷色只在确有品牌或图形依据时作极少量点缀，避免正红与亮黄原色对撞及黄底黑字按钮 |
| 商品主图系列 | 从商品包装确定主色，固定标题色、价格色、标签色和背景职责；各张可切换同体系深浅底，不能每张更换整体色调 |
| 街头、运动、潮流 | 黑白、队伍色、服装色或单一荧光色建立强对比，避免无来源彩虹渐变 |
| 柔软可爱、家庭消费 | 奶油白、织物色、商品色和清亮重点色形成柔和但清楚的明度关系，不必统一低饱和 |
| 当代东方 | 从矿物、漆器、木石、纸绢、植物、器物、茶酒和包装取色；红金只有在主题和材料支持时使用 |
| 复古印刷、档案 | 限定两至四个专色，以纸色、油墨色和轻微套印偏差形成年代感，不靠整体发黄 |
| 清洁科技、精密发布 | 冰白、银灰、浅蓝灰、金属色、品牌色或深浅中性色均可；由产品材质和功能决定，不默认深色底 |
| 数字实验、未来图形 | 电光蓝、紫红、酸性绿、银灰、黑白或品牌色任选一套主关系，用屏幕光和透明层扩展，不同时堆多种霓虹 |
| 3D 场景、IP 活动 | 颜色来自品牌、角色、商品与环境光；固定材质本色、环境色和高光色，避免每个物件使用不同渐变 |

大促可以保留红与暖黄的温度关系，但不直接使用高饱和正红配亮黄。红色从明亮正红向朱红、橙红或珊瑚红平滑过渡，参考色相可取 #ea390f、#f64237、#f46746、#db2321、#f86058；这些色值用于限定暖向、清透和有活力的红色范围，不要求平均并置。暖黄转为琥珀黄、橙黄色或奶油黄，仅用于小面积利益、光线或材质高光；标题可使用带环境色的暖白、浅杏白或同色阶浅色。避免用冷莓红、紫红、酒红、绯红或暗红压低整体明度，也不以冷色撞色破坏暖色主调。调整色相与纯度不等于把促销改成灰暗或浅色品宣，应继续保持清楚明度、强尺度和行动感。

文字颜色必须与画面取色和材质有关，并先满足实际观看距离下的明度识别。主标题可承担主色、反白或强调色，环境染色、同色阶渐变和材质高光只能建立在清楚轮廓与足够明度差之上；辅助文字用同色深浅、稳定实色、承载面或局部反白降级，透明度只用于不承担关键信息的图注与装饰字，正文、参数、日期和标签不得依靠低透明度维持层级。深色或高饱和背景不得让全部文字使用同一纯白，可从环境光、商品高光、品牌色或背景邻近色中提取高明度浅色，再用局部纯白高光建立主次；浅色背景也不自动使用纯黑超粗字。复杂摄影先通过取景、负形、局部实色承载面和明度整理建立稳定文字区，必要时再用克制描边或投影；同一系列预先固定深底与浅底两套文字版本，不逐张临时换色。

不要把“高级”理解为统一降饱和、加灰、褪色或低对比。画面发灰时应恢复主色清洁度和局部明度差；画面刺目时应调整色彩面积、背景明度和整体色调，不是简单降低所有颜色纯度。

### B6. 背景、材质、光影与图形装饰

背景必须承担至少一项作用：提供文字承载区；分离商品和人物；建立真实使用情境；延展商品材质、口味、香气或功能；建立品牌世界与活动现场；组织信息模块和阅读路径。

不要只写“高级背景、干净背景、梦幻背景、真实场景”。说明背景具体是什么、如何照明、如何承托标题与主体。
常用背景方向：

- 生活场景：桌面、窗边、浴室、卧室、通勤、户外、门店和工作现场；
- 产品氛围：包装色、台面、光影切片、微距材质和少量相关道具；
- 极简品牌：纸张、亚克力、织物、颗粒、压印和受控留白；
- 编辑拼贴：照片裁切、纸片、图注、标注、局部放大和图文错位；
- 插画图形：色块、线条、图标、路径和装饰纹样；
- 感官微距：液体、泡沫、果肉、肤感、织物、蒸汽和颗粒；
- 结构化发布：网格、展台、产品阵列、剖面和克制光影；
- 活动场景：主题装置、商品、人物/IP、入口、舞台、路径和空间层次。

选择平面、摄影、插画、3D 或混合媒介后，标题、主体、背景和装饰必须通过空间、色彩、光源、颗粒、边界或网格形成同一画面体系。
材质写成可见细节：

- 食品：气孔、酥皮层、粉末、流心、湿润切面、冰晶和液体挂壁；
- 美妆香氛：玻璃厚度、折射边缘、瓶盖、标签纸、液滴、水雾和膏体；
- 服饰鞋包：布料、缝线、皮革、金属扣、织物褶皱和接触阴影；
- 纸品包装：纸张纤维、压痕、折边、套印、局部烫印和磨砂膜；
- 3D/IP：软胶、陶瓷、硅胶、PVC、黏土、果冻、毛绒和树脂；
- 工业产品：金属拉丝、塑料磨砂、透明件厚度、结构接缝和装配关系；
- 文化手作：宣纸、岩彩、木刻、织锦、羊毛毡、彩铅、水彩和印章。

光线只设一个主要方向，说明方向、软硬、色温和阴影：

| 品类 | 光线起点 | 表现重点 |
|---|---|---|
| 食品、甜品、烘焙 | 暖光、棚拍硬光、清晰投影 | 酥脆、流心、粉末和食欲 |
| 饮品、冰品 | 高明度侧光、顶部高光、透明折射 | 气泡、冰感、液体和杯壁水珠 |
| 美妆、护肤、香氛 | 侧逆光、轮廓光、冷白或柔和渐变 | 玻璃边缘、标签和细腻肤感 |
| 服饰、鞋包、潮牌 | 自然硬光、杂志棚拍或闪光灯 | 布料、皮革、金属与编辑气质 |
| 3D 潮玩、IP | 大柔光、均匀环境光、轻接触影 | 角色材质清楚，不过曝不油腻 |
| 工业、结构图 | 灰白渐变、轮廓光、细接触影 | 结构、零件与理性层次 |
| 自然、户外、生活方式 | 低角度逆光、真实阴影、轻颗粒 | 空气感与使用现场 |
| 活动、演出、运营 KV | 路径光、舞台光或局部发光 | 标题、入口、舞台与活动动线 |

不要把所有画面都写成“柔和侧光、商业摄影质感”。光线必须与商品、材质、时间和场景有关。
图形装饰只保留能改变视线、语义、层级、材质或信息组织的元素：线条用于路径、标注和方向；色块用于承载、分区和节奏；纸片和贴纸用于拼贴层级；星点、光斑和粒子只用于必要氛围；图标用于说明、导航和模块识别；边框用于票券、装帧、信息区和品牌系统。

不能说明作用的装饰应删除。不要使用无语义礼盒、金币、红包、随机丝带、爆炸贴、光束、碎片和漂浮图标填空。

## C. 物料与传播场景适配

目的：在已经确定的美术方向上，根据物料、平台、行业、传播阶段和系列需求调整信息容量、观看距离、版式结构与视觉强度，不重新选择一套字体和风格。
### C1. 物料类型适配

#### 海报、KV 与系列传播

单张海报集中表达一个传播主题和一个主视觉核心；KV 建立可延展的标题字、色彩、主体与空间语言；系列传播先完成主视觉，再安排各张内容分工。预热、爆发、进行和收官共享活动身份，但信息压力与场景可以变化；不要让一张主视觉同时承载完整会场、全部商品和所有规则。
#### 电商商品与活动系统

商品主图、商品卡、权益卡、详情页和会场必须保证商品外形、包装、颜色、数量与文字准确。商品主图以售卖商品为第一视觉，商品全貌、关键角度、包装识别和真实比例优先于主卖点、价格与权益；文字不得遮挡商品识别面。会场中的活动标题、权益、品类入口、商品分组和导航需要明确顺序；同一活动的主 KV、权益卡、商品卡与机制页共享标题字、色彩和图形系统。
商品主图根据 C3 的平台与类目规则确定 1:1、3:4 或实际硬规格，同一套系列图保持统一比例。标准货架图优先商品识别和正面信息；内容化主图可加入场景、标题和卖点，但不得变成大字报。
内容型商品主图先由商品识别决定画面气质：从产品颜色、包装或结构、材质、使用场景、目标人群和主卖点中选择摄影、3D、扁平图形、拼贴或混合媒介。有真实商品素材时优先商品摄影与商业合成；只有商品类别或抽象卖点时，可用 3D 商品装置、扁平图形、包装轮廓或插画建立完整主视觉，不默认伪造一组写实摆拍。
每张商品主图或商品卡都要同时完成商品构图、标题设计和信息组织。商品保持最大的识别面积与最明确的视觉重量，但商品优先不等于孤立居中或正面平铺；内容型主图先根据卖点确定一种清楚的主视觉动作，可采用斜向悬浮、局部材质切片、手持或操作、原料与成分环绕、同轴舞台、从屏幕或包装结构中穿出、前景遮挡、光影路径或场景纵深。标题可用定制字形、数字嵌合、手写批注、轮廓避让、参数共轴或负形排布进入同一构图，字号与字重服从商品展示，不用超大粗字覆盖商品。价格窗、卖点标签、参数标注、口味或型号索引、权益和购买信息沿主视觉动线分布；陪衬图像、前景和道具必须证明卖点并建立层次，不作孤立装饰。整套系列固定标题系统、排版网格、标签语法、背景逻辑、配色职责、媒介和主光，商品角度可按每张卖点调整，不把角度一致当作系列一致。
商品主图的背景、标题、价格与标签优先从产品识别色、包装色、材质色和使用场景取色，活动色只服务促销信息。不默认用“整图摄影 + 大面积渐变蒙层 + 普通白字”解决可读性；先重构取景、明度、负形、实色结构、包装面或场景边界，让商品进入文字前景，或让文字沿商品避让、共轴、包围和形成标注关系，不让文字压到商品前景。

产品海报、新品发布、品牌宣传和产品系列宣传不执行商品主图的信息模块逻辑。先按 A5 与 A3 定稿传播母版：明确标题字的笔画与整组轮廓、产品与标题的空间关系、主视觉构图、摄影或图像处理、背景场域、辅助图形、材质和主光。产品传播标题必须执行 A5 的字体设计要求，在提示词中写明采用哪一种字体方法、怎样处理笔画与整组轮廓、怎样与产品或图像发生关系；不得直接使用基础字体，也不得用基础字体的简单变形替代设计。严格品牌字体保留字形身份，但仍要通过定制字组、层级、裁切、负形、网格或图文穿插形成标题系统。再让原料、工艺、功能、季节与场景信息进入既定动线，不能由参数卡、标签数量或商品正面展示反向决定构图。产品可以采用英雄视角、识别性裁切、材质微距、原料共景、使用动作、生活方式场景、结构切片或空间装置，不要求始终居中、完整正面或承担最大面积。配色以品牌与产品识别为锚点，同时明确背景场域、辅助色、强调色和文字色的职责，并把产品原有的明度、冷暖、纯度、通透度与情绪方向写入提示词；标题与辅助文字按 B5 建立可读对比，不把信息准确等同于货架式展示。
商品系列默认展示同一个具体商品或同一 SKU：外形、比例、关键部件、标签/屏幕/图案位置、Logo、主色、材质、规格标识和组件数量保持一致；允许正面、斜放、俯拍、手持、局部、质地、成分、参数和使用状态变化。只有用户明确要求多品或组合装时才更换商品。

同一套商品主图使用一套固定的版式与视觉系统。同级标题、卖点、价格、参数和标签分别保持相同字体样式、字号级别、字重、字距、行距、描边或阴影方法及颜色职责；商品尺度区间、版心、边距、对齐基准、标题与商品关系、信息模块造型、主要标注语法及其锚点和阅读次序、背景语言、图像媒介、材质和主光保持一致。标题长度变化只通过既定网格内的分行和有限缩放解决，不重新选择字体或改变同级信息的视觉等级。各张可以改变商品角度、局部特写、人物动作、使用场景和标注的具体锚点，但不能改变标注的语法、对齐与阅读逻辑，也不能因此另起一套排版、配色或视觉风格。

#### 简略促销简报的活动机制母版

母版的触发取决于简报是否足以独立形成画面，不按字数，也不把节点或品类本身当作排除条件。用户只给“做一套双 11/618/年货节大促海报”“做一张秒杀活动海报”“购物节主视觉”“五一促销海报”“母婴海报”等主题与物料，缺少完整上屏文案组、明确商品或人物素材、主视觉关系、配色与媒介、品牌规范、已确认主 KV 或详细参考时，启用母版补足设计。用户给出节点、品类或一句标题，仍可进入母版，但这些信息必须成为选型和改写依据。

出现以下任一情况时不进入母版：用户已给可以直接执行的完整提示词；已明确主标题、利益、商品、时间和行动等主要信息层级；已规定主体、构图、字体、配色、媒介与场景之间的关系；已提供足以决定构图的商品、人物、IP、品牌素材、主 KV、确认稿或详细视觉参考；任务不是营销传播，而是品牌规范、包装、编辑设计、信息图、一般摄影或其他已有独立方法的物料。此时按 A5 完成专属设计，不把母版中的场景与道具带入。

母版直接提供可用的完整主视觉提示词，不替用户虚构价格、折扣、满减、日期、赠品、功效和品牌。用户给出的标题、节点、品类与商品逐字或按身份保留；没有上屏标题时，根据任务定稿一个不涉及事实承诺的标题，如“限时秒杀”“购物狂欢”“五一好物出发”“成长好物集”，再补一条有实际信息作用的状态短句、栏目字和通用行动词。不得把“做一张母婴海报”等任务说明直接当作标题。

母版不是抽象风格参考，而是主 KV 的完整设计底稿。最终提示词以选定母版完整的视觉设计正文为基础逐项替换，保留其画幅逻辑、构图分区、标题位置、标题字的字重、宽窄、倾斜方向、圆角或尖角、切割方式、描边、投影和整组轮廓，以及主视觉装置、色彩职责、图像媒介、造型语言、材质、光线、透视、装饰路径和信息承接关系。这里的完整复用指视觉结构、设计动作和表现描述不得删减或改写，不要求逐字保留母版中的示例上屏文案。进入母版路线后，不再依据 A5 重新选择视觉方向，也不以 B2 的字体设计规则二次改造母版标题；母版正文已经写明的标题字方法就是该路线的执行标准。不得把母版压缩成“电商大促、圆角立体字、3D 场景”等概括性描述，也不得把不同母版的标题字统一改成圆润、鼓起、软胶或普通立体黑体。

具体对象可以在主 KV 定稿前按用户主题替换，但只能在相同视觉职能内调整商品品类、人物身份、活动角色、场景构件、舞台轮廓和辅助道具；替换后保持原有数量层级、位置、尺度、聚散、动势、透视、媒介、材质、光线与画面密度。对象替换不能改变主装置类别、标题字方法、图文关系和构图骨架。母版中的主标题、副标题、利益文字、活动名、栏目字、状态短句、行动词、品牌占位和节点符号属于可替换的上屏内容，不属于必须逐字复用的视觉结构：用户已经提供时使用其准确文案；没有对应信息时，只能改为不涉及金额、折扣、赠品、门槛、日期、配送、功效或品牌事实的通用栏目、状态与行动短句，无法安全改写时直接删除。不得让母版示例中未经用户确认的“领券”“买一赠一”“购机好礼”“新鲜送达”、活动节点或其他权益与事实进入最终提示词；用户明确提供这些内容时按准确文案使用。文案替换只改变文字语义和必要字数适配，不改变原有标题位置、字组轮廓、字体方法、层级、承载关系与构图。

用户提供活动色板或明确色彩倾向，且任务仍符合母版触发条件时，所有母版都在主 KV 定稿前完成促销配色映射。母版示例色板保留为色彩气质与光影关系的参考，维持主色、背景色、辅助色、强调色和文字色的职责、面积顺序、冷暖关系、明度结构、纯度节奏、活动强度与光线方向，再按 B5 和用户要求调整具体色相；没有明确活动色板时使用母版原有活动配色。品牌识别色单独按 B5 作为辅助识别嵌入，不视为需要覆盖背景、标题、装饰和环境光的活动色板；品牌色偏深或纯度过高时，不得写入大面积背景，只能以提亮、降纯并融入暖向环境光后的衍生色作局部呼应。映射结果必须逐项写回母版正文中的背景、标题、强调信息、主体材质、装饰和环境光，不用一句笼统的“改为某配色”代替，也不改变母版构图、字体、媒介、材质和视觉气质。主 KV 定稿后锁定色板及各颜色职责，后续资源位不得再次换色。

画幅与母版一致时直接复用全部空间关系；画幅不同时只做专业改版，保持主视觉装置、标题关系、区域占比、动线、色彩、媒介、材质和光线不变。不得新增创意方向、更换主装置或从其他母版借用标题字、造型与装饰。五个通用母版中的示例商品、场景和活动名称不构成适用范围，可按相同视觉职能替换具体对象；科技型、温暖型两条专用母版保留各自的使用情境和气质边界，不跨场景任意套用。具体对象的替换只发生在主 KV 形成前；主 KV 确定后，已经替换完成的商品、人物、角色、场景与道具即成为整套物料的固定素材，后续资源位只按 C2 改版。

通用母版不与“双 11、618、大促、秒杀、五一”等活动名称、行业、商品、示例场景或原始画幅固定绑定。先按 A1 确定整套物料唯一的主 KV，再在五个通用母版中比较标题与主体关系、主视觉装置、图文结构、主体聚散、空间动势、信息容量和多版位延展价值；不得先为 Banner、弹窗、朋友圈等各自筛选母版，也不得因母版编号、排列顺序或横竖方向形成默认项。母版只选择一次，其他资源位全部按 C2 从同一主 KV 改版，不能因比例变化再次选型。

在全部通用母版中，先选择最能承载传播内容、且标题关系与主装置在多版位中仍可识别的一条；示例配色作为次级判断，只比较冷暖倾向、明度、纯度、面积与对比节奏是否适合当前气质，不以“红黄、黄橙、粉紫、蓝绿”等具体色名直接选定或排除母版。用户色板能够在不破坏母版视觉气质的前提下完成映射时，具体色相差异不降低其优先级；多个母版在结构上同等成立时，再选择色彩气质和光影关系更接近的一条。母版路线与 A5 的普通设计路线分开执行：一旦选定，字体、构图、媒介和装饰语言以母版正文为准，配色按前述规则逐项改写，不再调用普通路线重新判断或混合另一套风格。不得根据“预售、团购、零食、家电、冬季”等单一词语固定母版，也不得把示例商品、人物、舞台或装置当作适用范围；活动弹窗只承接已定主 KV，不能反向决定母版。

用户主题属于科技品牌或科技产品，包括手机、平板、电脑、耳机、音响、穿戴设备、影像设备、游戏硬件、3C 配饰、充电与连接设备、智能配件、AI 硬件、家庭影音、智能家居及同类数码产品，且简报仍满足前述母版触发条件时，优先使用科技型，不因产品属于个人设备、配件或强调时尚与性能而退回 A5。科技型中的具体商品、配件、界面、功能可视化、人物身份和使用场景按用户提示词替换：手机与穿戴突出手持、佩戴、影像或移动使用，耳机与音响突出聆听关系，配件突出连接、充电与组合，家庭影音与智能家居突出空间、多设备互联和观看关系；只选择当前产品所需的一组。品牌或产品已有明确识别色时，按全局品牌促销配色规则建立主辅色职责，不保留与品牌冲突的示例色。只有用户已经给出足以决定构图、字体、配色、媒介与场景关系的完整科技设计简报，符合本节“不进入母版”的条件时，才进入 A5 专属设计；工业机械、工程设备和纯技术信息图按实际任务单独判断。

用户提出母婴育儿、儿童成长、宠物生活、家庭健康与营养、家居日用与清洁护理、烘焙食品与饮品、亲子教育、公益关怀或社区服务等内容，并且需要温柔、安心、陪伴、疗愈、童趣或家庭亲和气质时，使用温暖型。行业名称本身不自动触发；数码、运动、时尚等其他行业若明确要求同样的柔软亲和语气，也可以使用，但要把商品、角色和场景完整替换为当前主题。强调效率、专业、锋利、速度、奢华或硬核性能时不使用温暖型。温暖型没有对应画幅时从同一视觉中改版，不改走通用大促母版。

保持人物与 IP 身份，用动作、视线、服装、舞台、票面、路线和场景建立传播语境。娱乐与赛事可强化动势，但时间、地点、阵容和角色信息必须准确；粉丝应援不得伪造官方身份与商业合作。文化主题从工艺、材料、书写、器物、建筑、仪式和地域中提炼，不只堆传统符号；漫画与多格叙事保持人物、色彩、线条和场景连续。
#### 展览、线下、包装与品牌应用

展会、门店、展架和户外同时考虑观看距离、空间环境、灯光、出血与安装方式；包装考虑正面、背面、侧面、封口、标签、刀版、折线和跨面关系。品牌应用从主标志中提炼辅助图形、色彩、字体与材料，分别适配纸袋、杯子、盒子、吊牌、贴纸、卡片和陈列，而不是把同一 Logo 简单缩放后贴满所有物料；不同载体可以改变图形裁切和信息量，但保持识别原则。
### C2. 系列设计、多版位延展与多风格方案

#### 系列设计

先区分两种任务：

- **同一主视觉多版位**：同一活动、同一商品或同一品牌 KV 适配海报、Banner、弹窗、卡片、朋友圈、开屏、主图和会场；
- **同系列不同内容**：一组产品卖点图、栏目封面、社媒组图、详情模块或连续主题海报，各张内容不同但共享设计系统。

先按物料关系判断，不按数量或“一套”“整套”等措辞判断。主 KV 适配 Banner、弹窗、朋友圈、开屏、会场及其他尺寸，或明确要求同一画面适配不同资源位时，属于同一主视觉多版位；必须复用已经定稿的主体素材，只调整画幅内的裁切、尺度、位置和前后层级，本节限制优先于 A1、B4 中关于素材角度、组合、调光和重排的通用权限。产品海报搭配桌卡、柜台卡、卖点卡，或同一平台上的产品系列宣传、分别讲述功能、材质、工艺、场景和阶段的多张画面，属于同系列不同内容；用户未指定各张分工时按 A3 补全，不把它们机械裁成同一张 KV。只有用户明确要求卡片沿用主 KV 裁切时，才按同一主视觉处理。

用户提供已经完成或认可的主 KV、海报、首张成图或详细提示词时，直接以该成图事实建立视觉母版，不再经过 A5 重新选择方向，也不套用 C1 的促销母版。没有现成主视觉且简报完整度不足的促销任务需要一套物料时，只为第一张主 KV 选择一条活动机制母版并直接使用其完整正文；可以先按主题替换母版中的具体商品、人物、角色与道具，但必须保留母版的构图、媒介、造型、材质、色彩和光线。第一张确定后立即固定其准确标题、替换完成的商品组或活动装置、角色、图形关系、整体色调、标题字、材质和主光，后续版位只做适配，不为每个资源位重新选型。

| 必须固定 | 可以适配 |
|---|---|
| 同一 SKU 的外形、比例、包装结构、标签位置、颜色、材质、型号和组件数量；同一主视觉跨资源位还需固定已经确认的商品组合、数量、角度和主体素材 | 同一主视觉跨资源位只调整裁切、整体缩放、移位、局部遮挡和前后层级；同系列不同内容才可根据卖点轻微调整商品角度、俯仰、局部特写和使用状态 |
| 主标题字形来源、笔画、字重、宽窄、圆角或棱角、描边或阴影方法 | 标题分行、尺度、局部压缩和安全区内的位置 |
| 标题与主体的主要关系，如压叠、穿插、共轴、环绕或成为容器 | 为保持关系而调整主体大小、裁切和局部遮挡 |
| 背景素材、整体色调，以及主色、辅助色、强调色、标题色、正文色和标签色的具体色相、面积顺序与对象绑定 | 为适应明度和可读性，在既定色相范围内微调明度、饱和度及预先确定的深浅文字版本；不得换色或互换颜色职责 |
| 摄影、插画、3D、拼贴或印刷媒介及其颗粒、材质和主光 | 信息容量、辅助文字显隐、标签数量、CTA 和平台必要组件 |
| 辅助图形、装饰母题、标签语法、编号系统和品牌签名 | 原有装饰可裁切、延长、简化、隐藏、移位和重排；只有扩画形成结构空缺时，才补充同一光带、纹理、粒子、色块或连续线条，不新增商品、人物、角色、礼盒、票券装置和场景道具 |

同一主视觉的延展不得更换主 KV 中的商品组合、人物、IP、动作、主装置、核心场景、插画主体和关键道具，也不得新增另一套装饰母题。海报加三张卡片时，卡片应从主 KV 的同一商品、人物、背景和图形中取局部裁切、卖点特写、权益模块或近景，不另起新配图；促销主 KV 延展到 Banner、弹窗和朋友圈时，仍使用同一标题字、同一商品组、同一人物或角色、同一活动装置、整体色调和主光。尺寸变化优先裁切、隐藏、移位或延长原有边缘装饰；只能补充不承担新叙事的连续光带、纹理、粒子、色块和线条，不能增加新的商品、人物、角色、礼盒、票券装置或场景道具，也不能借此替换配图主体。

实际生成整套物料时，先完成并锁定主 KV，后续版位必须以该成图作为图像依据和唯一素材源，直接复用其中的商品抠图、人物或角色、主装置、核心场景和关键道具，通过裁切、扩画、整体缩放、移位、文字重排和前后层级调整完成改版；不得仅凭相同文字把各版位的主体重新制作一遍。只交付文字提示词时，每张先明确以所附同一主 KV 成图为底图，再写当前画幅的裁切、扩画、尺度、位置、信息容量与装饰显隐；可以复述固定对象的身份和识别特征以便独立阅读，但不使用“重新搭建、重新陈列、重新生成、放置一组”等表达重新绘制主体。只有用户明确要求同系列不同场景时才允许重新拍摄或重绘，仍需保持同一产品、人物/IP 与设计系统。

同一主视觉跨资源位延展在主 KV 定稿后，继续复用已经确认的商品抠图、人物或角色、主装置、核心场景和关键道具，只通过裁切、整体缩放、移位、局部遮挡和前后层级适配尺寸，不调整商品角度、人物动作、角色造型或场景身份。产品传播系列和商品主图系列只有在已被判定为同系列不同内容时，才可根据不同卖点微调同一 SKU 的展示角度、俯仰、局部特写或使用状态；这一变化只作用于商品本身，标题字形与字组轮廓、字体颜色、排版网格、信息层级、色彩职责、图形语言、背景质感、媒介和主光继续继承视觉母版。

视觉一致不要求所有版位逐字复制。主标题、产品名称、系列名、准确利益和品牌口径保持一致；各版位根据使用距离和阅读任务增减说明。主海报负责建立上新、活动或产品记忆，近距离桌卡与商品卡可以在同一主题下分别展开体验、卖点依据、季节场景、搭配或选择提示，每张只回答一个主要问题并提供足够支持信息。新增说明不得改变主标题语义，也不得把未经确认的产品事实写成卖点。

促销类主视觉延展时，副标题、核心利益、优惠标签、活动机制和行动语义也属于固定信息系统。它们可以根据 Banner、弹窗、朋友圈、卡片等版位缩短、拆行、换位置、降级显示或并入票券/标签/按钮式入口，但不能改成另一套优惠口径、另一句副标题或另一种行动理由；除非用户明确要求某个版位承担不同阶段信息，否则各版位的主标题、副标题、核心利益和行动关系应能对应回同一张主 KV。

商品系列和商品主图被判定为同系列不同内容时，锁定同一 SKU 的外形、比例、包装结构、标签位置、颜色、材质、型号和组件数量，各张可根据卖点改变角度、裁切、局部特写和使用状态，但不得重画成另一款包装或临时增加新品。已确认主 KV 中元素的数量与主次也属于母版：可以因画幅隐藏次要元素，不能用新元素补位。商品角度属于同系列不同内容的局部展示变量，不适用于同一主视觉跨版位；调整角度也不得触发标题字、字体颜色、文字层级、排版网格、信息模块、配色职责、背景、装饰母题、媒介和主光的重新设计。

同系列不同内容可以更换准确文案、产品角度、局部特写、人物动作或分主题场景，但保持同一构图骨架、标题系统、字级、色彩职责、图形语言、媒介、背景质感和光线。参考成熟商品系列图的做法：同一产品或同一品类反复出现，同一标题与信息模块反复建立识别，各张通过正面、斜放、局部、手持、成分、质地和参数改变内容，而不是每张换一套美术方向。

系列一致性不是固定坐标。毛笔、手写、书法和材料标题只能改变尺度、分行、位置和局部组织，不能换成宋体、黑体或普通印刷字；标题色、强调词色、正文色、标签色和背景色按既定职责继承。宣传册、画册和品宣页面的封面、封底及内页标题保持公司名、系列名、标题字形和颜色一致，封底可缩小或移位，不能重新选字体。

不要用“统一现代感、编辑感、字体气质”代替母版。必须写明具体字形、构图关系、颜色职责、媒介、背景、主光和固定素材。
#### 多版位延展

同一主视觉适配不同版位时，不做机械裁切，也不重新设计。Banner 将原有动线横向展开；开屏和竖版沿原有关系改为纵向推进；方形主图放大商品与核心卖点；卡片选择主 KV 的局部或单一权益；弹窗从主 KV 提炼核心利益、主体局部和唯一主操作，在实际内容区内完成信息适配；户外删除小字并扩大轮廓；展架保留远读与近读两级信息。弹窗是界面资源位，不写成“弹窗海报”，也不默认增加海报边框、卡片外框、设备框或外层圆角容器；只有用户素材或真实组件规范已经包含容器轮廓时才保留，关闭区属于界面功能层而非装饰。尺寸变化首先通过裁切、缩放、移位、遮挡，以及原有光带、纹理、粒子、色块和线条的延展或显隐解决，不改变配图主体，不新增具象物件。只有真实交互载体需要时才增加关闭区、页码或一个主操作入口；搜索框、票券口和 CTA 只选择一种入口形态，不同时出现两个按钮式色块，也不为填补下部空间增加全宽底栏。

输出同一主视觉的多版位提示词时，先为主 KV 写一份完整成图提示词；后续每张都写成基于第一张主 KV 成图的改版指令，开头使用“将第一张图改为……”或“基于所附主 KV 改为……”，不再以“生成一张……”重新起稿。改版指令逐项写明保留同一商品组合与数量、包装与角度、人物/IP 身份与动作、主装置、核心场景、标题字形与字组轮廓、标题与主体关系、字体颜色、排版逻辑、背景材质、媒介和主光；主色、辅助色与强调色继续写清具体色相、面积顺序及其绑定对象，不用一句“风格一致”代替。变化只包括当前比例下的裁切、扩画、整体缩放、移位、分行、信息容量、连续装饰显隐和唯一行动入口位置，不使用“放置、搭建、陈列、加入一组”等动作重新制作主体，也不因版位变化替换商品、人物、角色、装置、场景或关键道具。同系列不同内容才根据各张卖点写明商品角度、局部特写或使用状态，并完整继承其余视觉规则。
逐张写完后做删减检验：去掉物料名称、比例和平台控件，剩余描述仍应指向同一个标题字组、同一商品或角色、同一主视觉装置、同一背景与配色、同一光线和图形语言。若任一张仅剩通用风格词，或换掉名称后可以属于另一套活动，说明延展已经脱离母版，应回到主 KV 重写。
#### 多风格方案

默认只输出一个最匹配需求的完整方向，不自动生成四个方向。
只有用户明确要求多方案、四个方向、提案筛选、系列风格图或风格探索时，才输出多套设计。先固定用户准确文字、商品或人物身份、品牌规范和物料规格，再为每个方向分别定稿一套完整视觉机制：标题字的来源、笔画处理与整组轮廓；主视觉和主体关系；构图骨架与阅读路径；图像媒介、镜头或图像处理；主辅色职责；材质、光线、信息密度和辅助文字系统。每个方向都必须能够单独形成完整成图提示词。
风格探索的差异应发生在设计逻辑，不只换背景色、字体名称和装饰元素。产品风格图可分别从编辑摄影、表现性字体、感官材质、生活方式、未来数字、3D 空间、当代东方或插画叙事中选择真正适合产品的不同路线，但每条路线内部仍保持产品身份、文字准确和系列统一；不把某一方向的字体、配图、色彩和装饰混入另一方向。系列一致性规则作用于每一方向内部，不得把不同提案压回同一套保守版式。
### C3. 平台与观看环境适配

用户明确的主题、情绪和视觉方向优先于平台调性。平台适配只调整阅读行为、标题长度、主体尺度、信息密度、安全区和内容现场，不替换已经确定的标题字、配色、主视觉关系和美术方向，也不因商品品类改写用户表达。
平台规格会更新。用户未提供尺寸且成品需要直接投放时，先查阅当前官方平台或广告位规范；无法确认时，说明采用的常用比例，不把经验尺寸写成永久规则。
#### 小红书

图文封面常用 3:4，优先保证缩略图中的标题和主体识别；标题应像具体观点、体验、清单、路线或场景入口，而非空泛硬广口号。使用真实场景、产品细节、局部标注和中等信息密度，系列图保持统一比例与封面系统；避免电商大字报、贴纸堆叠、奶油模板和无内容装饰。
#### 朋友圈

朋友圈营销、倒计时和品宣海报在用户未指定尺寸时通常采用 3:4 竖版；广告位或实际容器另有规格时从其规格。使用中低信息密度、克制标题、可信产品质感和生活方式场景，允许更慢阅读与受控留白，但下部仍应由主体裁切、场景延伸、前景、图形路径或自然信息承接参与构图，不能形成空置下半区；优惠和行动信息清楚但不高压，避免默认方形、满屏权益、碎片拼贴和低对比空图。
#### 抖音、快手与短视频平台

视频和开屏通常优先 9:16，图文和商品字段按当前平台规范；一秒内识别活动、人物、商品或内容主题，标题短、主体大、重点少，并避开界面覆盖区。平台感不等于粗黑字和蓝紫霓虹。真实场景活动 KV 强化入口、舞台、人群、商品、餐饮、灯光与城市夜间氛围；吃喝玩乐类活动应体现现场规模、参与感和本地消费内容，不做普通餐饮拼贴；灯管字、霓虹字或发光装置必须与场景透视、人物和环境光真实结合。
#### 电商平台

先判断标准货架图、内容化主图、导购图、详情页、商品卡还是活动会场。标准主图突出商品全貌、正面、数量、包装与真实比例；内容化主图可增加卖点和场景，但不以大面积文字压住商品；详情页保证商品、文案、参数和模块一致。商品主图未遇到用户指定尺寸或实际字段硬规格时，按以下规则确定比例：抖音电商商品图片统一使用 1:1；淘宝、天猫及未指定平台时，服饰、鞋靴、箱包、美妆个护、珠宝饰品、家具家装、灯具及空间型商品优先使用 3:4，其他商品使用 1:1；指定京东时，箱包、美妆个护、珠宝饰品、家具家装、灯具及空间型商品使用 1:1，服饰和鞋靴按行业需求使用 3:4。无论平台和品类如何选择，同一套商品主图保持统一比例；直接使用时继续核对目标平台、类目和广告位的像素、文件大小、格式与安全区。
#### 公众号、H5 与长图

使用连续阅读、章节标题、导语、重点句、图像和行动模块，保持模块节奏与视觉重复，避免无分区长页面；重要文字不依赖过小字号和复杂背景，仅在需要交互时设计按钮、导航与页面控件。
#### 户外、门店、展会与印刷

远距离只保留主标题、主体和必要行动，使用强轮廓与明度分离，不依赖小字和细纹理；近读区域安排日期、地点、二维码、规则和联系方式。保留出血、折线、安装边、屏幕裁切与视线高度；印刷材质会改变颜色、黑位、细线和小字，设计时考虑纸张与工艺。
### C4. 行业气质与活动阶段适配

行业只提供设计依据，不构成固定模板。
#### 行业气质

- **美妆、香氛、奢品**：强调产品比例、玻璃/金属/纸张细节、克制色域、精细光线和标题字品质；不自动细宋黑金；
- **食品、饮品、餐饮**：强调食欲、切面、液体、温度、原料和使用现场；标题可由食材、包装、手写或印刷形成；
- **母婴、家居、健康**：强调安全、柔软、可信、清楚利益和亲和行动；不自动软糖圆体，也不能把促销做成无行动力品宣；
- **科技、工业、数码**：强调结构、功能、材质、界面和精密关系；不自动深蓝紫、HUD 和镀铬；
- **时尚、潮牌、娱乐**：强调人物姿态、摄影裁切、标题个性、拼贴与节奏；不让人物美化压过身份准确；
- **文化、节庆、文旅**：强调材料、书写、器物、建筑、地理和真实仪式；不自动宋体、红金、灯笼和祥云；
- **运动、赛事、游戏**：强调动作、透视、速度、装备、舞台和角色身份；辅助信息必须准确；
- **教育、机构、招商、公共传播**：强调结论、结构、可信场景和行动入口；不使用夸张效果掩盖信息。

#### 促销阶段

促销只改变行动压力、利益显著度、信息密度、时间感和商品规模，不重新选择品牌人格、标题字、媒介和商品身份。

| 阶段 | 传播重点 | 设计调整 |
|---|---|---|
| 预热 | 记住活动与时间，建立期待 | 标题和主题符号优先，保留悬念，商品可局部露出 |
| 爆发/开抢 | 立即理解活动、利益和商品 | 标题、利益、商品紧密聚合，提高尺度差和空间层次 |
| 秒杀/限时 | 缩短决策路径 | 时间、利益和 CTA 连续阅读，减少解释 |
| 机制/权益 | 读懂门槛和获得内容 | 使用票券、卡片、路径、分组和对比说明条件 |
| 常规进行 | 持续说明购买理由 | 稳定结构，增加商品与卖点证据，减少爆发装饰 |
| 收官/返场 | 强调时间压力和最终确认 | 收紧构图，时间靠近利益，删除无关信息 |
| 会员礼遇 | 权益与品牌身份 | 使用仪式感和会员识别，不过度低价化 |
| 新品首发 | 新品差异和发布事件 | 突出产品、材质、结构和首发信息 |

促销主视觉必须包含活动或购买标题、核心利益或第一行动理由，以及商品、品类、人物或 IP、服务场景、活动装置中的至少一种具体视觉承载。用户已明确商品或品类时，商品或品类必须进入主视觉；泛化购物节、平台活动或服务活动没有具体商品时，可由活动装置、角色或场景承载主题，不为填充画面虚构商品。用户已经提供机制、时间、价格、折扣、赠品、门槛或具体行动信息时准确使用；没有提供时不得虚构，可用“活动进行中”“限时开启”“精选好物”“进入会场”“立即了解”等不涉及具体商业事实的通用状态、栏目与行动短句补足阅读层级，或在不影响传播完整度时省略对应字段。通用词只说明活动状态和阅读方向，不能伪装成真实优惠、服务承诺或已确认时间。

温柔品类可以降低噪声，但不能丢失行动结构。使用票券窗、价格窗、轻量权益卡、倒计时标签、商品半环和清楚行动词建立促销感，不依赖金币和爆炸贴；一张图只选一种行动承载，不叠加两个按钮式圆角块。
### C5. 局部修改与商业信息准确性

用户要求修改现有画面时，先明确：

- **保持内容**：主体身份、原有构图、未指定文字、Logo、产品、人物、光源、材质和未要求改动的区域；
- **修改内容**：用户明确指定的标题字、背景、颜色、元素、光影、文案或局部问题；
- **衔接方式**：修改后的透视、颗粒、清晰度、色域、材质和空间关系如何与原图一致。

不因局部修改重做整张图。除非用户明确要求整体重设计，否则保留未指定内容。
商业素材需要保持准确时，在生图提示词中明确：

- 保持产品造型、包装比例、瓶盖结构、材质、颜色、图案、商标、品牌名、产品名和关键文字；
- 保持人物五官、脸型、发型、服装标志和身份；
- 不生成错字、乱码、镜像文字、无意叠字、重影字、重复标题、重复标签、额外 Logo 和无关品牌；同一文案只有在明确作为连续字纹、重复排版或图案文字时才重复；
- 不增加不存在的按钮、接口、配件和功能；
- 不遮挡包装、Logo、人物五官、价格、机制、参数和行动信息；
- 避免产品变形、标签错位、边缘融化、结构不对称、反射和材质失真。

只在相关任务中写这些要求，不把同一套限制无差别加到所有海报。

## D. 生图提示词与设计审查

目的：把已经完成的设计方案写成清楚、具体、可生成的画面描述，并在输出前检查专业度、可读性、商业效果和素材准确性。
### D1. 生图提示词写作

最终生图提示词应像一段可直接成图的商业视觉描述：从成品类型、主题、用途和整体气质进入，再把准确文字、标题字、主体、构图、配色、材质、光线和限制写进同一个画面。
非母版任务写作前回到 A5 的具体设计方案；母版任务回到 C1 已选定的完整母版。主视觉、标题字、图文关系、构图骨架、颜色职责、媒介、背景和主光必须从对应路线原样进入提示词，不得在提示词阶段重新选择方向、构图或配色。
写作要求：

- 使用自然、连续的画面语言，不写成设计规范目录；
- 使用具体名词、关系动词和空间描述；
- 先写整体画面，再推进到主体、标题、辅助信息、背景和细节；
- 同一事实只写一次；
- 准确文字用引号标出；
- 不把多个候选风格并列写进同一方案；
- 不使用“高级、好看、冲击力、氛围感”代替具体设计；
- 不把最终提示词写成设计过程、分类目录、审稿清单或与画面无关的说明；
- 不使用“配图主体：”“背景：”“保持：”“输出要求：”等表单式段落标题，除非用户明确要求固定格式；
- 只保留当前任务真正需要的 2—5 项限制，不堆通用反向词；
- 文字、商品、场景、配色和光线写成同一画面，不分别形成互相冲突的说明。

非母版提示词必须让人看出当前设计方向。如果把其中的“编辑”“复古”“大促”“科技”“东方”或其他风格名称替换后，字体、构图、图文关系、配色和材质仍然成立，说明写得过于通用，应回到 A5 补具体设计动作。
非母版任务的最终提示词至少要保留 A5 中已经定稿的四类可见信息：标题字的笔画与整组轮廓；主体与标题的空间关系和构图骨架；配图媒介、镜头或图像处理；颜色职责、材质与主光。产品传播还要写明产品色板的明度、冷暖、纯度与通透度，背景场域和辅助色如何扩展，主标题与各级文字如何保持识别；科技发布和风格探索不得只保留产品名称、居中商品和“高级/未来/编辑”等方向词。辅助文案、编号、图注或状态信息要以具体上屏文字进入版面，但必须服从已定主视觉，不能把画面改成信息模块的集合。
单张物料直接写完整提示词。多物料任务先在内部形成视觉母版：同一主视觉跨版位时，第一张主 KV 使用完整成图提示词，后续版位使用以第一张成图为底图的改版提示词，逐项复述需要保留的准确标题、字形、主体、场景、配色职责、背景、辅助图形和主光，再只说明当前画幅中的裁切、扩画、分行、尺度、位置、信息容量和行动入口变化；不得把后续版位写成另一张独立生成的同风格画面。同系列不同内容时，每张才写成可独立生成的完整提示词，并继承同一设计系统。不得让不同物料分别选择风格、配色、字体和配图。用户明确要求多风格提案时不执行这一母版共用规则，按 C2 为每个方向分别定稿；同一方向内如含多张物料，再共享该方向自己的视觉母版。
商品主图系列的每条提示词应写明该张的购买结论、二至四条支持信息及对应的商品全貌、细节、标注或场景表现，整套延续 B4 的内容配置，并统一使用 C3 确定的画幅比例。每条提示词都要写回同一套字体样式、同级字号与字重、排版网格、信息模块、颜色职责、背景语言、图像媒介和主光，不能只用“保持系列一致”代替具体设计。无论是商品全貌、细节规格还是真人使用场景，商品始终是第一视觉；标题和信息模块用于解释商品，不以超大字号和过重字重替代商品展示。

提示词长度由画面信息是否完整决定，不设统一字数。写到以下内容足以直接成图即可结束：准确文字已经定稿；标题字与主体关系明确；主体、商品或人物的数量、位置、角度和材质明确；前中后景或平面层级明确；利益、标签与行动有承载结构；背景、配色职责、主光和必要辅助元素明确；当前任务的素材边界与比例明确。不得为精简删掉这些决定，也不得为了显得详尽重复同一事实、同义形容或通用禁项。用户明确要求短版时，优先压缩解释，不压缩主视觉关系。

简报完整度不足的促销任务适用 C1 活动机制母版时，最终提示词以选定母版完整的视觉设计正文为底稿，不再另起设计，也不回到 A5 或 B2 重新选择风格和字体。用户准确文案、活动名、品牌占位和节点符号按需求替换；母版示例文案只作为排版位置与信息层级示范，可以按 C1 改为用户准确文案或不涉及事实承诺的通用短句，必要时删除，但不得连带删减或改写其标题位置、字组轮廓和承载关系。标题字的字重、宽窄、倾斜、圆角或尖角、切割、描边、投影、字组轮廓及其与主体的关系必须完整写回，不得概括成普通圆角立体字。具体商品、人物、角色、图标、舞台和道具可以在相同视觉职能内替换，但应保留其主次、位置关系、整体密度以及母版的构图、主装置、配色、图像媒介、造型语言、材质、光线、装饰路径和信息承接。合理补充的栏目字、状态短句和行动词直接定稿。交付中不说明母版编号和选择过程，也不同时展示其他母版。先按 C1 判断科技型或温暖型是否适用；符合时保留专用母版的产品关系、场景气质和设计结构，不符合时再从五个通用母版中先比较标题与主体关系、主装置、主体组织、空间动势、信息容量和延展价值，再以示例色板的冷暖、明度、纯度和对比节奏作次级判断；不按原始画幅、具体色名、活动名称、示例品类、母版编号或排列顺序固定或排除候选。用户给出色板时，按 C1 将具体色相逐项写回完整母版提示词。多版位任务先据此完成一张主 KV，再把已确定的对象、色板和全部视觉规则写入每张延展提示词，不继续替换。已有详细提示词、主 KV、确认稿或足以决定构图的参考时，不使用母版。
需要展示设计过程时，只输出可公开的设计判断摘要，不写试错和审稿记录。摘要顺序为：物料、数量、横竖方向与比例；创意简报与设计策略；配色策略；风格方向；标题字与版式；主体、配图与画布关系；系列一致性规范或版位延展。每项都给出可见的设计决定，例如标题字如何构造、主色如何分配、商品如何穿插、哪些元素统一、哪些元素变化；不要只记录“需求分析、文案整理、风格要求”。

### D2. 画面描述的内在顺序

以下顺序是写作内核，不是输出格式。最终应写成一段或数段自然描述，不显示编号、章节标题、字段名和冒号式模板。
#### 1. 物料与用途

说明海报、KV、主图、包装、信息图、Banner、弹窗、详情页、展板或户外物料；写清用途、平台、画幅、观看距离、已经确定的设计方向和媒介。单张成图或主 KV 可以从“生成一张……”开始；同一主视觉的后续版位必须从“将第一张图改为……”或“基于所附主 KV 改为……”开始，明确这是图像改版而非重新设计。弹窗直接称为“活动弹窗”或“促销弹窗”，不称“弹窗海报”。
开头示例：
> 生成一张 3:4 竖版商业海报，主题为……，用于……，整体呈现……的品牌视觉。
> 将第一张主 KV 改为 3:4 竖版活动弹窗，保留同一……，将……移至……，仅减少……并加入唯一主操作与必要关闭区。
#### 2. 主题与准确文字

写明传播主体、主标题、核心卖点、价格/折扣、活动机制、日期、CTA、品牌和必须出现的文字。准确文字逐字、只出现一次，不添加乱码和额外品牌。
用户文字不足时，先根据物料的摆放位置、观看距离和决策阶段判断读者还需要知道什么，再把已合理补充的辅助文案直接写入，不写“可添加一些文案”。同一套物料分别写清每张承担的文案任务：主视觉给出主题与核心理由，近距离物料补充体验、依据、场景、选择或行动，避免所有版位重复同一句副标题。
#### 3. 构图结构

说明采用中心聚合、斜向推进、编辑网格、产品舞台、场景切片、强透视、拼贴层叠、路径叙事或其他已经确定的构图；再写视角、主体尺度、位置、裁切、负空间、前中后景、遮挡和阅读路径。竖版与长画幅必须明确下部由主体裁切、地面或场景延伸、前景、图形路径、材质变化或既有信息结构中的哪一项完成承接；主动留白则写清对向重量和用途。先写第一眼看到的完整关系，再写视线如何移动。不得退回顶部标题、中部孤立配图、底部说明的默认三段式，不用独立深色底栏、按钮和小字填补空处，除非参考、品牌规范或真实载体明确需要。
#### 4. 文字视觉化

这是最具体的字体段。写清主标题准确文字；字形来源和笔画特征；整组标题的外轮廓、大小与分行；字色、材质和表面；标题与商品、人物、照片、数字、图形、背景或画幅边缘的关系；辅助文字、利益数字、标签和图注如何形成层级。

不允许只写“现代字体、粗体、醒目大字、居中排版”。
科技、未来主义、数字主义和数字实验还要写明至少两项已经作用于字形与整组结构的处理，以及标题如何与产品切片、结构线、透明层、参数、扫描路径或受控粒子共享同一版式；只写窄体、等宽字、科技字体、白色大字或霓虹描边不合格。
#### 5. 配图与主体

写清人物、商品、道具、商品阵列、场景和图像媒介；说明数量、主次、位置、角度、材质、动作和前后关系，以及它们如何具体呈现卖点、活动机制或品牌价值。
#### 6. 背景、配色与表现

写清背景环境或材质，逐一说明主色、背景色、标题色、正文色、标签色和强调色的来源与位置，再写光线方向、阴影、反射、空气感、颗粒和景深。高能活动可以使用清晰有力的综合色相和强明度关系，但不使用高饱和正红与亮黄原色组合，也不使用黄底黑字按钮；科技发布可以使用明亮或深色体系，具体选择服从 A5 方案，不用统一中性色覆盖风格差异。深色或高饱和背景应明确标题采用哪一种由环境光或主体高光提取的高明度浅色，哪些局部保留纯白高光，辅助文字如何以同色阶浅色或透明度降级；不能把整套文字笼统写成纯白。
不要只写“高级背景”“柔和渐变”“高饱和撞色”。
#### 7. 保持与避免

写明商品、包装、Logo、人物、准确文案、价格机制和素材边界；只列当前最相关的风险，例如不改包装、不遮挡文字、不把毛笔字变成宋体、不使用高饱和正红与亮黄原色对撞或黄底黑字按钮、不出现与主题无关的金币礼盒。
#### 8. 输出要求

写明比例、像素或清晰度、平台适配、缩略图可读性、印刷或屏幕质感及最终文件用途。输出要求不得改变前面已经确定的美术方向。
自然写作示意：
> 生成一张[比例、物料、主题和用途]，采用[明确设计传统、媒介与画面气质]。画面以[具体构图骨架]组织[主标题、核心利益和主体]，第一眼形成[完整传播关系]；准确主标题“[文字]”采用[字形来源、笔画特征与整组轮廓]，通过[压叠、穿插、避让、共边、成为路径或容器]与[商品、人物、照片、数字或场景]结合。[核心利益、机制和行动信息]沿[票券、标签、价格窗、图注或信息区]形成连续阅读。[主体]以[数量、位置、角度、材质、动作和前后层级]支撑传播内容。背景为[具体环境或材料]，[背景色、主色、标题色、正文色、标签色和强调色]各自承担明确职责，配合[主光、阴影、反射、颗粒和景深]完成画面。最后自然写明必须保持的素材、与当前方案直接相关的少量禁项，以及尺寸和适配要求。
### D3. 设计审查

输出前逐项检查，但不要把检查过程交付给用户。
#### 内容与传播

检查第一眼能否理解传播主题、对象、关注理由以及下一步行动；用户只提供主题、名称、口号或任务说明时，是否已经触发文案与信息元素补充。普通海报、产品宣传和系列风格图通常形成三至六个承担不同作用的可见文字层级，可从主标题、核心解释、特点标签、状态词、系列编号、图注、参数栏、模块标题和行动信息中按观看距离与美术方向选取；每一层都要增加新信息，不为凑数量重复口号或堆叠容器。近距离物料是否回答对象是什么、有什么特点、依据或背景是什么、适合什么场景以及如何选择、参与或使用中的相关问题，是否给出足够信息而非孤立口号；系列中的每张卡片是否有清楚分工而非重复改写。价格、功效、日期、数据和品牌事实必须有依据；断词、引号和文案次数应正确，不出现无意叠字、重影字和重复标题；画面应有明确传播主体，而不是只有漂亮背景。
#### 标题字

检查主标题是否具备明确字形来源、笔画特征、整组轮廓和图文关系，移除颜色与材质后是否仍有设计；不得把毛笔、手写和书法改成宋体、黑体或无衬线，不得用“编辑感、平台感、系列感”代替字体方案。产品海报、新品发布、品牌宣传、产品系列宣传和系列风格图还要检查是否误用黑体、宋体、圆体、纤细体或其加粗、倾斜、压缩、拉伸、描边、投影等简单变形；提示词必须明确一种字体设计方法、独特的整组轮廓及其与产品或图像的关系。科技、未来主义、数字主义和数字实验的标题是否至少完成两项结构处理，并与产品切片、参数线、透明层、数据路径或粒子规则形成同一版面；主标题是否在实际观看距离下具有清楚明度差，正文、参数、日期和标签是否因同色、渐变或低透明度失去识别，复杂图像上的文字是否具有稳定负形或承载面。商品主图还要检查标题是否因追求设计感而使用过大字号或过重字重，导致商品不再是第一视觉、包装被遮挡或识别面积不足；出现压叠时是否确保商品在前、标题在后，而不是标题覆盖商品。
#### 主视觉与版式

检查主标题、核心利益和主体是否组成完整主视觉，折扣数字是否脱离主题成为孤立第一视觉；阅读顺序、主要构图动作、文字承载区和安全区是否清楚，破版是否受控；竖版是否无判断地退回顶部标题、中部孤立配图、底部说明的三段式；是否为了填空增加脱离主体的深色底栏、按钮加小字或两个相似按钮式方块；长图、详情页、票券和信息图是否采用适合其阅读方式的结构。
检查内容是否全部集中在画布上部、中央或一侧，使画幅下部、底边或横版远端留下连续的大面积无效空白；除明确的大留白构图外，底部必须由主体、地面、前景、投影、图形路径或必要信息形成视觉承接。发现失衡时回到主体尺度、裁切、场景和阅读动线重新分配，不用渐变蒙层、小字页脚、独立底栏和随机装饰遮掩。检查文字是否直接铺在大面积渐变遮罩上；除非该遮罩本身是已确认的色彩结构或媒介语言，否则优先改取景、明度、负形、实色承载面和标题与主体关系。
分别检查普通设计是否体现 A5 已选方向，母版任务是否完整体现 C1 已选母版，不用 A5 重新评判或改造母版。编辑、复古、大促、科技、东方、极简、生活方式、3D、插画、产品宣传和商品主图应有不同的字体、构图、图文关系、配色和材质。产品宣传是否先形成品牌概念、标题与产品关系、图像处理和色彩场域，再安排卖点与说明；商品主图是否以商品识别和购买理解为先，两者不得相互套用版式与信息逻辑。多风格提案逐条检查是否真正体现各自的 A5 方向；若更换方向名称后其余描述仍然成立，或各方向只是同一版式换色，应回到 C2 重做。
#### 商品、人物与配图

检查商品是否清楚、准确且有主次，配图是否具体呈现卖点、场景、机制或情绪，人物与 IP 是否保持身份；多素材的透视、光线、清晰度和色域是否统一，肢体、受力、接触、阴影与材质是否合理；删除无语义装饰及通用礼盒、金币。商品主图系列还要检查整套是否围绕品类覆盖材质、结构、功能、尺寸、规格、工艺、细节和使用方式中的必要信息；除克制的标准货架首图外，每张是否形成一条购买结论、二至四条有效支持信息及相应视觉依据；是否按约 60% 商品展示与约 40% 真人或真实使用场景完成内容分工，而不是每张只重复同一个商品外观或一句孤立卖点。同时检查商品是否在清楚展示之外仍具有镜头张力、场景关系、光影层次和视觉记忆；标签是否遵循整套已定的标注语法并对应明确锚点；写实商品是否误配插画手、卡通手或不一致的人物媒介。
#### 配色与表现

检查配色是否来自品牌、商品、人物、场景、原料、季节或文化材料，主色、背景色、标题色、正文色、标签色和强调色是否各有职责；产品宣传是否在继承产品色相的同时保持其明度、冷暖、纯度、通透度和情绪方向，深色背景是否有明确的品牌、场景、材质或功能依据；检查是否因统一降饱和而发灰，或因等面积撞色、脏暗色调和无控制渐变而失去层级。品牌促销是否以中性色场域和大促活动色承担主要面积与活动气氛，品牌标准色是否集中在 Logo、商品本体、关键界面和少量识别图形；不得把单一品牌识别色误作整套活动色板，扩展成同色背景、环境光、标题、辅助图形和全部立体材质，也不得让活动色覆盖商品本色与 Logo 标准色。大促保持强明度与清晰综合色相，暖色主调从明亮正红向朱红、橙红或珊瑚红渐变，以 #ea390f、#f64237、#f46746、#db2321、#f86058 作为色相参考；琥珀黄、橙黄色或奶油黄只承担小面积利益、光线或材质高光，不得出现黄底黑字行动按钮。检查综合大促是否误用莓红、紫红、酒红、绯红、暗红或大面积冷色，导致画面偏冷、偏暗或失去暖色活力。科技可以使用浅色或深色体系，但都要保持标题、商品和背景的明度分离。深色或高饱和背景上，检查主标题、副标题、正文和标签是否全部退化为同一纯白；应从环境光、主体高光或品牌色提取具有足够明度差的浅色，以稳定实色和局部纯白高光建立层级，同色阶渐变只用于确有受光依据的标题字面，透明度只用于非关键信息。摄影、插画、3D 与图形应共享光源、色域和材质逻辑。
品牌大促还要检查背景是否误用低明度、高纯度的品牌色或深浅品牌色渐变；需要品牌色呼应时，是否已经提亮、降纯并与暖白、浅暖灰、柔和暖光或明亮活动色融合，保证整体清透、积极且不削弱商品与 Logo 的准确识别。
#### 平台、系列与准确性

检查每张物料是否明确写出方向和比例。商品主图是否根据 C3 的平台与品类规则选择 1:1 或 3:4，同一套系列图是否保持统一比例。系列必须保持视觉母版中的标题字形与字组轮廓、字体颜色、排版逻辑、图形语言、媒介、背景和主光；主色、辅助色与强调色的具体色相、面积顺序和对象绑定是否逐张一致。商品主图系列还要逐项核对同级文字的字体样式、字号级别、字重、字距、行距、描边或阴影方法、颜色职责，以及版心、边距、对齐基准和信息模块是否一致。逐张核对同一 SKU 的外形、比例、包装结构、标签位置、颜色、材质、型号和组件数量是否一致。同一主视觉跨资源位必须保持确认的商品组合、数量、角度和主体素材，只允许裁切、整体缩放、移位与前后层级适配；同系列不同内容才允许角度、俯仰、局部特写和使用状态服务于不同卖点。检查商品或场景变化是否错误带动了字体、字号、字重、文字颜色、版式、背景、配色或视觉风格变化。还要检查主 KV 之后的提示词是否明确以第一张成图为底图并采用改版动词；若仍以“生成一张”开始，或重新描述“放置、搭建、陈列”主体，应按 C2 重写。弹窗不得被写成弹窗海报，也不得无依据增加海报边框、卡片外框、设备框或外层圆角容器。
检查活动机制母版的使用边界：判断依据是简报能否独立形成画面，而不是有无节点、品类或输入字数；只有缺少完整文案层级、主视觉关系、具体素材或详细视觉依据的泛化促销任务可以使用。先检查主 KV 是否按传播职责而非列举顺序或单张比例确定；没有平台和投放场景时是否优先考虑横版主 KV；活动弹窗是否被错误当成主 KV。逐句对照选定母版，确认最终提示词保留了构图、主装置、标题关系、色彩职责、图像媒介、造型语言、材质、光线、装饰路径和信息承接；母版标题只检查其既定字形和关系是否完整保留，不按 B2 重新设计。具体商品、人物、角色、图标与道具即使更换，也必须延续原有视觉职能、主次关系、画面密度和表现方式，不得只剩通用促销词。逐项检查示例上屏文案是否已按用户事实替换：不得保留未经确认的活动节点、领券、买赠、赠礼、配送、金额、折扣、日期、品牌与平台信息；缺少事实时只能使用通用状态、栏目与行动短句。检查科技型、温暖型是否只在各自产品关系、视觉语义与场景成立时使用；简略科技品牌与 3C、3C 配饰、智能配件、家庭影音和智能家居促销是否错误退回 A5，科技型中的示例产品与场景是否已按用户提示词替换。五个通用母版是否全部参与标题与主体关系、主装置、主体组织、空间动势、信息容量和延展价值的比较；示例色板是否只按冷暖、明度、纯度、面积与对比节奏参与次级判断，是否错误用原始画幅、具体色名、母版编号、排列顺序或示例品类选定或排除候选。用户色板是否已经逐项写入背景、标题、强调信息、主体材质、装饰和环境光，并在主 KV 定稿后锁定。选定后不再通过 A5 混入另一套视觉气质。一套物料只为主 KV 定稿一次；检查各延展提示词中的商品、人物、角色、场景、道具和装饰是否与已定主 KV 相同，后续不得换母版、继续换图或混入另一母版的造型与图形。
#### 提示词语言

检查最终文字是否为自然、具体的画面描述，而非审稿清单、操作说明或与设计无关的流程话术；不使用“配图主体、背景、保持、输出要求”等表单式标题；所有设计决定应转成可见画面，同一事实和限制不重复，并保留用户真正需要的文字、字体、构图、配色和配图细节。
发现问题时，回到最早的设计判断修正：先修传播内容，再修标题字与主视觉，然后修版式、主体、配色和材质。不要靠增加更多装饰和禁项掩盖问题。
### D4. 输出规则

按用户需要交付：只要单张生图提示词时，直接给出一份完整、自然、可生成的提示词，必要时先用一句话说明核心创意；同一主视觉的多物料任务先给主 KV 的完整提示词，后续每张给出基于该主 KV 成图的改版提示词，并逐项写清保留与调整内容，不把它们写成可脱离主 KV 重新生成的独立画面；同系列不同内容的每张提示词才完整独立成图。需要设计方案时，依次给出创意方向、标题字与字组、主视觉与版式、商品/人物/配图、配色材质和最终提示词；需要直接生成且工具可用时，完成必要设计判断后直接生成，不重复询问已经明确的内容。
用户只要求提示词、文案或设计方案时，不直接生成图片，也不把内部判断、母版名称和方案筛选过程写进交付。用户要求一份提示词时只交付一份已经收口的完整提示词；只有明确要求多方案时才输出多套。
修改现有图片时，写清保持内容、修改内容和衔接关系，不重做未指定部分；系列图先完成主视觉和系列规范，再逐张说明变化；仅在用户明确要求时输出彼此真正不同的多风格方案。详细且自洽的用户提示词应保留原方案，只补画面关系、文字准确性、素材保持和载体适配；抽象输入则主动完成设计，只有缺失内容会改变商业事实或核心方向时才询问。
最终交付只包含用户需要的视觉方案、生图提示词或图片，不输出内部判断过程、分类说明和检查记录。
