# 临床危急值目录（国内口径）

> **数据源**：《国家卫健委临床危急值管理相关规范》+ 中国医院协会《临床危急值报告制度》+ 各专科指南
> **用法**：本表为**硬中断闸门**。命中任一项，输出的第一句话必须是就医指令，所有科普内容后置。
> **注意**：各医院危急值阈值存在 ±10% 浮动，本表取国内通行值。以报告出具医院标注的危急值为最终准据。

---

## 一、判读规则

1. **命中即中断**：不做铺垫、不先说"整体还好"、不逐项解读，第一句直给。
2. **分两级**：
   - **A 级（立即急诊）**：数小时内可致命，指令为"建议立即前往急诊"
   - **B 级（当日就医）**：需当日处理，指令为"建议今日内就医"
3. **趋势不参与**：单次命中即触发，不因"上次也这样"而降级。
4. **组合升级**：多项 B 级同时命中，按 A 级处理。

## 二、血液电解质与代谢（A 级）

| 项目 | 危急下限 | 危急上限 | 临床意义 |
|---|---|---|---|
| 血钾 K⁺ | < 2.8 mmol/L | > 6.2 mmol/L | 致死性心律失常风险 |
| 血钠 Na⁺ | < 120 mmol/L | > 160 mmol/L | 脑水肿 / 脱髓鞘风险 |
| 血钙（总） | < 1.5 mmol/L | > 3.5 mmol/L | 抽搐 / 心律失常 |
| 血钙（离子） | < 0.8 mmol/L | > 1.6 mmol/L | 同上 |
| 血糖 | < 2.8 mmol/L | > 22.2 mmol/L | 低血糖脑损伤 / 酮症酸中毒、高渗昏迷 |
| 血镁 | < 0.5 mmol/L | > 2.0 mmol/L | 心律失常 / 呼吸抑制 |
| 血磷 | < 0.3 mmol/L | — | 呼吸肌无力 |

> **强制陷阱排查**：高钾必须先排除**标本溶血**（同时看 LDH、游离血红蛋白）。溶血导致的假性高钾极常见，误判会引发不必要恐慌。见 pitfalls.md。

## 三、血液学（A 级）

| 项目 | 危急下限 | 危急上限 | 临床意义 |
|---|---|---|---|
| 血红蛋白 Hb | < 60 g/L | > 200 g/L | 重度贫血致组织缺氧 / 真性红细胞增多 |
| 血小板 PLT | < 20 ×10⁹/L | > 1000 ×10⁹/L | 自发性出血 / 血栓风险 |
| 白细胞 WBC | < 1.0 ×10⁹/L | > 50 ×10⁹/L | 重度粒缺感染风险 / 白血病可能 |
| 中性粒细胞绝对值 ANC | < 0.5 ×10⁹/L | — | 粒缺，感染即危重 |
| APTT | — | > 100 s | 出血风险 |
| PT | — | > 30 s | 出血风险 |
| INR | — | > 5.0 | 严重出血风险（尤其服华法林者） |
| 纤维蛋白原 | < 1.0 g/L | — | DIC 可能 |
| 血涂片 | 见到原始/幼稚细胞 | | 急性白血病需即刻血液科 |

## 四、心脏标志物（A 级）

| 项目 | 危急标准 | 临床意义 |
|---|---|---|
| 肌钙蛋白 cTnI / cTnT | 超参考上限即预警，动态升高为急性心梗证据 | **胸痛 + cTn 升高 = 立即急诊** |
| CK-MB | 显著升高 | 心肌损伤 |
| BNP | > 400 pg/mL | 心衰可能 |
| NT-proBNP | > 900 pg/mL（年龄分层：<50岁 >450，50-75岁 >900，>75岁 >1800） | 心衰可能 |
| D-二聚体 | 显著升高 | 需结合临床排除肺栓塞/主动脉夹层，**不可单独诊断** |

> **组合红旗**：胸痛 + cTn↑ + D-二聚体↑ → 立即急诊，不做任何延迟解读。

## 五、肝肾功能（B 级，达到下述加重标准转 A 级）

| 项目 | 危急标准 | 转 A 级条件 |
|---|---|---|
| ALT / AST | > 1000 U/L | 伴 INR 延长、意识改变 → 急性肝衰竭 |
| 总胆红素 | > 342 μmol/L（20 mg/dL） | 伴意识改变 |
| 血氨 | > 100 μmol/L | 伴意识改变 → 肝性脑病 |
| 肌酐 | > 530 μmol/L 或短期内翻倍 | 伴高钾、无尿 |
| 尿素氮 BUN | > 30 mmol/L | 同上 |
| eGFR | < 15 mL/min/1.73m² | 需肾内科即刻评估 |

## 九、眼科急症（A 级）

| 情形 | 识别要点 | 为什么是急症 |
|---|---|---|
| **视网膜脱离** | 眼 B 超见**较强带状回声、后运动受限、固定连于视盘**（V 形 / 漏斗形）；或主诉视野幕帘状遮挡、固定黑影 | 累及中心视力（黄斑）前修复，视力预后明显更好，**时间窗决定结局** |
| **急性闭角型青光眼** | 眼压显著升高（常 >40 mmHg）伴眼痛、头痛、恶心呕吐、虹视、视力骤降 | 高眼压持续可在数小时~数天内造成难以恢复的视神经损害 |
| **眼球穿通伤 / 眼内异物** | 影像见眼球壁连续性中断、球内高回声异物、前房变浅 | 感染性眼内炎与失明风险 |
| **眼化学伤（尤其碱烧伤）** | 病史明确 | 需即刻持续冲洗，延误直接影响预后 |
| **视网膜中央动脉阻塞** | 无痛性视力骤降至光感 / 手动 | 视网膜缺血耐受时间以小时计 |

> **最易误判的一条**：眼 B 超带状回声**弱而飘 = 玻璃体后脱离**（非急症，补散瞳眼底 + OCT 即可）；
> **强而僵、固定连于视盘 = 视网膜脱离**（A 级急症）。两者超声表现相似但处置档位相差三档，
> 详见 `imaging_grading.md` 眼科超声节。

> **症状红旗（任一出现即当日眼科就诊，不必等报告）**：闪光感 ｜ 飞蚊症骤然增多 ｜
> 视野固定黑影或幕帘状遮挡 ｜ 视力突然下降 ｜ 眼痛伴视力下降。

## 十、妇产科（A 级）

| 项目 | 危急标准 |
|---|---|
| HCG 异常 + 腹痛 | 排除宫外孕，立即就诊 |
| 血压 ≥160/110 + 蛋白尿（孕期） | 重度先兆子痫，立即产科 |
| 孕期 PLT < 100 + 肝酶升高 | HELLP 综合征可能 |

## 十一、输出模板（命中时使用）

```
⚠️ 建议立即前往急诊。

本次报告中「<项目名> <数值> <单位>」已达临床危急值范围（危急标准：<阈值>），
提示 <临床意义>，需要即刻医疗处置，不建议等待或自行观察。

就诊指引：急诊科（如已知专科归属，可直接挂 <科室>）
携带材料：本次完整报告原件、既往报告、正在服用的药物清单

--- 以下为补充说明，就医优先 ---
<后续常规解读内容>
```

---

## 边界

- 本表用于**触发就医建议**，不用于诊断疾病。
- 危急值命中不等于确诊，等于"需要即刻由医生处置"。
- 未命中危急值 ≠ 安全，仍需走完整交叉推理与个体目标值比对流程。
