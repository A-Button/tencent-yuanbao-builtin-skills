# 关注主题选择

用户提到自我认知时，能力优势落 `talent`，价值、意义和内在冲突落 `spiritual`；两者都合理时可同时使用，不另开一轮澄清。“整体看看”用于普通分析时主题保持为空；用户明确要求“整体 / 全面”的深度报告时映射为全部九项，不再询问。

主题只决定内容范围，不改变用户明确选择的产物深度。是否启动报告与补问由排盘响应／报告启动入口负责，不在这里重新路由。大运不是第十个关注主题，不进入 `request.topics` 或 `primary_topics`，也不参与主题数量计算。

## 主题要求

| ID | 主题 | 关注内容 |
|---|---|---|
| `career` | 事业发展 | 工作方式、能力优势、适配环境、发展阻力和当前策略 |
| `emotion` | 情感婚恋 | 用户自身的需求、表达、吸引、冲突、边界和沟通 |
| `family` | 家庭亲情 | 家庭角色、责任、依赖与边界、代际互动 |
| `economy` | 经济状况 | 收入创造、消费储蓄、资源管理和风险偏好 |
| `social` | 社会关系 | 社交能量、沟通、合作、冲突和信任建立 |
| `talent` | 天赋挖掘 | 2—3 项潜在优势、适用场景、代价和现实验证 |
| `spiritual` | 精神成长 | 价值观、意义感、内在冲突、自我认同和练习 |
| `study` | 学业考试 | 学习偏好、注意与压力模式、复习和应试策略 |
| `health` | 身体健康 | 压力、作息、精力和生活照顾；症状转专业医疗 |

高影响问题、第三方隐私和确定性预测统一遵循 [safety.md](safety.md)，不在每个主题重复一套禁止规则。
