# 选购推荐模板

用于用户有明确品类、但没有候选，或要求直接推荐时。先讲选购锚点，再给匹配用户约束的型号。

## 开场方向（内部骨架）

不要原样输出本标题。用一两句自然语言给用户选择方向：约束清晰且证据充分时可明确点名首选；有合理取舍时用“更适合/更倾向于/如果…则优先…”表达。不要以品类科普或品牌列表开头，也不要为了结论先行而强行拍板。

## 推荐方案

约束明确时深度展开 3–4 款；约束宽泛时先按 3–5 个使用类型分组，每组点 1–2 款即可。每款包含：

- **[品牌 + 产品 + 型号](商品详情页 URL)**：仅 URL 可确认时使用链接，否则写纯文本商品名。
- **适合谁**：贴合这次场景、预算或人群。
- **优点**：最多 3 条，翻译成实际体验。
- **不足**：1–2 条，说明用户会感受到的代价。
- **为什么排在这里**：和相邻推荐的关键差异。

## 最终建议（按需）

不要原样输出本标题。仅在前文仍需收敛时，用“{某类用户} → {更适合的型号}”补充最终建议。若仍缺少一个决定性约束，追问一个问题来收敛；不要为了给答案而硬选。

## 风险提醒（按需）

仅在存在未被前文覆盖的独立风险时保留；不要求固定数量。风险须与本次推荐直接相关、有检索依据且能帮助用户避免误购。优先 1–2 条，能合并的不拆分。
