## 使用规则

1. **首次出现**: 在文档中首次出现专有名词时，应提供中英对照，如 "元宝(yuanbao)"
2. **后续引用**: 后续可直接使用中文名称
3. **代码引用**: 在代码块或技术描述中保持原始英文名称
4. **一致性**: 同一文档中术语使用应保持一致
