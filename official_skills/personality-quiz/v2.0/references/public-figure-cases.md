# 公众人物与名人八字测试

## 默认：命盘盲读

用户没有明确说明对象是公众人物时，不根据姓名或独特出生资料识别人。普通排盘与明确请求的结论／分析，只读取返回 before_delivery 中的去身份化分析盘；明确只要盘面时不生成解释。明确进入深度报告时，由 `report_pipeline.py prepare` 在独立报告目录生成不含姓名、日期、地点和输入摘要的 `analysis-chart.json`。旧盘或导入盘才按需单独运行 `prepare_analysis_chart.py`。候选池与报告只读取报告目录中的去身份化文件。

宿主若支持独立的报告生成调用或隔离上下文，只向该调用提供 `analysis-chart.json`、用户关注主题和报告规范，这是强隔离方案。宿主若只能在同一对话中继续生成，模型仍可能记得早先输入；此时去身份化文件只是降低风险，不能保证彻底遗忘，候选仍必须通过具体信号路径和内容禁区检查，剔除行业、作品和传记式结论。

即使模型似乎认出了出生资料，也不得加入行业、公司、作品、奖项、关系史、疾病或具体事件；这项限制必须直接落实在候选文本和内容校验中。

## 用户明确说明是公众人物

把任务拆成两个互不回写的阶段：

1. **盘面先验**：仍按盲读流程生成并冻结报告，不使用传记资料修正措辞。
2. **公开资料对照**：仅在用户需要时，另行检索可靠公开来源，分别列出“较具体的吻合”“宽泛吻合”“不吻合”“资料不足”。给出来源，并明确这是事后对照，不能反过来证明命理有效。

不要把两个阶段混成一篇占卜报告，也不要为了让名人“更像”而改写已经冻结的盘面先验。

## 一期交互

一期不要求用户从四份报告中辨认。报告完成后可以非阻塞地问一句：“哪一条最像、哪一条最不像？”只有用户愿意反馈时才继续校准，并清楚标记哪些内容是在反馈后调整的。

测试优化时优先使用非公众人物、匿名且能提供自我反馈的普通样本；名人样本只评价文风、污染控制和事实隔离。
