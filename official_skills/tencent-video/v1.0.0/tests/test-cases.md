## 一、环境与前置检查（Workflow Step 1-3）

### TC-ENV-01: bun 可用性检测

- **输入**: 用户发送任意视频查询
- **预期行为**: 智能体先执行 `bun --version`，确认 bun 可用后再继续
- **通过条件**: 若 bun 不可用，智能体提示安装并给出对应平台安装命令

### TC-ENV-02: CLI 状态检查 — CLI 已安装且已登录

- **前置**: `bun scripts/cli-state.ts`
- **预期输出**:
  ```json
  {
    "cliExists": true,
    "needsUpdateCheck": false,
    "auth": { "authenticated": true }
  }
  ```
- **通过条件**: 智能体正确解析 JSON 字段，跳过安装步骤，直接进入搜索

### TC-ENV-03: CLI 状态检查 — CLI 未安装

- **前置**: `cliExists` 为 `false`（模拟或实际删除 CLI 二进制）
- **预期行为**: 智能体执行 `bun scripts/install-cli.ts` 安装 CLI
- **通过条件**: 安装成功后 `cliExists` 为 `true`

### TC-ENV-04: CLI 状态检查 — 需要更新

- **前置**: `needsUpdateCheck` 为 `true`
- **预期行为**: 智能体执行 `bun scripts/install-cli.ts` 检查并自动更新
- **通过条件**: 更新后输出版本信息，`needsUpdateCheck` 重置

## 二、搜索功能（Workflow Step 5-6，内容查询规则）

### TC-SEARCH-02: 自然语言搜索

- **输入**: "那个涉及到爆炸和循环的电视剧是什么"
- **预期行为**: 搜索词原样传递，不做任何改写
- **通过条件**: CLI 命令为 `ai-search "那个涉及到爆炸和循环的电视剧是什么"`

### TC-SEARCH-03: 类比推荐搜索

- **输入**: "类似绿皮书的电影"
- **预期行为**: 搜索词原样传递
- **通过条件**: 返回结果包含 AI 文本推荐和结构化卡片，格式正确

### TC-SEARCH-04: 热播/榜单类请求

- **输入**: "最近热播"
- **预期行为**: 使用 search 子命令，搜索词原样传递
- **通过条件**: 不使用网络搜索或其他 API

### TC-SEARCH-05: 搜索只执行一次（核心约束）

- **输入**: "有什么好看的电视剧"

- **通过条件**:

  3. 第一次搜索返回后立即格式化输出

### TC-SEARCH-06: 禁止修改搜索词

- **输入**: "庆余年3播到第几集了"
- **预期行为**: CLI 命令为 `ai-search "庆余年3播到第几集了"`，原样传递
- **通过条件**: 不扩写、拆分或"优化"关键词

### TC-SEARCH-07: 搜索无结果

- **输入**: "不存在的视频xyzabc123"
- **预期行为**: CLI 返回 0 条结果或报错时，直接告知用户未找到
- **通过条件**:
  1. 不回退到网络搜索
  2. 不自行编造内容
  3. 不引用记忆中的信息

### TC-SEARCH-08: 搜索词含特殊字符

- **输入**: "三体（动画版）"
- **预期行为**: 搜索词原样传递，特殊字符不丢失
- **通过条件**: CLI 命令正确包含特殊字符

## 三、输出格式（Output Format）

### TC-FMT-01: 结构化卡片 — 完整字段

- **CLI 输入**: `ai-search "绿皮书"`
- **预期输出格式**（参考 SKILL.md 完整示例）:
  ```
  🎬 **标题**

  📺 类型：品类

  📝 标签1 · 标签2

  ⭐ 评分：N.N

  🎭 主演：演员1 / 演员2

  📅 年份 · 地区

  > 简介文字

  🔗 [立即观看](URL)

  ---
  ```
- **通过条件**: 每个字段独占一行，字段之间有空行

### TC-FMT-02: 空行规则（最常见错误）

- **验证**: 每个字段之间必须有一个空行（两个 `\n`）
- **反例**（不通过）:
  ```
  🎬 **标题**
  📺 类型：电影
  📝 标签
  ```
- **正例**（通过）:
  ```
  🎬 **标题**

  📺 类型：电影

  📝 标签
  ```

### TC-FMT-03: 字段缺失处理

- **场景**: CLI 返回某条目缺少 `Score`、`Actors` 等字段
- **预期**: 缺失字段整行省略，不输出空值或占位符
- **通过条件**: 不出现 "评分：undefined" 或空行

### TC-FMT-04: AI 文本推荐拆分到引用块

- **场景**: CLI 返回含 AI 文本推荐（如"法国经典电影，讲述..."）
- **预期**:
  1. AI 推荐理由不在开头独立展示
  2. 通用总结语（如"根据您的需求..."）直接丢弃
  3. 各条目推荐理由以 `> ` 引用块格式放入对应卡片内
- **通过条件**: 卡片内引用块正确匹配对应条目

### TC-FMT-05: 条目数量一致性

- **场景**: CLI 返回 `Found 3 items`
- **预期**: 输出恰好 3 条卡片
- **通过条件**: 不多不少，与 CLI 返回数量一致

### TC-FMT-06: 条目顺序不变

- **场景**: CLI 返回 [1] [2] [3] 顺序
- **预期**: 输出保持 [1] [2] [3] 顺序
- **通过条件**: 不重新排序或分组

### TC-FMT-07: 来源标注

- **验证**: 所有条目之后最后一行为 `**来源：腾讯视频**`
- **通过条件**: 该行之后不得有总结、评价、补充说明等任何文字

### TC-FMT-08: Poster 字段不展示

- **验证**: 输出中不出现 `Poster` 相关信息
- **通过条件**: 海报图片地址不展示给用户

### TC-FMT-09: 标题加粗 + emoji

- **验证**: 标题格式为 `🎬 **标题**`
- **通过条件**: 有 🎬 emoji 且标题用 `**` 加粗

### TC-FMT-10: 条目间分隔线

- **验证**: 每条结果之间用 `---` 分隔
- **通过条件**: N 条结果间有 N-1 条分隔线

## 七、CLI 执行失败处理

### TC-ERR-01: 未登录错误

- **场景**: CLI 返回 `not logged in` 或 `session expired`
- **预期**: 引导用户执行 `<cliPath> login` 扫码登录
- **通过条件**: 不重试，不绕过

### TC-ERR-02: macOS Gatekeeper 拦截

- **场景**: CLI 返回 `cannot be opened` 或 `not verified`
- **预期**: 引导用户到 系统设置 → 隐私与安全性 → 「仍要打开」→ 确认
- **通过条件**: 不重试，给出明确操作步骤

### TC-ERR-03: 权限不足

- **场景**: CLI 返回 `permission denied`
- **预期**: 提示 `chmod +x <cliPath>`
- **通过条件**: 给出具体命令

### TC-ERR-04: 其他未知错误

- **场景**: CLI 返回非零退出码且不匹配已知错误模式
- **预期**: 展示完整错误信息，请用户处理
- **通过条件**: 不回退到其他信息源

### TC-ERR-05: 失败后不重试

- **场景**: CLI 执行失败后
- **预期**: 立即停止，不重试或绕过
- **通过条件**: 不自动重新执行命令

## 九、边界与异常场景

### TC-EDGE-01: 空搜索结果

- **预期**: 捕获错误并按失败处理流程处理
- **通过条件**: 不崩溃，给出可读错误信息

### TC-EDGE-05: 32 位架构不支持

- **场景**: 在 32 位系统上运行
- **预期**: 脚本报错
- **通过条件**: 智能体告知用户不支持 32 位架构

  1. 先 `search` 获取 CID

  - `📺 已更新` + `集` + `还剩` + `集未播出`

  - `📋 最近集数信息：`

## 十一、追剧提醒（Agent 侧能力）

### TC-REMIND-01: 设置更新提醒

- **输入**: "白日提灯更新了提醒我"
- **前置**: 已登录，正在热播的作品
- **预期行为**:
  1. 先查排播获取下一集时间
  2. 基于排播时间设置定时任务
  3. 告知用户提醒已设置
- **通过条件**:
  - 定时任务的时间 ≤ 下一集播出时间
  - 提醒内容包含作品名和集数

### TC-REMIND-02: 提前 N 分钟提醒

- **输入**: "下一集开播前10分钟通知我"
- **前置**: 已登录，正在热播的作品
- **预期行为**:
  1. 查排播获取下一集时间（如 4月20日 18:00）
  2. 定时任务设置在播出时间前 10 分钟（4月20日 17:50）
- **通过条件**: 提醒时间 = 播出时间 - 用户要求的提前量

### TC-REMIND-03: 已完结作品提醒

- **输入**: "庆余年更新了提醒我"
- **前置**: 已登录，已完结的作品
- **预期行为**: 告知用户该剧已完结，无需设置提醒
- **通过条件**: 不设置定时任务

### TC-REMIND-04: 播出时间未定的提醒

- **输入**: "庆余年第三季开播了通知我"
- **前置**: 已登录，播出时间未定（play_status=1，无播出日期）
- **预期行为**: 告知用户播出时间未定，暂无法设置提醒，建议后续再问
- **通过条件**: 不设置定时任务，给出合理解释

### TC-REMIND-05: 提醒内容格式

- **输入**: "白日提灯更新提醒我"
- **预期定时任务触发时的提醒内容**:
  - 包含作品名：`白日提灯`
  - 包含集数：`第 N 集`
  - 包含时间：`即将在 {时间} 开播`
