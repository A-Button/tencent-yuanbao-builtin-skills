# 个人日签

日签给用户一份轻量的启发与陪伴，持续服务可每天出现。喜欢象征、偶然性或一点想象的人可以从中得到惊喜；没有此类偏好时，从当天节奏与真实生活线索出发。它围绕用户、用户在意的人或一段关系，让一张签提供安慰或期待。已确认的偏好决定口味，仍在进行的事项提供近期阶段，今天的真实变化决定当张焦点；历史查询只提示可能的兴趣，不等于用户的身份、行程或现状。具体事情是创作依据，签文表达它给人的感受与启发。用户明确问到的内容直接回应，最新表达优先于旧画像，缺少 user insight 也能沿当前对话继续。

先确定用户要单次内容还是持续接收：单次咨询先回答；明确要日签时按图文日签承接，用户选纯文字则沿其选择；“每天出／每天给我＋日签”已是持续委托，内容主题或用户稍后提供的每日数据不改变这个判断。此时先读 [服务安排](references/service.md)，再按当前需要读取创作参考；后续补充数据、回答追问也沿同一份委托推进，不退成临时单张。沿用已确认的主题、方法、主体、形式和安排，只问会影响下一步的缺口。专业测算交给相应 Skill，日签承接其真实结果；原创意象以创作口吻表达。单次咨询的 AUQ 与专业接力读 [入口与需求澄清](references/experience.md)；确定要出签后再读 [每张日签的内容创作](references/content-directions.md)。

## 按入口行动

| 用户或回调意图 | 下一步 |
|---|---|
| 询问运势、幸运色、好彩头或类似内容 | 先回答所问；适合时用一句与本题相关的话邀请日签，不把邀请当成订阅 |
| 要每天或未来某时收到日签 | 沿已确认的主题与频率先读 [服务安排](references/service.md)；只补实际缺失的时刻或内容依据，满足条件后建立 Thing、Todo 与 Trigger。当天另有足够内容时可先出首张，但不以首张代替服务 |
| 改已有日签的内容、时间或画风 | 先按 [服务安排](references/service.md) 定位并修改原服务；不能修改旧会话服务时说明原安排仍在，不把另建一个每日服务当作已改好 |
| 持续委托后补充当天数据或回答安排 | 继续原日签委托：核对服务是否真实建立，补齐未完成的安排，并将本轮数据用于当日签；不因这轮只发了时长等数值就改走单次出图 |
| 要一张日签或图片 | 沿已知主题创作一张图文日签，按下方交付；用户明确要纯文字时沿其选择 |
| 定时回调“创建日签” | 按 [服务安排](references/service.md) 回到原 Session、核对服务和当日交付记录，再按 [每张日签的内容创作](references/content-directions.md) 出今天的新签；后台不发 AUQ |
| 查看、解释或修改旧签 | 沿原签与服务记录继续；解释复用旧签，修改本张生成新修订，仅改以后偏好则下次采用 |
| 暂停、关闭、跳过、改时间或重启 | 按 [服务安排](references/service.md) 修改真实服务；停止自动发送时保留历史，除非用户明确要求删除 |

## 创作与交付

1. 根据本轮主题、已确认的口味、相关事项的当前状态、当天真正相关的线索和近期日签，确定这张签的内容。先把依据转成用户能感受到的当张含义，再写完整签文，最后选择适合入图的文字；历史查询和未确认的画像只帮助找候选主题，不写成个人事实。专业标签与推导留在内部依据，用户追问方法或理解结论确实需要时再简短解释。[每张日签的内容创作](references/content-directions.md) 给出分层与筛选方法。
2. 需要图片时，根据签文的密度和重要性编排图上的文字与画面；日期、签名与适合视觉阅读的签文共同构成一张可独立阅读的日签图。默认生成与此刻 340×140 展示窗口同比例的横图，同一张图用于会话与此刻；用户明确选择其他形态时沿其选择。[生图与阅读](references/image.md) 说明构图与例外。直接在原 Session 展示完成的图片，并给出便于阅读的完整签文；不为展示另做短链解析或本地下载。
3. 需要周期服务时，依当前加载的 `make-things` 完成 Thing、Todo、Trigger；回调仍回到绑定的原 Session。图片生成与服务创建是两项独立交付，各凭真实回执确认。
4. 图片日签按已加载 `make-things` 的 `show_widget` 协议和 [此刻卡片](references/now.md) 发布，取得真实回执才说明卡片可用。“查看完整签文”静默打开承载完整回答的原会话；图片地址不满足实际封面协议时，保留此刻待发布状态，不把会话图片成功说成此刻已发布。

单张不意味着订阅；仅发此刻无需创建 Thing。重复查看或重复回调复用当日已交付的主签，修订保留真实版本与发布状态。对外回复以完成图和一份简洁、完整的签文为主体，图文互补，不把同一判断写成多套释义。选题理由和专业推导保留在内部，用户追问时再按真实依据解释；本轮确有新建或更改接收安排时，用一句话说明实际结果。定时出签只交付今天这张，不固定附加宜忌、总结、发布状态或下次时刻。任务标题与说明使用「我的日签」「每日签」等体验名称，不展示内部执行指令。
