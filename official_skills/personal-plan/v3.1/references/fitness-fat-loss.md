## 1. 场景和输入

适用于一般成年人的减脂、增肌、体能、居家训练和健身房计划。只问某个动作怎么做时，不使用本规则。

### 1.1 最小输入

| 字段 | 需要了解什么 |
|---|---|
| 目标 | 减脂、力量、体能或具体表现 |
| 周期 | 开始和截止日期 |
| 身体数据 | 身高、当前体重；用户给了目标体重时一并记录 |
| 当前基础 | 最近运动频率、可完成动作、训练经验 |
| 时间 | 每周次数、单次时长、固定可训练日 |
| 条件 | 场地、器械、预算和可替代条件 |
| 偏好 | 喜欢和排斥的运动 |
| 健康限制 | 疼痛、伤病、孕期、慢性病和医生限制 |
| 饮食现实 | 作息、外食、忌口、过敏和可执行程度 |

信息不足时优先询问：

1. 目标和周期是什么？
2. 身高和当前体重是多少？
3. 每周能练几次、每次多久、有什么器械，目前运动基础如何？
4. 是否有疼痛、伤病、孕期、疾病或医生限制？

目标涉及减脂或减重时，身高和当前体重必须问，不得用假设、人群均值或体型描述代替。

## 2. 安全筛查

遇到以下信息时停止生成常规训练计划，建议及时寻求专业评估：

- 运动中或近期出现胸痛、晕厥、异常心悸或严重呼吸困难；
- 急性损伤、明显肿胀、无法负重或持续加重的疼痛；
- 用户明确表示医生禁止运动；
- 其他看起来需要急诊或医疗判断的情况。

有伤病、孕期、慢性病、服药或医生限制但不属于紧急情况时：

1. 降低建议的确定性和强度。
2. 只给一般性低风险活动框架。
3. 明确哪些动作和强度需要医生或合格教练确认。
4. 不根据体检报告自行诊断或开治疗方案。

## 3. 目标合理性

### 3.1 减脂目标

- 先区分“体重数字”“体脂变化”“围度变化”和“体能提升”。
- 不保证具体减重结果，不把单日体重当成趋势。
- 没有身高和当前体重时，不判断减重幅度是否合理，也不排减重阶段目标，先按“1.1 最小输入”补齐。
- 可用每周约0.45—0.9千克的渐进减重作为一般性校准区间；若该区间会直接影响用户目标，先核对最新官方健康指南。个体差异、疾病、药物和身体条件会影响结果。
- 对明显更激进的目标，指出风险并给出更安全的周期或阶段目标。

### 3.2 运动量基线

一般成年人的群体活动量参考包括以下范围；若直接用于用户计划，先核对最新官方指南：

- 每周150—300分钟中等强度有氧，或75—150分钟高强度有氧；
- 每周至少2天覆盖主要肌群的力量训练；
- 久坐人群从少量开始，逐步增加频率、强度和时长。

这些是群体指南，不是必须一次达到的首周任务。久坐或初学者应从可完成的小剂量开始。

### 3.3 容量判断

默认按用户可训练时间的约80%安排，给临时事务、疲劳和恢复留出余量；这不是机械上限。若用户提供的是保守净时间，或理解代价后明确选择更高强度，可以在安全和可恢复范围内调整。若目标和容量不匹配，按顺序调整：

1. 先增加日常活动和稳定训练频率；
2. 缩小首阶段目标；
3. 延长周期；
4. 再考虑增加单次训练量。

不要用极端节食、脱水、惩罚性训练或连续高强度有氧弥补时间不足。

## 4. 训练结构

一份完整计划从以下模块中选择：

| 模块 | 作用 | 首期写法 |
|---|---|---|
| 力量训练 | 保持/提升肌力和肌肉量 | 覆盖主要动作模式，写清组次和强度 |
| 心肺训练 | 提升心肺和能量消耗 | 写清方式、时长和强度 |
| 日常活动 | 减少久坐、提高日常消耗 | 用步行、通勤、楼梯等现实动作 |
| 活动度/热身 | 为当次训练做准备 | 5—10分钟，围绕当日动作 |
| 恢复 | 管理疲劳、睡眠和休息 | 安排休息日与低强度替代 |

### 4.1 频率选择

| 基础 | 默认起点 |
|---|---|
| 久坐/初学 | 每周2次全身力量 + 2—3次低到中等强度活动 |
| 有规律训练 | 每周3—4次，按目标分配力量和心肺 |
| 经验较多 | 根据既有训练量调整，不无依据增加频率 |

以上是规划起点，不覆盖医生限制或专项竞技训练。

### 4.2 每次训练结构

1. 热身：5—10分钟。
2. 主要动作：优先安排需要精力和技术的动作。
3. 辅助动作：补充目标肌群或薄弱环节。
4. 心肺或收尾：按目标和剩余时间安排。
5. 放松与记录：记录RPE、疼痛和完成情况。

## 5. 动作和强度

### 5.1 任务字段

每个核心动作必须写明：

- 动作名称和器械；
- 组数、次数或时长；
- 目标RPE；
- 组间休息；
- 完成标准。

以下字段按条件补充：

- 器械、动作能力、疼痛或偏好可能导致无法执行时，给替代动作；
- 单个动作有特殊风险时，写该动作的停止条件；
- 通用的胸痛、晕厥、异常心悸、严重呼吸困难、新发疼痛等停止条件可以在计划的安全说明中统一写，不在每个动作下重复。

### 5.2 RPE

RPE是“主观用力程度”，采用1—10分：

| RPE | 感受 |
|---|---|
| 3—4 | 轻松，可以持续较长时间 |
| 5—6 | 中等，仍能稳定完成 |
| 7—8 | 较难，但动作和节奏可控 |
| 9 | 很难，只剩少量余力 |
| 10 | 极限，不用于一般初学计划 |

初学者默认以动作质量和稳定完成为先，不追求极限强度。

### 5.3 合格任务

```text
高脚杯深蹲：3组×8次，RPE 6—7，组间休息90秒。
完成标准：三组动作稳定，无明显疼痛，最后一组仍能保持躯干和膝盖轨迹。
替代（无哑铃时）：椅子深蹲3组×10次。
```

“练腿30分钟”“多做有氧”不属于合格任务。

## 6. 饮食与恢复

饮食只给可执行的一般原则：

- 每餐优先包含蛋白质、蔬菜/水果和适量主食；
- 根据家庭和外食场景提供替换方案；
- 先减少高频液体热量、无意识零食和过大份量；
- 不强制用户购买特定补剂；
- 只有信息充分且用户明确需要时才估算热量，并标明估算误差；
- 不提供极低热量饮食、长时间禁食或疾病治疗性饮食。

恢复安排至少包含：

- 训练日与休息日；
- 睡眠和疲劳提示；
- 疼痛与普通训练酸胀的区分提示，但不进行诊断；
- 时间不足时的20分钟替代训练。

## 7. 进阶和调整

每次只调整一个主要变量：

- 次数；
- 负重；
- 组数；
- 时长；
- 动作难度。

调整规则：

| 信号 | 动作 |
|---|---|
| 连续两次完成全部任务且RPE低于目标 | 下次小幅提高一个变量 |
| 完成率低于60% | 先缩短单次时间或减少频率 |
| 一周持续疲劳、表现下降或睡眠明显变差 | 降低训练量并增加恢复 |
| 出现新疼痛或异常症状 | 停止相关动作，必要时寻求专业评估 |
| 两周体重无变化但围度/表现改善 | 不仅凭体重修改计划 |
| 多周趋势无变化且执行稳定 | 一次只调整活动量或饮食中的一个变量 |

## 8. 领域内容与产物组织

### 8.1 核心内容

所有完整健身计划必须覆盖：

- 目标合理性和安全判断；
- 每周训练结构和首周详细训练；
- 每个核心动作的组次/时长、RPE、休息/恢复和完成标准；
- 心肺、日常活动、恢复和饮食原则；
- 时间不足或状态不佳时的最小训练；
- 训练量、疲劳、疼痛或趋势触发的调整规则；

### 8.2 条件内容

- 器械、能力、疼痛或偏好影响执行时，提供替代动作；
- 个别动作存在特殊风险时，补充专门停止条件；
- 新手需要动作说明时，优先提供可靠图片或视频链接；链接是辅助，不替代动作要点和统一安全边界；
- 只有用户信息充分且明确需要时才估算热量，并标明估算误差；
- 用户需要自行记录时，可以增加体重、围度、动作完成、RPE、疼痛或疲劳等少量领域字段，不暗示系统会自动维护。

### 8.3 XLSX推荐组织

工作表名称和数量不固定。按内容量和独立用途，可以采用：

- `计划概览`：概览。目标判断、阶段路线、训练与饮食重点、约束和安全边界；阶段能在概览中说清时，不另建阶段工作表。
- `训练安排`：执行表。必须是分列的 table：详细日期或训练日、当日动作或训练内容、该行的组次或时长、目标RPE、休息、完成标准；可直接作为详细执行表。列头用动作 / 训练内容、组次或时长，不要改成学习用的科目 / 题量。同一天多个动作多行，日期列可重复或合并。共用规则最多写在表上方几行。整张只有原则、没有按日或按训练日 / 按周的 table，不算做成执行表。首两周按已读颗粒度写出具体训练，其余按周一行，不要用「每周练 3–4 次」代替排期。
- `饮食与恢复`：阅读表。饮食原则、家庭/外食替换、训练与休息日、睡眠和疲劳提示。

根据内容量还可以增加：

- `动作说明`：阅读表。新手或动作较复杂时，写要点、替代和力量日处方；不要把整套动作清单塞进`训练安排`的一个单元格。内容少时，共用规则可以写在执行表上方几行。
- `身体与训练记录`：记录模板。用户希望在文件中自行记录体重、围度、RPE、疼痛、疲劳或训练结果时使用；日期或周次可预置，填写列空着。

详细日期和行动只在一张表维护。`训练安排`已经承载完整排期时，不再增加内容重复的通用执行表。具体格式、样式和通用文件规则由 `output-contracts.md` 统一决定。

## 9. 质量边界

- 不诊断疾病、解释异常指标或替代医生/康复师。
- 不鼓励极端节食、脱水、催吐、药物减重或惩罚性训练。
- 不用BMI或体脂秤单项结果决定整个计划。
- 不对未成年人、孕期、术后或复杂慢病用户直接套用一般成人模板。
- 不承诺长期打卡、设备数据同步或自动更新原计划。
