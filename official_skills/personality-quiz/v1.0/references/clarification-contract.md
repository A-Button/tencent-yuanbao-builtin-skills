# 必要澄清与宿主适配

只在主路由不清楚、星座标签或导入资料确实缺失，或维护宿主提问适配时读取。新排盘使用 `chart_quick.py` 返回的 `question/resume_request`；塔罗问题由 [tarot.md](tarot.md) 直接规定，不为这些流程再读本文件。

## 何时提问

只有同时满足“改变当前结果、没有安全默认或降级、用户能够回答”的缺口才阻塞。已有信息直接复用；多个彼此独立且当前已知的缺口合并为一次提问。只有前一答案决定下一问题时才增加一轮。

- 主路由不清楚：只列当前最可能的两个互斥方向，不展示完整菜单。
- 星座轻解读：只补个性化所需标签，已有标签部分／概念回答不因此等待。
- 导入盘面：只补影响解释的口径与可见事实；不知道时缩小范围，不逐项追问。
- 人格测试、已有结果、知识与趣味内容：正常不提问，不因缺少关注点重开采集。

性别、输出篇幅、页面样式、HTML 或分享卡模板不增加确认。出生时间的唯一可跳过填写机会由脚本管理；报告推荐／主题采集只在盘面展示后发生。大运是报告固定模块，不另问是否需要或让用户选择匿名分支。

## 控件与降级

自由输入使用宿主原生自由输入；真实互斥候选才用单选，报告主题才用可跳过的不限多选。同一阶段最多一次工具调用；多个必要字段合并，不用“单选 + 其他”伪装自由输入。只使用已验证的真实工具 Schema，能力不支持时用一条普通消息，不试错控件再拆成多轮。

出生时间复合控件可提供自由输入与“我不清楚具体的出生时间”，两者互斥；选择不清楚时清空输入。是否需要该控件服从脚本动作，不重新判断或初始化 `time_prompted`。

提问后直接继续，不复述资料或再次确认。报告末尾的校准问题和继续聊聊仅作为可跳过文字，不调用提问工具；这不适用于快速盘面后的报告主题选择。盘后返回 `ask_report_topics` 时按 [chart-flow.md](chart-flow.md) 优先调用真实 `ask-user-question`，一次可跳过多选，再按 [output-levels.md](output-levels.md) 续接报告；不与出生资料合并，不延迟已经可交付的 HTML。

维护旧状态接口或排查歧义 code 时读 [interaction-state.md](interaction-state.md) 和 [chart-contract.md](chart-contract.md)；有限选项只能来自解析器真实候选，不能凭 code 编造。
