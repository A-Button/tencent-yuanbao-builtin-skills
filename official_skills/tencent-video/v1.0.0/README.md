# 腾讯视频 Skill

腾讯视频内容检索与排播查询技能，让用户可以通过自然语言在 AI Agent 中搜索腾讯视频的海量影视内容，并查询排播进度。

## 核心能力

### 视频搜索

- **智能校准与匹配**：自动将用户的模糊描述转换为精确的检索关键词，通过多维度拆解（片名、演员、类型、年份等）进行多路并行检索，再基于检索结果让大模型分析最终输出
- **跨维度搜索**：支持按片名、演员、导演、类型、地区、年份、标签等多个维度进行组合搜索
- **结果精排与确认**：对检索结果进行智能排序和筛选，结合用户原始意图选出最匹配的结果
- **主动交互反问**：当检索结果不明确或存在多个候选时，主动向用户提问以缩小范围，确保返回用户真正想要的内容
- **直达播放**：每条结果附带腾讯视频播放链接，用户可直接跳转观看

### 排播查询

- **播出进度**：查询某部剧已更新集数、总集数、剩余未播集数
- **更新日程**：获取作品每周更新时间规律（如"周二 20:00、周三 20:00"）
- **下一集时间**：查询即将播出的下一集具体时间，区分免费/VIP/SVIP
- **排播日历**：按日期聚合多部作品的更新/开播信息，生成日历视图
- **追剧提醒**：结合排播时间设置定时提醒通知

## 示例

### 精确搜索

- "介绍一下《庆余年》"
- "白日提灯这部剧怎么样"

### 演员搜索

- "迪丽热巴最近有什么新剧？"
- "张凌赫演过哪些古装剧？"

### 模糊描述

- "那部讲时间循环的悬疑剧叫什么"
- "去年很火的那个探案综艺"

### 条件筛选

- "2026年有什么好看的国产悬疑剧"
- "最近有没有新上的韩剧"

### 播放引导

- "我想看长相思第二季，从第15集开始"
- "庆余年在哪里能看"

### 类型浏览

- "推荐几部腾讯视频上的高分纪录片"
- "有没有好看的动漫"

### 排播查询

- "《庆余年3》播到第几集了"
- "长相思每周几更新"
- "下一集什么时候能看"
- "这部剧一共多少集，还剩几集没播"

### 排播日历

- "这周有什么新剧开播"
- "最近有什么剧在更新"

### 追剧提醒

- "更新了提醒我"
- "开播前通知我"

### 智能推荐

可与用户的推荐逻辑结合，实现智能推荐效果
