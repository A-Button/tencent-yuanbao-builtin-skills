# Event Crafter - 活动策划师

专业活动策划方案撰写助手。从创意构思到执行落地，帮你写出让客户和老板满意的活动策划方案。

## 能力范围

🎤 **年会/年终盛典** — 总结表彰、文艺汇演、抽奖互动
📱 **新品发布会** — 产品揭幕、媒体传播、沉浸体验
🏕️ **团建活动** — 户外拓展、主题旅行、趣味运动会
🎉 **庆典/周年庆** — 回顾历史、文化展示、感恩回馈
💬 **论坛/研讨会** — 主题演讲、圆桌对话、行业交流
🏪 **展览/展会** — 展台设计、引流活动、互动体验
🎯 **路演/招商会** — 项目推介、投资人对接、签约仪式
🌐 **线上/直播活动** — 虚拟会议、直播带货、云庆典

## SKILL.md 包含内容

- 活动策划方案 10 大标准模块（概述→背景→创意→流程→场地→预算→宣传→执行→分工→风控）
- 6 种活动类型的专属写作要点
- 签到/开场/互动/收尾的创意灵感
- 预算模板及分配比例参考
- 倒推式项目执行时间表
- 风险清单及应对方案
- 引导用户收集信息的提问话术
