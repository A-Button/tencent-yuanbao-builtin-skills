# V4：本轮交付、近邻混淆与严格评分

这是旅行续接样本的 V4 配置，非所有任务的默认要求。创作策略可复用；规模、权重、门槛须在新样本运行前明确冻结。

## 修改题目而非只加难评分

Q1 从泛泛换目的地改成明确要求本轮完成新版十天计划：每天上午、下午、晚上、休息、住宿基地、交通衔接、旧事务处理顺序。允许实时价格/号源待核和必要授权，但不得把已可完成的方案推迟到下一轮。Q2–Q4 保持各自就医、就近预约、好友会面的条件方案要求，不强制十天表格。

## 扩充历史而非把答案暗示写进题目

保留旧的15个历史Session；新增7个近邻混淆和5个无关干扰Session，每段6个用户发言及对应回复。当前样本历史共27个Session，Q1截止25个，后续题27个；四个留出问题各自独立。

近邻分别混淆主体、日期、目的、预算、订单状态、同名/同音联系人及相同酒店的不同订单。每条须有可辨作用域和状态，不制造无解矛盾，不把作者标签放入正文。无关干扰只增加检索空间，不凭空成为评分条件。全部按各题真实截止保留，不能预先剔除“不相关”历史。

## 原子项与完成度门槛

当前Q1拆为38项，四组权重30/30/25/15：交付、约束继承、旧事务与预算、证据与边界。Q2/Q3各10项，Q4八项。每项0/1/2；满分须有答案原文及其落点，历史证据不能替答案补写实现。

当前协议完成方案上限100，主要交付不全上限69，仅列待办/推迟核心方案上限39；重大主体/订单混淆、无依据确诊或捏造执行成功上限39。封顶取最小值，不重复相减。未知实时资源的可执行条件方案不自动降档。

## 搜索效率另算

固定同一Snapshot、模型与工具预算，先验证并冻结无gold构造的参考路径B，再评价新的目标Run。B只能称“已验证参考”，不能称理论最短。改变历史、压缩或渐进预算后必须重验。

当前阶梯为 x=max(0,N-B-1)，扣分=min(20,2×min(x,2)+3×min(max(x-2,0),3)+5×max(x-5,0))。N包含模型发起的无效/重复Search，不含网络重试。Raw次数和可见token另报。不合格参考不得启用罚分；质量分可报告，效率及合成总分标记not_scored，未知罚分不冒充0。

运行后只做严格评分和失败分析，不因得分高低再调整本次rubrics。重新设计必须新版本，旧题、原始消息、答案、评分均保留。此Skill负责设计与验证材料，不自行启动模型实验。
