# 在线 Sheet 小改指南

## 准入条件

仅当以下条件全部满足时在线修改：

1. 目标是已有在线 Sheet；
2. 用户已明确位置和值或结构动作；
3. 执行前可构造完整 payload，不需要边读边写；
4. 数据操作最多一次批量读取、一次写入、一次定点复核；
5. 多格值可合并为一次 `set-range-value`；
6. 同一区域样式可由一次 `set-cell-style` 完成；
7. 连续行列操作可由一次 `insert-dimension` / `delete-dimension --count` 完成。

`sheet_id` 未知时可先调用一次 `get-sheet-info`。除此之外无法守住上述预算，立即转为本地处理。

## 在线流程

1. 必要时用 `get-sheet-info` 确认目标子表。
2. 用一次 `get-cell-data` 批量读取最小目标区域。
3. 核对零基行列，先在内存中构造完整 payload。
4. 只执行一次主写操作：批量值、连续区域样式或行列结构三选一。
5. 用一次 `get-cell-data` 定点复核受影响区域。

禁止逐格 `set-cell-value`、边读边写、为“确认一下”扫描整表或调用 `operation-sheet`。

## 转为本地处理

以下任一情况均不在线逐格处理：

- 新建表格；
- 大批量新增、清洗或替换；
- 多工作表联动；
- 同时需要多类写操作，无法一次完成；
- 复杂公式、图表、格式或结构重排；
- 需要精确验证公式文本；
- 预计超过在线调用预算。

复用用户本地源文件；没有本地源时先导出。使用可用的本地表格能力修改并验收后，只执行一次 `workflow import-file`，交付新版本链接并说明原链接未覆盖。

## 验收

- 读取、写入和复核使用同一 `file_id` / `sheet_id`；
- 复核范围只覆盖受影响单元格；
- 值、类型或行列位置与请求一致；样式写入只确认命令成功及目标值未被破坏，不宣称已回读具体样式；
- 没有额外工作表、重复写入或未要求的结构变化。
