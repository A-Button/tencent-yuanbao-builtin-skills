# 输出要求

## 所有 Excel 文件
- **专业字体**：除非用户另有指示，统一用专业字体（Arial、Times New Roman 等）。中文用环境已装字体：Noto Serif/Sans CJK SC、Microsoft YaHei、SimHei、WenQuanYi Micro Hei。
- **零公式错误**：交付时确保无 `#REF! #DIV/0! #VALUE! #N/A #NAME?`。
- **保留现有模板**：修改文件时精确匹配已有格式/样式/规范；已有固定模式的文件不强加标准化格式，现有模板规范优先于本指南。

## 财务模型（除非用户或现有模板另有说明）
- **颜色编码**：蓝字(0,0,255)=硬编码输入；黑字=公式/计算；绿字(0,128,0)=跨表链接；红字(255,0,0)=外部文件链接；黄底(255,255,0)=关键假设/待更新。
- **数字格式**：年份用文本("2024" 非 "2,024")；货币 `$#,##0` 且表头注单位（"Revenue ($mm)"）；零值显示为 "-"（如 `$#,##0;($#,##0);-`）；百分比默认 `0.0%`；倍数 `0.0x`；负数用括号 `(123)`。
- **公式构建**：假设值放独立单元格，公式中引用而非硬编码（用 `=B5*(1+$B$6)` 而非 `=B5*1.05`）；验证引用、检查偏移、预测期公式一致、无循环引用。
- **硬编码值记来源**：旁注格式 `来源: [系统/文档], [日期], [引用], [URL]`（如 `来源: Company 10-K, FY2024, Page 45, [SEC EDGAR URL]`）。

# XLSX 创建、编辑与分析

> **脚本路径**：下文 `scripts/...` 均相对**本 skill 目录**（即本 SKILL.md 所在目录）。运行时工作目录不一定是该目录，调用前按 SKILL.md 的实际位置解析出绝对路径，别假设当前目录、也别硬编码部署路径。

**公式重算需 LibreOffice**（假设已装）：用 `scripts/recalc.py` 重算（脚本会自动把自身目录加入 `sys.path`，`office.soffice` 无需额外配置）；首次运行自动配置（含受限沙箱，见 `scripts/office/soffice.py`）。

## 关键原则：用公式，不要硬编码
汇总/百分比/比率/差值等**一律用 Excel 公式**，让表格随源数据自动重算。

```python
sheet['B10'] = '=SUM(B2:B9)'      # 而非 Python 算出 5000 再写死
sheet['C5']  = '=(C4-C2)/C2'      # 增长率用公式
sheet['D20'] = '=AVERAGE(D2:D19)'
```

## 读取分析用 pandas
```python
import pandas as pd
df = pd.read_excel('file.xlsx')                       # 默认第一个 sheet
all_sheets = pd.read_excel('file.xlsx', sheet_name=None)   # 全部 sheet -> dict
df.head(); df.info(); df.describe()
df.to_excel('output.xlsx', index=False)
```

## 创建/编辑用 openpyxl（保公式与格式）
```python
from openpyxl import Workbook, load_workbook
from openpyxl.styles import Font, PatternFill, Alignment

wb = Workbook(); sheet = wb.active
sheet['A1'] = 'Hello'; sheet.append(['Row', 'of', 'data'])
sheet['B2'] = '=SUM(A1:A10)'
sheet['A1'].font = Font(bold=True, color='FF0000')
sheet['A1'].fill = PatternFill('solid', start_color='FFFF00')
sheet.column_dimensions['A'].width = 20
wb.save('output.xlsx')

wb = load_workbook('existing.xlsx'); sheet = wb['SheetName']
sheet.insert_rows(2); sheet.delete_cols(3)
wb.create_sheet('NewSheet')
wb.save('modified.xlsx')
```

## 工作流与重算
1. 选工具（pandas 处理数据 / openpyxl 公式格式）→ 2. 创建或加载 → 3. 修改 → 4. 保存 → 5. **重算**（用公式时必做）→ 6. 验证修复错误。

```bash
python scripts/recalc.py <excel_file> [timeout_seconds]
```
脚本重算所有公式、扫描 Excel 错误，返回 JSON（`status`=`success`/`errors_found`，含 `error_summary` 的类型与位置）。`errors_found` 时按位置修复再重算。

**公式自查**：先在 2~3 个单元格验证引用取值正确再铺开；注意列映射（第 64 列=BL）与行偏移（DataFrame 第 5 行=Excel 第 6 行）；用 `pd.notna()` 处理空值；`/` 前查分母防 `#DIV/0!`；跨表引用用 `Sheet1!A1`；边界值（0/负/极大）测试。

# 数据可视化图表

> 目标是**图文并茂**：文字讲结论，图做证据。**怎么画由你按"有什么数据、要回答什么问题"来想**，用 matplotlib/seaborn 自绘 PNG，别套模板化的固定几张图。完整方法论见 [visualization-principles.md](visualization-principles.md)（按需展开）。

## 先分流：图落进 xlsx（A）还是独立图片（B）
- **A．图是 xlsx 的一部分 → 优先 Excel 原生**（openpyxl 图表、条件格式色阶/数据条/图标集、切片器+透视图）：可编辑、随源数据刷新。**不要默认把 PNG 插进 xlsx。** 仅当原生做不到（漏斗/树图/瀑布/箱线/桑基/网络/日历热力/地图等）或对精美度要求高时，才用 matplotlib 出 PNG，再用 `openpyxl.drawing.image.Image` 插入，并说明"更精美但静态不刷新"。
- **B．图片独立于 xlsx → 用 PNG**（图文并茂作答、报告配图）：matplotlib 出高清 PNG，追求精美，静态无妨。
- 两类都要**在图旁保留原始数据表**。要"改数据自动更新的图"一律走 A；要交互/筛选/钻取只能用 A 的透视图/切片器（PNG 做不到）。

## 怎么想：先定"问什么"，再定"怎么画"
先问"**我有什么数据、要用图回答什么问题**"，从问题倒推表达，别从"图长什么样"出发。下表是思路指引，不是清单——用 matplotlib/seaborn 把它画出来即可。

| 要回答的问题 | 合适的表达 | 关键约束 |
|---|---|---|
| 随时间/有序维度的走向 | 折线/面积 | 横轴按真实数值等距，不等距别按索引画 |
| 大小/排名对比 | 柱/条形 | Y 轴从 0；排序后更易读 |
| 正负/增减/盈亏 | 发散条形（居中 0） | 正负分色 |
| 一个对象的多维画像 | 雷达 | 3~8 维、量纲差异先归一 |
| 部分对整体的构成 | 类别≤5 用环形；多类/层级用树图或百分比堆叠 | 占比同源、加总=100% |
| 单变量分布 / 分组分布 | 直方图(+KDE) / 箱线 | — |
| 两/三变量关系 | 散点 / 气泡（面积非半径编码） | — |
| 变量两两相关 | 相关热力图（有正负用发散色） | 系数标 2~3 位小数，别只显示 0 |
| 量 + 率 的派生关系 | 组合双轴（柱=量、线=率） | — |
| 流程逐级转化 | 漏斗 | — |
| 很多同类指标做总览 | 一张分面小多图（同型跨变量、风格统一、可横向对比） | 别拆成十几张散落图 |
| 探索多变量结构 | 散点矩阵/平行坐标/KDE叠加/ridgeline/小提琴/hexbin/二维KDE等高线 | EDA 可密集，见下 |

## 两种模式，别用错松紧
- **交付/汇报**（业务受众、结论导向）：克制、少而精。默认收敛 **3~5 张高价值图**；一句话能说清的（"女性略高于男性"）写进正文行内数字**不单独成图**；**一个结局受多因素影响时，合并成一张系数/发散条形 + 一张相关热力图**，别每个因素画一张 2~5 根柱的柱图（信息密度极低、彼此同质，最典型的"基础图海打扰用户"）。
- **探索性分析（EDA，技术受众、找规律）**：鼓励**密集、多序列、多面板**，上面的探索型表达大胆自绘，不受"3~5 张 / ≤6 色 / 单一锚点"约束。像"N 变量：箱线阵 + 直方叠加 + 相关热力 + 两两散点带回归 + 平行坐标 + KDE 总览"这种探索大图正是该出的形态。**别把探索硬压成固定几张图**——那会千篇一律、缺洞察。

## 铁律（任何图不可破）
1. **诚实性**：柱图 Y 轴从 0；折线横轴等距（不等距按真实数值画）；禁止 3D；面积/半径与数值线性对应。
2. **关键量用位置/长度编码**（柱高、点位），辅助维度才用颜色/透明度；不用色相+纹理同时区分同一维度。
3. **要件齐全**：标题、单位/坐标标签、必要图例；**中文用环境已装字体（Noto/思源黑体），不出豆腐块**（matplotlib 先设 `font.sans-serif` 与 `axes.unicode_minus=False`）。
4. **装饰即数据**：无数据含义的边框/阴影/渐变/网格不加。
5. **不造冗余图例**：单序列图别把同一类目字段又映射到颜色（凭空多出图例维度），用单色或直接标注，避免"彩虹图"。
6. **数值精度**：小数按量级保留有效位（相关系数、占比等别四舍五入成 0 或 -0）。

> **默认美学**（配色低饱和、≤6 色、一图一强调色、锚点标红、5 秒抓结论）是**交付默认**；探索图承载多序列时改用连续/定性色板 + alpha + 分面放宽。**财务模型场景**（见 `excel-financial-model`）更克制：统一单色系、不用斑马纹/色阶，该技能规则优先。

## 数据分析作答：文字洞察为主、图为佐证（图文并茂）
核心交付物是**文字里的结论与洞察**，图是支撑证据。两条底线对等、缺一不合格：① 核心结论不配图、或图全堆结尾不穿插 → 不合格；② 图只复述数字、无结论/归因/行动，或堆没对应洞察的图 → 不合格。

节奏：**先有值得说的洞察，再为它配一张图**，形成"文字→图→文字→图"。图统一存 `/data/workspace/` 下，用 `<media_info>` 穿插展示（`type`=`file`，本地图用 `path` 沙箱绝对路径）：
```
<media_info>[{"type": "file", "description": "各区域营收对比", "path": "/data/workspace/charts/region.png"}]</media_info>
```
- 穿插而非堆尾；`description` 必填、`path` 照抄实际路径不臆造。
- 每张图对应一个明确结论（趋势/对比/结构/异常），别为配图而配图。
- **出图前做一次图规划+去重**：交付默认收敛 3~5 张、宁少而精（探索大图不受此限）。

## 分析要有深度：从"数据罗列"到"洞察"
别把图里的数字用文字复述一遍（读者看图就懂，零增量）。每个要点走完四层：
1. **What** 现象（起点）→ 2. **So what** 影响（好坏/量级/是否触红线）→ 3. **Why** 归因（拆到量×价、结构、哪几项贡献大头）→ 4. **Now what** 行动/该盯什么。

**让数字有意义**：对比基准（vs 目标/同期/行业/大盘）、贡献度分解、量化代替形容（CAGR/倍数/占比/pct）、看动态（加速/拐点/季节性）、下钻结构（集中度/分布/分组差异，防 Simpson）、串联多指标成因果链。

**给建议时用决策透镜**（挑真正会改变结论的几个，非逐条打勾）：规模、动能、广度、集中度、强度、效率、可行动性、差异化/替代/风险/覆盖度。证据不足就把建议标"暂定"并说明什么会改变信心，别为显得果断而夸大。

**着墨点**：异常/离群、拐点/反转、超/不及预期、结构性变化、指标矛盾、高度集中失衡——别平均用力。**结论先行**（金字塔），每段一个观点+支撑图与关键数字。归因诚实：能被数据支撑才下判断，否则用"可能/推测"并给依据，守住"相关≠因果"。

示例——❌ 罗列：`华东128、华南96…华东最高`；✅ 有深度：`区域高度集中且仍在提升，是最大结构性风险。华东128亿占全国34%、为东北3.4倍，且增速+31%高于其余+12%，说明"东强西弱"在加剧→盘子越发依赖单一市场。建议加大华南/西南对冲，并复盘华东打法能否异地复制。`（配区域营收+增速图）

# 数据分析严谨性（下结论前必守）

## 分析前：数据体检
- **先定粒度与主键**（最易跳过、最易翻车）：确认"每行代表什么"（订单/用户/用户×月）、主键是什么。很多"质量问题"实为粒度混杂/重复 join/部分回填/迟到数据。用 `df[keys].duplicated().sum()` 验主键唯一；计数唯一实体用 `nunique()` 而非在明细/join 表上 `count()`。
- **缺失值**：看每列缺失**比例**；`pd.isna()` 检查，别让 NaN 混进求和/均值；留意伪缺失哨兵值 `'' unknown n/a 0 -1`。
- **重复行**：`df.duplicated().sum()`，分别看整行重复与主键重复。
- **有效性**：类型可转（数字被读成带千分位/单位/全角字符串）、ID/枚举/日期合法、无不可能值（负营收）、金额单位统一（元/万/亿）。
- **一致性**：跨字段自洽（`is_cancelled=false` 却有 `cancelled_at`）；多来源同指标对得上。
- **日期**：`parse_dates` 显式解析，查是否连续、有无缺失周期（影响折线等距）；留意未来日期、迟到数据致近期不稳。
- **异常值**：用分位数/IQR/MAD 定位，判断录入错误还是真实极端，别默默带进均值。
- **看比率、分维度、分严重度**：比"缺 1200 条"更有用的是"缺失率 2%→18%"；按时间/来源/地区/版本切开区分真问题与正常波动；按严重度排序（致命=坏核心 join/关键决策；高=明显带偏；中=局部可解释；低=小瑕疵），每条发现挂业务风险，写法：**现象→证据(数量+比率+分段+时间)→影响→可能原因→修复/校验建议**。

## 统计诚实
- **相关≠因果**：只说相关/同步；仅凭时间先后不断因果，未证实用"可能/推测"给依据。
- **看基数与样本量**：小样本百分比波动不可靠（"+200%"可能 1→3）；给比率同时给绝对量。
- **辛普森悖论**：整体与分组趋势可能相反；换分组维度看结论是否翻转。
- **口径一致**：同比/环比、含税/不含税、时点/时段——同图口径统一并在副标题注明。
- **别为叙事挑数据**：不裁时间窗、不藏不利分组。

## 常见陷阱：算得漂亮≠算得对（VLOOKUP/merge/透视/环比 高发）
- **连接爆炸**：多对多 join 成倍放大行数、虚增求和/计数。merge 前后对比 `len(df)` 与 `df[key].nunique()`；右表先聚合到目标粒度再连；穿 join 计数用 `nunique()`。
- **分母漂移**：不同期/组比率必须分母口径一致。
- **均值的均值**：别对已是均值的数再平均，用原始分子/分母或按规模加权。
- **部分周期对比**：别拿未走完的当期比完整历史期，用完整周期/对齐天数/标注"当期未完"。
- **幸存者偏差**：只看今天还在的实体会漏掉流失/失败样本——先问"谁不在数据里"。
- **选择偏差**：别用结果本身定义对比分组（lift/因果按处理前特征分组）。

## 可溯源、不臆造
- 每个数字可回溯真实数据，不脑补凑整；交付 xlsx 用公式而非硬编码。
- 时间不等距按真实数值画横轴，别按索引画歪趋势。
- 数据不足支撑结论就如实说局限，不硬给。

## 下结论前抽查（分享结论/高影响建议/结果反直觉时）
关键数字用原始分子分母重算；抽几条明细顺 join→筛选→汇总走一遍；关键合计对历史/财务量级；反推头号数字（用户数×人均≈总额）；边界抽查（某天/某组）；高风险换路径复算。给结论标可信度：**可直接分享 / 带保留分享（列明口径与局限）/ 需返工**。

# 最佳实践与常见坑
- **库选择**：pandas 做数据分析/批量/导出；openpyxl 做复杂格式/公式/Excel 特性。环境已预装，直接调用。
- **openpyxl**：索引从 1 开始；`data_only=True` 读计算值（但据此保存会永久丢公式）；大文件读用 `read_only`、写用 `write_only`；公式保留但不计算，需 `recalc.py`。
- **pandas**：`dtype={'id':str}` 防推断问题；`usecols=[...]` 只读需要列；`parse_dates=[...]` 处理日期。
- **CSV 中文**：给 Excel 用的 CSV 加 BOM：`to_csv(path, index=False, encoding="utf-8-sig")`；读入不确定先 `utf-8` 再 `gbk`。
- **大数据量（~10 万行+）**：用 pandas groupby/透视聚合，别用 openpyxl 逐格读写，小结果再写进 Excel。
- **媒体路径**：`<media_info>` 的 `path` 必须是运行时沙箱绝对路径（如 `/data/workspace/charts/x.png`），图统一存 `/data/workspace/` 下。
- **中文字体**：matplotlib 用环境已装的 Noto/思源黑体（设 `font.sans-serif` 与 `axes.unicode_minus=False`）；出豆腐块说明镜像缺字体（确认 `/usr/share/fonts/opentype/` 已装）。

# 代码风格
- 生成 Python 代码：简洁、无多余注释/print、不用冗长变量名。
- Excel 文件本身：为复杂公式/重要假设加批注，为硬编码值记来源，为关键计算加说明。
