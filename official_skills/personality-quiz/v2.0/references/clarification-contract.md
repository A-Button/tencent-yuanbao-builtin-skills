# 必要信息与提问控件

已有信息直接复用。只有缺口会影响当前计算或解释时才问，能回答已有部分就先回答；不为篇幅、语气、模板或已经给出的主题另开确认。新排盘按 `chart_quick.py` 的 `question/resume_request` 续接，不自行重写资料收集流程。

使用宿主真实的 ask_user_question／ask-user-question 工具。支持“标题 + 选项 + 自由输入”时，标题直接说明需要填写什么，选项提供真实可选值及固定的“不清楚 / 不想说”，用户可在输入栏填写；无需因为它不是专门的填空控件而改成普通聊天。工具确实不支持所需输入或不可用时，再用一条普通消息。

- 已知的独立缺口可一次收集；前一答案决定下一问题时再续问，不把多次工具调用当成固定仪式。
- 出生时间不知道或不想说：按日期级继续，保留 `time_prompted=true`，不改成中午或再次追问。
- 必需日期／地点被跳过：说明当前无法排盘，可回答已有资料允许的部分；不编造值，不重复弹窗逼问。
- 真实消歧选项只用脚本返回的候选，不能自行添加时区或地点。跳过时保留不确定性。
- 报告主题可多选或在自由输入中填写多个，用户明确跳过才结束；已有主题直接复用，不把未作答算作同意。

用户作答后直接继续。主路由确实不清楚才问最可能的方向，不展示整张能力菜单。诊断旧状态接口时再读 [interaction-state.md](interaction-state.md)；其余按当前入口与返回动作执行。
