# 八字分析

使用当前去身份化分析盘与用户问题。普通排盘先给命局概要和简要分析，再附盘面；用户只要盘面则不解读，明确要一句话或深入某题则按其要求展开。报告的输入格式由当前阶段返回，不提前加载其他阶段。

## 数据边界

- 精确盘可用 `chart.pillars` 及 `chart.details` 中实际存在的日主、干支、藏干、十神、十二长生、五行数量和干支关系。
- 日期级使用 `chart.stable`；范围盘若四柱完全稳定可用已提供的完整 `pillars/details`，否则只用稳定字段。月柱不稳定时，只说明可确定的盘面与精度限制，不给依赖月令的命局定论。
- 不补算未提供的柱、十神、合冲关系、起运或流年。旺衰、格局、取用是对已有事实的传统综合判断，须给出依据与条件，不能冒充引擎已计算的字段；资料不足时不硬定。
- `chart.details.luck_cycle_focus` 仅在实际提供且当前问题涉及阶段时使用。深报候选只用原局，第二阶段的 `timing_contract` 决定相关章节中的大运分析。缺少流年数据就不能叠加流年，更不能由年份联想具体事件。

## 分析提纲

1. **先抓结构。** 以日主和月令起笔，比较月令本气、根气、透干与生扶、耗泄、克制；五行数量只是旁证，不能用“缺什么补什么”或单凭某个字判旺衰。普通概要就应给出据此形成的主要判断，而不是只报四柱或性格形容词。
2. **贯通十神与格局。** 指出实际透出的十神、月令所藏及其相互作用，说明哪一股力量主导、哪一股牵制，以及这怎样影响旺衰、格局或取用判断。格局名称若有争议，说明采用的依据与竞争解释，不硬贴标签；合冲刑害不直接等于吉凶，关系存在不等于合化成立。扶抑、格局与调候各有判断目标，不混成一个无条件的喜忌结论。
3. **回答较大主题。** 沿同一条盘面逻辑解释用户所问。事业可讨论能力、产出、资源与回报怎样衔接，关系可讨论互动、稳定性与责任；既说可能的优势，也说成立条件和阻力。避免把多个章节反复改写成“多自省、做件小事、慢慢落地”；只有用户问怎么办时才给与判断相连的行动建议，没有支持的领域不硬补。
4. **解释动态。** 有可用阶段数据时，比较它怎样加强、缓解或改变原局结构，以及判断成立的条件；讲清原局与阶段的联系，不只背诵该步大运的十神词义。匿名条件分支不替用户选边。
5. **形成回答。** 先给出当前传统框架下的判断，再用少数关键盘面关系解释；每段推进一个新问题，勿换词重复同一主张。确定的干支事实直接说；综合判断在关键条件处交代局限即可，不逐句叠加自我否定。

这些是选材提纲，不是必须逐项输出的模板，也不新增候选文件、评分或润色回合。普通概要不再限于 60–120 字；用户要求简短时仍应简短。内容深度取决于真实资料与模型表现，不能靠篇幅或术语数量保证。

共同表达与边界使用已加载的 [safety.md](safety.md)。需要精确古籍引文或流派考据时才查 [source-registry.md](source-registry.md)，不要用一句古籍替代对当前盘面的解释。
