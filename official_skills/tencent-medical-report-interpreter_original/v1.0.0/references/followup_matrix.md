# 分级随访矩阵

> **用法**：每个异常项必须落到一个明确档位，并绑定**时间窗 + 科室 + 复查项目**三要素。
> 禁止输出"建议就医""注意观察"这类无法执行的模糊建议。

---

## 零、给用户看时的档位写法（重要）

**L1/L2/L3/L4 是内部代号，用户看不懂。输出给用户时必须换成人话：**

| 内部代号 | 给用户的写法 | 时间窗 |
|---|---|---|
| L1 | **需立即就医** | 数小时内 |
| L2 | **两周内专科就诊** | 14 天 |
| L3 | **一至三个月复查** | 30~90 天 |
| L4 | **年度随访** | 12 个月 |

正例：`需立即就医 · 数小时内`
反例：`L1 档`、`按 L1 处置`、`档位：L1` ← 用户不知道 L1 是什么
反例：`马上去医院（别等）`、`明年体检时再看就行` ← 过于口语，医疗报告需专业调性

**措辞演进说明**：早期版本用「马上去医院（别等）」「明年体检时再看就行」，
虽然通俗但过于随意。医疗报告的调性要求专业简洁，已统一收敛为上表措辞。
通俗性由正文承担，不由档位标签承担。

内部推理与本文件查表可用 L1~L4，**呈现给用户的文字一律用人话**。

## 一、四档定义与趋势联动

| 档位 | 时间窗 | 触发条件 | 趋势升降规则 |
|---|---|---|---|
| **L1 需立即就医** | 数小时内 | 命中危急值表；影像提示急性事件（气胸/夹层/颅内出血/肺栓塞/穿孔） | 不参与趋势计算，单次命中即触发 |
| **L2 两周内专科就诊** | 14 天 | 显著偏离区间；关联分析指向器质性问题；影像分级 ≥ BI-RADS 4 / TI-RADS 4 / Lung-RADS 4A / LI-RADS 4；肿瘤标志物数倍升高 | L3 项连续两次恶化且变化率 >20% → 升档至此 |
| **L3 一至三个月复查** | 30~90 天 | 轻度偏离；存在可逆干扰因素待排除；个体目标未达标但在区间内；影像 3 类 | 连续三次稳定无恶化 → 降档至 L4 |
| **L4 年度随访** | 12 个月 | 全部在区间内且达个体目标 | 区间内持续单向漂移 → 标记隐性风险并提示观察 |

## 二、按系统的科室与复查项目对照

### 2.1 心血管与代谢

| 异常项 | 档位 | 科室 | 复查/追加项目 |
|---|---|---|---|
| LDL-C 未达个体目标 | L3 | 心内科 / 内分泌科 | 血脂四项、Lp(a)、颈动脉超声、ASCVD 风险重算 |
| TG > 5.6 mmol/L | **L2** | 内分泌科 | 血脂、血糖、胰酶（防急性胰腺炎） |
| Lp(a) ≥ 300 mg/L | L3 | 心内科 | 家系筛查、强化 LDL-C 干预 |
| 血压 ≥140/90（新发） | L3 | 心内科 | 家庭血压监测 7 天、尿微量白蛋白、心脏超声、眼底 |
| 血压 ≥180/110 | **L2** | 心内科 | 立即评估靶器官损害 |
| 空腹血糖 6.1~7.0 | L3 | 内分泌科 | OGTT、HbA1c、胰岛素、C 肽 |
| 空腹血糖 ≥7.0 或 HbA1c ≥6.5 | **L2** | 内分泌科 | OGTT 确诊、并发症筛查（眼底/UACR/神经/足） |
| cTn 升高 | **L1** | 急诊 / 心内科 | 心电图、心脏超声、冠脉评估 |
| BNP/NT-proBNP 升高 | L2 | 心内科 | 心脏超声、胸片 |
| 颈动脉斑块 | L3（狭窄>70% 为 L2） | 心内科 / 血管外科 | LDL-C 目标下调、ASCVD 重算 |
| 代谢综合征（≥3 项） | L3 | 内分泌科 | 全套代谢评估 + ASCVD 风险 + 肝脏评估 |

### 2.2 肝胆

| 异常项 | 档位 | 科室 | 复查/追加项目 |
|---|---|---|---|
| ALT/AST 轻度↑（<3 倍） | L3 | 消化内科 / 肝病科 | 肝炎标志物、腹部超声、血脂血糖、FIB-4、停可疑药物后复查 |
| ALT/AST 中度↑（3~10 倍） | **L2** | 肝病科 | 病毒标志物、自身免疫抗体、铜蓝蛋白、腹部影像 |
| ALT/AST > 1000 U/L | **L1** | 急诊 / 肝病科 | 凝血、血氨、意识评估 |
| ALP/GGT↑ + 胆红素↑ | **L2** | 肝胆外科 / 消化内科 | 腹部超声/MRCP 查胆道 |
| 白蛋白↓ + PT延长 + PLT↓ | **L2** | 肝病科 | 肝硬化评估、胃镜查食管静脉 |
| FIB-4 > 2.67 | L2 | 肝病科 | 弹性成像、肝脏 MR |
| 脂肪肝（超声） | L3 | 消化内科 | 肝功、血脂、血糖、FIB-4、体重管理 |

### 2.3 肾脏与泌尿

| 异常项 | 档位 | 科室 | 复查/追加项目 |
|---|---|---|---|
| eGFR 60~89 + 有损伤标志 | L3 | 肾内科 | UACR、尿沉渣、肾脏超声、胱抑素 C |
| eGFR 30~59 | **L2** | 肾内科 | 全套肾功评估、贫血/钙磷/PTH |
| eGFR < 30 | **L2**（<15 为 L1） | 肾内科 | 替代治疗评估 |
| UACR ≥ 30 mg/g | L3（≥300 为 L2） | 肾内科 / 内分泌科 | 重复 2~3 次确认、血压血糖强化控制 |
| 尿蛋白阳性 | L3 | 肾内科 | 24h 尿蛋白定量、尿沉渣、肾脏超声 |
| 镜下血尿 | L3 | 泌尿外科 / 肾内科 | 尿相差镜检、泌尿系超声、尿细胞学（>40 岁需排除肿瘤） |
| 尿酸 > 480 μmol/L | L3 | 风湿免疫科 / 内分泌科 | 关节评估、肾功、双能 CT（如有关节痛） |
| 肾结石 > 6 mm 或伴积水 | L2 | 泌尿外科 | 泌尿系 CT、肾功 |

### 2.4 血液

| 异常项 | 档位 | 科室 | 复查/追加项目 |
|---|---|---|---|
| Hb 轻度↓ | L3 | 血液科 / 消化内科 | 铁四项、B12、叶酸、网织红、便隐血（**必须找失血源**） |
| Hb < 90 g/L | **L2** | 血液科 | 全套贫血病因筛查、胃肠镜 |
| Hb < 60 g/L | **L1** | 急诊 / 血液科 | 输血评估 |
| PLT 100~125 | L3 | 血液科 | 复查（先排除 EDTA 假性减少）、肝功、脾超声 |
| PLT < 100 | **L2** | 血液科 | 血涂片、骨髓评估指征、自身抗体 |
| PLT < 20 | **L1** | 急诊 / 血液科 | 输血小板评估 |
| WBC↑↑ 或见幼稚细胞 | **L1** | 血液科 | 血涂片、骨髓穿刺 |
| ANC < 1.0 | **L2**（<0.5 为 L1） | 血液科 | 病因筛查、防感染 |
| ESR/CRP 显著↑ 无明确感染 | L2 | 风湿免疫科 / 血液科 | 自身抗体、蛋白电泳、影像排查（结核/肿瘤） |

### 2.5 内分泌

| 异常项 | 档位 | 科室 | 复查/追加项目 |
|---|---|---|---|
| TSH↑ + FT4↓（甲减） | L2 | 内分泌科 | TPOAb/TgAb、甲状腺超声、血脂 |
| 亚临床甲减（TSH↑ FT4正常） | L3（TSH>10 或妊娠为 L2） | 内分泌科 | 2~3 月复查甲功 + 抗体 |
| TSH↓ + FT4↑（甲亢） | **L2** | 内分泌科 | TRAb、甲状腺超声、心率心电图、**先排除生物素干扰** |
| 中枢性甲减（TSH↓ FT4↓） | **L2** | 内分泌科 | 垂体 MRI、其他垂体激素轴 |
| 皮质醇异常 | L2 | 内分泌科 | 需明确采血时间、ACTH、节律试验 |
| 泌乳素↑ | L3 | 内分泌科 / 妇科 | 复查（排除应激/药物）、垂体 MRI |
| 睾酮↓（男） | L3 | 内分泌科 / 男科 | 晨起复查、LH/FSH |
| 维生素 D < 20 ng/mL | L3 | 内分泌科 / 全科 | 补充后 3 月复查、骨密度 |

### 2.6 影像与结节

| 异常项 | 档位 | 科室 | 复查/追加项目 |
|---|---|---|---|
| BI-RADS 3 | L3（6 月） | 乳腺外科 | 超声复查对比 |
| BI-RADS ≥4 | **L2** | 乳腺外科 / 甲乳外科 | 穿刺活检；4A 可选 3 月短期随访 |
| TI-RADS 3 | L3（6~12 月） | 内分泌科 / 甲乳外科 | 超声 + 甲功 |
| TI-RADS ≥4 | **L2** | 甲乳外科 | FNAB 细针穿刺 |
| 肺结节 <6 mm 实性 | L4 | 呼吸科 | 12 月 LDCT（高危者） |
| 肺结节 6~8 mm | L3 | 呼吸科 | 6~12 月 LDCT |
| 肺结节 >8 mm 或 4A 以上 | **L2** | 呼吸科 / 胸外科 | 增强 CT / PET-CT / 活检 |
| 胆囊息肉 ≥10 mm | **L2** | 肝胆外科 | 增强影像评估 |
| 骨密度 T ≤ −2.5 | L2 | 内分泌科 / 骨科 | 骨代谢标志物、FRAX、药物评估 |
| 骨密度 T −1.0~−2.5 | L3 | 内分泌科 | 1~2 年复查、钙+VD+运动干预 |

### 2.7 肿瘤标志物

| 情形 | 档位 | 处置 |
|---|---|---|
| 单项轻度升高（<2 倍） | L3 | 1~3 月复查看趋势，先排除良性原因（见 pitfalls.md） |
| 单项显著升高（≥2 倍） | **L2** | 对应专科 + 影像学检查 |
| 多项同时升高 | **L2** | 肿瘤科 / 对应专科，需影像学系统排查 |
| 持续进行性上升 | **L2** | 必须影像学确认，不可继续单纯观察 |

> 肿瘤标志物正常**不能排除**肿瘤；轻度升高**不等于**有肿瘤。输出必须同时说明这两点。

## 三、就诊准备清单（附在随访建议中）

```
就诊携带：
  □ 本次完整报告原件（含影像胶片/光盘）
  □ 既往同类报告（用于医生看趋势）
  □ 正在服用的所有药物与保健品清单（含剂量）
  □ 主要症状记录（起始时间、变化、诱因）
  □ 家族史要点（一级亲属重大疾病）

建议提前准备的问题：
  □ 这个结果需要进一步做什么检查？
  □ 需要开始治疗吗？如果暂不治疗，多久复查？
  □ 有哪些症状出现时需要提前就诊？
```

## 四、输出模板（随访段）

```
【随访行动清单】

L2 · 两周内专科（2 项）
┌ 甲状腺 TI-RADS 4A 结节
│   科室：甲乳外科 或 内分泌科
│   项目：超声引导下细针穿刺（FNAB）
│   备注：4A 类恶性概率 5~10%，穿刺是为明确性质，不等于已判定恶性
└ 空腹血糖 7.4 mmol/L（达糖尿病诊断阈值）
    科室：内分泌科
    项目：OGTT + HbA1c 确诊；同步做并发症筛查（眼底、UACR、神经、足部）

L3 · 一至三月复查（2 项）
┌ LDL-C 3.2 mmol/L（区间内但未达个体目标 <2.6）
│   科室：心内科 或 内分泌科
│   项目：血脂四项 + Lp(a) + 颈动脉超声；3 个月生活方式干预后复查
└ ALT 62 U/L（轻度升高，待排除脂肪肝与药物因素）
    科室：消化内科
    项目：肝炎标志物、腹部超声、FIB-4；停用红曲类保健品 1 月后复查

L4 · 年度随访（其余项目）
    血常规、肾功能、尿常规均在区间内且达目标，按年度体检节奏即可。
    ⚠ 隐性风险标记：TSH 三年数据 2.1 → 3.0 → 4.0，虽均在区间内（0.27~4.2）
      但持续单向上升，建议本次随访提前至 6 个月并加做 TPOAb。
```

## 边界

- 科室名称各医院设置不同，输出时给"科室 或 备选科室"，并提示"以就诊医院实际科室设置为准"。
- 不推荐具体医院、医生、体检机构。
- 时间窗是建议下限，不是上限。用户症状加重时应提前就诊 —— 每次输出需附一句"若出现症状加重请提前就诊"。
