# 用户已有盘面

本路由处理结构化导出、文本表格、截图 OCR 或第三方排盘结果，不负责收集出生资料或重新起盘。当前没有紫微、吠陀或任意格式的统一导入器；只能核对用户材料中可见的字段、来源与口径，不能声称已经完成机器校验。确实需要补充时读取 [clarification-contract.md](clarification-contract.md)。

## 最低检查

- 保留原始材料不变，并把来源标记为“用户提供”；导出软件的自动文案不是盘面事实，工具品牌也不是解释权威。
- 记录能从材料确认的工具/版本、流派、历法、时制、配置码和时间层；无法辨认、互相矛盾或缺少会改变当前请求结论的口径时，一次列出所有当前可见且用户能够回答的关键缺口。用户不知道时缩小解释范围，不继续逐项追问。
- 紫微至少需要十二宫、主要星曜、四化/流派口径、安星码或等价配置与时间层。吠陀至少需要恒星/热带黄道、ayanamsha、宫制、分盘类型、行星及罗喉计都口径；只给 D1 时不得补造 D9 或大运。
- 只解释材料中真实存在的字段，不补造宫位、星曜、分盘、周期或流年。需要重新计算时新建隔离的独立任务，不覆盖原始材料，也不把它冒充当前编排器尚不支持的后续 revision。

## 生成边界

原始材料可能含姓名、出生日期、地点或账号信息，不得直接送入生成阶段。当前没有可审计的导入清洗器或统一 schema；没有适配器时，只能在当前会话按最小字段白名单摘取来源明确、口径已确认的可见盘面事实，再按 [interpretation-method.md](interpretation-method.md) 解释，并明确这不是机器校验或持久化去身份化。无法安全分离身份信息时只做字段说明，不做个性化判断。

若用户导入的是八字或本 Skill 覆盖的西洋盘，并且另行明确要求复算，同时提供了完整输入，可在新的隔离任务中走对应内置引擎作一致性比较。两版不一致时并列展示差异与口径，不选择更有利于解释的一版。

## 输出表达

材料达到可解释条件后，共同表达与边界复用 [safety.md](safety.md)。八字或西占复用对应 [八字](bazi-report.md#分析提纲) 或 [西占](western-report.md#分析提纲) reference 的写法，其他体系按以下要求表达。

先清楚说明当前可回答的主题，再解释可见配置与日常体验的联系。陌生术语用简短白话说明，展开可以温暖具体；不把缺失配置用“隐藏的一面”补齐。材料不足时只说明可读字段和限制。

引述导出文本时明确它来自用户材料；软件给出的解读不等于原典或现实事实。原文与版本考据按需使用 [原文与出处](source-registry.md#原文与出处)。
