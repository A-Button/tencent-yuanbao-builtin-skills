## 2.2.0 — 2026-09-20

**行为变更**：第 05 段「干扰因素排查」的呈现方式大幅精简，**后台排查逻辑完全不变**。

### 变更

- **05 段前端压成三行纯文本**，不再拆 5.1/5.2/5.3 小节、不再用项目符号列表：

  ```
  **已排除**：<项目名>、<项目名>
  **待确认**：<项目名>（<涉及指标> · <要做什么>）、…
  **信息缺口**：<项目>、<项目>、<项目>
  ```

  - 已排除：**只报项目名，不写排除理由**
  - 待确认：**一项都不能少**（红线），格式 `名称（涉及指标 · 动作）`
  - 信息缺口：**必须有**（红线），顿号串联

- **机制解释归 03 段** —— 「为什么红曲会让肝酶升高」「为什么 ACEI/ARB 会升高血钾」这类说明
  写进 03 段对应指标的可能性分层，05 段不重复
- 自带样例 05 段实测 **351 字 → 181 字**，压缩 48%；三个待确认项、三条信息缺口一条未减
- 输出章节结构表的 05 行描述、Markdown 报告模板、md 与 html 两份样例，全部同步为新写法

### 设计依据

后台仍对每个异常项逐一跑四类干扰反问（采样因素 / 生理时相 / 药物影响 / 个体差异）。
本次只削「已排除的理由」与「机制铺陈」两类内容 —— 这与判读快查卡红线第 6 条一致：
**可以删「已排除」的展开，不能删「待排除」**。

## 2.1.0 — 2026-09-20

修复输出前言违规。**行为变更**：交付物中不再出现任何内部机制名与自我说明；
输入非医学报告时改为两句话应答，不再硬套章节结构。

### 新增

- **「零前言铁律」补入完整版**（此前仅速读版有，完整版一条都没有 —— 这是版本拆分时的遗漏）。
  同时把禁止范围从四类扩到**六类**，新增：
  - 第 5 类 **暴露内部机制名与步骤执行汇报**，如「可以按 skill 流程判读」「已跑危急值闸门：未命中」
  - 第 6 类 **第一人称辩解与工作方式说明**，如「硬套格式只会输出空段落，我不这样做」
- **「内部机制名禁止外泄」清单**：工具自称 / 流程名 / 资料名 / 规模控制 / 档位代号 /
  步骤执行汇报 / 第一人称元话语，七类禁用词一次列全。
  判断标准：这个词是医生和患者会用的，还是只有开发者会用的
- **非医学报告输入的处理规则**：缴费凭证、导诊单、挂号单、处方笺、知情同意书、检查预约单
  等不启动解读流程，只回两句话（一句说明没有可判读数据，一句引导补充材料），
  不解释内部机制、不做自我辩解
- 类型路由表新增两行：**验光单 / 屈光检查**（数值型但不套参考区间逻辑，屈光度无「正常值」）、
  **非判读对象**
- `scripts/check_report.py` 新增第 27 项校验「**无内部机制名**」，把上述禁令接入机器校验。
  已做边界收紧：「危急值」单独出现是规范术语予以放行，只拦「危急值闸门」；
  「第 3 段」放行，只拦「N 段解读 / 段数上限 / 字数上限」；「我们建议」放行，只拦明确的元话语句式

### 变更

- `scripts/check_report.py` 校验项由 26 项增至 **27 项**
- Verification 自检清单新增 4 条：首字符即标题 / 无内部机制名 / 无第一人称元话语 / 非报告输入应答

## 2.0.0 — 2026-09-20

相对 1.0.1 是**破坏性升级**：新增质量保障硬约束、更新多部过期指南、脚本调用方式变更。
从 1.0.1 升级请**整目录替换**，不要只覆盖部分文件。

### 新增

- **质量保障硬约束（A/B 两组）**，优先级高于一切篇幅与排版要求
  - A1~A7 术语与依据规范：术语以《医学名词》准用名为准；缩写首现写规范全称；
    歧义词必须落到具体指标与数值；引用指南前核发布年份；中国指南优先；
    国际标准须标人群局限；阈值一律写全名带年份
  - B1~B8 禁止清单：不夸大病情 / 不编造报告未提及的信息 / 不说「无需治疗」/
    不给用药剂量与疗程 / 不用绝对化表述 / 不涉及医疗纠纷表述 / 不下诊断与判良恶性 /
    不推荐具体药品保健品医院与体检套餐
  - **B6 专项规则「排除干扰 ≠ 质疑医院」**：保留「假性高钾先排除标本溶血」等必要医学动作，
    但措辞只能指向标本、采样、生理状态、文本提取环节，并必须同时给出复查或核对动作
- **眼科判读能力**
  - `references/imaging_grading.md` 新增「眼科超声（眼 B 超）」章节：玻璃体回声鉴别核心表、
    玻璃体混浊可能性分层、玻璃体后脱离随访窗口、症状红旗、常见描述解读
  - `references/critical_values.md` 新增「眼科急症（A 级）」：视网膜脱离、急性闭角型青光眼、
    眼球穿通伤与眼内异物、眼化学伤、视网膜中央动脉阻塞
  - 核心鉴别要点：**弱而飘 = 玻璃体后脱离（非急症）；强而僵且固定连于视盘 = 视网膜脱离（A 级急症）**
- **血压三种测量方式的诊断阈值表**（`references/unit_reference.md`）：
  诊室 ≥140/90、家庭自测 ≥135/85、24 小时动态全天 ≥130/80（白天 ≥135/85、夜间 ≥120/70）。
  判读前必须先确认读数来自哪一种测量方式
- `references/plain_language.md` 新增「准用名规范」章：旧称对照表 + 歧义词黑名单
- `references/guidelines.md` 新增「时效性核对」与「指南时效性复核记录」两节，
  并显式列出**本次未复核、按原样保留**的指南，避免把「没查」当成「最新」
- `scripts/selfcheck_paths.py`（新脚本）：包完整性三项自检
  - A 零写死本机路径
  - B `SKILL_DIR` 探测目标与本包实际目录名一致
  - C 文档引用的包内文件真实存在
- `scripts/calc.py` 新增 `calcium` 子命令：白蛋白校正血钙。
  血钙偏高时必跑 —— 约 40~45% 的血钙与白蛋白结合，白蛋白偏高会把总钙带高
- `scripts/check_report.py` 新增 `--template` 模板模式，跳过目录与参考指南段的内容完整性校验

- 移除 `SKILL.md` 中写死的本机解释器绝对路径（换机器即失效）

  `data-*` 属性会导致全部正则失配，校验器反报「未找到目录」把排查方向带偏
- `check_report.py` 表格列数校验改为按渲染网格计算，正确处理 `colspan` / `rowspan`

### 已知边界

- 本技能解读影像报告的**文字结论**，不解读影像图像本身，阅片需影像科医师
- 参考区间主要适用于 18~65 岁成人；儿童与孕产妇按专用区间判读，技能会主动提示
- 危急值阈值各医院存在浮动，以报告出具机构标注为最终准据
- 以下指南版本**未经本次复核**，引用其关键阈值时会注明：C-TIRADS（2020）、
  《全国临床检验操作规程》（第 4 版）、KDIGO CKD 指南、《肥胖症诊疗指南（2024年版）》
