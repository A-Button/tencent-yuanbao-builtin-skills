# 自包含 HTML 交付边界

人格测试和塔罗牌桌均构建为单文件离线 HTML。页面负责本地交互、确定性计算或抽牌、即时展示与复制交接；Agent 只负责构建、校验、交付，以及用户主动粘贴结果后的解释。

## 页面边界

页面必须：

- 内联运行所需的样式、脚本、题库或牌库和图片；
- 人格测评 HTML 首次打开直接显示第一题，已有本地产物状态时恢复原题或结果页，不增加欢迎页或“开始”按钮这类二次启动门槛；
- 在当前浏览器保存每份产物的最小交互状态，存储不可用时仍允许继续交互；
- 先尝试 Clipboard API，再尝试浏览器 `execCommand` 兼容路径；两者都失败时显示明确的失败提示并允许用户重试，不声称页面已经复制；
- 明确说明页面内容不会自动进入对话。

页面不得：

- 请求网络、调用模型或宿主工具；
- 把完整报告、图片、随机种子或无关个人信息写入持久化存储；
- 收集与当前交互无关的身份信息；
- 把客户端内容称为签名、认证或服务器证明。

人格页面复制透明的结构化汇总数据，不复制逐题答案、隐藏提示词、哈希或设备信息。塔罗页面复制的交接内容可包含背景问题、牌阵与已揭示位次、牌名与朝向、关键词、基础/即时牌义、原型与结构、图像锚点、来源和固定解读请求；不得复制未揭示牌、随机种子、隐藏控制信息或页面实现细节。Agent 不重新抽牌。

## 交付

塔罗、人格报告和独立星盘共用结果图片弹窗组件，保存与分享行为见 [image-save-share.md](image-save-share.md)。修改或诊断图片交互时先读该文件。

生成物必须先通过对应校验器。只交付校验返回的绝对 `.html` 路径，绝不交付源模板。

产物落点由 `delivery.py` 统一解析：优先写入宿主沙盒工作区（`AGENT_WORKSPACE`，默认 `/data/workspace`），该目录之外的文件宿主既不收取也不允许创建，因此不要再让产物停留在系统临时目录。没有工作区的宿主才回退到 `secure_run_dir` 的私有目录，此时脚本会一并返回 `cleanup_command`。交付文件用中文名、`0644` 权限，同名时自动加序号，不覆盖已交付的产物。发布用独占创建后的普通拷贝，不用硬链接；沙盒工作区常见的 virtiofs 不实现 `os.link`。

交付动作服从流水线返回的 `delivery`：`ok` 为 true 时把 `media_info` 贴进回复草稿，并用 `verify_html_delivery.py` 校验后再发出。没有通过这道门就没有交付。普通源码预览、编辑器预览、Markdown 本地链接和直接贴出路径文本都不执行脚本，不能当作交互成功。

## 人格页面维护与复制契约

页面打开后直接进入答题，不设置欢迎页或二次开始入口。题目顺序与正反向键保持原样；每页题数按窗口可用高度和题目实际高度计算，调整窗口大小时保留当前题和答案。正常首次答题自动切换到未答题，当前页完成后自动换页，全部完成后显示报告；不显示“本页还剩几题”或“下一页”。上一页位于左上角。

主动回看已答题、返回上一页或从报告回看后进入常驻回看状态：选择和改答案都保留在当前题，不自动跳到未答题。顶部“继续答题”恢复自动前进并定位第一道未答题；全部答完时该入口用于返回或更新报告。窗口变化时不抢走焦点。极小窗口或放大字体导致一题也放不下时，允许滚动以保证内容可达；正常窗口的答题页保持一屏，结果报告仍可滚动。

每次生成测评 HTML 时写入独立 `artifact_id`。仅用 `localStorage` 保存该产物的题号、1—5 答案、当前题、回看状态和当前页面；答完重开时依据原答案重新计分并生成报告。重新测试清除上一轮状态。状态读写失败时继续运行当前测评；不得将逐题答案写进分享内容或复制给 Agent。

不得随机改序、自适应删题或中途展示得分；不得发起网络请求、使用其他持久化接口或收集身份资料。

复制文本使用透明的 `PERSONALITY_RESULT_V1` 数据，只包含：

- `axes`：四轴两端值和字母；
- `big_five_mean_1_to_5`：五项 1—5 原始均值。

不得复制量表版本、题数、质量标签、类型对象、逐题答案、作答分布、姓名、生日、城市、时间戳、题库哈希、编码结果码或隐藏提示词。

元宝图片、称呼、资源哈希与角色选择也不得进入复制文本；它们只属于当前结果页的视觉解释层。
