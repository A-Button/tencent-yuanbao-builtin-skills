# 生图与阅读

沿当前生图 Skill 生成日签图片。先复用用户明确选择、仍适用的历史偏好与相关 user insight；没有审美依据时，让这张签的内容决定画法、配色和构图。年龄、性别等背景本身不决定画风。

## 画面与文字

先想清楚这张签要说什么，再选一个有记忆点的画面关系或意象。纸本的停顿感、刻印的概括力、写拙的亲近感，以及轻巧插画、摄影或拼贴，都可以作为创作语言；让视角、材质、色彩和留白共同表达当张内容。生成普通物件时，赋予它与这一天有关的动作或关系，让画面有可回味的细节。

完整日签图承载真实日期、当张签名和经过筛选的签文，让用户单独打开或保存时也能读到这张签的意思。先按 [内容分层](content-directions.md#从依据到签面) 写定完整签文，再判断图上的文字层次：短而重要的内容可将全文排入图中；内容较密时，留下能独立成立的主张与必要细节，完整原文随图片在回答中直接可读。字级、意象和留白随内容调整，专业依据自然影响画面与语气，不用其标签替代签文。

给生图工具的说明写清主意象、它与这张签的联系、画法、配色、需要入图的确切文字，以及文字和画面的阅读层级。默认请求与 340×140 同比例的横版成图，而不只是让主体落在另一种比例图片的中央；用户指定其他比例或用途时按其要求生成。生成后若能直接预览，检查成图比例、画面意图与图中文字在横幅中的实际可见性；文字遗漏、错字或不易读时，沿生图能力针对那一处修正，再交付成图。

## 会话图片与此刻封面

默认一张横版完成图同时用于会话回答和此刻封面，按 340×140 窗口安排视觉主体、日期、签名与核心签文；回答正文直接呈现完整签文。横幅的信息量由这张签的含义和文字密度决定，不固定为一句口号。图中文字太密时，先精炼到仍能表达具体含义，而不是缩小字级或把专业推导挤入图中。

用户明确要竖版或其他形态时，回答沿用户选择展示一张完整图片；若同时要发此刻，再根据同一内容制作横版封面，仅用于此刻。按实际图片工具返回的媒体地址展示，不把无字底图、封面或中间稿作为回答里的第二张图。图片地址与此刻的发布状态分别以真实回执为准。
