# 八字判断方法

本文件只维护选材方法，不重新决定产物深度。普通分析直接选择相关发现；报告候选范围服从流水线当前阶段的契约。

日期级解释先检查 `chart.stable.pillars.month`。月柱不稳定时停止下列判断顺序，只说明出生时刻可能改变月柱、补充精确时间后才能继续，不输出行为或性格判断。即使传统规则允许从干支计算更多字段，也不得自行推导去身份化分析盘中不存在的十神、旺衰、格局、藏干或关系；缺失事实必须保持缺失。

## 判断顺序

1. **日主处境**：以月令为主要环境，结合根气、十二长生、印比生扶和食伤财官耗泄克制综合判断；五行数量只能旁证。
2. **主导流转**：优先看透出或重复的十神、月支主气、藏干重复和实际生克通路，只保留一个主轴。
3. **结构张力**：把刑冲合害作为张力来源；没有满足合化条件时只说明关系存在，不直接映射成事故、疾病或吉凶。
4. **落到问题**：把主轴和张力翻译到用户关心的偏好、反应、取舍或高频场景；主题边界见 [topic-selection.md](topic-selection.md)。
5. **阶段信息**：只在当前任务允许时使用已投影的 `luck_cycle_focus`，结合原局解释，不自行挑选完整大运列表或补造流年；报告中的具体输入要求由第二阶段返回。

## 选择标准

优先保留能让用户用现实经验回答“像 / 不像”的内容：

- 与投入相关的具体偏好和条件；
- 压力、协作、金钱或亲密关系中的典型反应；
- 某种做法的适用条件与局限；
- 适合发挥的工作机制，而不是行业或职位清单；
- 能由盘面结构支持的不同表现，不为形成反差而添加判断。

一个明确的盘面信号可以支持候选解释；多个信号一致时优先保留该解释，不提高对现实行为的确信程度。存在反向信号时写清不同条件；只有弱信号、换到相反盘面仍大概率成立，或无法形成可对照表现时直接省略。

## 表达

表达沿用已加载的八字分析规范和公共语气，不重复加载入口。本文中的主轴、张力等只用于判断选材；用户可见语句按输出指令写作。通用安全边界见 [safety.md](safety.md)。
