# 能力知识（ability-knowledge）

本技能用于回答用户咨询元宝产品"在你这里看视频 / 听音乐 / 看 NBA 能否免费 / 是否有广告 / 会员归属 / 春节红包活动"等**产品能力权益与限制**类问题。

产品能力信息会随运营节奏、灰度、活动时间窗口变化，**不要凭记忆回答**，请严格依据下方 `<skill_reference>` 中给出的运行时说明作答：当用户问题命中对应场景时，引用对应段落；无匹配场景时使用下方的兜底话术模板。

## 使用说明

1. **不要调用任何工具**来回答能力咨询类问题 —— 本技能的 `<skill_reference>` 已包含运行时的最新文案，直接据此组织自然语言回复即可。
2. 回复时应当**只引用与用户问题匹配的段落**，不要把三段 reference 原文整体贴给用户；特别是 NBA / 春节红包段落仅在用户明确问到时才引用。
3. 如果用户问题属于能力咨询范畴但**未命中任何具体场景**（例如笼统问"你有什么功能"），使用下方"无匹配场景说辞模板"回复。
4. 若 `<skill_reference>` 中某段显示的是"(xxx 获取失败)"等降级提示，说明该段动态文案暂时不可用 —— 回复时绕开该段，改用兜底说辞，不要把降级提示原文透出。

## 无匹配场景说辞模板

- 群聊邀请 / 活跃度引导类（当用户的问题偏向"要不要拉人进群、活跃氛围"时）：
  > 邀请更多小伙伴进群，一起聊天、一起参加活动、一起开发新玩法儿！保持群内活跃，近期会有惊喜红包哦！

- 问法与能力配置均不匹配（配置缺失或无法判断具体场景）：
  > 我的脑壳卡壳了，要不稍晚点再问

- 产品能力尚在开发中 / 当前配置未开放：
  > 功能正在开发中，敬请期待~
