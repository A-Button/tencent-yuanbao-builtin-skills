# 元宝默认写作与排版规范（Word / docx）

> 被 `SKILL.md` 引用。本文件规定**通用中文 Word 默认风格**。

## 字体与字号

| 元素 | 默认 |
| --- | --- |
| 中文正文 | 宋体（或系统等价中文衬线），**小四（12pt / 24 half-points）** |
| 长文档正文 | 可降为五号（10.5pt），但同一文档内保持一致 |
| 英文/数字混排 | 与中文正文同字号；必要时用 Times New Roman 或 Arial 作西文 fallback |
| 一级标题 | 黑体或加粗宋体，比正文大 2–4pt，不滥用颜色 |
| 二三级标题 | 加粗即可，不再放大过多层级 |

**禁止**：中文正式文档（报告、公文、论文、研报）正文默认 Arial。

## 段落与页面

- **首行缩进**：中文正文段落首行缩进 2 字符（约 420–480 DXA，或 docx-js `indent.firstLine`）。
- **行距**：正文 1.25–1.5 倍行距。
- **段前段后**：标题下 6–12pt 段后；正文段间 0–6pt，避免过大空白。
- **页面**：默认 A4；页边距中文习惯约上下 2.54cm、左右 3.17cm（除非体裁规范另有要求）。

## 标题层级

- 一级标题：文档主标题或章标题，全篇仅少量使用。
- 二级标题：节标题，编号可用「一、」「（一）」「1.」等，**同一文档内体系统一**。
- 三级及以下：不过度加粗/着色；不要用颜色代替层级。
- 用户要求「Word 标题分区」「可导航目录」或分章节交付时，必须使用内置 Heading 1/2（docx-js `HeadingLevel` 或 OOXML `w:pStyle`），不得仅用加粗正文段落冒充标题。

## 表格

- 必须有**表头行**，列名清晰。
- 数值列标注**单位**；必要时在表下注明「数据来源」或「备注」。
- 使用完整边框或清晰横线，避免无边框散列表（除非用户明确要求简约列表）。
- docx-js 表格遵循 SKILL.md「双重宽度」规则。

## 颜色与强调

- 颜色、高亮**仅**用于关键风险、核心结论或必须警示的内容。
- 不做花哨渐变、大面积色块装饰（营销封面除外，见 `illustrations.md`）。

## 体裁优先级

```
用户显式格式要求 > genre-guides.md 体裁规范 > 本文件默认风格 > docx-js 库默认（Arial）
```

公文、论文、研报、简历等**不得**套用营销号文的感叹号、口语化或「爆款标题」风格。

## 新建 vs 编辑

- **新建**（docx-js）：在 `styles.default` 与 `paragraphStyles` 中显式设中文字体与字号，勿依赖库默认 Arial。
- **编辑现有文档**：保留原稿字体体系；仅在新插入段落无法继承时，按本文件默认补齐。
