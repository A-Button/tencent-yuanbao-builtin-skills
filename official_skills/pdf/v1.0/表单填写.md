**重要：必须按顺序完成以下步骤，不要跳过。**

首先检查 PDF 是否包含可填充的表单字段。在此文件所在目录下运行：
`python scripts/detect_form_fields.py <file.pdf>`

根据结果跳转到"可填充字段"或"不可填充字段"章节，按对应流程操作。

---

# 可填充字段

如果 PDF 包含可填充的表单字段：

- 在此文件所在目录下运行：`python scripts/parse_form_fields.py <input.pdf> <field_info.json>`。它会生成一个 JSON 文件，列出所有字段，格式如下：
```
[
  {
    "field_id": (字段的唯一 ID),
    "page": (页码，从 1 开始),
    "rect": ([left, bottom, right, top] 边界框，PDF 坐标系，y=0 在页面底部),
    "type": ("text"、"checkbox"、"radio_group" 或 "choice"),
  },
  // 复选框有 "checked_value" 和 "unchecked_value" 属性：
  {
    "field_id": (字段唯一 ID),
    "page": (页码，从 1 开始),
    "type": "checkbox",
    "checked_value": (设置为此值表示勾选),
    "unchecked_value": (设置为此值表示取消勾选),
  },
  // 单选按钮组有 "radio_options" 列表，包含可选项：
  {
    "field_id": (字段唯一 ID),
    "page": (页码，从 1 开始),
    "type": "radio_group",
    "radio_options": [
      {
        "value": (设置为此值以选中该选项),
        "rect": (该选项按钮的边界框)
      },
      // 其他选项
    ]
  },
  // 下拉选择框有 "choice_options" 列表：
  {
    "field_id": (字段唯一 ID),
    "page": (页码，从 1 开始),
    "type": "choice",
    "choice_options": [
      {
        "value": (设置为此值以选中该选项),
        "text": (显示文本)
      },
      // 其他选项
    ],
  }
]
```
- 将 PDF 转换为 PNG 图片（每页一张），在此文件所在目录下运行：
`python scripts/pdf_to_images.py <file.pdf> <output_directory>`
然后分析图片，确定每个表单字段的用途（注意将边界框的 PDF 坐标转换为图片坐标）。
- 创建 `field_values.json` 文件，格式如下：
```
[
  {
    "field_id": "last_name", // 必须与 parse_form_fields.py 输出的 field_id 一致
    "description": "用户姓氏",
    "page": 1, // 必须与 field_info.json 中的 page 值一致
    "value": "张"
  },
  {
    "field_id": "Checkbox12",
    "description": "年满18岁确认复选框",
    "page": 1,
    "value": "/On" // 复选框使用其 "checked_value" 来勾选；单选按钮组使用 "radio_options" 中对应的 "value"
  },
  // 更多字段
]
```
- 在此文件所在目录下运行填充脚本：
`python scripts/populate_form_fields.py <input pdf> <field_values.json> <output pdf>`
该脚本会验证你提供的字段 ID 和值是否有效；如有错误信息，请修正后重试。

# 不可填充字段

如果 PDF 没有可填充的表单字段，需通过添加文字注释来填写。优先尝试从 PDF 结构中提取坐标（更准确），如不可行则回退到视觉估算。

## 第一步：优先尝试结构提取

运行以下脚本提取文本标签、线条和复选框的精确 PDF 坐标：
`python scripts/analyze_pdf_structure.py <input.pdf> form_structure.json`

生成的 JSON 文件包含：
- **labels**：每个文本元素及其精确坐标（x0, top, x1, bottom，单位为 PDF 点）
- **lines**：定义行边界的水平线
- **checkboxes**：小正方形矩形，即复选框（含中心坐标）
- **row_boundaries**：根据水平线计算的行上下边界

**判断结果**：如果 `form_structure.json` 包含有意义的文本标签（与表单字段对应），使用**方案 A：基于结构的坐标**。如果 PDF 是扫描件/图片型，标签很少或没有，使用**方案 B：视觉估算**。

---

## 方案 A：基于结构的坐标（推荐）

当 `analyze_pdf_structure.py` 成功检测到文本标签时使用此方案。

### A.1：分析结构

阅读 form_structure.json，识别：

1. **标签组合**：相邻的文本元素可能构成完整标签（如"姓" + "名"）
2. **行结构**：`top` 值相近的标签在同一行
3. **字段列**：输入区域起始于标签结束位置（x0 = 标签.x1 + 间距）
4. **复选框**：直接使用结构数据中的复选框坐标

**坐标系**：PDF 坐标，y=0 在页面**顶部**，y 向下递增。

### A.2：检查遗漏元素

结构提取可能无法检测所有表单元素，常见情况：
- **圆形复选框**：只有方形矩形才会被检测为复选框
- **复杂图形**：装饰性元素或非标准控件
- **颜色较浅的元素**：可能无法被提取

如果在 PDF 图片中看到了 form_structure.json 中没有的表单字段，需对这些字段使用**视觉分析**（见下方"混合方案"）。

### A.3：创建 fields.json（使用 PDF 坐标）

根据提取的结构，为每个字段计算输入区域坐标：

**文本字段：**
- 输入区域 x0 = 标签 x1 + 5（标签后的小间距）
- 输入区域 x1 = 下一个标签的 x0，或行边界
- 输入区域 top = 与标签 top 相同
- 输入区域 bottom = 下方行边界线，或标签 bottom + 行高

**复选框：**
- 直接使用 form_structure.json 中的复选框矩形坐标
- entry_bounding_box = [checkbox.x0, checkbox.top, checkbox.x1, checkbox.bottom]

使用 `pdf_width` 和 `pdf_height` 创建 fields.json（表明使用 PDF 坐标）：
```json
{
  "pages": [
    {"page_number": 1, "pdf_width": 612, "pdf_height": 792}
  ],
  "form_fields": [
    {
      "page_number": 1,
      "description": "姓氏输入框",
      "field_label": "姓氏",
      "label_bounding_box": [43, 63, 87, 73],
      "entry_bounding_box": [92, 63, 260, 79],
      "entry_text": {"text": "张", "font_size": 10}
    },
    {
      "page_number": 1,
      "description": "中国公民-是 复选框",
      "field_label": "是",
      "label_bounding_box": [260, 200, 280, 210],
      "entry_bounding_box": [285, 197, 292, 205],
      "entry_text": {"text": "X"}
    }
  ]
}
```

**注意**：使用 `pdf_width`/`pdf_height`，坐标直接取自 form_structure.json。

### A.4：验证边界框

填充前检查边界框是否有误：
`python scripts/validate_bbox.py fields.json`

该脚本会检查边界框是否重叠，以及输入框是否太小以至于放不下指定字号的文字。修复所有报错后再继续。

---

## 方案 B：视觉估算（备选）

当 PDF 是扫描件/图片型，结构提取找不到有效文本标签时使用（例如所有文字都显示为 "(cid:X)" 模式）。

### B.1：将 PDF 转换为图片

`python scripts/pdf_to_images.py <input.pdf> <images_dir/>`

### B.2：初步识别字段

检查每页图片，识别表单区域并**粗略估算**字段位置：
- 表单字段标签及其大致位置
- 输入区域（线条、方框或空白处）
- 复选框及其大致位置

为每个字段记录大致的像素坐标（不需要很精确）。

### B.3：放大精修（关键步骤，确保精度）

对每个字段，裁切其估算位置附近的区域以精确确定坐标。

**使用 ImageMagick 创建放大裁切：**
```bash
magick <page_image> -crop <width>x<height>+<x>+<y> +repage <crop_output.png>
```

其中：
- `<x>, <y>` = 裁切区域左上角坐标（用粗略估算值减去一些边距）
- `<width>, <height>` = 裁切区域大小（字段区域加约 50px 边距）

**示例：** 精修一个估算位于 (100, 150) 的"姓名"字段：
```bash
magick images_dir/page_1.png -crop 300x80+50+120 +repage crops/name_field.png
```

（如果 `magick` 命令不可用，可尝试 `convert` 加相同参数）。

**分析裁切后的图片**以确定精确坐标：
1. 确定输入区域的精确起始像素位置（标签之后）
2. 确定输入区域的结束位置（下一个字段之前或边缘处）
3. 确定输入行/框的上下边界

**将裁切坐标换算回完整图片坐标：**
- full_x = crop_x + crop_offset_x
- full_y = crop_y + crop_offset_y

示例：如果裁切起始于 (50, 120)，输入框在裁切图中位于 (52, 18)：
- entry_x0 = 52 + 50 = 102
- entry_top = 18 + 120 = 138

**对每个字段重复此步骤**，相邻字段可以合并到一个裁切中。

### B.4：创建 fields.json（使用图片坐标）

使用 `image_width` 和 `image_height` 创建 fields.json（表明使用图片坐标）：
```json
{
  "pages": [
    {"page_number": 1, "image_width": 1700, "image_height": 2200}
  ],
  "form_fields": [
    {
      "page_number": 1,
      "description": "姓氏输入框",
      "field_label": "姓氏",
      "label_bounding_box": [120, 175, 242, 198],
      "entry_bounding_box": [255, 175, 720, 218],
      "entry_text": {"text": "张", "font_size": 10}
    }
  ]
}
```

**注意**：使用 `image_width`/`image_height`，坐标为放大精修后的精确像素值。

### B.5：验证边界框

填充前检查边界框：
`python scripts/validate_bbox.py fields.json`

检查项：边界框是否重叠、输入框尺寸是否足以容纳文字。修复所有报错后再继续。

## 混合方案：结构 + 视觉

当结构提取对大部分字段有效、但遗漏了某些元素（如圆形复选框、非标准控件）时使用。

1. 对 form_structure.json 中已检测到的字段使用**方案 A**
2. **转换 PDF 为图片**，对遗漏字段进行视觉分析
3. 对遗漏字段使用**方案 B 的放大精修**
4. **合并坐标**：结构提取的字段使用 `pdf_width`/`pdf_height`；视觉估算的字段需将图片坐标转换为 PDF 坐标：
   - pdf_x = image_x * (pdf_width / image_width)
   - pdf_y = image_y * (pdf_height / image_height)
5. 在 fields.json 中**统一为一种坐标系** —— 全部转换为 PDF 坐标，使用 `pdf_width`/`pdf_height`

---

## 第二步：填充前验证

**务必先验证边界框再填充：**
`python scripts/validate_bbox.py fields.json`

检查项：
- 边界框是否相互重叠（会导致文字叠加）
- 输入框是否太小以至于放不下指定字号

修复 fields.json 中的所有错误后再继续。

## 第三步：执行填充

填充脚本会自动检测坐标系并进行转换：
`python scripts/annotate_pdf_form.py <input.pdf> fields.json <output.pdf>`

### 关于中文内容

`annotate_pdf_form.py` 使用 pypdf 的 FreeText 注释写入文字，**只能写入字体名，不嵌入字体文件**。`entry_text` 里的 `font` 字段本质上只是写到 PDF 的 `/DA` 字符串里，给阅读器一个"建议"。中文在不同阅读器中的表现取决于阅读器的字体回退：Adobe Reader / Chrome / Preview 通常能自动回退到系统 CJK 字体；但若 PDF 发布到未安装中文字体的环境，可能渲染成方块。

当需要**确保跨阅读器可靠显示中文**时，不要用 FreeText 注释，改用 **overlay（叠加页）方案**：先用 ReportLab 生成一张相同尺寸、仅含要填写文字的透明页（使用 SKILL.md 「中文字体注册（必读）」一节给出的 7 行片段注册思源黑体），再用 pypdf 的 `page.merge_page()` 将其合并到目标页上。这样文字会以真实字形嵌入进 PDF，不依赖阅读器的字体系统。

## 第四步：验证输出

将填好的 PDF 转换为图片，检查文字定位：
`python scripts/pdf_to_images.py <output.pdf> <verify_images/>`

如果文字位置不对：
- **方案 A**：确认是否使用了 form_structure.json 中的 PDF 坐标，且 pages 中使用了 `pdf_width`/`pdf_height`
- **方案 B**：确认图片尺寸是否正确，坐标是否为精确的像素值
- **混合方案**：确认视觉估算字段的坐标转换是否正确
