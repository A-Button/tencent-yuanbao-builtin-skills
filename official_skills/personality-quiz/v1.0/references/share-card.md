# 通用分享图卡

分享图卡是主回答完成后的可选展示层，不是新的占卜方法，也不是 `conclusion / analysis / report` 之外的产物层级。它把已经确认的结论压缩到固定竖版模板中，便于阅读、保存和分享；渲染工具不得补写盘面判断或重新解释用户资料。

## 何时生成

请求字段使用 `share_card`：

- `required`：用户明确要求“图卡、海报、分享版、保存成卡片”等，内容通过安全检查后必须生成。
- `forbidden`：用户明确不要图卡，或内容含隐私、高影响建议、第三方敏感推断，禁止生成。
- `auto`：只由进入 Skill 前已经配置好的宿主策略写入，Agent 不自行开启。只有内容已经冻结、适合公开表达、压缩后仍不失真，并且能完成渲染、校验和 `<media_info>` 交付整条链路时才生成；未完成全链路时静默跳过，不能口头声称已经生成。跳过图卡不影响主回答交付。

字段缺失时默认 `forbidden`；用户明确要求图卡时改为 `required`。不得为了决定是否生成图卡增加一次询问。

是否生成图卡不能反向改变主路由。八字、天体星座、紫微、印占、塔罗或娱乐内容仍按各自方法生成结论；图卡只是最后一步的展示转换。本版本的人格测试使用页面内结果与打印保存，不提供独立人格分享卡。

## 输入澄清

优先复用当前会话或已验证产物中的冻结结论；来源存在时直接整理，不询问模板、视觉偏好或出生资料。模板按内容确定，分享卡不得成为重新排盘或补充个性化判断的入口。

没有冻结结论时，`auto` 静默跳过。只有用户明确要求图卡时，才可用一次普通自由输入请其粘贴或概括希望放入卡片的已确认结论；不调用多轮选择题，也不收集新的出生资料。一次补充后仍无可追溯或可安全公开的内容，就说明无法生成并结束。

## 三类模板

| `template_id` | 适合内容 | 必需结构 |
|---|---|---|
| `profile` | 星座/星盘、命盘结构概览 | 一个主标识、1—4 个结构项、简短总结 |
| `insight` | 单条牌意、阶段洞察、一个最重要的结论 | 一个主标识、1—3 个关键词、简短总结 |
| `guide` | 喜用宜用、当下可采用的侧重点、三个并列提醒 | 2—4 个并列项、简短总结；不使用伪精确分数 |

模板借鉴常见分享卡的竖版信息层级：强标题、主视觉、摘要模块和底部边界说明。不得照搬第三方品牌、二维码、商标、文案或受版权保护的牌面图片。

## 输入契约

```json
{
  "schema_version": "1.0.0",
  "product_kind": "share_card",
  "template_id": "profile",
  "source_kind": "western",
  "eyebrow": "星盘速览",
  "title": "关系中的平衡感",
  "subtitle": "把复杂结果收束成一张可分享的卡",
  "highlight": {
    "symbol": "♎",
    "title": "太阳 · 天秤",
    "caption": "重视协调与公平"
  },
  "keywords": ["协商", "审美", "关系感"],
  "items": [
    {"symbol": "☽", "title": "月亮 · 白羊", "caption": "情绪反应直接"}
  ],
  "summary": "先确认彼此在意的标准，再做决定，通常比急着给出唯一答案更有效。",
  "sections": [
    {"title": "适合分享的结论", "body": "偏好协调不等于回避立场；关键是为取舍设定清楚的截止点。"}
  ],
  "footer": {
    "date": "2026-08-25",
    "boundary": "基于本次结果的简版整理，不代表确定预测。"
  },
  "suitability": {
    "contains_birth_data": false,
    "contains_identity_data": false,
    "contains_high_impact_advice": false,
    "contains_third_party_inference": false
  }
}
```

`source_kind` 允许 `bazi`、`western`、`ziwei`、`vedic`、`tarot`、`entertainment`。图卡只接收可公开的冻结结论，不接收原始命盘、出生日期/时间/地点、姓名、账号信息、`signal_paths`、候选判断或模型提示词。若按上述一次补充仍没有可追溯的冻结结论，跳过图卡，不让模型为了填满 schema 新增判断。

长度上限由渲染器强制执行：标题 24 字、摘要 180 字、单节正文 140 字；关键词最多 3 个、结构项最多 4 个、补充段最多 3 个。调用前直接从已冻结结论中选择更少内容；超限时渲染失败，不自动缩小字号、截断语义或触发反复改写。

## 渲染

```bash
python3 scripts/artifact_pipeline.py share-card <run_dir>/share-card.json
```

不传 `--output`，落点由流水线解析到宿主能收取的位置并在 `output` 返回。

流水线依次调用渲染器和校验器，再把已验证文件独占拷贝到目标路径；失败时不留下可交付的半成品，也不覆盖已有文件。脚本失败时不要改流水线、不要自己搬文件。渲染器只做输入校验、转义和模板排版，校验器从同一 JSON 重建期望页面并进行字节级比对。独立渲染器和校验器只用于开发、诊断与离线审计。

交付状态固定为：`input_ready → renderer_ok → verifier_ok → delivery_ok`。流水线返回 `delivery.ok=true` 后，必须把 `media_info` 贴进回复草稿并运行 `verify_command`，通过后才进入 `delivery_ok`：

- `delivery_ok`：可说“分享卡 HTML 已生成并附上”。
- 文件已写出但 `delivery.ok` 为 false，或校验命令未通过：只能按返回的 `delivery.message` 说明未附上，不得使用完成时态。
- 渲染或校验失败：明确说未生成或交付失败，不得使用完成时态。

当前渲染器只生成 HTML。宿主可另行把已校验 HTML 截图或导出为 PNG，但只有真实 `.png` 文件存在且已展示时才能说“分享图片/海报已生成”；计划截图或可导出不等于图片已经生成。

## 禁止生成

- 含完整出生日期、时间和地点组合，或其他可识别个人的信息。
- 医疗、法律、财务、升学、就业等高影响决定的吉凶、概率或行动指令。
- 对第三方忠诚、犯罪、疾病、性取向、秘密或精神状态的推断。
- 必须依靠长上下文才能理解，压缩后会把条件性判断变成必然结论。
- 为了视觉效果新增“综合运 86”“成功率 90%”等没有来源的数字。
