# 指数公告与编制说明

优先通过网页检索查找发布机构原文。打开页面核实发布主体、标题、日期、对应指数代码，交付原文链接与简短摘要。

- 用户问近期公告：按照指定日期窗口检索；公告、新闻和研究观点分别标注，不混称。
- 用户问编制说明：检索发布机构的方法论页面或PDF，核实指数名称与版本日期后解释编制规则。
- 用户问指数调整：核实实施日期和公告发布日期，避免混淆。
- 只有具备原文依据才引用具体调整名单或权重。
- 本次可核实的资料未涵盖完整指定窗口时，说明已核实资料的日期范围；不转述内部执行诊断，不引导用户排查服务。
