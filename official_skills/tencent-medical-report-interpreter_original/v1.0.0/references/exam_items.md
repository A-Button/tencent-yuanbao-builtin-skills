# 指标 → 检查项目映射表

> **用途**：每个指标必须说清它属于哪个检查项目。
> **为什么必需**：用户拿报告去医院，医生问「上次查了什么」，答**「血脂四项」远比答「LDL 高」有效** ——
> 前者医生能直接开单，后者还要反问。这直接决定复查能不能顺利完成。

---

## 一、四类标注写法

| 情形 | 写法 | 示例 |
|---|---|---|
| 有标准子项目名 | 直接用项目名 | **血脂四项**、**肝功能**、**甲功三项**、**血常规** |
| 大项目下的单指标 | 大项目 · 子类 | 生化全项 · 血糖、生化全项 · 电解质 |
| 由其他指标算出 | 计算得出 | 腰高比、AST/ALT 比值、eGFR、BMI |
| 本次未查但建议加 | 未查 · 建议加项 | Lp(a)、TPOAb、UACR |

**第四类必须单列**。告诉用户哪些指标本次套餐没包含、需要额外开单，否则用户会以为「查过了」，
复查时漏项，白跑一趟。

---

## 二、体检套餐的项目层级

理解这个层级是正确标注的前提：

```
体检套餐
├── 一般体格检查        身高、体重、腰围、血压、脉搏
├── 血常规              红细胞系、白细胞系、血小板系
├── 尿常规              尿蛋白、尿糖、尿沉渣
├── 便常规 + 隐血
├── 生化全项            ← 最大的容器，内含多个标准子项目
│   ├── 肝功能          ALT、AST、GGT、ALP、总蛋白、白蛋白、胆红素
│   ├── 肾功能          肌酐、尿素氮、尿酸、胱抑素C
│   ├── 血脂四项        总胆固醇、LDL-C、甘油三酯、HDL-C
│   ├── 血糖            空腹血糖
│   ├── 电解质          钾、钠、氯、钙、镁、磷
│   └── 心肌酶 / 酶类   CK、CK-MB、LDH
├── 甲功三项 / 五项      TSH、FT3、FT4（+ TPOAb、TgAb）
├── 糖化血红蛋白 HbA1c
├── 肿瘤标志物          AFP、CEA、CA125、CA19-9、PSA…
├── 凝血功能            PT、APTT、INR、D-二聚体
├── 心电图
├── 腹部超声            肝、胆、胰、脾、肾
├── 甲状腺超声
├── 乳腺超声 / 钼靶
└── 胸部影像            DR 或 低剂量 CT
```

> **关键点**：「生化全项」是容器不是项目。用户说「我查了生化」时，
> 里面可能含也可能不含血脂四项，取决于套餐配置 —— 需按报告实际项目判断。

## 三、常见指标归属速查

### 3.1 血脂

| 指标 | 所属项目 |
|---|---|
| 总胆固醇 TC | **血脂四项** |
| LDL-C（坏胆固醇） | **血脂四项** |
| 甘油三酯 TG | **血脂四项** |
| HDL-C（好胆固醇） | **血脂四项** |
| 非 HDL-C | 计算得出（TC − HDL-C） |
| ApoA1 / ApoB | 血脂扩展项（部分套餐含） |
| Lp(a) 脂蛋白 a | **未查 · 建议加项**（主要由遗传决定，多数套餐不含） |
| AIP 致动脉粥样硬化指数 | 计算得出（log(TG/HDL-C)） |

> **复查话术**：「查血脂四项」即可，不用逐个报指标名。

### 3.2 血糖与代谢

| 指标 | 所属项目 |
|---|---|
| 空腹血糖 | 生化全项 · 血糖 |
| 餐后 2 小时血糖 | OGTT 糖耐量试验（需单独预约） |
| HbA1c 糖化血红蛋白 | **糖化血红蛋白**（独立项目，反映近 3 月平均血糖） |
| 空腹胰岛素 | **未查 · 建议加项**（算 HOMA-IR 需要） |
| HOMA-IR 胰岛素抵抗指数 | 计算得出 |
| C 肽 | 未查 · 建议加项 |

### 3.3 肝脏

| 指标 | 所属项目 |
|---|---|
| ALT 谷丙转氨酶 | **肝功能** |
| AST 谷草转氨酶 | **肝功能** |
| GGT 谷氨酰转肽酶 | **肝功能** |
| ALP 碱性磷酸酶 | **肝功能** |
| 总蛋白 / 白蛋白 | **肝功能** |
| 总胆红素 / 直接胆红素 | **肝功能** |
| AST/ALT 比值 | 计算得出 |
| FIB-4 肝纤维化评分 | 计算得出（需 年龄 + AST + ALT + 血小板） |
| 肝脏回声 / 脂肪肝 | **腹部超声** |
| 乙肝五项 | **乙肝血清学检查**（独立项目） |

### 3.4 肾脏

| 指标 | 所属项目 |
|---|---|
| 肌酐 Cr | 生化全项 · **肾功能** |
| 尿素氮 BUN | 生化全项 · **肾功能** |
| 尿酸 UA | 生化全项 · **肾功能** |
| 胱抑素 C | 肾功能扩展项 |
| eGFR 估算滤过率 | 计算得出（由肌酐 + 年龄 + 性别算） |
| 尿蛋白（定性） | **尿常规** |
| UACR 尿白蛋白/肌酐比 | **未查 · 建议加项**（早期肾损伤最敏感，需单独留尿） |

> UACR 是糖尿病与高血压患者的关键筛查项，**多数常规套餐不含**，必须提示加项。

### 3.5 电解质与心肌

| 指标 | 所属项目 |
|---|---|
| 钾 K⁺ / 钠 Na⁺ / 氯 Cl⁻ | 生化全项 · **电解质** |
| 钙 / 镁 / 磷 | 生化全项 · **电解质** |
| CK 肌酸激酶 | 生化全项 · **心肌酶** |
| CK-MB | 生化全项 · **心肌酶** |
| LDH 乳酸脱氢酶 | 生化全项 · **酶类**（判断溶血的关键线索） |
| 肌钙蛋白 TnI/TnT | **心肌损伤标志物**（急诊项目，体检套餐通常不含） |
| BNP / NT-proBNP | 心衰标志物（未查 · 建议加项） |

### 3.6 血常规

| 指标 | 所属项目 |
|---|---|
| 红细胞 RBC / 血红蛋白 Hb | **血常规** |
| MCV / MCH / MCHC / RDW | **血常规** |
| 白细胞 WBC 及五分类 | **血常规** |
| 血小板 PLT / MPV | **血常规** |
| 铁蛋白 / 血清铁 / 转铁蛋白饱和度 | **铁代谢四项**（未查 · 建议加项，判断贫血类型必需） |
| 叶酸 / 维生素 B12 | 未查 · 建议加项（大细胞性贫血需要） |

> **贫血分型必须靠铁代谢四项**，光有血常规只能看出「有没有贫血」，看不出「为什么贫血」。

### 3.7 甲状腺

| 指标 | 所属项目 |
|---|---|
| TSH 促甲状腺激素 | **甲功三项** |
| FT3 游离三碘甲状腺原氨酸 | **甲功三项** |
| FT4 游离甲状腺素 | **甲功三项** |
| TPOAb 甲状腺过氧化物酶抗体 | **甲功五项**（三项套餐不含，需加项） |
| TgAb 甲状腺球蛋白抗体 | **甲功五项** |
| 甲状腺结节 / 回声 | **甲状腺超声** |

> TSH 升高时**必须提示加做 TPOAb** —— 它决定是不是自身免疫性甲状腺炎，影响后续处理。

### 3.8 一般体格检查与计算项

| 指标 | 所属项目 |
|---|---|
| 身高 / 体重 / 腰围 / 臀围 | **一般体格检查** |
| 血压 / 脉搏 | **一般体格检查** |
| BMI 体重指数 | 计算得出（体重 ÷ 身高²） |
| 腰高比 | 计算得出（腰围 ÷ 身高） |
| 腰臀比 | 计算得出 |

### 3.9 影像

| 发现 | 所属项目 |
|---|---|
| 肝/胆/胰/脾/肾 描述 | **腹部超声** |
| 甲状腺结节（含 C-TIRADS 分级） | **甲状腺超声** |
| 乳腺结节（含 BI-RADS 分级） | **乳腺超声** 或 **钼靶** |
| 肺结节（含 Lung-RADS 分级） | **胸部 CT**（DR 平片分辨率不足） |
| 颈动脉斑块 / 内膜增厚 | **颈动脉超声**（未查 · 建议加项） |

## 四、「未查 · 建议加项」的高频清单

按触发条件组织 —— 出现左列情况就应提示加做右列项目：

| 触发条件 | 建议加项 | 理由 |
|---|---|---|
| TSH 升高或持续上升 | TPOAb、TgAb | 判断是否自身免疫性甲状腺炎 |
| 糖尿病 / 高血压 | UACR、眼底检查 | 早期肾损伤与视网膜病变筛查 |
| 血脂异常 + 早发心血管家族史 | Lp(a) | 遗传性风险，常规血脂查不出 |
| 贫血 | 铁代谢四项、叶酸、B12 | 只有血常规无法定型 |
| 单次空腹血糖 6.1~6.9 | OGTT、HbA1c | 确诊糖尿病前期或糖尿病 |
| ALT 升高 | 乙肝五项、腹部超声、FIB-4| 排除病毒性与评估纤维化 |
| 尿酸升高 | 24h 尿尿酸、关节超声 | 区分生成过多与排泄减少 |
| 血钾异常 | 复查电解质 + 心电图 | 排除溶血假性升高、评估心脏影响 |
| 腰围超标 | 空腹胰岛素、颈动脉超声 | 评估胰岛素抵抗与动脉粥样硬化 |
| 40 岁以上从未查过 | 心电图、颈动脉超声、幽门螺杆菌 | 基线筛查 |

## 五、「跟医生怎么说」对照表

按**检查项目**说，比只报指标名有效。输出第 08 段时应包含此对照：

| 这样说 | 而不是 |
|---|---|
| 「**血脂四项**里坏胆固醇 3.2，我有糖尿病要压到 2.6 以下」 | 「我 LDL 高」 |
| 「**生化全项**里血钾 5.9，想确认是不是溶血」 | 「我钾高」 |
| 「**甲功三项**的 TSH 三年从 2.1 涨到 4.0，想加做 TPOAb」 | 「我甲状腺有问题」 |
| 「**肝功能**里 ALT 62，**腹部超声**提示轻度脂肪肝」 | 「我肝不好」 |
| 「**血常规**显示血红蛋白 105，没查过铁代谢四项」 | 「我贫血」 |

**关键**：说项目名 + 具体数值 + 自己的目标或疑问，医生三秒内就能判断要开什么单。

## 六、标注注意事项

| 注意 | 说明 |
|---|---|
| 不确定归属时用大项目名 | 宁可写「生化全项」，不要猜具体子项目名 |
| 报告已写项目名则照用 | 各医院套餐命名有差异，以报告原文为准 |
| 「计算得出」要说明依据 | 「eGFR（由肌酐、年龄、性别计算得出）」 |
| 加项要说清是否需特殊准备 | UACR 需留尿、OGTT 需空腹并耗时 2 小时、糖化血红蛋白无需空腹 |
| 不推荐具体体检套餐或机构 | 只说需要哪些项目，不做商业推荐 |
