## 0. 分流与触发

> 本技能只回答两件事：**① 这条诉求触不触发**（什么是空间设计图、什么不算）；**② 触发后怎么分流**（3D 还是 2D、有底图怎么走）。先判定触发，再考虑分流。细节见对应正文节。

### 0.1 触发判定
以下诉求即触发，无需出现"3D/效果图/2D/平面"字样：
- **室内/商业/公共空间**：住宅客厅卧室厨房、餐饮奶茶咖啡门店、展厅大堂会所办公零售车站等——只要要的是"人在空间内、看得到天花/立面材质/空气光影/透视景深"，默认按 3D 渲染；门店"适合拍照打卡/网红风"等营销描述不改变空间渲染本质；多区域分图（主空间/吧台区/卡座各一张）即取多个机位。
- **建筑外观**：立面表现、楼栋透视、体量三维表现。
- **景观**：庭院/花园/广场/园林的实景渲染、鸟瞰、3D 大样。
- **有底图旧改**：按载体性质归流（旧卧室图→室内、旧楼→建筑、旧庭院→景观），不按输入媒介分类。
- **2D 平立/展板**：顶视/俯视平面图纸、彩平、功能分区与家具点位、立面标注、平立剖展板（如监控中心平面图、手绘草图转彩平、立面标注图）。

**不触发与边界（归 commercial_design 或外部）**：
- **不触发**：画面主体是商品/角色/纯卖货主图、详情页、无空间环境；没有空间结构的纯平面海报 / 图形。
- **仍触发**：空间内"展示墙/陈列墙/装备墙"作为墙面陈设界面呈现的（有空间环境 = 触发）。
- **红线·门店装修 ≠ 商品卖货**：奶茶/咖啡/餐饮门店的"室内装修透视效果图"（有空间、人在店内）属本技能；仅当画面主体是无空间的奶茶商品/菜单/促销海报才归 commercial_design。口诀：看得到天花立面与空间纵深 → 触发；只看到商品无空间 → 不触发。
- **红线·平面/格局改动 100% 归 2D**：凡"改家具平面位置 / 改平面图 / 重设计平面布局 / 手绘草图转彩平" → 严禁误判 3D；仅当用户明确要"具 3D 纵深透视的效果图"才走 3D。
- **红线·"平面图"字样优先归 spatial_design，勿误判 infographic_design**：凡诉求出现 **"平面图 / 彩平 / 平面布局图 / 户型图 / 立面图 / 平立剖 / 总平面图"** 等空间制图字样 → **默认优先进入 `spatial_design`（本技能 2D 平立/展板大类，见第 3 节）**，严禁因"含图表/标注/排版"特征被误分到 `infographic_design`（信息图设计）。判据：内容主体是**"承载空间/建筑/户型的几何骨架（轴线·墙体·分区·家具点位·标高）"** → 归本技能；仅当内容主体是**"与空间无关的数据可视化/流程图/信息版式（图表·数据·概念示意，无空间几何骨架）"** 才归 `infographic_design`。口诀：图里有"空间格局" → spatial_design；图里只有"数据/信息" → infographic_design。
- **红线·多层面混合**：鸟瞰同时含建筑+景观+室内 → 按内容占比选主工作流，其余"快速跟随"做必要补充。

### 0.2 分流逻辑
> 两步定位，落到下表唯一一行。

**第 1 步：要 3D 还是 2D？**
- 想看"人在空间里"的天花 / 墙面 / 材质 / 光影 / 透视感 → **3D**（第 2 大类）
- 想看"俯视 / 正投"的平面、彩平、立面标注、展板 → **2D**（第 3 大类）

**第 2 步：有没有底图？怎么用？**
- 无底图：直接生成。
- 有底图、且**同维度**改：单图精修 / 局部编辑（如实拍翻新、效果图重渲、已有彩平改方案）。
- 有底图、且**跨维度**升：2D 平面 / CAD → 3D 透视。

| 你要的结果 | 有无底图 | 走哪条 | 做什么 |
|---|---|---|---|
| 3D 透视效果图 | 无 | 无底图全流程 | 四步：分析 → 布局 → 锚相机 → 出图 |
| 3D 透视效果图 | 有（图本身已是 3D 空间） | 同维精修 | i2i 精修 / 局部编辑 / 效果重渲 |
| 3D 透视效果图 | 有（给的是 2D 平面 / CAD） | 跨维升维 | 2D 底图 → 3D 转化 |
| 2D 彩平 / 立面 / 展板 | 无 | 无底图全流程 | 五步 T2I |
| 2D 彩平 / 立面 / 展板 | 有（图类相同或要改） | 同维精修 | 转图类 / 精修 / 改方案 |

## 1. 风格基因引擎（顶层决策 + 映射表，3D/2D 共享）

### 1.1 风格求解
- **经典单风格绑定**：用户明确给出映射表中的风格 → 直接关联其空间拓扑、色彩系统、材质肌理、标志性物体锚点。
- **跨流派混搭百分比**：若用户提出混搭需求（无论是表内，还是表外自建流派），AI 必须在后台智能测算并划定各风格的占比（例如：`70% 现代法式作为硬装墙面天花基底 + 30% 南洋复古作为木百叶软装和局部铜件点缀`），后续工作流的平面布局、立面、陈设与色调均完美按此百分比进行交叉融合。
- **表外新流派自建推理**：指向映射表外风格时，完全参照"四维一体"架构（空间拓扑与光影、色彩系统、材质与肌理、标志性物体锚点）自主推理构建一套专属风格基因，不局限于表内。
- **主动创意发散**：映射表锚点仅作"种子骨架"，须自主发散搭配更多符合流派的高阶单品与特殊构造，杜绝死搬。
- **一脉相承一致性**：确立风格配比后，后续所有机位的材质、色彩、落光方向、色温、机位构图必须继承该底座，禁止跨视角时空割裂。

### 1.2 无风格偏向时的智能推荐
用户未限定风格时，依两类线索自行判断：
- **空间业态自适应**：按业态气质定基底风格，由 AI 灵活权衡、无需死板配比——商业/公共空间取包豪斯基底并做主结构变异避免千馆一面；居住类在韩系 ins 留白与阿尔托温润间取舍；度假/别墅融南洋复古与新中式；园林以现代骨架借安藤/日式收束意境。
- **底图特征逆向**：已有底图须尊重既有特征——工业框架/粗梁柱 → 包豪斯；圆弧门框/极窄踢脚线 → 韩系 ins；中式窗格/深木对称 → 新中式或古典中式。

## 2. 3D 透视效果大类

> 本大类统一管 3D 透视效果图：先走工作流（2.1，按输入状态分派）→ 再看零件库（2.2，语法 + 通用规范 + 业态内容，被 2.1 调用）→ 出图前过自检闸门（2.3）。

### 2.1 3D 生图工作流

> 生图流程。按输入状态分三条：无底图 → 2.1.1（T2I 四步，7 槽全填）；有底图·同维 → 2.1.2（I2I，②③ 锁死继承、①④⑥ 写变更）；有底图·跨维 → 2.1.3（2D 底图作骨架，重拼 ①③④⑤⑥⑦）。具体每个槽怎么填，跳 2.2 零件库。

#### 2.1.1 无底图主流程（T2I · 四步框架）
走 2.1.1.1–2.1.1.4 四步框架，内容参数由 2.2.2（室内/建筑/景观）注入。槽位全量拼装按 2.2.0 语法。

##### 2.1.1.1 第 1 步：诉求分析
- 运行风格基因引擎（1.1/1.2）判定风格及混搭占比。
- 槽位分析：`base_image`（无）、`space_type`、`area`、`style`、`target_users`、`rooms`、`views`、`aspect_ratio`（室内主视角 16:9 或 4:3；竖向高空间 3:4；鸟瞰 1:1 或 4:3）。
- 室内须主动校核三大功能前提：电视与沙发绝对面对面（或无电视则对艺术留白墙）；吧台/中岛操作侧留通行开口；绿植有盆器、不堵道。

##### 2.1.1.2 第 2 步：布局方案（平面优先）
- 结构骨架：墙体/门窗洞口/固有结构/开间进深/层高。工装空间默认大轴网不小于 `8m × 15m`；层高——挑高图 ≥ `4.5m`、标准层高图按工装普通尺度（约 `4.2–4.8m`）。
- 家具与软装：逐件标注位置/尺寸/朝向/动线；从风格表软装招牌库选 1–2 件作招牌，其余同风格未具名家具填充；植物按内容参数分层分区（≥3 种、风格表优先）。
- 人体工程学校核：主通道 ≥800–1000mm；沙发与茶几 300–450mm；吧台前过道 ≥900mm 等。
- 立面与结构：焦点墙 60–70% 主材 + 20–30% 辅材 + 5–10% 点缀；④ 槽位须从风格结构动作库选 1–3 个主结构呈现（如 开放平面/悬挑体块/光井/片墙）；室内天花体量/第五立面由 `2.2.1.2 天花体量选配包` 注入（工装挑高类 1–2 个机位图、其余标准层高，B 仅挑高图须含显性结构），不再单列"顶面动作库"。
- 灯光联动风格：暗藏灯带 / 洗墙灯 / 重点射灯，按风格选用，不强制。

##### 2.1.1.3 第 3 步：在平面上锚定相机（构图增益核心）
- 所有相机锚定同一平面 → 多视角天然自洽。
- 每个相机定义：平面位置、高度（成人 1.3–1.5m / 儿童 1.0–1.2m）、视线方向、焦距（24–28mm 主力 / 35–50mm 特写 / ≤18mm 慎畸变）、透视类型（强制移轴校正，垂直线条笔直不歪）。
- 校核：电视沙发面对面、吧台操作开口、植物不堵道不凭空冒出。
- 从 2.2.2.1/2.2.2.2/2.2.2.3 相机预案选 1 个锁定，并按 2.2.0 槽③ 布局三层字典填充。

##### 2.1.1.4 第 4 步：由视角推导效果图 + 自检
- 站在相机点推断可见内容（前景家具/中景主体/背景墙窗/可见天花立面/透视落地）。
- 校核电视沙发面对面呈现、吧台入口可见、植物真实合理生长。
- 全局 DNA（色彩/材质/光影）跨视角死锁。
- 出图前 5 铁律（见 2.2.2.1/2.2.2.2/2.2.2.3 末尾）。

#### 2.1.2 有底图 · 同维精修（I2I）
> 有底图即"继承几何/机位为先"，任何变更不得破坏底图空间骨架。分两态：单图精修、局部编辑。I2I 槽级规则：顶部声明 `base_image: <路径>`，`② 机位`/`③ 布局` 默认 `[继承底图]` 不重写；`① 风格`/`④ 材质`/`⑥ 光影` 改为变更指令（只写要改成什么）；`⑦ 渲染尾部` 同 T2I。

##### 2.1.2.1 单图精修（实拍/毛坯/旧图/效果图 → 翻新/替换/微调）
- 触发：用户提供单张实拍/毛坯/旧图/效果图（含用户给的参考底图），要求翻新、软装替换、材质替换、风格微调、或将底图深化/重渲为效果渲染。
- 路由：按"物理空间载体性质"归流到对应内容（室内/建筑/景观），非按输入媒介。
- 执行：`base_image` 声明 + I2I 槽级规则（继承机位/布局，只写变更）。仅改局部走 `local-edit`（见 4.1）。
- 渲染升级（I2I 下的 ① ④ ⑥ 注入）：用户"有渲染要求"时，① 风格/④ 材质/⑥ 光影改为变更指令注入，但**底图几何与机位锁死**，只在材质/光影/风格层面升级，不重写 ② ③。
- **实拍周边场地 P 进效果图（环境合成）**：当用户在做效果图/渲染、且手上有一张**实拍周边场地**（窗外街景、庭院现状、景观环境、相邻建筑等），可把这张实拍作为环境背景**合成进效果图**的对应位置——以 `reference_image`（环境 transfer 模式）输入，仅在 **⑤ 借景/环境** 槽注入，让效果图的窗景/庭院/背景与真实场地一致；**严格只 transfer 环境、不 transfer 几何/物体**，实拍里的临时杂物/无关人物/与成品无关元素不得塞入。即"主体按风格渲染、周边环境用真实实拍兜底"，避免凭空编造窗外景/场地。

##### 2.1.2.3 局部编辑（local-edit）
- 仅改局部时启用：`edit_mask` 圈定区域，mask 外像素锁死（通用规范见 4.1）。

#### 2.1.3 有底图 · 跨维升维（2D 底图 → 3D 转化）【亮点待强化】
- 触发：用户提供 2D 底图（平面/CAD/手绘/立面线框）要求转化为 3D 透视效果图。
- 路由：判定载体性质（室内平面→A / 建筑立面→B / 景观总平→C）。
- 执行：以 2D 底图为空间骨架约束（墙体/开间/层高/门窗位置锁死），在 3D 语法（2.2.0）下重新拼装 ① 风格 ④ 材质 ⑤ 借景 ⑥ 光影 ⑦ 尾部，并重新锚定 3D 相机（由 2D 平面推导 ② 机位、由平面布局推导 ③ 布局）生成透视。
- **转化亮点（待强化方向）**：2D→3D 的"空间还原保真 + 风格化升维"增益点尚在探索（如如何把平面逻辑无误翻译为透视几何、如何避免跨维穿帮），待补充具体规则。

### 2.2 3D 零件库

> 本块是语法骨架 + 每个槽的填充规范 + 按业态的内容注入。被 2.1 工作流调用。先读 2.2.0 看整体骨架，再按「通用规范 / 业态内容」两块填充各槽。

#### 2.2.0 结构化拼装语法（7 槽位，顺序固定）
```text
[① 风格DNA] + [② 机位/焦段] + [③ 布局: 前景→中景→背景] + [④ 立面/材质/结构（工装必须从风格结构动作库选 1–3 个主结构呈现，家装必须选天花）] +
[⑤ 借景/环境] + [⑥ 光影天气/季相] + [⑦ 渲染尾部]
```

| 槽 | 数据来源 | 填法要点 |
|---|---|---|
| ① 风格DNA | 风格映射表 | 如 `新中式庭院`、`南洋复古热带度假` |
| ② 机位/焦段 | 内容参数相机预案 + 2.2.1.2 A项体量 | `预设三框景借景 @ 1.4m / 90°正投`；选 `2.2.1.2 A项=大挑高/斜顶` 时，机位混排须带挑高广角词（双倍层高、垂直往上透视、广角镜头 等，见 2.2.1.2） |
| ③ 布局三层 | 三层字典驱动（前景→中景→背景 三段） | `前景→中景→背景` 三段，每段具体名词 |

#### 2.2.1 通用规范（填 ④⑥⑦，跨业态不变）
> 以下细则所有业态共用，填 ④ 立面/材质、⑥ 光影、⑦ 尾部。

##### 2.2.1.1 ④ 材质肌理物理化规范（极致写实 · 物理级质感颗粒）
- **大一统写实底色（实拍照片质感为基准）**：整套流程以"真实相机在空间现场拍下的照片"为质感基准，而非精修建筑效果图——保留自然现场光的不均匀、真实材质磨损与环境真实感，屏蔽一切模糊、卡通与 CG 渲染感；材质描述须逼出生图引擎对光的最细腻漫反射与真实颗粒计算，拒绝发灰、扁平、塑料壳观感（与 2.2.1.4 零模糊死锁配合卡死）。
- 微水泥/抹灰/艺术涂料：哑光抹灰肌理，计算极细颗粒微漫反射（拒绝大白墙死板无质感）
- 饰面/地坪/造型：富有真实肌理、高级哑光处理
- 大理石/瓷砖/金属：高光反弹、高细节奢石裂纹理（金属仅局部点缀处出高光，勿全屋反光成塑料壳）
- 木饰面/木格栅/实木：木纹纤维结构细部、真实触觉肌理
- 藤编/粗麻/棉麻织物：藤编透空孔隙与经纬手工织纹
- 绿植叶色：统一自然柔和哑绿叶色、真实叶片质感，多品种间叶色明度须有层次；适用于所有风格植物家族，拒绝荧光绿与过饱和（不限于现代主义）
- **主体材质总闸**：除大理石/金属/镜面确需高光处外，默认哑光柔和漫射，避免整体塑料反光壳观感
- **落地硬要求**：每个中文材质后都必须带物理质感描述（肌理/反光/颗粒），不可只写"木饰面""大理石"而无任何质感交代；硬装（微水泥、木饰面、大理石、清水混凝土）与软装（藤编、亚麻、真皮）一律按上表逼出逼真触觉与反光颗粒感。

##### 2.2.1.2 ★ 天花体量选配包（Ceiling & Volume Pack）· ④槽天花/第五立面专项
> 根因：AI 默认权重里"商业室内 = 平吊顶+射灯"。本包把"层高/体量（A 项随机池）"与"天花结构（B 项引用 附录 A 天花库）"两个半轴单拎出来，分解注入 ② 机位 + ④ 第五立面（此前 skill 完全缺"层高提示词"这一维，且天花与风格脱节，是退化到默认大白板的根因）。
**【触发规则】**
- 工装（餐饮/零售/办公/公共空间/展厅）：**默认强制触发**；A 从`工装子集`分配——**挑高类占 1–2 个机位图、其余一律`标准层高`（标准层高取工装普通尺度 约 4.2–4.8m、非住宅 3m，层高不塌但免 B 平顶）**（例：一套 5 机位 = 1–2 张挑高 + 3–4 张标准层高）；B 仅挑高图须由 `附录 A 天花库` 取含显性结构，标准层高图免 B（平顶/暗藏灯槽即可）。A×B 按图分配、按风格气质成形。
- 家装/大平层/别墅：可选；默认 A标准层高 × B由风格天花库取，**且家装天花尽量从简**——优先选平顶/线性暗藏灯槽/单梁类子项，避免跌级吊顶/藻井/斗拱/异形石膏等重体量天花（除非用户明确要风格化顶面）；用户要挑高感时从 A 子集升级（斜顶/大平层/夹层等）。
- 历史建筑改造/买手店：A 可越界抽`历史大平层/穹顶巨构/通高采光井`，B 仍由 附录 A 天花库取。

**【A 项：空间体量·层高（随机池，注入 ② 机位 + ④）】**
> 机制：按套图机位图数量分配 A——**挑高类取 1–2 个机位图**（从工装挑高子集随机），其余机位图全部走`标准层高`；挑高图带"往上广角"机位词，标准层高图用普通平视机位词。
- **工装子集（挑高类，随机 1–2 个）**：大挑高工装 / 斜顶阁楼感 / 历史大平层 / 中庭吹拔 / 穹顶巨构 / 通高采光井 / 夹层挑空 loft；其余机位图统一 `标准层高`
- **家装子集（随机抽 1）**：标准层高 / 斜顶阁楼感（部分） / 夹层挑空 loft / 错层跌级体量
- **老建筑改造/买手店（可越界）**：历史大平层 / 穹顶巨构 / 通高采光井
- **各类型描述**：
  - [大挑高工装]：双倍层高、空旷高耸、垂直往上透视、广角镜头拉伸
  - [斜顶阁楼感]：教堂式斜顶、坡屋顶几何、极高挑空
  - [历史大平层]：老建筑高天花、大尺度空间、纪念碑式体量
  - [标准层高]：常规住宅层高、温馨尺度
  - [中庭吹拔]：多层回廊俯瞰、垂直贯通中庭、挑空共享
  - [穹顶巨构]：大跨度半圆穹顶、拱顶展厅
  - [通高采光井]：顶部天窗、天光倾泻、通高玻璃引光
  - [夹层挑空 loft]：上下双层、夹层俯视、小空间放大
  - [错层跌级体量]：阶梯式升高、地面高差、流动错层
  - [超尺度空旷]：极简巨物感、无人尺度开阔
  - [曲面流线顶]：流线型曲面天花体量、雕塑感
  - [下沉庭院体量]：下沉负空间、俯瞰式围合

**【B 项：天花结构·第五立面（引用 附录 A 天花库，注入 ④）】**
> 机制：B 由所选风格的 `附录 A 天花库` 提取 1–2 个，**不另设中性五选一清单**（消解"业态硬绑天花"导致的土味冲突，风格即天花板词汇）。**仅挑高类图须含"显性结构/体量"子项**；标准层高图免 B 强制（平顶/暗藏灯槽即可，也可自由取 1 个风格天花但不强制）。若风格本身极简平顶（如 现代/韩系），挑高图须叠加一个结构天花（露明梁/井字格/木梁/网格），禁止把"无主灯平顶"当唯一天花。**家装场景优先从简**：即便风格天花库里有藻井/斗拱/跌级/异形等重体量子项，家装默认只取平顶/暗藏灯槽/单梁类，不强行上复杂顶面。
- **例外优先级**：当 A ∈ {斜顶阁楼感 / 穹顶巨构 / 通高采光井 / 曲面流线顶} 时，天花几何已由 A 定，B 仅作"该几何下的材质着色"（如 斜顶×包豪斯=露钢椽、斜顶×南洋=木椽；穹顶=清水砼/木/金属）。
- 各风格天花库见 `附录 A 天花库`（例：包豪斯→露明钢梁/网格天花、安藤→清水混凝土天花/一字漏光缝、南洋→深木梁/木百叶天花、古典中式→榫卯梁架/雕花藻井…）。

> 混排接法：A 词放 ② 机位混排段——挑高图带"往上广角"词、标准层高图用普通平视词（不强制广角）。B 词放 ④ 第五立面段，**仅注入挑高图**（标准层高图免 B）。工装底线改为"挑高图含显性结构（B 含结构）+ 标准层高图保底普通尺度"即视为满足"天花非默认平顶"要求；若挑高图自检发现天花退化为平顶大白板，须回本包给 B 叠加结构天花。

##### 2.2.1.3 ⑥ 光线 DNA
- 整体空间共用一次定义、所有视角继承：对齐风格表"空间拓扑与光影逻辑"，确定时段（晨光/正午/午后斜阳/黄昏/暮色蓝调/阴天）与色温（暖 2700–3200K / 中性 4000K / 冷 5000–6500K）。
- 每机位落光：主光从哪侧进、打在哪面墙/主体、形成高亮区与反弹；人工照明分层（环境+线性灯带+重点聚焦）。
- 丁达尔光/体积光前提：① 低角度晨昏强斜照主光；② 空间相对暗；③ 有百叶/格栅/窗格外框。严禁均匀漫射下强打光束。
- 景观专属：树影斑驳、水面平静反光、季相气象自洽（禁止秋枫下开春樱等时空割裂）。

##### 2.2.1.4 ⑦ 零模糊死锁（负向词）
- 画质尾部固定追加：`写实摄影感，真实相机实拍照片质感，自然现场光，柔和自然日光，哑光表面，有机肌理，超高细节，锐利对焦，真实环境氛围，V-Ray 渲染`
- 负向词硬隔离（所有生图工具 `negative_prompt`）：`模糊、景深虚化、失焦、柔焦、浓雾、雾气、脏噪点、过量噪点、做作暗角、光晕、眩光、CG感、黏土渲染、三维渲染感、过饱和、荧光绿、塑料光泽、人工假色`
- 艺术化景深例外（仅限以下，须遵循"主体清晰、仅边缘/前景/人物可控虚化"）：景观预设二前景 `柔和散景`/预设四 `浅景深`、框架式构图前景极浅虚化、室内预设一人物 `轻微动态模糊`。
- **实拍照片质感（默认基准）**：追求"似真实相机在空间现场拍下"的观感，而非精修建筑效果图。允许并鼓励保留：轻微真实传感器颗粒/胶片颗粒、轻微镜头暗角、自然现场光的不均匀与真实环境氛围、材质真实磨损与瑕疵；硬禁仍是 `CG感/黏土渲染/三维渲染感/塑料光泽/人工假色/过饱和`（这些是"假渲染"特征，与真实照片无关）。

#### 2.2.2 业态内容注入（填 ①②③⑤，随业态变）
> 按室内/建筑/景观注入内容参数（相机预案/功能前提/植物分层/铁律）。此处按业态重排，供 2.2.0 语法与 2.1 工作流调用，原"工作流 A/B/C"标签系误用——室内/建筑/景观是内容注入维度，不是工作流。

##### 2.2.2.1 室内
**布局/功能前提**：电视沙发面对面、吧台中岛操作侧开口、绿植有盆不堵道；工装层高——挑高图 ≥ 4.5m，标准层高图取工装普通尺度（约 4.2–4.8m，非住宅 3m 住宅尺度）。
**植物分层分区**：落地大型标本层（地，沙发旁/窗边）+ 桌面小绿植层（台，边几/餐桌）+ 垂吊层（悬，窗台/书架），全屋 ≥3 种、均出自风格表植物家族。
**立面结构**：焦点墙多材质拼接+金属压条/留缝收边；④ 槽位须从风格结构动作库选 1–3 个主结构呈现（如 开放平面/悬挑体块/光井/片墙）；天花体量/第五立面统一由 `2.2.1.2 天花体量选配包` 注入——A 体量按套图分配（工装挑高类 1–2 个机位图、其余标准层高），B 显性结构仅挑高图强制、标准层高图免 B（禁纯平顶无主灯仅约束挑高图），禁止默认平顶大白板。
**相机预案（等效焦段 35–50mm，构图增益来源）**：
- 预设一 纯粹正投影：垂直主功能墙，机位 1.2–1.3m，90° 正投锁垂直线；混排 `建筑正立面摄影，90° 正对垂直投影，对称建筑对齐，垂直线条锁定，长厨房中岛基线，行走人物轻微动态模糊`。
- 预设二 视线穿透边界框景：门洞/屏风外侧，机位 1.3–1.5m，0° 平视；暗框占 20–30%；混排 `穿门洞透视视野，建筑分隔，层叠室内空间，框景景深，前景隔断元素，水平线对齐`。
- 预设三 非对称角落切面：机位 1.5m，30° 或 60° 偏轴；前景截雕塑椅局部；混排 `非对称空间构成，雕塑感天花几何，30° 偏轴角度，裁切重点家具，肌理抹灰上的光影游戏，美术馆氛围`。
- 预设四 室内外融景框景：大落地窗，机位 1.4m，0° 平视；窗外景观如画框入；混排 `室内外无缝过渡，框景景观视野，木质天花延伸，水平建筑线条，大玻璃展厅立面，极简休闲椅`。
- 预设五 极限斜切长廊：沿走廊纵深 15°–30° 极窄侧切，机位 1.4–1.5m；混排 `纵深走廊透视，窄角侧拍，后退墙面透视，推拉门重复，强烈线性灭点，韵律建筑光影`。
- 画幅：预设一/二/四 适配 16:9 或 3:2；预设三/五 适配 4:3 或 1:1。所有平视预设混 `线条笔直` + `垂直线条稳定`。
**出图前 5 铁律**：① 电视沙发面对面；② 造型必有配套家具（凹槽配电视、吧台配吧凳）；③ 商业空间有入口+吧台开口可见；④ 植物不堵道不凭空冒出；⑤ 窗框极窄/隐框 `通高玻璃、极窄边框、大块整面玻璃`。

##### 2.2.2.2 建筑
**体量比例**：三段式（基座-中段-顶部），立面材质完全承接风格表发散。
**建筑与环境融合**：景观铺装/植被拉取风格表并拓展（如包豪斯配白桦、新中式配太湖石迎客松）。
**相机预案（等效焦段 24–35mm；幕墙特写预设五 50mm）**：
- 预设一 地平线正立面画卷：正立面居中，机位 1.5–1.6m，90° 正对无仰角；前景草坪 40% + 天空 30%；混排 `建筑立面摄影，90° 正对面视，绝对水平地平线，大前景草坪，均衡中轴构图，线条校正`。
- 预设二 日常街道人视侧切：街道/邻院，机位 1.5–1.6m，15°–30° 浅偏轴；含街道干扰物（木栅栏/车尾/邻栋）；混排 `行人视平透视，真实社区街景，非对称住宅构成，前景木栅栏，真实日常环境，移轴透视校正`。
- 预设三 低彩度大地鸟瞰：机位 30–50m 高空，30°–45° 俯视；建筑占 20–30% 中央，四周自然地表；混排 `航拍无人机摄影，30° 俯视角，总规视角，辽阔戏剧性自然景观背景，极简建筑雕塑，高空景致`。
- 预设四 低重心悬挑戏剧切角：转角下方，机位 1.4–1.5m，45° 偏轴仰拍 10°–15°；悬挑体量遮蔽+硬阴影；前景低矮阔叶植物微遮；混排 `大胆建筑悬挑，动态两点透视，锐利转角镜头，低处行人仰视，结构戏剧阴影，温暖室内光晕对比暗立面`。
- 预设五 玻璃幕墙穿透交织：50mm 中焦，机位 1.6–1.8m，0°–15° 平/微俯；室内网格灯光+室外反射重叠；混排 `中焦建筑，50mm 镜头透视，半透玻璃立面，温暖发光网格天花灯，旧砖与现代钢并置，层叠室外反射`。
- 大师级光影母题（与预案正交融合）：框架式构图（暗框框景，适合中式/安藤）；引导线构图（百叶/铺装透视，适合南洋/包豪斯）；对称与留白（适合安藤/韩系）；倒影与反射（适合新中式）；镜头物理控制 `垂直线条笔直` + `全程锐利对焦、大景深`（艺术化虚化除外）。
**场景配景（建筑须置于真实场景）**：森林湿地公园 / 街区活力广场 / 极简文化巨物广场三选一；人流密度强制 `数十个微小尺度人物熙攘人群` + 具体交互动作（避免 1–2 个孤影）。
**出图前 5 铁律**：① 三段体比例不崩；② 窗洞格网规律重复；③ 无错代/风格混搭；④ 玻璃反射与环境一致；⑤ 构件实体无悬空。

##### 2.2.2.3 景观
**俯视布局**：功能分区（引导区/核心水景/休闲停留/绿化过渡）+ 主交通动线。
**竖向与驳岸**：须有下沉卡座/台地/微地形之一；驳岸按风格（现代 平齐池边、黑色石板湿边压顶 / 中式自然 风化毛石驳岸 / 日式 悬挑木质步道临水）。
**种植三层骨架**：骨架乔木层（油橄榄/黑松/白桦等）+ 中景灌木层（鸡爪槭/绣球/黄杨球）+ 地被覆盖层（苔藓/果岭草坪）。
**植物色彩（低饱和优先 · 景观专项）**：景观植被统一走低饱和自然哑绿/哑色调，叶色明度层次柔和、避免高饱和鲜绿；彩叶（鸡爪槭/红枫/绣球等）一律以哑光暗调呈现，拒绝荧光感与过饱和花色；整体绿量饱满但不艳、不"塑料假绿"，与 2.2.1.4 实拍照片质感一致（参考 2.2.1.1 全局 `绿植叶色` 自然哑绿总闸）。
**相机预案（大景 16–28mm；特写预设四 85mm）**：
- 预设一 S形向导路径：沿汀步/木栈道走向，机位 1.5m 平视；混排 `曲线引导路径透视，S形汀步，蜿蜒花园小径，视平行人视角，动态路径引导，怡人景观流动`。
- 预设二 沉浸漫步前景遮蔽：藏于绿丛，机位 1.2–1.4m，平/微仰；前景虚化绿植 20–30%；混排 `沉浸低视角花园视野，前景柔焦绿植，层叠植物窥视透视，自然花园框景，柔和散景，戏剧性斑驳光影`。
- 预设三 框景借景庭院：木格栅/花格墙/垭口横拉，机位 1.3–1.5m，90° 正投；框内古松/白砂；混排 `框景庭院透视，完美线性构图，透过木格栅屏风观景，庭院雕塑感孤植树，细砾石地面，极简静谧日式庭院`。
- 预设四 意境特写微观材质：85mm 近摄，机位 1.5m；聚焦白砂波纹/置石苔藓；混排 `85mm 建筑特写，浅景深，带苔藓的精细石材肌理，砾石细波纹，石与水并置，微观景观元素，诗意光影`。
- 光学控制：平视加 `垂直线条笔直`；前景加 `近景柔和虚化绿植`。
**出图前 5 铁律**：① 水景有实体驳岸；② 铺装路网不离散断裂；③ 植物不侵入实体（不穿墙/玻璃）；④ 竖向标高杜绝纯平贴纸；⑤ 季相气象自洽。

### 2.3 3D 出图自检（出口闸门）
- 各业态 5 铁律见 2.2.2.1/2.2.2.2/2.2.2.3 末尾，出图前逐条校核。
- 全局 DNA 死锁：色彩/材质/光影跨所有机位与视角必须继承同一风格底座（见 1.1 一脉相承一致性），禁止跨视角时空割裂。
- 负向词（2.2.1.4）须进入 `negative_prompt`；I2I/跨维不得破坏底图几何与比例。

## 3. 2D 平立/展板大类

> 本大类统一管 2D 顶视/正投图纸：先走工作流（3.1，按输入状态分派）→ 再看零件库（3.2，语法 + 表现风库 + 图类内容 + 通用红线，被 3.1 调用）→ 出图前过自检闸门（3.3）。2D 交付物是顶视/正投的图纸化结果，与 3D 透视共享第 1 节风格基因引擎，但语法自立——不写光影透视，改走"骨架→分区→填色→标注→图框"的制图链。
> **核心前提（见 3.2.3.1）**：2D 图内禁止任何三维/透视/立体表达，所有物件以其顶视图（平面）或正视图（立面）的二维符号呈现。彩平/立面/展板/总平面 共享同一套表现风库（3.2.1）与 3.2.3.2 色彩规范。

### 3.1 2D 生图工作流

> 生图流程。按输入状态分两条：无底图 → 3.1.1（T2I 五步，7 槽全填）；有底图·同维 → 3.1.2（I2I，②③ 继承底图、①④⑤ 写变更）。槽具体怎么填跳 3.2 零件库。

#### 3.1.1 无底图主流程（T2I · 五步框架）
走 3.2.0 语法全量拼装，内容由 3.2.2 图类内容注入；表现风按 3.2.1 随机池抽取（无指定时）。
1. **诉求分析**：运行风格基因引擎（1.1/1.2）判定风格及混搭占比；槽位分析：`base_image`（无）、`space_type`、`area`、`style`、`drawing_type`（彩平/立面/展板）、`render_style`（表现风，缺省则 3.2.1 随机）、`aspect_ratio`（彩平 1:1 或 4:3；立面 3:4 或 16:9；展板 A1/A2）。
2. **平面布局（骨架优先）**：轴线/网格/比例尺/指北针（平面）或标高基准（立面）；功能分区 + 动线 + **二维家具点位**（顶视/正视符号，3.2.3.1）；人体工程学校核（3.2.2.2 第 5 条）。
3. **材质铺填 + 色彩与质感规范**：附录 A 色彩系统经 3.2.3.2.1 适度降饱和 + 3.2.3.2.2 描边 + 3.2.3.2.3 统一方向投影。
4. **标注 + 文字 + 图框**：尺寸/标高/引线/图例/字体层级（3.2.3.2.4）+ 表现风尾部（3.2.1）。**展板类**此步升级为「风格化整合」：对用户上传素材统一风格化处理、标题做艺术字（见 3.2.2.1 展板条）。
5. **自检**：比例自洽、动线闭合、维度死锁（全二维符号）、风格 DNA 与表现风跨图类一致、3.3 5+1 铁律。

#### 3.1.2 有底图 · 同维（手绘 / CAD / 旧平面 / 已彩平 → 转图类 / 精修 / 加标注 / 改方案）
> **⚠️ 原图骨架遵循（本工作流默认优先级，允许 skill 判断的合理性调整）**：凡有底图，输出**默认严格遵循原图几何骨架**——轴网、开间进深比例、分区位置、门洞关系、指北方向、图幅比例**原则上继承 `base_image`**。但**允许 skill 判断下的合理结构微调**：在已有墙体上开门/开窗、在既有分区内做家具/动线/隔断的局部调整、表面信息的增改，均属正常，可直接执行。**仅当触及"底层空间关系"时视为越界、需用户确认**：移动/拆改整面承重墙、改变轴网尺度或整体比例、重排分区方位、翻转/镜像图面、改变指北方向。改方案若需动上述结构，须显式声明"结构变更"并由用户确认；墙体开门/开窗等局部微调无需确认、由 skill 自行判断。
> I2I 槽级规则：顶部声明 `base_image: <路径>`，`② 图类`/`③ 骨架` 默认 `[继承底图]` 不重写；`① 风格`/`④ 分区`/`⑤ 材质` 改为变更指令（只写要改成什么）；`⑦ 图框尾部` 同 T2I。仅改局部走 `local-edit`（`edit_mask` 圈区、mask 外像素锁死，见 4.1）。
- **触发**：用户提供底图（手绘/草图/CAD/旧平面/已是彩平）要求转图类、加标注、精修、改布局、改方案。
- **路由**：先走 3.2.2.1 底图性质预判（按底图类型归流到对应图类 + 表现风决策）。
- **执行**：`base_image` 声明 + I2I 槽级规则。**所有输出严守「原图骨架遵循」红线**，并继承 3.2.3.1 维度死锁（二维符号）与 3.2.3.2 通用红线；改方案触结构须先确认。

### 3.2 2D 零件库

> 本块是「语法骨架 → 表现风选择 → 图类内容注入 → 通用红线闸门」四段链，被 3.1 工作流调用。2D 不按业态单列参数（无相机预案/无分业态铁律），直接复用 附录 A 风格基因映射表 取基底色/材质语言/图形符号语言。阅读顺序：先 3.2.0 看整体拼装语法 → 3.2.1 选表现风 → 3.2.2 填图类内容 → 3.2.3 过通用红线闸门。

#### 3.2.0 结构化拼装语法（7 槽位，顺序固定）
```text
[① 风格DNA] + [② 图类/视角] + [③ 空间骨架] + [④ 分区与陈设] +
[⑤ 材质铺填] + [⑥ 标注系统] + [⑦ 图框尾部]
```

| 槽 | 数据来源 | 填法要点 |
|---|---|---|
| ① 风格DNA | 附录 A 风格映射表 | 如 `新中式庭院彩平`、`南洋复古平面`；定基底色 / 材质语言 / 图形符号语言 |
| ② 图类/视角 | 3.2.2.1 图类分支（含底图性质预判） | `彩平俯视 / 立面正投 / 展板整合 / 总平俯视`；决定③起的骨架形态与后续槽侧重；同时锁定表现风（3.2.1） |
| ③ 空间骨架 | 3.2.2.2 规则 + 风格表 | 轴线网格 + 比例尺 + 指北针（平面类）/ 标高基准（立面类）；墙体/开间/分区锁定 |
| ④ 分区与陈设 | 风格表锚点 + 3.2.2.2 | 功能分区填色、动线箭头、**二维点位图例**（家具/植物全以顶视/正视符号，见 3.2.3.1），逐件带尺寸与朝向 |
| ⑤ 材质铺填 | 附录 A 色彩系统（适度降饱和，见 3.2.3.2.1）+ 材质 | 色块铺填 + 平面符号（木纹/混凝土斜线/石材点），拒绝无质感死色块；承接 3.2.3.2 通用红线 |
| ⑥ 标注系统 | 3.2.3.2.4 标注与文字语言 | 尺寸线/标高/材质引线标注/图例/字体层级；立面类必含尺寸与标高 |
| ⑦ 图框尾部 | 3.2.3.3 零模糊与负向词 + 3.2.1 表现风（详 附录 B） | 按图类与表现风定尾部词（彩平/立面：扁平色块/白细边；展板：图框线稿）+ 负向词 |

#### 3.2.1 表现风库（2D 通用技法层，8 风 · 索引）
> **双轴模型**：`风格DNA（色系，附录 A）× 表现风（技法，本库）` 正交叠加；表现风为彩平/立面/展板/总平面共用。
> **随机机制**：用户未指定表现风时，从随机池 `{高级色块风 / 编辑建筑风 / 竞赛分析风 / 水彩提案风 / 梦幻总平风 / 模型摄影风}` **随机抽一个**；`马克笔手绘风` **不参与随机**，仅当底图为手绘草图（3.2.2.1 底图性质预判）时锁定启用；`CAD 制图风` **不参与随机**，仅当用户有明确 CAD 出图诉求（要施工图/工程图/黑白线稿制图/CAD 出图）时锁定启用。
> **本节点仅管双轴模型与随机机制**；8 风完整定义（定位/适用图类/7 维 schema/招牌/避坑，全部继承 3.2.3.1 维度死锁）**统一见文末 附录 B · 表现风库详解**，生成时按需跳查，无需在此展开。

#### 3.2.2 图类内容注入（填 ②③④，随图类变）
> 按图类（彩平/立面/展板）注入内容，供 3.2.0 语法与 3.1 工作流调用。

##### 3.2.2.1 图类分支（② 图类驱动；含彩平/立面/展板/总平面）
**底图性质预判（路由前置，先判底图再定流程）**：
- 底图 = CAD / 手绘草图（无线稿彩色、明显非目标图类）→ 强制转对应图类（彩平/立面），骨架继承、色彩重铺（I2I 重绘上色）。
- 无底图 → T2I 直接出对应图类（全量拼装）。
- 底图已是目标图类（如用户传的已是彩平）且无风格变更诉求、仅改方案 → 不重绘原风格，走 `local-edit` / 轻度 I2I，在用户原图调性上调整（保留其配色与线稿语言）。
- **表现风决策**（详见 3.2.1）：用户未指定时从随机池 `{高级色块风 / 编辑建筑风 / 竞赛分析风 / 水彩提案风 / 梦幻总平风 / 模型摄影风}` **随机抽一个**；`马克笔手绘风` 仅当底图为手绘草图时锁定启用，不参与随机；`CAD 制图风` 仅当用户有明确 CAD 出图诉求（施工图/工程图/黑白线稿制图/CAD 出图）时锁定启用，不参与随机。彩平/立面/展板/总平面共享同一风库。

- **彩平 / 平面布局图**（俯视顶视）：轴线 + 网格 + 比例尺 + 指北针；功能分区填色、动线箭头、家具/植物二维点位图例（顶视符号）；承接 3.2.3.2 通用红线。**→ 输出必注入 3.2.3.3 反透视正向词（正交顶视 / 无透视）**。
- **立面标注图**（正投影）：墙体/门窗/标高竖向表达（正视图符号）；尺寸标注 + 材质引线标注 + 图例，立面类强制带标高。**→ 输出必注入 3.2.3.3 反透视正向词（正交正投 / 无透视）**。
- **展板 / 成果汇报板（整合 + 风格化）**：将平/立/效果图/用户上传素材整合进 A1/A2 图框的**成果展示板**。**核心差异（与直出拼图拉开差距）= 风格化整合**：
  - **素材必做风格化处理**：用户上传的任意图片（实拍/效果图/渲染/截图）**不得原图直贴**，须统一施加本板风格 DNA 的调性——统一色温/滤镜感、加风格化衬框或底纹、与整体配色/线稿语言对齐；多素材间强制"同一调性、同一字体系统、同一边距网格"。
  - **标题艺术字**：展板主标题/分区标题按所选风格 DNA 做艺术字体处理（新中式→书法/印章体、复古→衬线花体、现代→无衬线大字重、竞赛→工程标题体等），非普通工程字；艺术字与图框/配色统一。
  - **⚠️ 文字零乱码红线（展板最高优先级）**：所有展板文字（主标题/分区标题/图注/标注/比例尺数字）必须**清晰可读、零乱码、零错字、英文零拼写错误**；艺术字若生图管线对字体支持不稳，**宁可降级为"风格化排版骨架 + 干净矢量文字叠层（后期合成）"，也绝不硬生成易乱码的艺术字**——可读规整字 > 乱码艺术字。
  - **图件维度**：内嵌的平面/彩平类图件保持二维符号（见 3.2.3.1）；用户上传的效果图/照片素材做风格化整合（保持原图但统一调性，不重绘为二维符号）。
  - → 内嵌图件必注入 3.2.3.3 反透视正向词（平面类图件适用）。
- **总平面 / 场地规划图**（俯视顶视）：建筑/景观/场地符号化平面铺陈，轴线 + 网格 + 比例尺 + 指北针；功能分区填色、动线/分析箭头、景观与设施符号（顶视符号）；承接 3.2.3.2 通用红线与 附录 B ⑥ 符号。**→ 输出必注入 3.2.3.3 反透视正向词（正交顶视 / 无透视）**。

##### 3.2.2.2 平面骨架与分区规则（③ 空间骨架细则）
③ 空间骨架必须含比例基准（轴线/网格 + 比例尺 + 指北针或标高），禁止无比例自由画。规则：
1. 每区/每层取具体名词（来自风格表锚点），禁止只写手法词。
2. 分区填色由 附录 A 色彩系统驱动，经 3.2.3.2.1 降饱和红线转换；具体色彩组织（底基 / 主调 / 强调色）详见 附录 B ⑤。
3. 家具/植物以"二维点位图例"呈现（顶视/正视符号，见 3.2.3.1 维度死锁）；具体符号长相（植物线型 / 人宠 / 设施 / 分析动线）由表现风库定义，详见 附录 B ⑥。
4. 动线箭头必须连贯闭合（入口→核心区→辅助区），杜绝断头动线与穿墙动线。
5. 人体工程学校核（室内/工装）：主通道 ≥800–1000mm；沙发与茶几 300–450mm；吧台前过道 ≥900mm；工装轴网 ≥ `8m × 15m`；层高——挑高图 ≥ `4.5m`、标准层高图按工装普通尺度（约 `4.2–4.8m`）。
6. **中文功能分区名必注**：每个功能分区/房间填色后必须叠加中文名标注（见 3.2.3.2.4 平面方案中文标注强制）；禁纯色块无字——无中文功能分区名即视为拼装失败、禁止出图。

#### 3.2.3 通用红线（跨图类限定规则 · 闸门）
> 以下细则各图类共享，无论选哪套表现风都不得突破；凡违反即视为拼装失败、禁止出图。

##### 3.2.3.1 维度死锁铁律（最高优先级，压过表现风与 附录 A）
图内一切物件均为其**顶视（平面）/正视图（立面）的二维投影符号，绝非立体造型**。
- 家具/设备/植物 → 平面图例符号（沙发=矩形+靠背线、桌=矩形、植物=同心圆、设备=功能矩形）；立面→门/窗/柜矩形立面、构件正投影轮廓。禁立体透视、禁照片感盆栽、禁 2.5D 轴测（用户明确要轴测除外）。
- 人 → 平面俯视小圆点；立面侧视剪影。非立体人偶。
- 材质 → 色块 + 平面纹理符号（木纹/蝉缝网格/石材点），禁 3D 肌理透视。
- 图例视角对齐：图例图标投影视角必须与图类主视图严格一致（彩平=顶视、立面=正视图），严禁混用，图例是图内"符号字典"。
- 立面纯正投影，禁灭点禁立体块面；展板内嵌图件同理，绝不混入透视渲染图。

##### 3.2.3.2 通用红线（色彩 / 线稿 / 投影 / 标注）
- **3.2.3.2.1 色彩红线（2D 通用）**：承接 附录 A 色系（色相+占比不变）仅轻度降饱和/柔明度，保留纯度可辨识、禁灰闷发脏；禁纯黑块（结构用深灰非 `#000`）、禁 3D 高饱和直搬、禁荧光。平/立/展板统一适用。
- **3.2.3.2.2 描边/线稿**：具体线色×线宽×线质由表现风库定义（附录 B ②）；本节点红线仅"主体禁纯黑块描边"。
- **3.2.3.2.3 投影范式**：形态（none/soft-drop/model-photo）由表现风库定义（附录 B ①）；本节点红线仅"投影须为二维平面影子、全局统一光源、绝不制造立体透视错觉"。model-photo 仅限模型摄影风。
- **3.2.3.2.4 标注与文字（2D 专属）**：尺寸线（细实线+建筑箭头，mm）/标高（±0.000 基准，立面必含）/材质引线（→图例表）/指北针+比例尺/展板标题栏齐全；家具·植物·材质三类图例视角须与主视图一致；字体无衬线为正、深灰非纯黑、字号层级（图名>分区>标注>图例）递减，手写体仅手绘/马克笔风（具体文字模式由风库定义，附录 B ⑦）。**平面方案中文标注强制（最高优先级，覆盖表现风 ⑦ 的 none/英文）**：凡 drawing_type=彩平/户型/布局/平面设计图，必须带**中文功能分区标注**——每个功能分区（及房间）的**中文名**（如办公区/展厅/车间/仓储/接待/客厅/卧室…）、中文图名（一层平面布置图…）、指北针中文「北」、关键尺寸（开间/进深/轴网，数字+mm）、图例中文名（家具/植物/材质）；用无衬线中文字体、深灰非纯黑、字号层级（图名>分区>标注）递减。此标注为**平面图刚性需求**，不受 ⑦=none / editorial-title 影响——⑦ 仅约束"装饰性展示标题"，中文功能分区标注始终必含。展板标题/项目名按风格 DNA 选**艺术字体**（新中式→书法/印章体、复古→衬线花体、现代→无衬线大字重、竞赛→工程标题体），与正文无衬线标注字形成层级对比；艺术字仅用于标题/项目名，尺寸标注/轴号仍用工程字体，禁艺术字滥用到标注。**展板所有文字须零乱码、零错字（艺术字不稳时降级为干净矢量叠层），详见 3.2.2.1 展板条。**

##### 3.2.3.3 零模糊与负向词（2D · ⑦ 图框尾部）
- **反透视强锁（最高优先级拼装动作）**：3.2.3.1 的禁止透视必须落到最终 prompt 文本。拼装时：① `② 图类` 槽与 `⑦ 图框尾部` **必注入**反透视正向词；② `维度死锁负向词` **必入** `negative_prompt`。两条缺一即禁止出图。
  - 彩平：`正交顶视图、无透视、无灭点、无 3D 景深，所有家具/植物为俯视二维平面符号`
  - 立面：`正交正投影、无透视、无灭点，所有构件为正视二维符号`
  - 展板：内嵌图件同上、整图为扁平信息图无透视
- 画质尾部按图类与表现风定（附录 B）；通用追加 `矢量清晰，扁平信息图，超高细节，锐利细线`；彩平/立面用"扁平色块/白细边"，展板保留图框线稿感。
- 负向词硬隔离（所有工具 `negative_prompt`）：`模糊、模糊线、手绘抖动、透视畸变、照片噪点、3D 渲染感、卡通、涂鸦、色块溢出、文字乱码、标注错位、比例失真、过饱和、荧光、纯黑块`。
- **维度死锁负向词（最高优先级，须入 negative_prompt）**：`三维透视、立体造型、写实实物照片、灭点透视、2.5D、伪三维、轴测透视（除非用户明确要轴测）、家具立体渲染、盆栽照片感、图例视角与平面不一致、图例混用正视图与顶视`。
- 特例（马克笔手绘风）：可放宽"线稿干净"为"手绘线稿"，但仍须比例正确、标注清晰、符号可辨、保持二维（见 3.2.3.1/3.2.1）。

### 3.3 2D 出图自检（出口闸门）
① 比例/比例尺正确不畸变；② 动线闭合不穿墙不堵道；③ 家具/构件均为**二维符号**（顶视/正视，无立体透视，见 3.2.3.1）、对位合理无悬空；④ 材质符号清晰可辨、色彩承接风格表且经适度降饱和（保留纯度、不灰闷）；⑤ 标注/图框齐全（立面必含标高、展板必含标题栏）；⑥ **全局统一投影方向、无三维错觉**（3.2.3.1/3.2.3.2.3）。

## 4. 跨类衔接与通用编辑（共享收尾）

### 4.1 局部编辑统一规范（引擎无关，只写一次）
> 3D（2.1.2）与 2D（3.1.2）的局部编辑共用本规范，避免重复。
```text
base_image: <路径>
mode: local-edit
edit_mask: <区域描述 / 坐标框>      # 仅此区域重绘
edit_prompt: <该区域改成什么>
# 或参考图引导模式
reference_image: <路径>
transfer: <材质 / 色彩 / 风格>       # 仅迁移声明的属性
```
局部性硬保证：
1. 含 `edit_mask` → mask 外像素级继承（pixel-lock），仅 mask 内按 `edit_prompt` 重绘。
2. 含 `reference_image + transfer` → 几何骨架锁死，仅作用于声明属性。

### 4.2 2D ↔ 3D 升维衔接
- **2D → 3D 升维**在 2.1.3（跨维升维）处理，2D 流程不重复；若用户先要 2D 平面再要 3D，须保持同一风格 DNA 与骨架约束向下传递，避免跨维穿帮。
- 风格 DNA（附录 A）与内容参数（2.2.2 / 3.2.2）在两链间一致继承；跨维时 2D 的墙体/开间/层高/门窗位置作为 3D 空间骨架约束锁死。

### B.3 风库通用规则
1. **强调色跟随**：当 ③=solid-accent 时，② 线稿色默认跟随强调色（紫墙配紫线、蓝墙配蓝线），避免线墙撞色；仅无强调墙的风（高级色块）用黑线。
2. **主调边界**：mono 风允许 1 个强调色跳出（墙或分析层）；多色风强调色=0（靠粉彩本身区分）。
3. **图类适配**：彩平/总平用本库全维；立面沿用彩平风 + 2D 通用规范（线稿/标注）；展板=**风格化整合板**（用户素材统一风格化处理 + 标题艺术字 + 图框线稿拼版），风格取主图风。
4. **随机池**：高级色块 / 编辑建筑 / 竞赛分析 / 水彩提案 / 梦幻总平 / 模型摄影风 入随机池；马克笔手绘风仅手绘底图锁定；CAD 制图风仅明确 CAD 出图诉求锁定，二者均不入随机池。
