# SW_GRP — 主题群组对比

## 1. 概述

多指数归一化走势对比 + 多周期收益排名 + 成分股 Top3 + 风险收益指标。内置两个预设：大类风格 6 指数 / 金创 5 指数；也支持自定义 2-8 个指数。回答"大类风格轮动 / 金创指数对比 / 自定义指数群组走势"。

## 2. 输入

```
sw_group.py --preset PRESET [--days N]           # 预设模式
sw_group.py --codes a,b,c [--names A,B,C] [--days N]   # 自定义模式
```

| 参数 | 必填 | 默认 | 说明 |
|------|------|------|------|
| `--preset` | 或 `--codes` 二选一 | — | `style_broad`（大类风格 6 个：周期/先进制造/消费/医药/TMT/金融地产） / `jc`（金创 4 个） |
| `--codes` | 或 `--preset` 二选一 | — | 自定义代码（逗号分隔，2-8 个） |
| `--names` | 否 | — | 自定义名称（与 codes 对齐）。省略时脚本自动查 |
| `--days` | 否 | `90` | K 线回溯根数，最小 60 |

## 3. 输出

```json
{
  "status": "ok",
  "mode": "group",
  "preset": "style_broad",
  "count": 6,
  "summary_text": "指数群组: 大类风格轮动全景\n数据日期: 2026-04-17\n周期(801271): 最新1119.22, 日涨跌-0.37%, 5日0.48%, 20日1.58%, 60日2.64%, YTD7.24%, ...\n...\n5d排名: 科技TMT > 先进制造 > ...\n20d排名: ...\nytd排名: ..."
}
```

**summary_text 关键内容**：
- 每个指数一行：最新价 + 日涨跌 + 5/20/60 日 + YTD + 年化收益/波动 + 成分股数
- 4 个排名行：5 日 / 20 日 / 60 日 / YTD 各自排序
- 数据日期
- **agent 直接引用，不重新统计**

## 4. 路由示例

| 用户说 | Agent 执行命令 |
|-------|--------------|
| "六大板块轮动" / "大类风格对比" / "板块配置" | `sw_group.py --preset style_broad` |
| "金创指数对比" / "金创指数表现" | `sw_group.py --preset jc` |
| "近半年大类风格轮动" | `sw_group.py --preset style_broad --days 125` |
| "银行和非银和保险对比" | `sw_group.py --codes 801780,801790,801740 --names 银行,非银,保险` |

## 5. 已知坑 / 边界

- `--preset` 和 `--codes` **二选一必填**，都不传会报错
- 金创指数（`jc`）实际只有 4 个（参见之前案例），不是 5 个
- 大类风格指数 (`style_broad` 801271-801276) 先通过网页检索核实对应指数数据；不将普通行业数据代入这些代码。
- 用户问"基础化工 vs 电子"（2 个指数普通对比）→ 优先 `sw_chart.py --mode compare`（更轻），而非 sw_group
- 用户问"31 个一级行业对比" → 走 `sw_heatmap.py` / `sw_rank.py`，不是本脚本
- 不支持历史日期快照；对 "某日 的群组快照" 走 `sw_period_rank.py`
