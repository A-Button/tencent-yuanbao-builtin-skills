# 活动创意灵感库

## 创意签到方式

| 方式 | 适合场景 | 体验感 | 预算 |
|------|---------|--------|------|
| 指纹签到树 | 年会、庆典 | ★★★ | 低 |
| AR 签到合影 | 发布会、科技类 | ★★★★★ | 高 |
| 盲盒签到（随机抽小礼品） | 年会、展会 | ★★★★ | 中 |
| 时间胶囊（写一封信给未来） | 周年庆、团建 | ★★★★ | 低 |
| 拼图签到（每人一块拼完整图） | 团建、庆典 | ★★★ | 低 |
| 沙画/流沙签到 | 高端晚宴、发布会 | ★★★★★ | 中 |
| 声音/视频留言签到 | 温情主题 | ★★★★ | 中 |
| 微信扫码签到 | 通用 | ★★ | 低 |

## 创意开场方式

- **倒计时快闪视频**：全场灯光熄灭，大屏播放倒计时
- **领导创意出场**：视频出场 / 升降台 / 从观众席走出
- **特效开场**：激光秀 / 全息投影 / 无人机
- **故事化开场**：情景剧 / 沙画 / 微电影
- **互动开场**：全场灯光秀 / 手机闪光灯海

## 创意互动环节

- **大屏互动**：弹幕墙、摇一摇抽奖、扫码投票
- **即兴挑战**：现场命题创作 / 知识竞赛 / 猜谜
- **分组 PK**：团队游戏、桌间竞赛
- **沉浸体验**：VR/AR 体验、装置艺术互动
- **公益结合**：现场义卖、捐书、公益跑
- **众创环节**：共同完成一幅画、拼一首诗

## 创意收尾方式

- **时光胶囊封存**：大家的愿望/照片封存，明年开启
- **璀璨合影**：全员大合影 + 闪光灯齐亮
- **惊喜礼花**：全场彩带/气球雨
- **大合唱/主题歌**：全场同唱一首歌
- **星空寄语**：每个人写一张明信片寄出
