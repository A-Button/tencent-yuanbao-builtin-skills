# 故障排查

## 常见错误码

| 错误码 | 错误类型 | 解决方案 |
|--------|----------|----------|
| **401** | **Token 鉴权失败** | 停止并说明运行环境授权异常；不要主动登录、退出、探测或操作凭据 |
| **403** | **权限不足** | 先用 `manage get-privilege` 只读确认现状；用户明确要求分享或协作编辑时，按目标设置相应权限，否则请所有者授权或在腾讯文档前端调整 |
| **429** | **请求频率超限** | 触发速率限制，等待几秒后重试。避免紧密循环，优先使用批量命令 |
| **400006** | **权限不足** | 当前账号对该资源无操作权限。先用 `manage get-privilege` 只读确认；用户明确要求分享或协作编辑时，按目标设置相应权限，否则请所有者授权或在腾讯文档前端调整。仅当对任意资源都报此码时，才是运行环境授权异常，停止并说明；两种情况都不要主动登录、退出、探测或操作凭据 |
| **400007** | **请求频率超限** | 触发速率限制，等待几秒后退避重试（同 `429`），优先改用批量命令。与账号权益无关，**不要引导用户付费** |
| **400008** | **权限不足** | 访问的资源超出当前账号的授权范围，按 `400006` 处置，不要靠缩小范围反复重试。与账号权益无关，**不要引导用户付费** |
| **400014** | **该能力需会员** | 当前账号无会员权限。不要重试；优先改用不需要会员的等价做法，没有替代时告知用户该能力需会员或建议在腾讯文档前端操作。**不要提供购买链接，也不要代为购买** |
| **320125** | **文件超过非会员大小上限** | 不要重试，也不要照搬服务端文案里的「开通会员后重试」。改用更小的文件，或告知用户该操作需会员。**不要提供购买链接，也不要代为购买** |
| **-32601** | **请求接口错误** | 确认调用的命令是否在 CLI 命令列表中存在，使用 `tdocs-cli --help` 查看 |
| **-32603** | **请求参数错误** | 确认请求参数是否正确，例如 `--file-id`、`--content` 等 |
| **11607** | **请求参数错误** | 确认请求参数是否正确，例如 `--file-id`、`--content` 等 |
| **50000** | **服务端兜底错误** | 不要仅因文案显示“服务繁忙”就 `sleep` 后原样重试。先核对参数、真实返回的 ID、索引和当前开放能力；没有新的诊断依据时停止重复调用并安全降级 |
| **5xx** | **服务端错误**（500/502/503/504） | 不要打开 `--debug`。保留普通错误输出中的错误码或 trace ID；确认请求无误后仍持续失败则停止写入并升级处理 |

## 排查步骤

1. **匹配错误码**：先查上方错误码表，按对应方案处理
2. **确认命令可用**：一般命令用 `--help` 查看签名；`slide` 子命令统一用 `tdocs-cli slide <command> -h`
3. **鉴权错误**：停止并说明运行环境授权异常；不要主动登录、退出、探测或操作凭据
4. **查阅品类参考文档**：根据场景路由表找到对应参考文档，确认命令调用规范和参数约束

## 常见场景问题

### 超时 / "context deadline exceeded"

- **原因**：HTTP 超时设置过低。
- **修复**：提高 `--timeout <秒>`（默认 30）。workflow 命令还需提高 `--poll-timeout-secs`。

### `workflow import-file` / `workflow export-file` 接近完成时超时

- **原因**：文件过大，处理时间超出轮询截止。
- **修复**：

  ```bash
  tdocs-cli workflow import-file --file ./big.xlsx \
      --poll-timeout-secs 1800 --timeout 120
  ```

### 命令找不到

- **原因**：CLI 版本过旧或本地缓存未同步。
- **修复**：

  ```bash
  tdocs-cli cache refresh
  tdocs-cli --help
  ```

### `--jq` 返回 null

- **修复**：去掉 `--jq`，查看完整 JSON 后调整表达式。或用 `--jq '.'` 美化输出。

### `--format table` 显示乱码

- **修复**：切换到 `--format json`。

## 升级处理清单

提交 bug 时请包含：

1. 完整命令（token 替换为 `<TOKEN>`）。
2. `tdocs-cli version` 输出。
3. 普通错误输出中已有的错误码或 trace ID（没有则如实说明）。
4. 操作系统和终端类型。

**不要**使用 `--debug` 获取诊断信息，也不要在公开场合包含实际 token 或含个人数据的响应。
