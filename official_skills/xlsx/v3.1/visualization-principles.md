# Excel 可视化准则（完整方法论）

> `SKILL.md` 的「可视化图表」章节是必读精简版。本文件是完整方法论，遇到复杂/高要求图表时按需展开阅读。
> **先按 A/B 分流选渲染方式**（见第五节 / `SKILL.md`）：图要落进 xlsx 且需可编辑/随数据刷新时，优先 openpyxl 原生图表；只有图文并茂作答、报告配图，或原生做不到的图型，才用 matplotlib/seaborn 自绘 PNG。本文件讲的是**怎么想**（选图、诚实性、配色），两种渲染方式都适用，不绑定任何固定函数库——按数据和问题自己实现；自绘 PNG 时先设中文字体（`font.sans-serif` + `axes.unicode_minus=False`）避免豆腐块。

## 零、两种模式：交付 vs 探索（先定位，再谈"该画几张、几种色"）

同一套诚实性铁律，两种松紧完全不同的场景，别用错标准：

- **交付 / 汇报**（业务受众、结论导向）：克制、少而精，默认 3~5 张、≤6 色、每图一个锚点。目标是"5 秒抓结论、不打扰"。
- **探索性分析（EDA，技术受众、找规律）**：**鼓励密集、多序列、多面板**。散点矩阵(SPLOM)、平行坐标、KDE 叠加 / ridgeline、小提琴、hexbin、二维 KDE / 等高线、相关网络、谱系树、QQ 图、bump / horizon / 蜂群等都该大胆自绘；一版"N 变量：箱线阵 + 直方叠加 + 相关热力 + 两两散点带回归 + 平行坐标 + KDE 总览"的探索大图正是该出的形态，不必受"3~5 张 / ≤6 色 / 单一锚点"约束。

**铁律对两种模式都生效**：诚实性（柱图 Y 从 0、折线等距、无 3D、面积/半径线性）、位置/长度编码关键量、要件齐全 + 中文不出豆腐块、无意义装饰不加、单序列不造冗余图例。**配色上限、图数量、单一锚点是"交付默认"，探索图可带理由放宽**（用连续/定性色板 + alpha + 分面承载更多序列）。别把探索硬压成"固定那几张图"——那会让分析千篇一律、缺少洞察。

## 一、什么数据 + 做什么分析 → 选什么图

选图的首要问题是「**我有什么数据、要用图表回答什么问题**」，而不是「图表长什么样」。先判定分析意图属于下列哪一（或哪几）类，再从该类里挑图，用 matplotlib/seaborn 自绘。

### 趋势类｜看数值随连续/有序维度（多为时间）的变化
- 数据特征：一个有序维度（时间/阶段）上的数值走向。
- 选图：**折线图**（多序列对比走向）、**面积图**（强调累积量/单序列）、堆叠面积图（各部分随时间的量）。
- 注意：横轴不等距须按真实数值定位；折线序列 ≤4 条，多了改小多图。

### 比较类｜比大小、排名
- 数据特征：若干分类项的数值对比。
- 选图：**柱状图/条形图**（类目 ≤ 约8 用柱、类目多或标签长用条形）、**分组柱**（多子类对比）、**发散条形**（带正负/盈亏/增减，居中于 0）、**雷达图**（同一对象多指标画像，3~8 维）、玫瑰图（周期性类目）。
- 注意：柱图 Y 轴必须从 0；排序后更易读（除非类目有固有顺序）；雷达图各维量纲差异大时先归一到同一量程。

### 占比类｜部分对整体的构成
- 数据特征：一个整体拆成几块，关注份额。
- 选图：**环形/饼图**（**类目 ≤5**）、**百分比堆积柱/条**（多个整体的构成对比）、**矩形树图**（层级 + 数值大小，类目多也不糊）、旭日图（层级占比，matplotlib Wedge）。
- 注意：类目 >5 一律弃饼改条形/堆积/树图；占比须同源、加总=100%。

### 分布类｜数据如何分布、离散、有无异常
- 数据特征：关注一个/两个变量的分布形态与离群。
- 选图：**直方图**（单变量频数分布，可叠核密度）、**箱线图**（分组比较离散与异常）、小提琴图（分布形状）、**散点图**（两变量相关）、**气泡图**（三变量：x/y+面积）、**热力图**（矩阵密度/相关系数）、散点矩阵 SPLOM（多变量两两相关，seaborn `pairplot`）。
- 注意：气泡用**面积**而非半径编码数值；散点别下因果结论；相关系数矩阵走双向发散色，系数标 2~3 位小数别显示成 0。

### 区间类｜数值的范围/上下限
- 数据特征：每个类目是一个区间而非单点（min–max、开高低收、起止时间）。
- 选图：蜡烛图/K 线（金融开高低收）、区间柱/条（带误差线/置信区间）、甘特图（任务起止）。
- 画法：matplotlib `errorbar`/`bar(bottom=)`/`barh`，K 线用 `mplfinance`。

### 流程类｜流转、转化、路径分解
- 数据特征：有先后阶段并逐级衰减，或从一个总量分流到多去向。
- 选图：**漏斗图**（转化各级留存，管道隐喻）、桑基图（多级流向/结构分解）。
- 画法：漏斗用居中条形；桑基数据合适时可退化为百分比堆积柱表达结构。

### 关联类｜实体之间的关系网
- 数据特征：节点 + 关系（边），关注连接结构。
- 选图：关系图/网络图（社交/依赖）、和弦图（两两流量）、韦恩图（集合交叠）。
- 画法：网络图用 `networkx`（环境已装）+ matplotlib。

### 时间类｜时间上的事件与密度
- 数据特征：带时间戳的事件序列或周期密度。
- 选图：**日历热力图**（按天密度，如打卡/交易/活跃）、时间轴（里程碑）、甘特图（排期）。
- 画法：日历热力图用 `pcolormesh`，时间轴/甘特用 `barh`。

### 地图类｜地理空间分布
- 数据特征：数据带地理位置（省市/经纬度）。
- 选图：区域填充图（choropleth，行政区着色）、点/气泡地图、热力地图、轨迹地图。
- 画法：依赖地图底图/GeoJSON（`geopandas`）；本 skill 默认不做地图，需要时明确告知用专门地图工具。

**一份数据常含多重意图**：电商转化分析既有「曝光→点击→加购→支付」的**流程**（漏斗），又有「新客 vs 老客」的**比较**（分组柱），还有「渠道构成」的**占比**（堆积柱）。意图不同就分别成图；但**同一意图内部**别拆成一堆小图——见下。

## 一之二、多张简单图 vs 一张高级图（决策树）

这是最容易做错的一步，两个方向的错都常见：

- **错误 A（最高频）**：该用一张信息密度高的高级图，却拆成一堆基础图。例：把「多阶段转化」画成 4 根孤立柱而不是一张漏斗；把「相关系数矩阵」画成十几张散点；把「一个人的六维能力」画成六张柱；**把「一个结局受哪些因素影响」（某评分 vs 性别/年龄/BMI/共病…）画成每个因素一张 2~5 根柱的柱图，而不是一张系数/效应量发散条形图**——这类单维柱图信息密度极低、彼此同质、还常与仪表盘/系数图重复，是"基础图过度、打扰用户"的典型。**注意区分**：把很多同类指标收敛到**一张**分面小多图做整体概览不是"过度"，而是正解；"过度"指的是把它们拆成十几张独立图散落穿插。
- **错误 B**：把量纲无关、受众看不懂的东西硬塞进一张图，读者反而更懵。

### 决策流程

1. **先列问题清单**：把"这批图要回答的问题"逐条写出来（如：整体趋势？各区域对比？构成占比？异常在哪？）。
2. **按意图归类**：不同意图（趋势/比较/占比/分布/流程…）本就该分开成图——这是错误 B 的边界。
3. **同一意图内，做"三问"决定要不要合并成一张高级图**：
   - **同度量？** 数据是同一量纲/单位、能进同一坐标轴？
   - **要对照？** 用户想"放一起看关系/对比/构成"，而非各看各？
   - **同框架？** 围绕同一对象的多个维度、或同一整体的多个部分？
   - 三问基本都「是」→ **合并成一张高级图**（信息密度更高，读者不必跨图切换）。
4. **合并前做"过载/门槛"复核**（错误 B 的闸门），任一命中就退回多图或先聚合：
   - 序列/类别 >6；量纲差异大且无法用双轴（指标 >2）；受众非专业且图型有认知门槛；合并后守不住硬规则（单锚点/诚实性/≤6 色）。

### "该合并成一张高级图"的高频映射

| 想同时表达 | ❌ 易犯：多张简单图 | ✅ 更优：一张高级图 |
|---|---|---|
| 多类别构成随时间 | 每类一张折线 | 堆叠面积 / 百分比堆叠柱 |
| 多变量两两相关 | 画 C(n,2) 张散点 | 相关性热力图 / 散点矩阵 SPLOM |
| 同一对象多维评分 | 每维一张柱 | 雷达图 |
| 多组分布对比 | 每组一张直方 | 箱线 / 小提琴 |
| 多阶段逐级流失 | 每步一根柱 / 一个数字 | 漏斗 |
| 层级 / 多类别占比 | 多张饼图 | 矩形树图 |
| 时段×类别强度 | 每行一张折线 | 热力图 |
| 绝对量 + 比率 | 柱图 + 另画折线 | 组合双轴 |
| 正负 / 盈亏 / 增减排名 | 普通柱 | 发散条形 |
| 三变量（x/y + 规模） | 两张散点 | 气泡图 |
| 全年按天节律 | 12 张月度柱 | 日历热力图 |
| **一个结局受多因素影响**（多个"因素 vs 同一指标"） | 每个因素一张 2~5 根柱 | 一张系数/效应量发散条形（方向+大小一图看全；带 CI 画 `errorbar` 森林图） |
| **很多同类指标做整体概览**（多变量分布 / 多分类构成） | 十几张独立图散落穿插 | 一张分面小多图（同一图型跨多变量、风格统一、可横向对比） |
| 经营总览多指标（异构指标讲一个故事） | 一堆零散图 | 复合仪表盘（见第八节） |

### "该保持多张简单图"的情形

- **量纲/尺度差太远**：营收（亿）和转化率（%）放一张会互相压扁——最多用组合双轴且指标 ≤2，再多就分图。
- **问题相互独立**：每张图回答不同问题、面向不同受众、或需贴各自数据表单独复用。
- **维度过载**：序列/类别 >6，一张必糊——先聚合"其他"或拆分。
- **受众有门槛**：SPLOM/桑基/雷达对非专业读者不友好时，降级为基础图 + 文字解释。

**一句话**：同一意图内先问"能不能一张讲清"，能就上高级图；被"过载/门槛"闸住才拆。既别习惯性堆多图（错误 A），也别硬塞一张（错误 B）。

## 二、视觉通道调度（编码优先级）

人眼对视觉通道的感知精度由高到低：

**1. 位置 > 2. 长度 > 3. 角度 > 4. 面积 > 5. 色相 > 6. 饱和度 > 7. 纹理**

- **黄金法则**：**关键指标必须用位置/长度编码**（柱高、点的位置）；辅助维度才用颜色/透明度（区分产品线）。
- **禁忌**：不要同时用色相 + 纹理区分同一批数据（认知过载）。
- **时序进阶**：趋势用「位置 + 方向」编码（斜率/箭头），波动幅度可用「面积 + 颜色」。

**落实**：关键量走柱高/点位，辅助序列走低饱和色板，不叠纹理。

## 三、信息密度与认知负荷分层

一张图要经得起三种阅读时长：

- **第一层（5 秒抓结论）**：一个明确的**视觉锚点**——最大/最小值、目标线、关键点标红标注。每张图必须有且只有一个主锚点。
- **第二层（15 秒懂趋势）**：主趋势/主结构清晰（曲线走向、结构占比）。
- **第三层（深入分析）**：细节。**Excel 图片图表是静态的**，细节不能靠悬停，改为：把明细数据表放在图旁边或同一 sheet，需要精确值时查表；标准差/区间等放单元格批注或副表。

## 五、原生图表 vs 图片：按"图表是否落进 xlsx"分流（重要）

先分清图表最终归属，再决定用原生还是 PNG（详见 `SKILL.md` 同名章节）：

- **A. 图表落进 xlsx 文件里 → 优先 Excel 原生**：openpyxl 原生图表（柱/条、折线、饼/环、散点、面积、气泡、雷达、K线）、条件格式（色阶=热力、data bar=数据条、图标集）、切片器 + 数据透视图。它们**可编辑、随源数据自动刷新、是真正的 Excel 对象**。**不要默认把 PNG 插进 xlsx。** 仅当原生图型不支持（漏斗/树图/旭日/瀑布/直方/箱线/桑基/网络/日历热力/地图等）或对精美度要求高时，才退回 matplotlib 出 PNG 嵌入（`openpyxl.drawing.image.Image`），并说明"更精美但静态不刷新"。
- **B. 图片独立于 xlsx → 用 PNG**：图文并茂分析作答、独立 PNG/仪表盘交付、报告配图等，用 matplotlib 出高清 PNG，追求精美，静态无妨。
- **交互（悬停/联动/钻取）在 PNG 里无法实现**：确实需要筛选/钻取/随数据刷新时，一律走 A 的原生能力；若用户要"改数据自动更新的图"，即使原本在 B 场景也转 A 并说明取舍。

## 六、视觉诚实性防御（发布前必查）

用数学约束保证图形不撒谎：

- **面积编码线性**：数值 2 倍 → 面积 2 倍（不是半径 2 倍导致面积 4 倍）。气泡图用面积不用半径映射。
- **横轴等距**：折线/时序的横轴时间间隔必须物理等距。2023→2024 的物理长度必须等于 2022→2023。缺失年份要留空位，不能挤掉。
- **不用 3D**：3D 柱/饼会因透视扭曲比例，一律禁用。
- **Y 轴基线**：柱状图 Y 轴**必须从 0 起**（截断基线会夸大差异）；折线图可不从 0，但要在副标题注明。
- **颜色梯度**：连续数据用单色渐变（顺序型），发散数据（有正负/中点）用双向发散色，不要用彩虹色（感知非线性）。

自绘时确保柱图 Y 轴含 0、横轴按真实值等距、不用 3D；**基线截断和面积映射尤其要自查**。

| 阶段 | 关键问题 |
|---|---|
| 数据准备 | 是否识别出所有潜在关系维度（数学/时空/对比/构成/分布/流程）？ |
| 图形选择 | 视觉通道分配是否符合感知优先级（关键量用位置/长度）？ |

| 交互设计 | 若做了交互，是否揭示了静态图给不了的信息，还是纯炫技？ |
| 可读性 | 标题、图例、坐标轴标签、单位是否齐全？中文是否正常无豆腐块？ |

## 八、复合仪表盘：一图呈现完整信息（按需使用）

当用户要"一张图看全局""汇报封面""数据大屏""整体概览"时，用**单图复合仪表盘**（matplotlib `GridSpec` 拼 KPI 卡片 + 多个子图）：在一张图内讲完整故事，且配色、字体、坐标风格全局统一。**这不是默认形态**——若用户只要普通几张图、或图要贴着各自数据表，用独立多图分别出。

设计要点：

- **信息分层落到布局**：顶部一行 KPI 卡片承载"5 秒结论"（核心数字 + 涨跌，涨绿跌红且带 ▲▼，不做反直觉）；主网格承载"15 秒趋势/结构"；细节仍放旁置数据表。
- **叙事顺序 = 阅读顺序**：从左上到右下按"总量 → 趋势 → 结构 → 对比/明细"排布，符合 Z 型视线。
- **全局一致性**：整张图共用一套色板/字体，不要每个子图各挑配色；字体同族同层级同字号。
- **克制面板数**：一张仪表盘 4~6 个面板为宜，超过则信息过载、单元过小；宁可拆两张主题仪表盘。
- **每个子图仍遵守前七节**：选图匹配关系、关键量用位置/长度、单一锚点、诚实性（Y 轴从 0、等距、无 3D）。

### 八之二、分面小多图：很多同类指标的整体概览

当"一组数据有很多同类指标"（多个连续变量的分布、多个分类变量的构成），要的是**整体概览**而非讲一个故事时，用**分面小多图**：同一种图型跨所有变量、逐格风格/坐标逻辑一致、可横向扫读对比，拼成**一张**高信息密度图。

- 与"基础图过度"的区别：小多图是**收敛到一张**的组合图（每格同型同风格），不是把十几张独立图散落穿插正文——后者才是打扰用户。
- 与复合仪表盘的区别：仪表盘是**异构面板 + KPI** 讲一个综合故事；小多图是**同型面板**做变量总览。指标同类、只求扫一眼分布/构成，用小多图；要突出核心数字与因果叙事，用仪表盘。
- 纪律：柱图格统一单色（不逐格标红成"彩虹"）；直方图格省略重复 y 轴标签、看形状即可；概览之后再对关键指标出 1~2 张聚焦图，别每格都追加细化图。

## 九、配色纪律

- **低饱和**：既要能区分对比，饱和度又不能太高刺眼。选一套低饱和色板（商务蓝 / 莫兰迪 / 科技深色等），不要自由发挥高饱和撞色。
- **颜色数 ≤ 6（交付默认）**：超过 6 类人眼难辨，合并小类为"其他"或改用可排序图表。**探索图例外**：平行坐标、KDE/直方叠加、SPLOM 等按变量上色是"变量身份"而非装饰，可用定性色板（tab10/Set2 等）+ alpha，此时颜色数可 >6。
- **一张图一个强调色（交付默认）**：锚点/关键值用强调色，其余用同色系深浅，避免**单序列**每根柱一个颜色的"彩虹图"（这类颜色不编码任何信息）。
- **无障碍**：避免纯红/绿相邻区分（色盲不友好），可辅以深浅或标注。
